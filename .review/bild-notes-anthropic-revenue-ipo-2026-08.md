# Bild notes: anthropic-revenue-ipo-2026-08

## Стратегия: primary-source (логотип компании)

Материал без человека-субъекта (выручка/run rate перед IPO) — handoff и reporter-notes
прямо указывают: "нет явного визуального субъекта", рекомендация — логотип/бренд Anthropic
или Claude.

## Что проверено и отклонено

1. **og:image страниц anthropic.com/news** (series-h, google-broadcom-partnership-compute) —
   `https://www.anthropic.com/api/opengraph-illustration?name=Object%20Growth&backgroundColor=coral`
   (1900×1000 PNG). Это шаблонный декоративный "doodle" движок Anthropic: у каждой статьи
   своё имя пресета (`Object Growth` для Series H, `Hand BarChart` для Series G) и ротация
   пастельного фона — по сути абстрактная "лестница роста" / рисованный бар-чарт без единой
   цифры. По духу совпадает с прямо забракованным в редполитике примером "стрелки вверх" /
   "столбики диаграмм" — отклонено, даже притом что это официальный ассет первоисточника.
2. Отдельного press kit / brand assets страницы на anthropic.com не нашлось (проверил
   /company — ссылок на медиа-кит нет).
3. Символ-марка (`apple-touch-icon.png`, favicon) — слишком маленькая (180×180), не тянет
   на самостоятельный кадр 1600×900.

## Источник картинки

- Взят инлайн-SVG wordmark "Anthropic" — тот же, что стоит в шапке официального сайта
  (`<svg aria-label="Anthropic">`, viewBox 0 0 570 64), путь извлечён напрямую из HTML
  `https://www.anthropic.com/news/series-h`.
- Цвета — реальные брендовые hex-значения со страницы anthropic.com (фон `#F4F4EB`,
  чернила логотипа `#141413`, акцентная полоса `#D47F2A` — их собственный "clay"-акцент,
  использован их же оттенок, а не бренд-палитра LEAP, т.к. это логотип другой компании).
- Собрано в SVG 2400×1350 (16:9), сконвертировано в PNG через cairosvg, затем JPG.
- Обработка: `python3 scripts/prepare-image.py`. Результат:
  ```json
  {
    "fit": {"mode": "cover", "scale": 0.6667, "cropLoss": 0.0, "upscaled": false},
    "output": {"width": 1600, "height": 900, "bytes": 35246, "quality": 90}
  }
  ```
  Обрезки нет (кадр уже был собран в пропорции 16:9), апскейла нет.

## Отклонённые варианты

- Templated og:image "Object Growth" (abstract doodle growth chart) — see выше.
- Templated og:image "Hand BarChart" (Series G) — тот же движок, тот же паттерн.
- Bloomberg — не источник изображений (P1 whitelist, но статьи 403 и всё равно
  paywalled/агентство, лицензия на фото не проверяема).
- Живого фото офиса/события/человека Anthropic для этой конкретной новости не искал —
  reporter/editor прямо исключили человека-субъекта (см. mainVisualSubject).

## Alt-текст

## Уверенность в подборе: 75%
Логотип — точная воспроизведённая копия официального wordmark с их собственного сайта
(не сток, не выдумка), нейтрален и однозначно указывает на субъект статьи. Не фотография,
поэтому не идеальный вариант по духу "живой фотографии", но для темы без человека-субъекта
и без единого пригодного фото в первоисточниках — это лучший вариант из доступных,
прямо согласуется с image-hint из handoff ("логотип/бренд Anthropic").
