# Fact-check: stripe-openrouter-7bn-deal-bloomberg

## Общий вердикт: APPROVE-WITH-DOWNGRADES

Материал хорошо атрибутирован: и заголовок, и лид явно приписывают факт сделки Bloomberg, а не выдают её за состоявшийся факт от лица Stripe/OpenRouter; второй абзац прямо фиксирует отсутствие официального подтверждения. Прямой перепроверкой SiliconANGLE и PYMNTS подтверждены почти все числовые данные из таблицы цитат (строки, где у репортёра были только пересказы WebFetch без дословных цитат). Есть три некритичных проблемы — все лечатся понижением формулировки, без повторной проверки.

## Проверка ключевых требований из задания

1. **Атрибуция везде, где факт не подтверждён официально** — соблюдено. Каждое ключевое утверждение сопровождается «сообщает Bloomberg» / «пишет PYMNTS» / «отмечает SiliconANGLE»; абзац 2 отдельно и заметно фиксирует, что ни Stripe, ни OpenRouter сделку не подтвердили, с цитатой представителя Stripe.
2. **Заголовок и лид не выдают сделку за свершившийся факт** — соблюдено. Заголовок заканчивается «— сообщает Bloomberg»; лид — «...сообщило агентство Bloomberg со ссылкой на источники, знакомые с делом».
3. **Суммы и детали (>$7 млрд, 400+ моделей от 60+ компаний, майская оценка $1,3 млрд)** — все подтверждены прямой перепроверкой первоисточников (см. таблицу ниже).
4. **Не менее двух источников, все citable** — три источника (Bloomberg, SiliconANGLE, PYMNTS), ни один не в чёрном списке §2.

## Список понижений для editor'а (применяет сам, без повторной проверки)

1. **Последний абзац**: «Bloomberg называет сделку одной из крупнейших ставок Stripe на искусственный интеллект.» → убрать предложение целиком, или заменить на констатацию без атрибуции конкретному изданию: «Это одна из крупнейших сделок Stripe в сфере ИИ за последний год» — на основе приведённых цифр.
2. **Абзац 3**: атрибуцию «по цене, скорости и качеству» сменить с SiliconANGLE на PYMNTS (или дать обоим изданиям без точной привязки).
3. **Лид** (27–28 слов, превышает лимит §9): разбить на два предложения — «Платёжный сервис Stripe договорился купить американский ИИ-стартап OpenRouter больше чем за $7 млрд. Об этом 16 августа сообщило агентство Bloomberg со ссылкой на источники, знакомые с делом.»
