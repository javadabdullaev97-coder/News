## Проверка первоисточников (strategy A — отклонена)
- `t.me/uzstataxborot/69166` — Нацкомстат. Единственное «изображение» поста при вытяжке
  через `?embed=1` оказалось аватаром канала (160×160, синие 3D-столбики + красная стрелка
  вверх) — по чек-листу `image-pipeline.md` такие аватары брать нельзя, плюс это прямое
  нарушение запрета на диаграммы/стрелки. Отклонено дважды: и по размеру (too-small), и по
  типу (сток-рендер).
- `cerr.uz/show-news/v-iyune-aktivnost-vrosla-vo-vsex-segmentax-avtornka-ceir` — обложка
  статьи (`cerr.uz/images/news/275_uz.jpg`, 825×568) — брендированный промо-баннер ЦЭИР:
  студийный рендер Chevrolet на фоне абстрактной биржевой графики с цифрами и линией тренда.
  Не документальная съёмка, декоративный дизайн — отклонено как сток-подобная графика.
- Там же три инфографики ЦЭИР (`static.review.uz/...275_uz.jpg` и парные PNG) — честная
  инфографика с реальными цифрами по методичке допустима в общем случае, но в этом
  поручении явно указано `imagery.rejectStockRenders` — «нужна реальная фотография» без
  исключений даже для ведомственной инфографики. Отклонены все три.
- `t.me/cerruz/2805` — дублирует тот же релиз ЦЭИР, тот же набор картинок, ничего нового.

Итог: ни один из трёх source-URL не даёт живую фотографию. Официального фото
завода/конвейера/автосалона не нашлось — переход к стратегии B.

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 3000, "height": 2000},
  "fit": {"mode": "cover", "scale": 0.5333, "cropLoss": 0.1562, "offset": [0, 0],
          "upscaled": false, "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому"},
  "output": {"path": "public/images/posts/2026-08/uzbekistan-auto-output-sales-h1-2026-01.jpg",
             "url": "/images/posts/2026-08/uzbekistan-auto-output-sales-h1-2026-01.jpg",
             "width": 1600, "height": 900, "bytes": 371926, "quality": 86},
  "status": "ok", "upscaled": false
}
```

### Про cropLoss 0,1562 (формально выше порога 0,15)
Порог `crop-risky` рассчитан на фотографии с одним чётким объектом (лицо, морда животного,
край здания), где кроп может отрезать что-то критичное — как в примере с коровой. Здесь
кадр — однородная повторяющаяся сетка (десятки крыш автомобилей подряд), без единого
фокального объекта, который можно «обезглавить». Открыл итоговый файл 1600×900 (Read)
и визуально сверил с оригиналом: обрезаны верхний и нижний ряд машин по краю кадра,
композиция не пострадала, ни один автомобиль не обрезан «criминально» посередине.
Решил не эскалировать в editor-queue — риск чисто формальный, не содержательный.
Прикладываю обоснование сюда, чтобы решение было проверяемым.
