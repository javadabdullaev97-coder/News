OpenAI on August 20 [launched](https://techcrunch.com/2026/08/20/chatgpt-can-now-send-texts-for-you-with-new-apple-messages-plugin/) a ChatGPT plugin that reads conversations and sends messages in Apple Messages — Apple's standard app for SMS, RCS and iMessage — at the user's request.

The plugin — an add-on module that expands ChatGPT's standard functions — can [read and search messages](https://techcrunch.com/2026/08/20/chatgpt-can-now-send-texts-for-you-with-new-apple-messages-plugin/) in a user's conversations, draft replies, send messages on the user's behalf and delete them. It runs in the ChatGPT desktop app for Mac and is available on all plans, including ChatGPT Work and Codex.

The feature requires a [Mac computer with Apple Silicon chips](https://9to5mac.com/2026/08/20/chatgpt-update-adds-apple-messages-integration-on-mac/) — Apple's current generation of in-house processors. The plugin does not work on Intel-powered Macs.

By default, ChatGPT sends a message only after the user approves the text and the list of recipients, [OpenAI's documentation says](https://help.openai.com/en/articles/9737562-how-your-data-is-handled-when-you-use-chatgpt-through-apples-integrations), as cited by TechCrunch and 9to5Mac. The same OpenAI documentation explains that the company does not recommend enabling standing permission to send messages without confirmation. In its wording, such a setting "removes the last chance to review a message before ChatGPT sends it on your behalf."

OpenAI [told Bloomberg](https://techcrunch.com/2026/08/20/chatgpt-can-now-send-texts-for-you-with-new-apple-messages-plugin/) that the plugin processes data locally on the user's device and does not create a combined index of the user's entire message history.
