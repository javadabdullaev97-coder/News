# Bild notes: cbu-microloan-debt-burden-risk

## Стратегия: primary-source

## Источник картинки
- URL: https://cbu.uz/upload/media/images/social.jpg
- Найдено через: og:image меты страницы пресс-релиза https://cbu.uz/en/press_center/releases/4124365/
  (сам пресс-релиз статей-специфичного изображения не содержит — только логотипы,
  соцсети и промо-баннер финграмотности; og:image страницы — общий имидж сайта,
  но это фото самого здания ЦБ, поэтому subject-first выполняется).
- Тип: официальное фото здания Центрального банка Узбекистана (фасад с характерными
  синими стеклянными лифтовыми шахтами) — используется самим ЦБ как соцсети-превью сайта.
- Размер оригинала: 1110×740 (landscape, AR 1.5) → cover, scale 1.4414 (умеренный
  апскейл, в пределах MAX_UPSCALE=2.5 текущей версии prepare-image.py), обрезано 15.6%
  по высоте → 1600×900 (235 347 байт, q90).

Полный JSON prepare-image.py:
```json
{
  "source": {"width": 1110, "height": 740, "path": "/tmp/cbu_social.jpg"},
  "fit": {
    "mode": "cover",
    "scale": 1.4414,
    "cropLoss": 0.1562,
    "offset": [0, 167],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.44× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/cbu-microloan-debt-burden-risk-01.jpg",
    "url": "/images/posts/2026-08/cbu-microloan-debt-burden-risk-01.jpg",
    "width": 1600, "height": 900, "bytes": 235347, "quality": 90
  },
  "status": "ok"
}
```

## Соответствие image-hint / image-avoid
- image-hint (handoff): «Здание Центрального банка Республики Узбекистан в Ташкенте» — выполнено буквально.
- image-avoid: стоковые «бизнесмены», графики без подписи, фото частных лиц — на фото нет
  людей и нет инфографики, только фасад здания.

## Отклонённые варианты
- HTML пресс-релиза cbu.uz (og:image страницы и содержимое) — отдельного фото к
  конкретному релизу нет, только логотипы/иконки/промо-баннер финграмотности —
  не годится (не по теме, часть — SVG-иконки).
- Telegram-канал ЦБ (t.me/centralbankuzbekistan) не проверялся отдельно: og:image
  сайта уже дал подходящее фото здания, дальнейший поиск не потребовался.

политике prepare-image.py (MAX_UPSCALE=2.5) это допустимо и визуально кадр
