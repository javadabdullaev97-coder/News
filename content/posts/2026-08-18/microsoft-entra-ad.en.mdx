Microsoft on August 13 published recommendations for businesses in its corporate blog, advising them to move from an on-premises Active Directory server to the cloud-based access management service Entra ID in order to reduce their dependence on it.

Active Directory is a Windows service where companies have stored employee accounts, passwords and access rights on their own servers for decades. Microsoft Entra ID is its cloud counterpart: access to corporate systems is managed over the internet, without an on-premises server at the company's location. The post's author, Jorge Lopez, senior product manager for Microsoft Entra, [explained](https://techcommunity.microsoft.com/blog/microsoft-entra-blog/why-active-directory-alone-is-no-longer-enough/4546402) why Active Directory alone may not be enough for businesses.

According to him, applications used by employees increasingly run in the cloud — Microsoft 365, Salesforce, ServiceNow, Workday. Corporate systems are also accessed by contractors, partners, suppliers and AI agents. According to the post, separate access rights for working with data and services are needed primarily by AI applications and agents.

## Five signs it's time to look to the cloud

The post lists five signals for an organization:

- the IT help desk spends more time maintaining the system than developing it;
- security rules depend on where the user is physically located;
- cloud applications have become the foundation of business operations;
- company systems are accessed not only by full-time employees but also by contractors, partners and AI agents;
- the company plans to deploy artificial intelligence tools.

Microsoft clarified that it is not calling for a complete abandonment of Active Directory. "The goal isn't necessarily to replace Active Directory, but to reduce reliance on it where cloud identity delivers a better outcome," the post says. According to the post, the on-premises server may continue to support certain legacy tasks. Entra ID, meanwhile, is becoming the primary platform for new scenarios — authentication, access control and AI agent operations.

A separate Microsoft Learn guide describes the transition as a five-stage process — from connecting cloud identity to an existing Active Directory to fully retiring the on-premises server. The [documentation](https://learn.microsoft.com/en-us/entra/architecture/road-to-the-cloud-introduction) was updated on July 31, 2026.
