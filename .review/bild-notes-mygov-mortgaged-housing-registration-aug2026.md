# Bild notes: mygov-mortgaged-housing-registration-aug2026

## Стратегия: stock

## Явного визуального субъекта нет
Материал — про изменение юридического порядка регистрации на портале
my.gov.uz, без конкретного человека/здания-героя. `mainVisualSubject` в
reporter-notes и editor-verdict отсутствует (файлы notes/verdict пустого
"визуального" поля не содержат). Следуя брифу задачи, порядок попыток:
скриншот/визуал интерфейса my.gov.uz → официальный логотип → нейтральный сток
жилого дома → AI-генерация.

## Отклонённые варианты (первоисточник)
1. **Telegram-пост my.gov.uz (t.me/MyGovUz/3951)** — фото 800×565 (взято из
   виджета `?embed=1`, других размеров публичный виджет не отдаёт). Это не
   фотография события, а декоративный маркетинговый коллаж: весы Фемиды
   (иконка), дом в цепи с навесным замком (иконка), стоковые фото семьи и
   ЖК, ноутбук со скриншотом портала внутри. По духу — тот же класс, что и
   запрещённые «3D-графики на клавиатуре»: собрано из стоковых элементов,
   не сообщает по сути ничего специфичного о конкретной новости. Отклонено
   как stock-render, несмотря на официальный источник.
2. **og:image сервисной страницы my.gov.uz/ru/service/363**
   (`my.gov.uz/__og-image__/image/ru/service/363/og.png`, 1200×600) —
   авто-генерируемая текстовая карточка (заголовок услуги, рейтинг 4.24,
   «7 минут», счётчик заявок). Не фотография и не скриншот интерфейса —
   плоский текстовый шаблон, реального визуала не несёт. Отклонено.
3. **og:image главной страницы my.gov.uz** (`__og-image__/image/uz/og.png`,
   1200×600) — тот же тип текстовой карточки, только для домена в целом.
   Отклонено по той же причине.
4. **Логотип портала** (`assets.my.gov.uz/assets/mygov/img/logo.svg`,
   186×48) — слишком мал (не пройдёт `too-small`), к тому же это лого, не
   самостоятельный кадр статьи. Отклонено.
5. **Реальный скриншот интерфейса my.gov.uz** — недоступен: в окружении нет
   headless-браузера/Playwright для рендеринга JS-страницы, снять
   «чистый» скриншот сервиса не удалось.

## Источник использованной картинки
- Тематический сток Unsplash (поиск "apartment building tashkent",
  landscape orientation): фото многоэтажного жилого дома с характерным
  узбекским геометрическим орнаментом на фасаде (бирюзовые декоративные
  панели) — типовая архитектура жилых кварталов Ташкента. Прямая связь с
  темой (регистрация по месту жительства / недвижимость), subject-first
  соблюдён в пределах доступного — жильё показано напрямую, не абстракция.
- URL оригинала: https://images.unsplash.com/photo-1727982786777-fe204dcac8bf
- Автор: Leonid Privalov (@lampovyj), Unsplash License (свободное
  использование с атрибуцией).
- Локация "Ташкент" в подписи Unsplash не подтверждена явно (страница не
  показывает location-тег) — поэтому alt-текст не утверждает город напрямую,
  описывает только то, что видно на кадре (архитектурный орнамент типичен
  для жилых домов Ташкента).

понадобилась, обрезка 15.6% — ниже порога crop-risky (0.25), здание в кадре
не срезано (проверено визуально после обработки).

## AI-генерация
Не потребовалась — тематический сток с реальной фотографией жилого дома
нашёлся и покрыл тему лучше абстрактной генерации. (Higgsfield-инструмент
в этой сессии также недоступен в наборе тулов bild-агента.)
