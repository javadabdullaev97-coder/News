## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 2400, "height": 1800},
  "fit": {
    "mode": "cover",
    "scale": 0.6667,
    "cropLoss": 0.25,
    "offset": [0, 237],
    "upscaled": false,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/world-paramount-warner-merger-collapse-01.jpg",
    "url": "/images/posts/2026-08/world-paramount-warner-merger-collapse-01.jpg",
    "width": 1600, "height": 900, "bytes": 385129, "quality": 86
  },
  "status": "ok",
  "upscaled": false
}
```
`cropLoss` вышел ровно на границе 0.25 (порог редполитики для ручной проверки —
"больше 0,25", не "равно"), поэтому editor-queue не потребовался. Дополнительно
проверил визуально готовый кадр 1600×900: вывеска «Paramount Pictures», арка и
фонтан остались полностью в кадре, обрезаны только верхушки пальм и внешние края
зданий по бокам — главный субъект не пострадал.
