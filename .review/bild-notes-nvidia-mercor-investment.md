## Ход подбора
1. Handoff (`image-hint`) дал чёткую инструкцию: нет единого события/человека,
   подходит нейтральный визуал — чип/дата-центр Nvidia, логотип, скриншот Mercor,
   либо фото Дженсена Хуанга, если есть в фотобанке. `NOTES_PATH` не открывал —
   в handoff всё было заполнено.
2. Фототека редакции (`config/stock-photos.json`) — темы `cbu/sum/inflation/...`
   к Nvidia/tech не относятся, пропустил (тема не входит в topicKeywords).
3. Первым делом проверил официальный источник: nvidianews.nvidia.com (bios,
   press kit). Нашёл официальный портрет Дженсена Хуанга (1920×1920,
   `iprsoftwaremedia.com`, хостинг пресс-материалов Nvidia) — но smart-crop
   при вписывании в 16:9 из квадрата (44% обрезки по высоте) срезал лицо по
   переносицу, оставив только подбородок и куртку — визуально нечитаемо,
   не публикую (см. «Отклонённые варианты»).
4. Взял вместо этого продуктовое фото из того же официального press kit —
   стойка Nvidia Blackwell Ultra (AI-инфраструктура), уже почти 16:9 в
   исходнике, кроп почти нулевой. Прямо иллюстрирует «чип/дата-центр Nvidia»
   из image-hint, без риска deepfake/подмены лица и без стоковых «бизнесменов».
   Rule №2 (только живая фотография): это официальная студийная фотография
   реального физического продукта Nvidia, а не рисованная стоковая 3D-заготовка
   («бизнес-концепция», диаграмма) — принято как содержательный визуал по
   аналогии с «инфографика ведомства».

## Отклонённые варианты
- Официальный портрет Дженсена Хуанга (nvidianews.nvidia.com/bios, 1920×1920) —
  после cover-кропа до 16:9 лицо срезано почти полностью (видны только
  подбородок/куртка), нечитаемо как портрет — отклонено по качеству кадра,
  не по правам.
- Логотип Nvidia / скриншот сайта Mercor — не проверял: продуктовое фото из
  официального press kit оказалось под рукой сразу и лучше передаёт тему
  «Nvidia + ИИ-инфраструктура», чем плоский логотип.
