## Шаг A — первоисточники проверены, не подошли
Оба поста Telegram-канала @mehnatvazirligi (единственные первоисточники статьи) содержат
приложенные изображения, но это не фото, а карточки-иллюстрации формата «SAVOL/JAVOB»:

- https://t.me/mehnatvazirligi/20209 — карточка 800×800: мультяшный офисный работник со спины
  чешет затылок, штамп «ISHGA KIRITILGAN», 4 плоские векторные иконки (нумерованный список).
- https://t.me/mehnatvazirligi/20187 — карточка 800×800: заголовок «BIR SAVOLGA — BIR JAVOB»,
  клипборд с документом, штамп «NOQONUNIY RASMIYLASHTIRILGAN», иконка трудовой книжки,
  плоские векторные иконки-стрелки (инспектор → заключение → удаление из системы).

Обе карточки — типовые декоративные плоские иллюстрации/клипарт (мультяшный человек, generic
иконки), без содержательных данных (не статистика, не инфографика с цифрами). Это ровно тот тип
«дешёвой заготовки», который редполитика запрещает даже из первоисточника (аналог примера с
3D-столбиками ВВП из CORE.md/newsroom-policy.json → `rejectStockRenders`). Отклонены.

Отдельно проверил: WebFetch на `?embed=1` изначально по ошибке вернул только аватар канала
(160×160, статичный для обоих постов) — перепроверил прямым curl HTML `?embed=1` и нашёл
реальные `tgme_widget_message_photo_wrap` карточки (800×800, см. выше) — они и есть приложенные
изображения постов, не просто аватар.

Третий источник (lex.uz, текст постановления КМ №971) — страница нормативного акта, фото/медиа
не содержит и не проверялась на этот счёт (не тот тип страницы).

Официальный сайт mehnat.uz редиректит на gov.uz/oz/bv — там нет реальной фотографии здания
министерства, только шаблонная иконка портала `building.fb8e2de2.png` (общий для всех ведомств
gov.uz элемент интерфейса, не фотография конкретного здания). Не используется — это не
документальный кадр субъекта, а UI-иконка портала.

## Отклонённые варианты
- Карточка-иллюстрация из https://t.me/mehnatvazirligi/20209 — decorative флэт-вектор клипарт
  (мультяшный человек + generic иконки), запрещённый тип «сток-заготовки».
- Карточка-иллюстрация из https://t.me/mehnatvazirligi/20187 — то же самое.
- gov.uz/oz/bv building-иконка — не фотография, шаблонный UI-элемент портала, общий для всех
  ведомств, не специфичен для Минзанятости.
- Unsplash `premium_photo-1661313626999...` (папки/степлер) — Getty/Unsplash+ платная лицензия,
  пропущен по правилу «не тащим Getty».
- Pexels `macbook-pro-on-brown-wooden-table-110644` (ноутбук + чистый лист на столе) —
  рассматривался как альтернатива; отклонён в пользу более тематически точного варианта
  (печати/бланки прямо иллюстрируют «фиктивную запись», а не абстрактный «ноутбук на столе»).
- ID-документы (UK driving license, US passport) — страново нерелевантны Узбекистану, могли
  ввести читателя в заблуждение, пропущены.
- Higgsfield AI-генерация — недоступна технически в этом тулсете (см. выше).
