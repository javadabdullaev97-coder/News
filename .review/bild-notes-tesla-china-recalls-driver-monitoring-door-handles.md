# Bild notes: tesla-china-recalls-driver-monitoring-door-handles

## Стратегия: stock

## Ход поиска
1. **Первоисточник SAMR** — прямая страница уведомления по этому (второму) отзыву
   не найдена ни репортёром, ни повторно бильдом (см. reporter-notes: три
   целевых попытки вернули 503/недоступность). Изображений с сайта SAMR нет.
2. **mydrivers.com** (один из sources) — открыл статью через WebFetch, вытащил
   два встроенных изображения:
   - `img1.mydrivers.com/.../d13bb885...png` — скриншот текста официального
     уведомления SAMR (перепечатка пресс-релиза о ДВУХ отзывах разом — и по
     ручкам, и по мониторингу внимания). Это текстовый скриншот, не живое
     фото салона/камеры — не подходит под image-hint и по типу ближе к
     «скриншот», не даёт визуального субъекта. Отклонено.
   - `img1.mydrivers.com/.../890586f5...jpg` — живое фото белой Tesla Model 3
     в движении по дороге (экстерьер, 3:2). Хорошего качества, явно тот же
     модельный ряд, но не показывает салон/камеру/руль — слабее совпадение
     с image-hint, чем салонные кадры ниже. Оставлено как запасной вариант,
     не выбрано.
3. **nbd.com.cn** — единственное изображение статьи это скриншот с сайта
   регулятора (текст уведомления), не визуальный субъект. Отклонено.
4. **Фототека редакции** (`config/stock-photos.json`) — не проверял: темы
   фототеки (cbu/sum/fx/inflation/banking/payments) не пересекаются
   с автомобильной темой.
5. **Unsplash** — целевой поиск "tesla steering wheel" (по альтернативе из
   image-hint: «салон Tesla с рулевым колесом крупным планом», так как
   отдельного кадра именно камеры у зеркала не нашлось):
   - `photo-1698653222638-026473b1a375` (Mateusz Zatorski, @knowbody) —
     **выбрано**. Руль Tesla Model 3 крупным планом, виден рычаг
     переключения режимов P/R/N/D на рулевой колонке — узнаваемый салонный
     элемент именно той модели, что попадает под отзыв. Горизонтальная
     ориентация (1600×1067), метаданные автора включают теги "tesla",
     "tesla model 3". Unsplash License.
   - `photo-1700411881934-3c30715decfd` (Bram Van Oost) — тоже руль/рычаг
     Tesla Model 3 Highland, но вертикальная ориентация (1600×2400) —
     не годится для горизонтального кадра статьи, отклонено.
   - Отдельный поиск "tesla rearview mirror" / камера мониторинга у зеркала —
     релевантного кадра с самим модулем камеры не нашлось (WebFetch не смог
     идентифицировать нужную деталь по превью-описаниям).

и на Unsplash не нашлось.
