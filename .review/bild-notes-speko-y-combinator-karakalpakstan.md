## Почему выбрано именно это изображение
- На карточке YC (https://www.ycombinator.com/companies/speko) нашёл несколько кандидатов:
  1. og:image страницы — логотип Speko (bookface-images/logos/...) — рассмотрен, но это просто
     квадратный логотип, плохо смотрится в формате 1200×630 без явного контента.
  2. Аватар основателя (bookface-images/avatars/...) — отклонён по ограничению задания:
     фото человека, публиковать нельзя даже при наличии в официальной карточке YC —
     инструкция явно просила избегать риска и по умолчанию не брать, если есть альтернатива
     без человека. Альтернатива нашлась.
  3. **Launch-post изображение (id 108267)** — собственная инфографика Speko «One endpoint,
     one key → 1. Stack routing → 2. Failover», без людей, без логотипа YC, только бренд
     Speko. Прямо иллюстрирует «маршрутизатор голосовых AI-моделей» — тему статьи. Выбрано.
