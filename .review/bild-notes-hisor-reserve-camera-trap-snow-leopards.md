# Bild notes: hisor-reserve-camera-trap-snow-leopards

## Стратегия: primary-source

## mainVisualSubject (из задания)
Снежный барс на фоне горного ландшафта, в идеале кадр из t.me/ecogovuz/49462.
Fallback-порядок предложен: пейзаж Гиссарского хребта / архивное фото барса.

## Что делал
1. Открыл `https://t.me/ecogovuz/49462?embed=1` через WebFetch — пост оказался
   видео (не фотопост). og:image в HTML — превью-кадр видео 320×180 (проверено
   `file`: JPEG 320x180) — ниже `MIN_SOURCE=600` в `prepare-image.py`,
   для главной не годится. Второй `cdn4.telesco.pe` URL в HTML — аватар
   канала 160×160 (по документации image-pipeline.md — его не берём).
2. Прямая страница `https://t.me/ecogovuz/49462` (без `?embed=1`) отдаёт тот же
   320×180 og:image — тупик, других изображений в HTML нет.
3. Скачал сам видеофайл поста (`c6f77612d9.mp4`, 1280×720, 19 секунд,
   H.264). Установил `imageio-ffmpeg` (статический ffmpeg-бинарник) и Pillow
   через pip — на раннере их не было. Разложил видео на кадры (`fps=1`,
   затем точечно `fps=5` в диапазоне 10–14 с).
4. Осмотрел все 19 кадров с шагом в секунду:
   - Кадры 1–10 (дневная съёмка, ~0–9 с): чёткий, хорошо освещённый
     сибирский горный козёл (второй субъект из заголовка/лида статьи) —
     крупные рога, каменистый склон, зелёные пятна травы.
   - Кадры 11–18 (ночная ИК-съёмка, ~10–17 с): практически чёрный кадр,
     единственный различимый элемент — одна светящаяся точка (отражение
     глаза в ИК-подсветке). Это, судя по всему, и есть снежный барс
     («группа, двигавшаяся» — упомянута в посте), но кадр физически
     не показывает животное: ни силуэта, ни очертаний тела, только
     точка-блик размером в несколько пикселей. Такой кадр не даёт
     subject-first депикции — читатель не поймёт, что на фото барс, а не
     шум. Проверил доп. кадры каждые 0,2 с в этом диапазоне (`fps=5`,
     20 кадров) — светимость точки не меняется, силуэт зверя нигде
     не проявляется чётче.
   - Кадр 19: чёрный экран с логотипом ведомства (аутро) — не годится.
5. Вывод: пригодного к публикации кадра именно со снежным барсом в этом
   видео нет — только шумный ИК-блик. Кадр с горным козлом — законный
   первый приоритет: реальная документальная съёмка с фотоловушки, из
   того же самого первоисточника (`t.me/ecogovuz/49462`), тот же участок
   заповедника, тот же материал (горный козёл — второй субъект в
   заголовке и лиде статьи, не посторонний объект). Это явно предпочтительнее
   генерации через Higgsfield, которая по правилам — последний fallback,
   когда нет уместного стока/фото; здесь официальное фото есть.
6. Взял кадр `frame_001.jpg` (~0.5 c от начала) — самый чёткий, голова
   и рога в фокусе, животное не обрезано по краям кадра.
7. Прогнал через `scripts/prepare-image.py`:

```json
{
  "source": {"width": 1280, "height": 720},
  "fit": {
    "mode": "cover",
    "scale": 1.25,
    "cropLoss": 0.0,
    "offset": [0, 0],
    "upscaled": true,
    "note": "обрезано 0% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.25× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/hisor-reserve-camera-trap-snow-leopards-01.jpg",
    "url": "/images/posts/2026-08/hisor-reserve-camera-trap-snow-leopards-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 314484,
    "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

Источник — уже готовые 16:9 (1280×720, кадр видео), поэтому `cropLoss: 0.0`
и `crop-risky` не применяется. Апскейл 1.25× — в пределах `MAX_UPSCALE=2.5`,
качество на выходе сохранилось (обычная YouTube-подобная резкость видео,
не мыло).

## Отклонённые варианты
- og:image превью-поста (320×180) — `too-small`, ниже `MIN_SOURCE=600`.
- аватар канала `@ecogovuz` (160×160) — по инструкции image-pipeline.md
  не берётся никогда (это второй cdn-URL в embed-HTML).
- ИК-кадры со снежным барсом (10–17 с видео) — единственный видимый
  элемент это блик от глаза размером в несколько пикселей на чёрном фоне,
  не депикция животного; в главную не годится (не subject-first,
  фактически неотличимо от шума).
- Higgsfield-генерация — не понадобилась: primary-source сработал.

## Уверенность в подборе: 80%
Снижено с обычных ~90%+ из-за одного нюанса: на фото сам снежный барс
(главный субъект заголовка) не изображён — только горный козёл, второй
субъект того же материала, снятый тем же способом на том же участке в
том же видео. Это ближе к «прямая депикция реального со-субъекта
материала из первоисточника», чем к абстрактному пейзажу или стоку, но
не идеальное 1:1 совпадение с `mainVisualSubject`. Технической причины
спрашивать владельца нет (`crop-risky`/`no-image`/`stock-render` не
применимы, `source-doubt` тоже — источник и права очевидны), поэтому
публикую без похода в очередь.
