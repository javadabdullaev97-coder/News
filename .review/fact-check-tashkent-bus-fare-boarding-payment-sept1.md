## Список понижений для editor'а (применяет сам, без повторной проверки)

1. Заголовок: «Кабмин обязал пассажиров автобусов Ташкента платить при посадке с 1 сентября» → «Кабмин обязал платить при посадке в городских автобусах на валовом контракте с 1 сентября» (постановление формально не называет Ташкент).
2. Лид: «...пассажиры автобусов Ташкента, работающих по системе валового контракта, обязаны...» → «...пассажиры городских автобусов, работающих по системе валового контракта — такая схема сейчас действует в Ташкенте, — обязаны...».
3. «...разработать проект закона об усилении...» → «...разработать проект нормативно-правового акта об усилении...».
4. Первое упоминание «МВД»: «...совместно с МВД...» → «...совместно с Министерством внутренних дел (МВД)...».
5. Первое упоминание «Минтранс»: «По этой статье Минтранс...» → «По этой статье Министерство транспорта (Минтранс)...».
