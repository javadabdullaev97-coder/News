# Reporter notes: uzbekistan-business-loan-rate-3yr-low

## Тема
ЦБ РУз: средневзвешенная ставка по сумовым кредитам в июне снизилась до 21,6% годовых, для
бизнеса — до 21,8% (минимум с октября 2023). Данные разошлись через Gazeta.uz 6 августа.

## Первоисточники — ВАЖНАЯ ОГОВОРКА
- cbu.uz/ru/statistics/dks/4248563/ (кредиты в нацвалюте) и .../dks/4248572/ (в инвалюте) —
  именно те URL, на которые ссылалась Gazeta.uz. Подтвердил: страницы существуют, хостят
  Excel-файл Protsentnye-stavki-po-kreditam-v-natsionalnoy-valyute-06.2026.xlsx (89,3 КБ),
  с меткой обновления 6 августа 2026, 17:32 — файл официальный, за июнь 2026.
- НЕ СМОГ прочитать содержимое xlsx. Read выдаёт ошибку "cannot read binary files", WebFetch
  на извлечении текста возвращает нечитаемый XML/бинарные потоки. Искал альтернативную
  PDF-инфографику ЦБ по кредитам (по аналогии с "Bank depozitlari" для вкладов) — не нашёл ни
  на сайте, ни в Telegram-канале @centralbankuzbekistan за начало августа.
- Все конкретные цифры (21,6%, 21,8%, разбивка по срокам/категориям) взяты из вторичного
  анализа Gazeta.uz. Топ-линия (21,6% / 21,8% / -0,4 п.п. за месяц / -1,4 п.п. за год) совпала
  в 3 независимых попытках извлечения. Разбивка по срокам (26,2% короткие потребкредиты vs
  21,3% длинные/ипотечные физлицам; 21,3%/22,2% для бизнеса) — только из одной попытки,
  внутренне непротиворечива, но без второй независимой проверки.
- Депозитный контекст (17,6% / 19,2% / 15,3%) — проверен на 100%, читал напрямую официальную
  PDF-инфографику ЦБ "Bank depozitlari, Iyun 2026" (cbu.uz/upload/medialibrary/342/.../depozit_uz.pdf) —
  тот же файл, что уже был источником статьи LEAP от 5 августа.

## Про дублирование с депозитной темой (важно для editor)
Третий пункт кластера (вклады, t.me/gazetauz/63382) — это те же данные ЦБ за июнь, которые
LEAP уже опубликовал 5 августа (content/posts/2026-08-05/cb-sum-deposit-yield-rise.mdx),
тот же PDF, тот же период, идентичные цифры. Новой информации за сутки не появилось — Gazeta
просто опубликовала материал на день позже. Решение: отдельную статью-дубль не писал, вклады
вошли контекстным блоком в статью про кредиты со ссылкой на вчерашний текст LEAP.

## Пропуски и слабые места (приоритетно для fact-checker'а)
Главный риск: цифры 21,6% / 21,8% и разбивка по срокам не подтверждены напрямую из xlsx ЦБ —
только через P0 Telegram-сигнал, как разрешено инструкцией при недоступности первоисточника.
Если у fact-checker'а есть инструмент для чтения .xlsx (Excel/LibreOffice/pandas) — стоит
скачать файл с cbu.uz/ru/statistics/dks/4248563/ и сверить цифры перед публикацией. Ставка по
валютным кредитам (10,3%) — подтверждена слабее всего, помечена в тексте как "около".

## Уверенность в статье: 62%
Топ-линия подтверждена несколькими независимыми извлечениями и внутренне логична, но ни разу
не сверена напрямую с сырыми данными ЦБ — только с пересказом Gazeta.uz. Депозитный контекст
проверен на 100%. Рекомендую fact-checker'у попытаться открыть xlsx перед публикацией.

## Примечание для fact-checker'а (от планёрки)
Приоритет: попробуйте скачать xlsx с cbu.uz напрямую (curl/wget + любой парсер, если доступен)
и сверить 21,6%/21,8% и разбивку по срокам. Если не получится прочитать xlsx техническими
средствами — решите, тянет ли материал на approve-with-downgrades (понизить точность
формулировок разбивки по срокам до "по данным Gazeta.uz со ссылкой на ЦБ") или на reject.
