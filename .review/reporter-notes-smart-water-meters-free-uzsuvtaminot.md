# Reporter notes: smart-water-meters-free-uzsuvtaminot

**Тема:** АО «Ўзсувтаъминот» 9 августа опубликовало в Telegram-канале, в рубрике #Mutaxassis_minbari, короткое видео (0:16) с вопросом: бесплатны ли «умные» счётчики воды для потребителей, заключающих новый договор.

**Первоисточники, проверенные:**
- t.me/uzsuv/45491 — сам пост. Это видео; подпись содержит ТОЛЬКО заголовок-вопрос и хэштег, без текстового ответа. Транскрибировать видео по URL инструментами из набора не удалось (проверено многократно). Соседний пост того же канала (t.me/uzsuv/45497) текстовую подпись отдаёт нормально — ограничение специфично для конкретно этого видео-поста.
- lex.uz — ПП-257 от 24.05.2022 (https://lex.uz/ru/docs/6033210) — прочитан полностью. Пункт 4 — ключевой источник фактов: 4"а" (замена просроченных счётчиков населению бесплатна с 01.01.2023), 4"б" (новые объекты «под ключ» — счётчик уже установлен, житель только подписывает договор и пломбирует), 4"в" (юрлица/ИП ставят современные счётчики за свой счёт с 01.01.2023, с налоговой льготой до 4× БРВ; с 01.01.2024 без счётчика — тариф как для неучтённых).
- my.gov.uz/ru/service/224 — госуслуга «установка/снятие/опломбирование счётчика холодной воды», статус «Стоимость услуги: Бесплатно».
- lex.uz — ПП-343 от 24.10.2023 (https://lex.uz/docs/6648585) — п. 9"ж": с 01.04.2024 цифровые решения учёта воды обязательны во всех новых проектах.

**Расхождения с inbox-снипетом:** нет, заголовок процитирован точно.

**Main visual subject:** установка/опломбирование «умного» счётчика холодной воды специалистом «Ўзсувтаъминот» (крупный план цифрового счётчика с радиомодулем); запасной вариант — офис/логотип компании.

**Что не вошло:** точный текст ответа компании в видео 45491 (не извлекается); соседний пост того же канала (45497, про запрет наличных для контролёров) покрыт отдельным черновиком uzsuvtaminot-no-cash-controllers.mdx, не дублировал.

**Слабые места:** статья отвечает на вопрос поста по независимо проверенным нормативным актам, а не цитирует ответ самой компании (его физически нет в тексте сообщения — только в непрочитанном видео). Последний абзац статьи содержит экстраполяцию (что бесплатная госуслуга my.gov.uz распространяется и на подключение к уже существующей сети, не только к новым объектам «под ключ») — в ПП-257 это прямо не расписано для этого сценария, fact-checker должен явно решить, ужесточить ли формулировку. Контакты горячей линии не включены — не подтверждены.

**Уверенность: 65%.** Ядро (кто платит за счётчик) прочно опирается на два президентских постановления и госуслугу my.gov.uz. Слабое место — сам инфоповод: содержание видео-ответа компании не подтверждено напрямую.
