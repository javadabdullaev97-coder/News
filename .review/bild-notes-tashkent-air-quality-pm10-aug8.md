# Bild notes: tashkent-air-quality-pm10-aug8

## Стратегия: stock (переиспользование провалидированного кадра, консистентность серии)

## Ход подбора
`mainVisualSubject` от reporter: явного портретного субъекта нет — «вид Ташкента
с дымкой/смогом — для консистентности с предыдущими двумя материалами серии».
Задание планёрки прямо просило сохранить визуальную консистентность серии
(4-й материал в кластере «качество воздуха в Ташкенте», после
`tashkent-vozduh-zagryaznenie-avgust`, `tashkent-air-quality-aug6-uzgidromet`,
`tashkent-air-quality-pm10-aug7-morning`), допуская новый ракурс/дату, но не
требуя его.

### Шаг A — первоисточник
Проверил `t.me/uzgydromet/21915` (сводка на 9:00 8 августа, основной источник
статьи) через `?embed=1`. Вложенное фото — снова квадратная карта мониторинга
станций, 756×720 (соотношение ≈1.05), тот же формат, что в постах
21893/21898/21903 из предыдущих трёх материалов кластера: зелёные/жёлтые
маркеры по районам, логотип O'ZGIDROMET, без читаемого текста в кадре 16:9.
Заливка 16:9 потребовала бы ~40% обрезки по высоте → автопереключение на
`contain` с подложкой. По правилу владельца от 04.08.2026 («подложка — красный
флаг, если есть горизонтальная альтернатива») и по прямому трёхкратному
прецеденту в этом же кластере — отклонил без прогона `prepare-image.py` на
этой ориентации.

### Шаг B — поиск нового горизонтального фото (не обязательно того же файла)
Прежде чем переиспользовать кадр Александра Зыкова в третий раз, проверил
свежие источники:
- Openverse (`license_type=commercial&orientation=landscape`), запросы:
  «Tashkent smog», «Tashkent haze», «Tashkent air pollution», «Tashkent dust»,
  «Tashkent skyline haze». Единственные тематически точные результаты
  («Smog at U tower, Tashkent», «Smog at square of Friendship of Nations,
  Tashkent», 4000×3000 и 3000×4000) — оба хостятся на `upload.wikimedia.org`,
  запрещённый источник по редполитике («не бери с wikipedia.org»). Не
  использовал ни один. Остальные запросы — 0 результатов, новых кадров с
  апреля (последняя проверка в материале от 7 августа) не появилось.
- Unsplash API (`api.unsplash.com/search/photos`) — `401 OAuth error: invalid
  access token`, как и в предыдущих материалах кластера. Недоступен из
  окружения.
- Pexels API (`api.pexels.com/v1/search`) — `401 Missing API key`. Недоступен.
- AI-генерация (Higgsfield) — инструмент генерации не выдан агенту в этой
  сессии (не входит в список доступных инструментов), недоступен как fallback.
- Полный Flickr-фотопоток Александра Зыкова по Ташкенту уже просмотрен в
  прошлом материале (7 августа) — 22 из 23 кадров сняты под ясным небом без
  дымки, повторный обход не дал бы новых результатов.

Новой горизонтальной живой фотографии смога/дымки над Ташкентом в разрешённых
источниках снова не нашлось.

### Решение
Переиспользовал уже трижды провалидированный кадр (тот же, что в двух
предыдущих статьях серии): фотосерия Александра Зыкова (Flickr, CC BY-SA 2.0),
аэросъёмка Ташкента с широким проспектом, парком и застройкой, серовато-сизая
дымка на горизонте — тематически соответствует «вид Ташкента с дымкой/смогом»,
горизонтальная ориентация, лицензия открыта, коммерческое использование
разрешено. Прогнал заново через `prepare-image.py` с новым slug'ом — вывод
идентичен предыдущим двум по сути (тот же исходник, тот же crop), файл
физически новый по пути. Обеспечивает визуальную консистентность 4-го
материала серии, как и просило задание.
