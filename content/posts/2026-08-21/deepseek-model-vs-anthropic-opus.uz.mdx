DeepSeek 21 avgustda tasvirlarni aniqlay oladigan DeepSeek-V4-Flash-Vision-Exp sun'iy intellekt tajriba modelini taqdim etdi, [Bloomberg xabar berishicha](https://www.bloomberg.com/news/articles/2026-08-21/deepseek-unveils-test-model-to-rival-anthropic-s-opus-4-8). Kompaniya vizual kirish ma'lumotli agent vazifalarida yangi model Anthropic ishlab chiqargan Opus 4.8'ga yaqinlashayotganini ma'lum qildi.

Yangi model — matnli DeepSeek-V4-Flash modelining tajriba versiyasi. Unga vizual so'rovlarni qo'llab-quvvatlash qo'shilgan: model nafaqat matnni, balki tasvirlar va skrinshotlarni ham tahlil qila oladi.

21 avgustdagi [DeepSeek yangilanishlar jurnali](https://api-docs.deepseek.com/updates/) ma'lumotlariga ko'ra, yangi model matnli vazifalarda asosiy DeepSeek-V4-Flash bilan bir xil natijalarni ko'rsatadi. Bu agentlar bilan ishlash, mulohaza yuritish va bilimlar bilan ishlashga tegishli. Tasvirlarni aniqlashni talab qiladigan benchmarklarda, DeepSeek ma'lumotlariga ko'ra, model V4-Flash'ga nisbatan sezilarli o'sish ko'rsatdi. Uning vizual kirish ma'lumotli agent vazifalaridagi ko'rsatkichlari Opus 4.8 darajasiga yaqinlashdi.

Kompaniya o'z test natijalarini keltirdi: Terminal-Bench 2.1'da 83,9 ball, NL2Repo'da 57,7, DeepSWE'da 59,3, DSBench-Hard'da 63,6 va Chartography'da 64,3 ball. Nashr etilgan paytda bu raqamlarning mustaqil tashkilotlar tomonidan tekshiruvi yo'q.

Model DeepSeek API orqali `deepseek-v4-flash-vision-exp` nomi bilan mavjud. Kompaniya uni tajriba modeli sifatida belgiladi — ya'ni yakuniy relizgacha imkoniyatlar va baholar o'zgarishi mumkin.
