## Первоисточник — почему не подошёл
- URL поста: https://t.me/ToshkentFVBB/18214 (пост Toshkent shahar FVBB, 5 августа, 15:02).
- В посте есть видео (0:55) — сотрудник УЧС стоит на территории рынка «Куйлюк», за спиной видны
  торговые ряды. Это ИДЕАЛЬНО совпадает с mainVisualSubject.
- Проблема: публичный видео-превью (video_thumb) отдаётся Telegram только в разрешении
  **320×178px** — подтверждено загрузкой файла напрямую
  (`https://cdn4.telesco.pe/file/j9mns7cvzWU0...jpg`, 17 503 байт, 320×178). Проверил и через
  `t.me/s/...`, и через `?embed=1` — оба раза отдаётся один и тот же маленький файл. Bot API для
  получения оригинала видео недоступен в рамках задачи.
- Порог `prepare-image.py`: минимум 600px по длинной стороне. 320px < 600px →
  скрипт вернул бы `status: too-small`. Публиковать это фото нельзя технически, не по вкусу.
- gov.uz/oz/fvv-toshkent (новостной раздел ведомства) — SPA на React/Mantine, статический HTML
  не содержит текста новостей (проверено curl), упоминаний «Qo'yliq»/«Куйлюк» не нашёл.
- Instagram @toshkentfvbb — недоступен для скрейпинга (HTTP 429 при прямом запросе).
