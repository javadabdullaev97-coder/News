## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 3000, "height": 2000, "path": "/tmp/original.jpg"},
  "fit": {
    "mode": "cover",
    "scale": 0.5333,
    "cropLoss": 0.1562,
    "offset": [0, 90],
    "upscaled": false,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/gold-forex-reserves-july2026-01.jpg",
    "url": "/images/posts/2026-08/gold-forex-reserves-july2026-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 389746,
    "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```
cropLoss 15.6% — ниже порога 25% для `crop-risky`, режим cover без апскейла.
Кадр — плотный повторяющийся узор слитков без единого хрупкого объекта
(лицо/животное), обрезка сверху/снизу не теряет смысл — вопрос владельцу не
нужен. Визуально проверил итоговый JPEG: клеймо «GOLD» и «NET WT 200g»
остались полностью в кадре.

## Отклонённые варианты
- Здание ЦБ РУз — не нашлось фото ни на статистической странице, ни на
  главной, ни в разделах gallery/about (404 и логотипы соответственно).

  (случайные административные здания без привязки к Узбекистану), не
  subject-specific, отклонены в пользу более точного по теме золота стока.
- Andrej Sachov «gold bars» — похоже на 3D-рендер (см. выше), отклонён по
  правилу «живая фотография, не заготовка».
- AI-генерация (Higgsfield) — не понадобилась: нашёлся живой свободный сток
  по прямой теме статьи (золото — 87% резервов).
