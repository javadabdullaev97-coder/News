# Bild notes: anthropic-claude-text-watermark-eu

## Стратегия: primary-source

## Источник картинки
- Страница: https://www.anthropic.com/news/claude-text-watermark
- Найдено через `og:image` / `twitter:image` этой конкретной статьи:
  `https://www.anthropic.com/api/opengraph-illustration?name=Hand%20Quill&backgroundColor=heather`
- Тип: официальная брендовая line-art иллюстрация Anthropic (собственный API генерации OG-картинок,
  параметр `name` подтверждённо различается по статьям — проверено на другом посте
  Anthropic, там `name=Hand%20HeadOrbit`; значит иллюстрация подобрана редакцией Anthropic
  именно под эту тему — «рука выводит текст пером», перо/письмо тематически совпадает
  с материалом о водяных метках в тексте)
- Размер оригинала: 1900×1000 (PNG) → cover, масштаб 0,9, обрезано 6,4% по ширине,
  окно кропа по содержимому (без потери композиции) → 1600×900 (46,5 КБ, q90)
- Апскейл не применялся, letterbox/подложка не потребовались — исходник горизонтальный
  (1.9:1, шире целевых 16:9)

## Почему не альтернативы
- В теле статьи Anthropic нашёлся ещё один SVG-арт (1000×1000, alt "How Claude's text
  watermark works") — квадратный, потребовал бы подложку с полями (>22% обрезки при
  приведении к 16:9) — отклонён по правилу «ищи горизонталь, а не спасай вертикаль».
- Google DeepMind как источник изображения не рассматривался — по image-avoid
  (DeepMind — технология-первоисточник, не главный субъект материала).
- Стоковые «роботы»/«бизнесмены» и AI-генерация не понадобились — нашлось официальное
  изображение первого порядка.
- Лиц людей на иллюстрации нет (стилизованная линия руки, не фотография и не
  идентифицируемый человек) — соответствует image-avoid.

## Alt-текст
"Минималистичная line-art иллюстрация Anthropic: рука с пером выводит текст на листе
бумаги — образ письма и генерации текста"

## Уверенность в подборе: 75%
Картинка официальная, с первоисточника, горизонтальная, без обрезки проблемных зон,
без людей/роботов/графиков. Снижает уверенность то, что иллюстрация абстрактная
(перо/рука, а не буквально «водяная метка» или интерфейс Claude с выделенными
словами) — это ближе к альтернативе из handoff («нейтральная иллюстрация»), чем
к первому варианту хинта. Прямого визуала с логотипом Claude или выделенными
словами в тексте у Anthropic для этого поста не нашлось.
