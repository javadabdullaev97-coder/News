# Bild notes: andijan-khojaobod-pdd-restriction-3-years

## Стратегия: stock (Unsplash)

## Чувствительность темы — определило всю стратегию
Уголовный приговор, имя осуждённой не называется и не должно появиться нигде,
включая подпись к фото. Reporter notes (`mainVisualSubject`): «нет явного
субъекта — конкретное лицо в первоисточнике не показано и не названо».
Подходит: здание суда/зал заседаний общим планом, дорожный знак ПДД, эмблема
Верховного суда. Изображать людей, похожих на предполагаемую осуждённую,
нельзя. Это исключило любой кадр, где мог быть узнаваемый человек, даже
случайно похожий на фигурантку.

## Путь A — первоисточник: проверен и отклонён
`t.me/oliysuduz/51361` — единственный первоисточник. В HTML embed нашёл два
изображения:
1. `tgme_widget_message_user_photo` — аватар канала (по правилам image-pipeline
   его брать нельзя, это не контент поста).
2. `tgme_widget_message_video_thumb` — постер прикреплённого видео (3:46),
   1280×720 в разметке, реальный файл 320×180 px. Скачал и открыл: это не
   зал суда и не подозреваемая, а заставка новостной телепрограммы «Bu kun»
   (студия, два ведущих на фоне графики). Отклонён по двум причинам:
   (1) 320 px по длинной стороне < 600 px порога `too-small`;
   (2) даже при достаточном размере — генерическая TV-заставка, не по теме,
       и содержит людей крупным планом (ведущие), что для этой темы —
       дополнительный риск ложной ассоциации с фигуранткой дела.
- `sud.uz` / `oliysud.uz` — оба отдали HTTP 503 при прямой проверке (reporter
  уже фиксировал аналогичную недоступность `sud.uz` в своих notes). Не удалось
  проверить фото зданий районных судов Андижанской области.

## Путь B — Unsplash: использован
Тематический сток «зал судебных заседаний» уже был отобран и провалидирован
для другой сегодняшней статьи (`supreme-court-anticorruption-law-analysis`) —
пустой исторический зал заседаний, деревянные панели, колонны, кафедра судьи,
без людей, без узнаваемой привязки к конкретной стране (герб на кафедре
мелкий и нечитаем на итоговом кадре). Автор: Dragon White Munthe,
`unsplash.com/photos/Bh6u25Qv9qA`, Unsplash License (свободно). Скачал исходник
заново по прямому URL `https://images.unsplash.com/photo-1711003596872-aa68f08a4b8e`
(4032×3024, тот же файл) — независимая обработка под слаг этой статьи.

Решил переиспользовать именно этот кадр, а не искать новый, по трём причинам:
- полностью соответствует subject-first альтернативе из notes («зал заседаний
  общим планом»);
- нулевой риск персональных данных — в кадре нет ни одного человека;
- уже прошёл жёсткий отбор на «не 3D-рендер / горизонтальная ориентация /
  без узнаваемой чужой юрисдикции» для аналогичной судебной темы.

### Проверенный и отклонённый альтернативный вариант
- Unsplash `irisojcwKaM` (Michael Yuan) — жёлто-чёрный дорожный знак «zigzag»
  с подписью «NEXT 4 MILES» на фоне пустынного шоссе (Valley of Fire, Невада).
  Формально подходил под альтернативу «дорожный знак ПДД», реальная фотография,
  горизонтальная, без людей. Отклонён: английская надпись и характерный
  американский пустынный пейзаж делают кадр географически конкретным и
  тематически диссонирующим (Андижанская область — не пустыня), выбор в пользу
  нейтрального зала суда точнее передаёт тему «суд вынес приговор».

```json
    "offset": [0, 0],

    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/andijan-khojaobod-pdd-restriction-3-years-01.jpg",
    "url": "/images/posts/2026-08/andijan-khojaobod-pdd-restriction-3-years-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 214476,
    "quality": 90
  },
  "status": "ok"

```
cropLoss ровно 0,25 — на границе порога `crop-risky` (эскалация нужна только
при значении строго больше 0,25), не превышает. Кроп срезал только нижнюю
пустую часть кадра (пол, ступени), верхняя смысловая часть (свод, колонны,
кафедра) сохранена целиком. Визуально проверил итоговый файл — людей и
опознаваемых деталей конкретной юрисдикции в кадре нет.
