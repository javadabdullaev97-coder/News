# Fact-check: aerodromes-tourism-lease-small-aviation

## Общий вердикт: APPROVE

## Проверенные утверждения

Все 15 проверенных утверждений (передача аэродромов бизнесу, регулятор малой авиации,
весовые ограничения ВС по ICAO, сроки 3/6 месяцев, таможенная льгота 2027–2030 на ~40
наименований, 162 природных объекта с разбивкой по областям, курсы горных гидов в 8
регионах, электронные разрешения за 10 дней, статус ПП-348 и цели по доле туризма в ВВП)
дословно подтверждены на gov.uz (пресс-релиз Комитета по туризму от 04.08.2026) и lex.uz
(ПП-348 от 19.11.2025). Расхождений в цифрах не найдено.

Весь фактический массив опирается на один первоисточник (gov.uz) — это ведомственный
пресс-релиз государственного органа, легитимный источник «из первых рук» по белому списку.
Отсутствие второго независимого подтверждения самой фактуры не является нарушением
редполитики для свежего пресс-релиза (не «слух без первоисточника»).

## Список понижений / необязательных правок для editor'а

Блокирующих проблем нет. Три опциональных уточнения:

1. Лид/абзац 1: «...4 августа опубликовал проект постановления...» → точнее «...4 августа
   сообщил о разработке проекта постановления...» (комитет публикует новость о проекте,
   не сам текст акта).
2. «автодома» → «автокемперы» (термин источника) — необязательно, синоним не искажает смысл.
3. Первое упоминание «Комитет по туризму» → можно дать полное официальное название
   «Комитет по туризму Республики Узбекистан».
