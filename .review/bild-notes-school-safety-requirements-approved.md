### JSON обработки (scripts/prepare-image.py)

```json
{
  "source": { "width": 3906, "height": 3010 },
  "fit": {
    "mode": "contain",
    "scale": 0.299,
    "placed": [1168, 900],
    "note": "вписано целиком на размытую подложку из самого кадра; обрезка съела бы 27% по высоте"
  },
  "output": {
    "path": "public/images/posts/2026-08/school-safety-requirements-approved-01.jpg",
    "url": "/images/posts/2026-08/school-safety-requirements-approved-01.jpg",
    "width": 1600, "height": 900, "bytes": 172549, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

Размер оригинала: 3906×3010 → contain, масштаб 0,299, ничего не обрезано → 1600×900
(172,5 КБ, q90). Апскейла нет. Кадр 4:3, cover срезал бы 27% по высоте — выше порога 22%,
скрипт сам ушёл в `contain`. Поля по бокам узкие (по 216 px на две стороны), подложка —
размытие из самого кадра, читается как поле, а не как брак.

`cropLoss = 0` — триггер `crop-risky` (порог 0,15 из `config/newsroom-policy.json`) не наступил,
в очередь материал не уходит.

### Проверки перед использованием

- **Людей в кадре нет вообще** — ни детей, ни взрослых. Это главное требование поручения по §8:
  материал о биометрической идентификации школьников, узнаваемый ребёнок здесь недопустим вдвойне
- Нет сцен досмотра, охраны, оружия, силового антуража — коридор пустой и нейтральный
- Нет вывесок с названием школы, адресов, госномеров, лиц — PII нулевые
- Watermark'ов и логотипов нет
- Не 3D-рендер, не «отпечаток пальца в синем неоне», не сканер сетчатки, не киберпанк —
  ровно тот класс картинок, который запрещает `imagery.rejectStockRenders`
- Тон документальный, дневной свет, приглушённая палитра (жёлтый / синий / серый) — рядом
  с фирменным `#FF4D2E` не спорит

## Заметка для редактора поручений

Слабое место этого выбора — география, и его стоит знать. Коридор со шкафчиками читается как
североамериканская школа: в узбекских школах шкафчиков в коридорах нет. Кадр честен по
лицензии, по содержанию (пустой школьный коридор) и по подписи, но узбекскому читателю он
скажет «это не наша школа».

Правильное решение здесь — собственная съёмка: пункт пропуска в ташкентской школе, турникет
со считывателем, пост охраны. К 1 сентября, когда посты охраны по программе мер должны быть
организованы, тема вернётся минимум дважды (сентябрь — планы действий и проект совместного
решения о пропускном режиме; декабрь — тестовый запуск ИС «Безопасное образование»).
Один выезд фотографа закроет визуал для всей серии.

Отдельно: `@mvd_uz` не отдаёт публичное веб-превью (`t.me/s/mvd_uz` возвращает страницу-контакт
без сообщений), хотя в `config/telegram-channels.json` он стоит как P1-источник с обычным
`t.me/s/`-URL. Для бильда этот канал сейчас нерабочий — медиа оттуда не достать без Bot API.
Стоит либо проверить slug, либо пометить канал в конфиге как недоступный для парсинга медиа.

## Уверенность в подборе: 74%

Лицензия чистая и проверена у первоисточника, запреты §8 и `rejectStockRenders` не нарушены,
композиция ровно та, что просило поручение, обработка без обрезки и без апскейла.
Минус 26% — фотография иллюстративная и не узбекская: она не документирует событие и
визуально принадлежит другой стране. Для новости о конкретном постановлении это всегда
компромисс, и идеальный кадр (пункт пропуска в узбекской школе) первоисточником не опубликован.
