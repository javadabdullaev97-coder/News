## Общий вердикт

Материал корректно квалифицирован репортёром под приложение 10.1 («первоисточник назван, но недоступен»): обязательная формула в лиде и завершающая строка про запрос — на месте, цитаты обеих сторон атрибутированы изданиям. Но есть три структурных пробела: заголовок не несёт понижающей оговорки, сумма сделки подана как точное число вне цитат (а не порогом), и июльское одобрение Комитетом по конкуренции перехода 50% Rubicon Wireless — отдельное действие госоргана — не прошло собственной процедуры верификации по 10.1 (нет попытки проверки именно этого эпизода).

## Список понижений для editor'а (применяет сам, без повторной проверки)

1. **Заголовок**: добавить обязательную по 10.1 оговорку.
   Было: «Маматджанов попросил Мирзиёева ускорить сделку VEON и Perfectum на $200 млн»
   → Стало: «Маматджанов попросил Мирзиёева ускорить сделку VEON и Perfectum на $200 млн — по данным СМИ».
2. **Сумма сделки вне цитат** — заменить точное «$200 млн» в фоновом тексте (не в прямых цитатах) на пороговую формулировку: «...на сумму порядка $200 млн».
3. **Июльское решение Комитета по конкуренции (50% Rubicon Wireless)** — отдельное действие госоргана без собственной процедуры верификации.
   Было: «По данным изданий, Комитет по конкуренции в июле одобрил переход 50% Rubicon Wireless Communication в его собственность.»
   → Стало: «По данным нескольких изданий, в июле Комитет по конкуренции якобы одобрил переход 50% Rubicon Wireless Communication в собственность Маматджанова; официального подтверждения или номера решения нет.» Либо убрать предложение до отдельной верификации.
4. **Название Комитета** — унифицировать: расхождение между «Комитет по конкуренции» (в прозе) и «Комитет по развитию конкуренции» (в цитате).
5. **Риск-заметка про цитату президента** (не блокирует) — дословная цитата Мирзиёева не подтверждена пресс-службой напрямую; формально разрешено по 10.1, но editor может перевести в косвенную речь для снижения риска.
6. Проверить, есть ли прямая публикация Интерфакса (разрешённый источник) — если да, процитировать напрямую вместо обезличенного «несколько изданий».
7. Лид длиннее нормы (~50 слов при 25–30) — сократить, сохранив формулу понижения дословно.

## Применимость правила §10.1

Все 4 условия для главного эпизода выполнены (первоисточник назван, 6 независимых изданий, попытки подтверждения задокументированы, событие проверяемо задним числом). Но приложение 10.1 покрывает событие целиком, а не автоматически каждый факт внутри материала — июльское решение Комитета (claim про Rubicon Wireless) не прошло отдельную процедуру.

## Чек-лист — ключевые нарушения

- Заголовок не несёт обязательной оговорки 10.1
- H2 «Что предшествовало обращению» в новости об одном событии — формально спорно
- Действие госоргана (Комитет, июль) не подтверждено первоисточником напрямую
