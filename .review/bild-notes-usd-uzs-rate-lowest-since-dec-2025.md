## Main visual subject

По логике из задания для такой темы: здание/вывеска ЦБ РУз, обменный пункт или
купюры сум/доллар — что найдётся первым как живая фотография. Единственный

(подтверждено заданием).

## Ход поиска

### A. Первоисточник (cbu.uz)
- Проверил `https://cbu.uz/ru/press_center/news/` — свежих новостных материалов
  про курс/валютный рынок с изображениями нет (лента — банковское сотрудничество,
  исламские финансы, ИИ), в сайдбаре только текстовый виджет курсов без графики.
- Нашёл `og:image` самого сайта cbu.uz — `https://cbu.uz/upload/media/images/social.jpg`,
  1110×740, JPEG 233 КБ. Это фирменное официальное фото фасада здания ЦБ РУз в
  Ташкенте (характерные стеклянные цилиндрические лифтовые шахты, ракурс снизу
  вверх), которым регулятор сам представляет себя в соцсетях (стоит в
  `<meta property="og:image">` на `cbu.uz`). Живая фотография, не рендер и не
  диаграмма, людей и политиков в кадре нет.
- Тот же файл уже использовался как кандидат для трёх предыдущих материалов о ЦБ
  РУз/курсе (`cb-cash-fx-500-usd-no-passport`, `cbu-extends-fx-exchange-trading-hours`,
  `uzbekistan-usd-rate-rising-aug2026`) — устоявшийся фирменный визуальный образ
  учреждения для тем без иного субъекта, а не разовая случайная находка.
- Stock (Unsplash/Pexels) и Higgsfield-генерацию не потребовалось пробовать —
  порядок попыток A→B→C остановился на шаге A с приемлемым результатом.

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 1110, "height": 740},
  "fit": {
    "mode": "cover",
    "scale": 1.4414,
    "cropLoss": 0.1562,
    "offset": [0, 167],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.44× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/usd-uzs-rate-lowest-since-dec-2025-01.jpg",
    "url": "/images/posts/2026-08/usd-uzs-rate-lowest-since-dec-2025-01.jpg",
    "width": 1600, "height": 900, "bytes": 235347, "quality": 90
  },
  "status": "ok"
}
```

Апскейл 1,44× (в пределах MAX_UPSCALE, не создаёт заметного размытия — тот же
коэффициент и тот же итоговый файл, что и в трёх предыдущих материалах на эту
тему, визуально уже проверен ранее).

## Про cropLoss и порог crop-risky
`cropLoss = 0.1562`. Текущий порог в `config/newsroom-policy.json` —
`imagery.cropRiskThreshold = 0.25` (проверено в конфиге перед публикацией).
0,1562 < 0,25 — порог **не превышен**, эскалация к владельцу не требуется.
(Для сравнения: 03–04.08.2026 тот же кадр эскалировался, потому что тогда
действовал более строгий порог 0,15 — с тех пор порог обновлён владельцем до
0,25, и он попадает в норму.) Визуально: обрезается только полоса неба над
зданием, все четыре стеклянные шахты и фасад видны целиком — ничего из
главного объекта не потеряно.

## Ориентация кадра
Исходник 1110×740 — горизонтальный (AR ≈ 1,5), соответствует правилу
«ищи горизонталь, а не спасай вертикаль». Подложка (contain) не потребовалась.
