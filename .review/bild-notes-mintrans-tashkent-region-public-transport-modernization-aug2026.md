## Обработка (scripts/prepare-image.py)
Скачано напрямую (не через 800px виджет-превью, а по прямой cdn4.telesco.pe ссылке
из полной HTML-версии поста) — источник всё равно 800×533 (порог Telegram публичного
доступа).

```json
{
  "source": {"width": 800, "height": 533, "path": "/tmp/original.jpg"},
  "fit": {
    "mode": "cover",
    "scale": 2.0,
    "cropLoss": 0.1557,
    "offset": [0, 61],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 2.00× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/mintrans-tashkent-region-public-transport-modernization-aug2026-01.jpg",
    "url": "/images/posts/2026-08/mintrans-tashkent-region-public-transport-modernization-aug2026-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 218168,
    "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

cropLoss 0.1557 — ниже порога crop-risky (0.25 из config/newsroom-policy.json), человека
переспрашивать не нужно. Апскейл 2.0× — в пределах текущего MAX_UPSCALE=2.5 в
scripts/prepare-image.py (актуальная версия скрипта; более старое правило "апскейла нет
никогда" из image-pipeline.md устарело и заменено политикой cover-заливки без блюра).
Визуально после апскейла картинка читаема — экран с дашбордом не превратился в кашу,
текст на экране мелкий, но это фон, а не смысловой центр кадра.

## Отклонённые варианты
- og:image канала (аватар/логотип Минтранса) — не фото события, отклонён на этапе
  первичного WebFetch.
- Остальные 5 фото из альбома поста (общий план стола совещания, портрет участника,
  подписание документа, группа стоя) — все годные документальные фото без стока и
  без графиков-заготовок, но выбранное фото сильнее по subject-first: единственное,
  где виден именно предмет статьи — цифровая система мониторинга маршрутов/автобусов,
  а не просто протокольная встреча за столом.
- AI-генерация (Higgsfield) не понадобилась — нашлось живое официальное фото по теме.

хокимияту), горизонтальная ориентация, cropLoss низкий, содержание экрана совпадает

от Минтранса — в тексте статьи и alt не приписываю фото конкретному лицу).
