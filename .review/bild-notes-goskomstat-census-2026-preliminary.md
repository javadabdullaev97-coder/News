## Определение стратегии
Reporter в notes прямо указал: явного субъекта-человека нет. Предложил
инфографику с цифрой на фоне карты либо кадр самой переписи (работник
махалли с планшетом / пресс-конференция главы Нацкомстата).

Проверил stat.uz (назначенный первоисточник в sources) через curl/WebFetch:
контент рендерится через JS, в HTML нет ни `og:image`, ни встроенных фото
статьи — только шаблонные ассеты сайта (логотип, декоративная иконка
здания `bldg.png`, общая для всего сайта, не относится к материалу).
Совпадает с тем, что reporter уже фиксировал в notes про stat.uz.

Дальше прошёл по всем постам `t.me/census_2026`, перечисленным в
`frontmatter.sources` (те же посты, на которые уже даны inline-ссылки в
тексте) — забрал превью-изображение каждого через `?embed=1`:

- 1287 (общая численность) — оказался видео-сообщением (стоп-кадр эфира
  «Ozbekiston 24», 320×181, тёмный неинформативный кадр) — отклонил:
  слишком мелко и нет содержания.
- **1280 (разница с прежними оценками) — живое фото пресс-конференции:
  спикер на трибуне, на большом экране за ним крупно цифра «39 047 321» и
  подпись «O'ZBEKISTON RESPUBLIKASI AHOLISI». 800×497, горизонтальная
  ориентация. ВЫБРАНО.**
- 1299 (первая перепись) — живое фото конференц-зала, тоже документальное,
  но менее конкретное (просто заседание без релевантных цифр в кадре) —
  запасной вариант, не потребовался.
- 1272 (нацсостав/язык) — живое фото: человек отвечает на вопросы прессы
  (сцена со стойкой микрофонов) — субъект не идентифицирован по имени,
  риск неточной атрибуции без подтверждения личности; к тому же слабее
  тематически привязан к главной цифре лида. Не использовал.
- 1293 (возрастная структура) — рисованная инфографика: donut-чарты,
  плоские иконки людей, огибающие «плашки». Официальные цифры, но
  визуально это готовая «заготовка» дизайнера, а не документальная
  съёмка — по правилу subject-first/live-photo такой стиль не годится
  для главной, даже с реальными данными. Отклонил.
- 1296 (скот) — то же самое: мультяшная ферма, иконки животных, два
  столбца таблиц — классический «рисованный сток», reject.
- 1288 (жилфонд) — тоже дизайн-инфографика с иконками домов и 3D-рендером
  коттеджа — reject по тому же правилу.

Итог: единственный живой документальный кадр, прямо привязанный к
главному факту материала (итоговая цифра переписи), — пост 1280.
Subject-first выполнено косвенно: «субъекта-человека» в классическом
смысле нет, но есть прямая визуализация факта — момент официального
оглашения итоговой цифры, а не абстрактная картинка (карта/глобус/график).

## Источник картинки
- URL: https://t.me/census_2026/1280 (медиа: cdn4.telesco.pe/file/...)
- Тип: живая фотография с официальной презентации предварительных итогов
  переписи (не рисованная инфографика, не стоковый рендер)
- Тот же пост уже используется в теле статьи как inline-источник для
  цифры «810 617 человек, 2,1%», поэтому кредит согласован с уже
  раскрытым в статье источником (не вводит нового непроверенного канала).
- Размер оригинала: 800×497 (потолок публичного Telegram-виджета) →
  `prepare-image.py`: cover, scale 2.00× (упскейл в пределах MAX_UPSCALE
  2.5×), обрезано 9,46% по высоте (окно кропа по содержимому, офсет
  [0, 39]) → 1600×900, 191 553 байт, quality 90.
- Полный JSON-отчёт скрипта:
```json
{
  "source": {"width": 800, "height": 497},
  "fit": {
    "mode": "cover",
    "scale": 2.0,
    "cropLoss": 0.0946,
    "offset": [0, 39],
    "upscaled": true,
    "note": "обрезано 9% по высоте; окно кропа выбрано по содержимому; исходник растянут в 2.00× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/goskomstat-census-2026-preliminary-01.jpg",
    "url": "/images/posts/2026-08/goskomstat-census-2026-preliminary-01.jpg",
    "width": 1600, "height": 900, "bytes": 191553, "quality": 90
  },
  "status": "ok"
}
```
- `cropLoss` 0,0946 — далеко ниже порога 0,25, `crop-risky` не применяется.
  Апскейл 2× — в пределах жёсткого лимита скрипта (MAX_UPSCALE=2.5), это
  штатный режим `cover`, не подложка/contain.
