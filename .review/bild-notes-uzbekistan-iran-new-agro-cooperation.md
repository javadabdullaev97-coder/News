## Обработка
Исходник 1280×853 (соотношение 1.5, горизонтальный) → `scripts/prepare-image.py`:
```json
{
  "source": {"width": 1280, "height": 853},
  "fit": {
    "mode": "cover",
    "scale": 1.25,
    "cropLoss": 0.1559,
    "offset": [0, 27],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.25× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/uzbekistan-iran-new-agro-cooperation-01.jpg",
    "url": "/images/posts/2026-08/uzbekistan-iran-new-agro-cooperation-01.jpg",
    "width": 1600, "height": 900, "bytes": 202157, "quality": 90
  },
  "status": "ok"
}
```
cropLoss 15.6% — ниже порога 0.25 из newsroom-policy.json → editor-queue не требуется. Обрезка только по высоте (сверху/снизу), все люди, флаги и эмблема остались в кадре — проверено визуально после обработки.
