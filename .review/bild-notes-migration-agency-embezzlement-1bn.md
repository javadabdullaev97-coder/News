## Что проверено

### A. Первоисточник (t.me/Department_uz/12955)
- Пост содержит одну картинку: `cdn4.telesco.pe/.../....jpg`, 800×533, горизонтальная.
- По содержанию — драматизированный сток-коллаж: наручники и тюремная решётка слева,
  силуэты двух людей, входящих в дверь с вывеской «MIGRATSIYA AGENTLIGI», в центре —
  официальная круглая эмблема Агентства миграции, справа — рука в костюме передаёт
  конверт с деньгами другой руке, на переднем плане — калькулятор с суммой
  «1.020.100.000», пачки купюр, молоток судьи и книга «Jinoyat kodeksi».
- **Отклонено**: это не документальная съёмка события, а типовая сток-заготовка на тему
  «коррупция» с добавленным логотипом ведомства — прямое совпадение с примером
  «не работает» из редполитики (набор дешёвых стоковых элементов). Дополнительно
  содержит людей (силуэты, руки) — по прямому указанию в задании фото людей на этом
  материале быть не должно (активное уголовное дело, чувствительная тема).

### B. Поиск живого фото по теме
- **migration.uz** (официальный сайт Агентства миграции) — SPA на Next.js,
  `og:image` отдаёт только векторный логотип (`/images/logo/uz.svg`, 47×48 viewBox —
  маленький значок для навбара), фотографий здания/офиса на главной не нашлось.
- **Telegram @uzmigration** (официальный канал агентства, подтверждён по og:description
  сайта) — фото в канале не по теме дела: подписание меморандума с иностранным
  партнёром (два человека, US+UZ флаги), скриншот фишингового предупреждения о
  фейковом аккаунте. Ни одного фото здания/вывески агентства без людей не найдено
  за просмотренную часть ленты.
- **prodepartament.uz** (официальный сайт Департамента по борьбе с экономическими
  преступлениями, подтверждён по og:description канала @Department_uz) — фотоархив
  дел содержит только оперативные фото задержанных (лица замазаны белым кружком)
  с наличными на столе — люди в кадре, к тому же это другие уголовные дела, не
  Агентство миграции. Не подходит.
- **prokuratura.uz** (Генпрокуратура) — сайт отдаёт пустой SPA-шелл без
  серверного og:image с полезным содержимым.
- Международные фотостоки (Unsplash) по запросам «government building»,
  «tashkent» — либо здания Капитолия США (флаг, орёл — вводит в заблуждение

  (медресе Кукельдаш/Хазрати Имам с толпой туристов) — не подходят по существу
