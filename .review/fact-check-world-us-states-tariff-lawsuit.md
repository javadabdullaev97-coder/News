# Fact-check: world-us-states-tariff-lawsuit

## Общий вердикт: APPROVE-WITH-DOWNGRADES (confidence 72, погранично)

Центральный факт — 25 штатов подали иск против пошлин Трампа 3 августа в Суд по международной торговле США — подтверждён дважды независимо (пресс-релиз AG NY + Al Jazeera). Цитаты Джеймс/Хокул/Десаи дословно совпадают с источниками. Проблемы — в деталях второго уровня.

## Критические находки
1. **Дата вступления пошлин в силу («24 июля»)** — ссылка стоит на USTR fact sheet, но тот НЕ называет точную дату в доступном тексте. AG NY press release говорит «23 июля», Al Jazeera — «24 июля» (это дата истечения СТАРЫХ временных пошлин, не обязательно новых). Источники расходятся, текущая привязка к USTR неверна.
2. **Разбивка ставок 10%/12,5% по конкретным странам (6 vs 54 экономики, конкретный список стран)** — НЕ найдена в USTR fact sheet при трёх точечных запросах. Не подтверждено ни одним источником в frontmatter.sources.
3. Счёт голосов Верховного суда (6:3) и название дела (Learning Resources, Inc. v. Trump) привязаны в тексте к ссылке на Al Jazeera, которая этих деталей не содержит (только общий факт решения SCOTUS).
4. BBC News — World остаётся в frontmatter.sources как второй блок (anglo) для world.sourcing minDistinctBlocs=2, но ни reporter, ни fact-checker не смогли зафетчить и проверить его содержание — риск неверифицированной ссылки.

## Список понижений для editor'а (применяет сам, без повторной проверки)
1. «Пошлины действуют с 24 июля» → «Пошлины вступили в силу в конце июля (по данным Al Jazeera — 24 июля, по пресс-релизу генпрокурора Нью-Йорка — 23 июля)» — атрибутировать обе даты к их источникам, не выдавать одну как факт от USTR.
2. Убрать конкретный список стран и цифру «6 экономик»/«54 партнёра» — оставить только подтверждённое: «10% для партнёров, взявших на себя обязательства ограничить импорт товаров принудительного труда, и 12,5% для остальных — из 60 партнёров, обеспечивающих 99,4% импорта США».
3. Убрать привязку счёта голосов (6:3) и названия дела к ссылке на Al Jazeera — либо снять эти детали, либо (если editor может добавить источник) сослаться на официальное решение суда отдельной ссылкой.
4. «ещё более полутора десятков штатов» → «ещё полтора десятка штатов» (точная арифметика: 23−8=15).
5. Заголовок: «...против 60 стран» → «...против 60 торговых партнёров» (в списке есть ЕС, не страна).
6. **BBC в frontmatter.sources**: убрать, если он не используется как реальная опора ни для одного факта в тексте (что подтверждено — ни reporter, ни fact-checker не смогли прочитать его содержание). Тема остаётся достаточно подтверждённой Al Jazeera (mena) + двумя официальными документами США (истец и регулятор) — это сильнее типичного «два СМИ», но формально world.sourcing minDistinctBlocs=2 требует независимый блок. Решение editor'а: либо найти реально проверяемый источник другого блока (DW/Le Monde/NYT), либо оставить как есть с пометкой риска в отчёте планёрки.
7. **Удалить `publishedAt`/`updatedAt` из frontmatter полностью.**
