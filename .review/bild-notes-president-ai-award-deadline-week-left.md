## Источник картинки
- Первоисточник статьи `t.me/itpark_uz/20584` (форвард из `t.me/president_ai_award/23`) —
  проверил оба поста через `?embed=1&mode=tme`: фото в посте нет, только PDF-вложение
  `President_AI_Award_Tutorial_UZ.pptx.pdf`. Использовать нечего.
- `awards.gov.uz/ru/paia` — SPA, `og:image` в HTML не отдаётся вообще (страница почти
  пустая до JS). Пошёл по прямым путям ассетов, которые уже фигурировали в
  bild-notes сестринской статьи: `/logos/pta/president_ai_award_logo.png` — 200 OK,
  официальный горизонтальный логотип-локап (белая линейная эмблема-глобус +
  надпись «PRESIDENT AI AWARD») 1954×633, RGBA с прозрачным фоном.
- it-park.uz — SPA без серверного рендера, og:image и фотоассетов через curl не достать
  (нужен headless-браузер, инструмента для скриншотов нет в доступе).

## Обработка
Прямая подача PNG-логотипа в `prepare-image.py` дала `cover` с `cropLoss 0.42` и
апскейлом 1.42× — обрезка по ширине срезала правую часть слова "AWARD" до "A",
нечитаемо (аналог обрезанной легенды на графике — по правилам такое не публикуем).
Вместо кропа собрал промежуточный кадр вручную: логотип (без каких-либо изменений
содержимого, тот же файл) вписан целиком, без апскейла, по центру на сплошную
графитовую подложку `#1A1A1A` (синхронизирована с `SOLID_BG_COLOR` в самом
`prepare-image.py`, это не изобретённый цвет) — та же логика, что contain-режим
скрипта, только сделана до подачи, потому что скрипт не умеет корректно
разворачивать альфа-канал PNG (RGBA→RGB в скрипте не композитит на фон, а просто
отбрасывает альфу — на этом конкретном файле результат случайно совпал с чёрным,
но полагаться на это не стал бы).
Промежуточный кадр уже 1600×900 — прогнан через `prepare-image.py` штатно:

```json
{
  "source": {"width": 1600, "height": 900},
  "fit": {"mode": "cover", "scale": 1.0, "cropLoss": 0.0, "offset": [0, 0], "upscaled": false,
          "note": "обрезано 0% по высоте; окно кропа выбрано по содержимому"},
  "output": {"path": "public/images/posts/2026-08/president-ai-award-deadline-week-left-01.jpg",
             "url": "/images/posts/2026-08/president-ai-award-deadline-week-left-01.jpg",
             "width": 1600, "height": 900, "bytes": 86299, "quality": 90},
  "status": "ok",
  "upscaled": false
}
```

Ноль обрезки, ноль апскейла, содержимое логотипа не менялось (не перекрашивал, не
дорисовывал) — только позиционирование на нейтральном фоне.
