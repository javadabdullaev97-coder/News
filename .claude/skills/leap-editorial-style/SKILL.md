# Редполитика LEAP News — куда идти за правилом

Полный текст редполитики — `references/policy.md`, 42 тысячи знаков.
**Целиком его не читает никто.** У каждой роли есть готовый срез: только те
правила, которыми эта роль может ошибиться.

| Роль | Что читать |
|---|---|
| корреспондент | `config/generated/policy-reporter.md` |
| фактчекер | `config/generated/policy-fact-checker.md` |
| редактор | `config/generated/policy-editor.md` |
| бильд | `config/generated/policy-bild.md` |
| переводчик | `config/generated/policy-translator.md` |
| SEO | `config/generated/policy-seo.md` |

Срезы собирает планёрка командой `node scripts/policy-slice.mjs --all` перед
вызовом агентов. Файла нет — собери сам той же командой; нет и Bash — читай
`references/policy.md`, но знай, что платишь за него вчетверо.

## Редкие ситуации — отдельные приложения

В срез не входит то, что нужно раз в двадцать материалов. Такие правила лежат
по одному файлу в `config/generated/policy-appendix/`, и в начале каждого среза
есть список: при какой ситуации какой файл открыть. Сработала ситуация —
открываешь одно приложение, а не всю редполитику.

## Что здесь ещё есть

- `references/image-pipeline.md` — устройство обработки картинок, для бильда.
- `docs/terminology-glossary.md` — словарь названий и терминов на трёх языках;
  тематические части (спорт, технологии) — в `docs/terminology/`.
- `docs/rationale/editorial-style.md` — почему правила такие: замеры, разборы,
  инциденты. Для человека, который правит редполитику, а не для прогона.

**При конфликте побеждает `references/policy.md`.** Срез — производный файл,
он не редактируется и не может содержать того, чего нет в источнике.
