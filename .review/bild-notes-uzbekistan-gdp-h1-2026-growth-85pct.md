# Bild notes: uzbekistan-gdp-h1-2026-growth-85pct

## Стратегия: primary-source

Изображение взято с сайта первоисточника — со страницы того самого релиза Нацкомстата,
на который опирается лид статьи (релиз 69576 от 31 июля 2026).

## Источник картинки
- Страница релиза: https://stat.uz/ru/press-tsentr/novosti-goskomstata/69576-zbekiston-yalpi-ichki-ma-suloti-azhmi-8-5-foizga-sdi-3
- Прямой URL файла: https://stat.uz/img/yaim_p29371.jpg (`yaim` = ЯИМ = ВВП)
- Тип: заглавная иллюстрация пресс-релиза Нацкомстата (3D-рендер, не фото, не инфографика с данными)
- Размер оригинала: 800×600, 83 КБ → итог 1200×630, 75 КБ, JPEG q82, progressive, EXIF снят
- Лицензия: футер stat.uz на самой странице релиза — «Все материалы сайта доступны по лицензии:
  Creative Commons Attribution 4.0 International», плюс «При использовании информации, ссылка
  на www.stat.uz обязательна». Требование атрибуции закрыто через `credit` с указанием stat.uz.

## Обработка
ImageMagick/`convert` на раннере отсутствует — ресайз сделан через Pillow (доустановлен в скретч).
Оригинал 4:3, целевой формат 1,91:1. Прямой центр-кроп (`v1`) обрезал апекс красной стрелки сверху
и основания столбцов снизу — композиция разваливалась. Взят вариант `v2`: исходник целиком вписан
по высоте (840×630) поверх собственного размытого и затемнённого фона-заливки до 1200×630.
Контент не потерян, полей-«letterbox» нет.

## Отклонённые варианты

### 1. Картинка из Telegram-поста `t.me/uzstataxborot/69154` — ОТКЛОНЕНО
В поручении была гипотеза, что в посте лежит «графика с рядом ВВП». **Это не так.**
Через `?embed=1&mode=tme` вытащен единственный медиа-файл поста:
`cdn4.telesco.pe/file/f_RHXzxPYoLVW5y11kr9CWtOpsHHoAjVXT2n7zRc-...jpg` (800×611, 74 КБ).
Это декоративный 3D-клипарт «синие столбцы + линия тренда», и на нём **подписаны годы 2000–2012**.
Ряд ВВП (2022–2026) в посте есть, но в тексте, а не на картинке.
Причина отказа: подписи 2000–2012 на иллюстрации к материалу про январь–июнь 2026 вводят читателя
в заблуждение по датам. `og:image` того же поста — тот же кадр в 320×244, не альтернатива.

### 2. Unsplash / Pexels (нейтральный Ташкент, деловой центр) — НЕДОСТУПНО
Ключей API в окружении нет (`env`, `config/`, `.env` — пусто). Без ключа:
Unsplash `/s/photos/tashkent` → HTTP 401, Pexels `/search/tashkent/` → HTTP 403.
Тащить кадр в обход (Google Images, парсинг выдачи) запрещено политикой — не делал.

### 3. Higgsfield (AI-генерация) — ИНСТРУМЕНТ НЕ ПОДКЛЮЧЁН
В поручении разрешён как fallback, но в тулсете этого сабагента MCP-инструментов Higgsfield
(`generate_image`) нет — только Read/Edit/Bash/WebFetch/Grep/Glob. Вызвать нечем, HTTP-ключа тоже нет.

### 4. Wikipedia / Getty / Shutterstock / узбекские СМИ из чёрного списка — не рассматривались по политике.

и жёлтых столбцов, красная стрелка вверх и разноцветная круговая диаграмма, всё на клавиатуре

Описывает то, что реально в кадре, а не заголовок статьи. Сознательно не пишу «рост ВВП на 8,5%»:
на картинке нет ни цифр, ни подписей, и alt не должен приписывать изображению данные, которых
в нём нет.

## Остаточные риски (для редактора поручений)

1. **Цепочка прав на сам рендер.** Файл — узнаваемый коммерческий сток-рендер («столбцы + пай-чарт
   на клавиатуре»), почти наверняка лицензированный Нацкомстатом у стокового банка, а не созданный
   ведомством. Бланкетная плашка CC BY 4.0 в футере госсайта формально распространяется на «все
   материалы сайта», но переуступить чужую сток-лицензию ведомство не может. Формальное основание
   у нас есть и оно задокументировано; юридически железобетонным я его не считаю.
   Если редакция хочет нулевой риск — нужен либо Higgsfield, либо ключ Unsplash/Pexels.
2. **Апскейл 1,5×.** 800→1200 по ширине содержимого. Для OG-превью (реальный показ ~500–600 px)
   незаметно, на ретине в карточке статьи мягкость видна.
3. **Картинка не несёт данных статьи.** Это декор, а не инфографика. Ожидание из поручения
   («картинка сама несёт данные») выполнить было нечем — ни у Нацкомстата, ни в его ТГ такой
   графики к этому релизу нет.
4. **Предложение на будущее:** у редакции есть все проверенные числа для собственной карточки
   (1 072,7 трлн сумов; +8,5%; 8,1 / 0,4 п.п.) с `credit: "LEAP News"` и нулевым риском по правам.
   Собственный шаблон карточек — отдельная задача, в рамках этого поручения не делал.
   Ряд 2022–2026 для столбчатой диаграммы брать **нельзя**: editor снял базу 900,7 трлн
   как непроверяемую (п. 1 вердикта), и график на этом ряде вернул бы в материал ровно то,
   что редакция из него вырезала.

## Что не трогал
Только блок `image:` во frontmatter, точечным Edit'ом. `description`, `tags`, `category`
(зона агента `seo`), текст статьи и `sources` не изменялись. На момент правки файл уже был
изменён параллельным агентом — edit применился чисто, конфликта нет.

## Уверенность в подборе: 72%
Минус — картинка декоративная и её сток-происхождение под бланкетной CC-плашкой не идеально
чистое. Плюс — это иллюстрация ровно того релиза, на котором стоит статья, атрибуция честная
и проверяемая, людей в кадре нет, дезинформирующих подписей (в отличие от ТГ-варианта) нет.
