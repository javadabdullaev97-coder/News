## Источник картинки (стратегия B)
- Платформа: Unsplash (images.unsplash.com), Unsplash License
- Страница: https://unsplash.com/photos/people-wait-at-a-crosswalk-with-a-green-pedestrian-signal-RFd4Yc9QGfk
- Прямой файл: https://images.unsplash.com/photo-1779729823145-0af450095f07
- Автор: Simon Ray (@simonbhray)
- Содержание: пешеходный светофор с зелёным сигналом «идите» (горящая зелёная фигурка
  человека) на переднем плане, люди на пешеходной зоне внизу кадра, город на фоне.
  Прямое совпадение с mainVisualSubject reporter'а («регулируемый переход со светофором
  для пешеходов, работающий пешеходный сигнал») за вычетом конкретной геолокации —
  фото не претендует на съёмку в Ташкенте, это тематическая иллюстрация, что отражено
  в alt-тексте (без упоминания конкретного места).
- Размер оригинала: 3000×2000 (альбомная ориентация, соотношение 1.5, проходит порог
  «шире 1.3»)
- Обработка (`scripts/prepare-image.py`):
```json
{
  "fit": {"mode": "cover", "scale": 0.5333, "cropLoss": 0.1562, "offset": [0, 0], "upscaled": false,
          "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому"},
  "output": {"width": 1600, "height": 900, "bytes": 368533, "quality": 90},
  "status": "ok", "upscaled": false
}
```
  cropLoss 0.1562 — ниже порога 0.25, `crop-risky` не применяется. Визуально проверил
  итоговый кадр: зелёная фигурка светофора и весь корпус светофора остаются полностью
  в кадре, обрезаны только верх/низ (немного неба сверху, часть голов людей снизу) —
  главный субъект не пострадал.
