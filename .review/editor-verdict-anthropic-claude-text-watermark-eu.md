## Что оставил как есть
- Архитектуру с двумя H2 («Технология Google DeepMind», «Что требует Евросоюз») — материал имеет два самостоятельных контекстных блока (происхождение технологии + регуляторное требование ЕС), это расширенная новость (событие + контекст), а не новость об одном факте, поэтому H2 уместны по таблице жанров.
- Концовку без блока «Что дальше» — правильно: у публичного API нет названной даты, ставить фиктивный блок было бы имитацией концовки; материал корректно заканчивается фактом об ограничениях метода.
- Ссылку на Google DeepMind в `frontmatter.sources` — не убрал, хотя в теле она теперь подтверждает только общий факт авторства технологии, а не детали Nature/Gemini/2024. Источник остаётся легитимным (реальная официальная страница DeepMind о SynthID-Text), убирать его из `sources` без факта-повода не стал.
- Лид короче стандартных 25–30 слов (15 слов) — не стал искусственно удлinять добавлением непроверенных деталей ради формального соответствия счётчику слов.
