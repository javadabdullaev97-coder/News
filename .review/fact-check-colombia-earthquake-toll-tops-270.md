# Fact-check: colombia-earthquake-toll-tops-270

## Общий вердикт: APPROVE-WITH-DOWNGRADES

## Проверенные утверждения (ключевое)
Все факты по числу жертв (265→274, 13-14 августа), USGS-параметрам землетрясения
(M7.4, 5 км от Сан-Хосе-дель-Пальмар, деп. Чоко, глубина 110.3 км, event id
us6000tjl2 — не перепутан), обрушению больницы в Кали, цифрам по Перейре (83) и
Кали (74), спору вокруг мексиканских спасателей (цитаты Шейнбаум и главы МИД Булы)
подтверждены дословно шестью источниками (Al Jazeera×4, PBS, USGS). Формула для
живого события (атрибуция + округление/порог + метка времени: «превысило 270» на
«14 августа») соблюдена корректно — источник даёт «at least 274», округление вниз
с атрибуцией правильное.

Единственная проблема: «сильнейшее для Колумбии за всю историю наблюдений» —
источник Al Jazeera дословно говорит «the strongest to hit Colombia this century»
(«сильнейшее в этом веке»), не «за всю историю» — землетрясение 1906 года
(М~8.8) было значительно мощнее. Формулировка драфта завышает характеристику.

Раздел «При чём здесь Узбекистан» корректно отсутствует.
