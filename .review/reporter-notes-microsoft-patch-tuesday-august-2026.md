**Reporter notes: microsoft-patch-tuesday-august-2026**

**Тема.** Microsoft выпустила августовский Patch Tuesday 11 августа 2026 года, закрыв несколько сотен уязвимостей в Windows и поддерживаемом софте. Одна брешь (CVE-2026-68820) уже активно эксплуатируется, ещё две раскрыты публично до выхода патча.

**Первоисточники (проверенные):**
- `api.msrc.microsoft.com/cvrf/2026-Aug` — официальный машиночитаемый бюллетень Microsoft. Заголовок документа: «This release consists of 422 Microsoft CVEs», разбивка по продуктам (Windows: 236, Office: 98 и т.д.). Полную таблицу severity через WebFetch вытащить не удалось — инструмент возвращает усечённый summary, не полный JSON.
- `msrc.microsoft.com/update-guide/.../CVE-2026-68820` — официальная страница уязвимости. Прямой WebFetch не рендерит контент (JS-приложение, отдаёт только заголовок страницы «Security Update Guide»). Факты по этой CVE подтверждены кросс-проверкой через NVD.
- `nvd.nist.gov/vuln/detail/CVE-2026-68820` — официальная база NIST США, рендерится корректно. Подтверждает: use-after-free в Windows Ancillary Function Driver for WinSock, CVSS 3.1 = 7,0, дата публикации 11 августа 2026, затрагивает Windows 10/11 и Server 2012R2–2025, включена в каталог CISA KEV как активно эксплуатируемая.
- Krebs on Security (исходная ссылка задания) — 398 CVE, 42 критических, CVE-2026-68820 (эксплуатируется), CVE-2026-62832 и CVE-2026-72971 (раскрыты публично до патча), дата 11 августа, сравнение с июлем (570, рекорд) и июнем (~200).
- Tenable blog — подтверждает 398/42/355/1 (critical/important/moderate), детали по всем трём CVE (CVSS 7,0 / 7,8 / 5,5).
- The Hacker News — даёт другую цифру критических (62 из 398), список четырёх критических RCE с CVSS 9,8 (DNS Server, WDS, MS QUIC, HPC Pack), напоминание про SharePoint (нужны оба фикса — июльский и августовский). Также содержит версию про атрибуцию Check Point Research к группе Lazarus / Operation Dream Job — не включена в статью, только один источник.
- Qualys blog — даёт третью цифру по общему числу (421, вероятно с учётом Adobe в том же обзоре) и критических (62), подтверждает срок CISA KEV — устранить CVE-2026-68820 до 25 августа 2026.

**Расхождения с inbox-снипетом.** Задание указывало «не менее 398» — подтверждено (Krebs, Tenable, The Hacker News сходятся на 398). Официальный CVRF-бюллетень Microsoft называет более высокую цифру — 422 (вероятно, включает ревизии прошлых месяцев). Qualys даёт 421, возможно из-за объединения с Adobe-патчами. Все цифры зафиксированы в статье с атрибуцией, ни одна не выбрана произвольно. Число «критических» тоже расходится: 42 (Krebs, Tenable) против 62 (The Hacker News, Qualys) — дано диапазоном по правилу раздела 10 редполитики.

**Main visual subject:** «Экран установки обновлений Windows Update / щит кибербезопасности» — нет конкретного человека, тема техническая. Не нужен сток «хакер в капюшоне».

**Что не вошло в статью:**
- Версия The Hacker News про атрибуцию CVE-2026-68820 группе Lazarus (Check Point Research) — один источник, требует проверки, возможен отдельный материал.
- Полная разбивка CVRF по продуктам — не критично для широкой аудитории.
- SharePoint-история (оба патча нужны) дана одной строкой, можно развернуть отдельно для ИТ-аудитории.

**Пропуски и слабые места.** Общее число CVE и число критических даны диапазоном с атрибуцией сознательно — fact-checker не должен схлопывать это в одну цифру. Полный CVRF JSON не вытащен целиком (ограничение WebFetch). Формула понижения §10 не применялась: MSRC подтверждён косвенно через NVD и собственный CVRF, контент доступен, просто не через HTML-рендер.

**Уверенность: 78%.** Ключевые факты (дата, факт эксплуатации, две публично раскрытые CVE, CVSS-баллы) подтверждены минимум двумя независимыми источниками каждый. Confidence снижен из-за честно зафиксированного (не устранённого) расхождения в общих цифрах между источниками.
