## Источник картинки
- URL: https://images.siliconangle.com/blogs.dir/1/files/2026/08/Broadcom.png
- Тип: фото официального стенда Broadcom на технологической выставке. Сама
  SiliconANGLE атрибутирует кадр как "Photo: Broadcom" со ссылкой на
  официальный Twitter/X-аккаунт компании (twitter.com/Broadcom/status/...) —
  то есть это собственное официальное фото компании, республикованное
  изданием в статье, уже указанной в `sources` черновика.
- Живая фотография (не рисованная заготовка, не 3D-рендер): реальный стенд
  на выставке, крупный план на логотип и слоган "Connecting Everything".
  На заднем плане — размытая толпа посетителей выставки, не в фокусе, не
  выдаётся за представителей компании — соответствует image-avoid из handoff.
- Размер оригинала: 900×501 → cover, масштаб 1,80×, обрезано 1% по ширине →
  1600×900 (200 КБ, q90). JSON prepare-image.py:
  ```json
  {
    "source": {"width": 900, "height": 501},
    "fit": {"mode": "cover", "scale": 1.7964, "cropLoss": 0.0104,
            "offset": [17, 0], "upscaled": true,
            "note": "обрезано 1% по ширине; окно кропа выбрано по содержимому; исходник растянут в 1.80× ради заливки кадра"},
    "output": {"path": "public/images/posts/2026-08/broadcom-ai-chip-debt-financing-01.jpg",
               "url": "/images/posts/2026-08/broadcom-ai-chip-debt-financing-01.jpg",
               "width": 1600, "height": 900, "bytes": 199806, "quality": 90},
    "status": "ok"
  }
  ```
  Масштаб 1,80× — в пределах MAX_UPSCALE=2.5, заложенного в текущей версии
  prepare-image.py (умеренный апскейл ради cover вместо letterbox-подложки,
  см. комментарий в скрипте). Проверил визуально итоговый файл — логотип и
  текст читаются чётко, размытия не видно.
- `node scripts/photo-dupes.mjs --check` — кадр свободен, за 2 дня не выходил.

## Проверка официального сайта Broadcom
- www.broadcom.com/company/news — og:image даёт только универсальный
  брендовый баннер (радужный градиент + логотип, 1200×627), не фото. Не
  использовал: это не «живая фотография» (плоская графика с градиентом),
  формально попадает под запрет на дешёвые «заготовки».
- Отдельной страницы media library / press kit с фото найти не удалось
  (редиректы/404 на company/news/media-library и product-news).

## Отклонённые варианты
- https://www.broadcom.com (og:image) — универсальный логотип-баннер с
  радужным градиентом фона, не фото. Отклонён по правилу №2
  (только живая фотография, никаких «плашек»/градиентных заготовок).
