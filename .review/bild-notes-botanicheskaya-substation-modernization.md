# Bild notes: botanicheskaya-substation-modernization

## Стратегия: stock (thematic)

Main visual subject (по вводным): подстанция «Ботаническая» — трансформаторное
оборудование / распределительное устройство.

## A. Первоисточник — почему не сработал

Оба поста из `frontmatter.sources` открыты через `t.me/<slug>/<id>?embed=1`
и через сырой HTML (не через WebFetch — он у обоих постов галлюцинировал
описание фото по тексту, а реальным media был файл 160×160, аватар канала,
брать который прямо запрещено в `image-pipeline.md`):

- `t.me/Toshkent_shaharMET_Axborot/2982` — пост содержит **видео**
  (`tgme_widget_message_video_player not_supported`), публичный виджет отдаёт
  только превью-кадр видео **320×180**.
- `t.me/poytaxt_uz/51276` — тот же ролик, тот же превью-кадр 320×180
  (оригинал поста, `#2982` — репост).

Прогнал превью через `prepare-image.py`:
```json
{
  "source": { "width": 320, "height": 180 },
  "status": "too-small",
  "reason": "исходник 320×180, длинная сторона меньше 600px — в главную не годится, нужен другой источник"
}
```
Апскейл запрещён политикой скрипта (искусственно растягивать 320px до 1600px —
мыло), другого фото самой «Ботанической» в постах нет.

Проверил соседние посты канала филиала (`2974`, `2979-2981`, `2984-2985`) и
канала хокимията (`51274-51278`) — тематически не про «Ботаническую»
(встреча с молодёжью АО, доклад президенту по ТЭК без конкретики по объекту,
другие темы). Реальных фото самой подстанции с достаточным разрешением нет
нигде в первоисточниках.

## B. Тематический сток — что взял

Искал через Openverse API (`api.openverse.org`, работает без ключа;
`UNSPLASH_ACCESS_KEY`/`PEXELS_API_KEY` в окружении нет) с фильтром
`license=cc0,pdm`, `orientation=wide`, исключая `wikimedia` (не берём Wikipedia
по чёрному списку) и Getty/Shutterstock/Depositphotos (не искал вовсе).

Выбрано: **"Power plant cables transformers"**, rawpixel, CC0 Public Domain
(снято на подстанции Игналинской АЭС, Литва — тег в метаданных, визуально
неотличимо от обычного распределительного устройства 110+ кВ, в тексте и
alt не заявляется как реальная «Ботаническая»).

- Openverse ID: `6b6df88f-8ada-46e5-a584-21c9859d62be`
- Landing page: https://www.rawpixel.com/image/6035421/photo-image-public-domain-technology-free
- Использован URL из Openverse API (`editor_1024`, 1024×683) — **чистый, без
  водяного знака**. Пробовал подобрать URL большего размера напрямую у
  rawpixel (`image_1300`) — та версия оказалась **с водяным знаком
  "rawpixel"** по диагонали кадра, для публикации не годится, отклонена.
- Прогон через `prepare-image.py`:
```json
{
  "source": { "width": 1024, "height": 683 },
  "fit": {
    "mode": "cover",
    "scale": 1.5625,
    "cropLoss": 0.1567,
    "offset": [0, 8],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/botanicheskaya-substation-modernization-01.jpg",
    "width": 1600, "height": 900, "bytes": 409724, "quality": 90
  },
  "status": "ok"
}
```
`cropLoss` 0,1567 — ниже порога `crop-risky` (0,25); кадр без единого
чёткого объекта (лицо/животное/здание), это повторяющаяся структура проводов
и изоляторов — обрезка по высоте безопасна, `crop-risky` не применяется.
Апскейл 1,56× — в пределах политики скрипта (`MAX_UPSCALE = 2.5`).

## Отклонённые варианты

- Аватары каналов `poytaxt_uz` и `Toshkent_shaharMET_Axborot` (160×160) —
  логотипы, `too-small` и не по содержанию.
- Превью-кадр видео из постов `#2982`/`#51276` (320×180) — `too-small`,
  апскейл запрещён.
- rawpixel `image_1300` (та же фотография, но с водяным знаком) — водяной
  знак делает публикацию невозможной.
- Openverse: `fe239fc8...` (High-voltage transformer 750 kV) и
  `f051eb06...` (Witten Trafostation) — источник `wikimedia`, чёрный список
  редполитики (Wikipedia/Wikimedia Commons не берём).
- Openverse `691391ec...` («Electrical power line transformer», rawpixel,
  1920×1280) — одиночная опора с тремя маленькими трансформаторами на фоне
  пустого неба, композиция беднее и меньше говорит о «подстанции» как объекте
  — предпочёл более насыщенный кадр распределительного устройства.
- Openverse `32525253...` (Palestine Electric Corporation Power Plant) —
  не смотрел детально, первый по релевантности кандидат уже нашёлся и прошёл
  все проверки.

## AI-генерация

Не понадобилась — тематический сток нашёлся и прошёл все фильтры (живое
фото, не рендер, горизонтальная ориентация, чистый CC0 без водяного знака).

## Alt-текст

«Высоковольтные трансформаторы и распределительное оборудование на
электроподстанции (иллюстративное фото)» — сознательно не называет объект
«Ботанической»: это тематическая иллюстрация, не фото конкретной подстанции
из статьи, и alt не должен вводить читателя в заблуждение.

## Уверенность в подборе: 65%

Кадр показывает высоковольтное распределительное устройство/трансформаторы —
ровно тот класс объекта, который упомянут в `mainVisualSubject`, живая
фотография (не рендер, не инфографика), горизонтальная ориентация, без
людей — все технические требования редполитики выполнены. Не 90%+ только
потому, что это не фото самой «Ботанической», а тематический сток общего
плана (снято на подстанции АЭС в Литве) — честно отражено в alt-тексте, но
идеалом остаётся живое фото объекта из статьи, которого первоисточники не
дали.
