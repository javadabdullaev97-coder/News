Microsoft 13 avgustda korporativ blogida biznes uchun tavsiya e'lon qildi: Active Directory'ga bog'liqlikni kamaytirish uchun lokal serverdan bulutli kirish huquqini boshqarish xizmati Entra ID'ga o'tish kerak.

Active Directory — Windows xizmati bo'lib, kompaniyalar unda xodimlarning hisob yozuvlari, parollari va kirish huquqlarini o'nlab yillar davomida o'z serverlarida saqlaydi. Microsoft Entra ID esa uning bulutli analogi: korporativ tizimlarga kirish internet orqali, kompaniya hududidagi lokal serversiz boshqariladi. Postning muallifi, Microsoft Entra mahsulotlari bo'yicha katta menejer Jorge Lopez nega biznes uchun yolg'iz Active Directory yetarli bo'lmasligi mumkinligini [tushuntirdi](https://techcommunity.microsoft.com/blog/microsoft-entra-blog/why-active-directory-alone-is-no-longer-enough/4546402).

Uning so'zlariga ko'ra, xodimlar foydalanadigan ilovalar tobora ko'proq bulutda ishlaydi — Microsoft 365, Salesforce, ServiceNow, Workday. Korporativ tizimlarga shuningdek pudratchilar, hamkorlar, yetkazib beruvchilar va sun'iy intellekt (SI) agentlari ham murojaat qiladi. Post ma'lumotlariga ko'ra, ma'lumotlar va xizmatlar bilan ishlash uchun alohida kirish huquqlari birinchi navbatda SI ilovalari va agentlariga zarur.

## Bulutga o'tish vaqti kelganini bildiruvchi beshta belgi

Postda tashkilot uchun beshta signal sanab o'tilgan:

- IT-qo'llab-quvvatlash xizmati tizimni rivojlantirishdan ko'ra uni saqlab turishga ko'proq vaqt sarflaydi;
- xavfsizlik qoidalari foydalanuvchi jismonan qayerda joylashganiga bog'liq;
- bulutli ilovalar biznes ishining asosiga aylandi;
- kompaniya tizimlariga nafaqat shtatdagi xodimlar, balki pudratchilar, hamkorlar va SI agentlari ham murojaat qiladi;
- kompaniya sun'iy intellekt vositalarini joriy qilishni rejalashtirmoqda.

Microsoft Active Directory'dan butunlay voz kechishga chaqirmayotganini aniqlashtirdi. «Maqsad — Active Directory'ni albatta almashtirish emas, balki bulutli identifikatsiya yaxshiroq natija beradigan joylarda unga bog'liqlikni kamaytirish», — deyilgan postda. Post ma'lumotlariga ko'ra, lokal server alohida eskirgan vazifalarni qo'llab-quvvatlashni davom ettirishi mumkin. Shu bilan birga Entra ID yangi ssenariylar — autentifikatsiya, kirishni nazorat qilish va SI agentlari ishi — uchun asosiy platformaga aylanadi.

Microsoft Learn'ning alohida qo'llanmasi o'tishni beshta bosqichdan iborat jarayon sifatida tasvirlaydi — bulutli identifikatsiyani mavjud Active Directory'ga ulashdan tortib, lokal serverdan butunlay voz kechishgacha. [Hujjat](https://learn.microsoft.com/en-us/entra/architecture/road-to-the-cloud-introduction) 2026-yil 31-iyulda yangilangan.
