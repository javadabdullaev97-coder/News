Since August 14, 2026, Microsoft has been removing the WMIC command-line tool from Windows 11 versions 24H2 and 25H2 — an outdated utility that ransomware operators and other cybercriminals have used for years.

WMIC (Windows Management Instrumentation Command-line) is a built-in Windows tool that lets users manage the system and retrieve data about it through text commands. The program is signed by Microsoft itself, so antivirus software often let it pass as safe, and attackers used WMIC for years to carry out malicious actions without installing separate programs. Such tools are called LOLBins (living-off-the-land binaries): they are legitimate on their own but dangerous in the hands of attackers.

The change is documented in the release notes for update KB5120998 (builds 26100.9267 and 26200.9267) for the Release Preview channel. [The document states](https://learn.microsoft.com/en-us/windows-insider/release-notes/release-preview-24h2-25h2/build-26100-9267-26200-9267): "Starting in August 2026, Windows 11 versions 24H2 and 25H2 no longer include the WMIC utility." WMIC is already removed by default on new installations of these versions and is no longer available as an optional component (Feature on Demand), Microsoft says.

Three days later, on August 17, WMIC also disappeared from the Windows 11 Insider Beta test build 26220.9202. In the release notes for that build, Microsoft [said](https://learn.microsoft.com/en-us/windows-insider/release-notes/beta/preview-build-26220-9202) the removal "is part of the ongoing deprecation of WMIC."

The underlying WMI (Windows Management Instrumentation) technology itself, which lets programs and administrators retrieve system data, is unaffected — only the outdated command-line interface to it is being removed. Microsoft separately [confirms](https://support.microsoft.com/en-us/topic/windows-management-instrumentation-command-line-wmic-removal-from-windows-e9e83c7f-4992-477f-ba1d-96f694b8665d) this on the support page dedicated to the WMIC removal.

## How attackers used WMIC

According to [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-removes-wmic-lolbin-tool-in-windows-11-beta-builds/), ransomware operators used WMIC to delete shadow copies of files in Windows. That strips victims of the ability to restore data after encryption without paying a ransom. The tool was also used to detect and disable installed security solutions and to add exceptions to Microsoft Defender antivirus, hiding malicious files from it.

Microsoft itself explains the removal as an effort to "improve the security and resilience of the environment" — that is how it is phrased on the [support page](https://support.microsoft.com/en-us/topic/windows-management-instrumentation-command-line-wmic-removal-from-windows-e9e83c7f-4992-477f-ba1d-96f694b8665d). The same page describes the entire course of WMIC's deprecation: the tool has been disabled gradually since 2016. Since 2024, it has been off by default in Windows 11 versions 23H2 and 24H2, while remaining available as a separately installable component.

## What comes next

According to the same [Microsoft support page](https://support.microsoft.com/en-us/topic/windows-management-instrumentation-command-line-wmic-removal-from-windows-e9e83c7f-4992-477f-ba1d-96f694b8665d), WMIC "will be fully removed from Windows 11 in a future major update of Windows." After that, the tool will not be able to be added back even as an optional component. Instead, the company recommends using PowerShell and other modern tools for tasks that used to be handled through WMIC.
