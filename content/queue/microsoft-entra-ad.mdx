Microsoft 13 августа опубликовала в корпоративном блоге рекомендации для бизнеса — перейти от локального сервера Active Directory к облачному сервису управления доступом Entra ID, чтобы снизить зависимость от неё.

Active Directory — служба Windows, где компании десятилетиями хранят учётные записи, пароли и права доступа сотрудников на собственных серверах. Microsoft Entra ID — облачный аналог: доступ к корпоративным системам управляется через интернет, без локального сервера на территории компании. Автор поста, старший менеджер по продуктам Microsoft Entra Хорхе Лопес, [объяснил](https://techcommunity.microsoft.com/blog/microsoft-entra-blog/why-active-directory-alone-is-no-longer-enough/4546402), почему одной Active Directory бизнесу может быть недостаточно.

По его словам, приложения, которыми пользуются сотрудники, всё чаще работают в облаке — Microsoft 365, Salesforce, ServiceNow, Workday. К корпоративным системам также обращаются подрядчики, партнёры, поставщики и ИИ-агенты. По данным поста, отдельные права доступа для работы с данными и сервисами нужны прежде всего ИИ-приложениям и агентам.

## Пять признаков, что пора смотреть в сторону облака

В посте перечислены пять сигналов для организации:

- служба поддержки ИТ тратит больше времени на обслуживание системы, чем на её развитие;
- правила безопасности зависят от того, где физически находится пользователь;
- облачные приложения стали основой работы бизнеса;
- к системам компании обращаются не только штатные сотрудники, но и подрядчики, партнёры и ИИ-агенты;
- компания планирует внедрять инструменты искусственного интеллекта.

Microsoft уточнила, что не призывает полностью отказаться от Active Directory. «Цель не обязательно заменить Active Directory, а снизить зависимость от неё там, где облачная идентификация даёт лучший результат», — говорится в посте. По данным поста, локальный сервер может продолжать поддерживать отдельные устаревшие задачи. Entra ID при этом становится основной платформой для новых сценариев — аутентификации, контроля доступа и работы ИИ-агентов.

Отдельное руководство Microsoft Learn описывает переход как процесс из пяти стадий — от подключения облачной идентичности к существующей Active Directory до полного отказа от локального сервера. [Документация](https://learn.microsoft.com/en-us/entra/architecture/road-to-the-cloud-introduction) обновлена 31 июля 2026 года.
