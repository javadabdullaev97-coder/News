## Предобработка перед prepare-image.py (важно)
Нижняя ~30% часть оригинала (координаты y≈380–542) показывала открытые паспорта
третьих лиц («гражданин А.З. использовал чужие паспортные данные») — там видны
лица людей на паспортных фото. Reporter в notes прямо указал: «Лица людей
показывать нельзя». Это не фигуранты дела, а пострадавшие от использования их
данных — публиковать их лица недопустимо по той же логике, что и лица обвиняемых.

Поэтому перед прогоном через `scripts/prepare-image.py` вручную обрезал источник
по высоте (Pillow `crop((0,0,800,390))`), убрав только зону с открытыми паспортными
фото, сохранив всё содержательное: iPhone-боксы, доллары, титульный лист таможенной
декларации (без личных фото), список IMEI, закрытые обложки паспортов (без лиц).
Это редакционная обрезка по соображениям приватности до подачи в пайплайн, а не
замена работы `prepare-image.py` — все финальные пропорции/качество/сжатие сделаны
скриптом.

## Обработка (`scripts/prepare-image.py`)
```json
{
  "source": {"width": 800, "height": 390},
  "fit": {
    "mode": "cover",
    "scale": 2.3077,
    "cropLoss": 0.1333,
    "offset": [246, 0],
    "upscaled": true,
    "note": "обрезано 13% по ширине; окно кропа выбрано по содержимому; исходник растянут в 2.31× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/tashkent-customs-inspector-iphone-bribe-01.jpg",
    "url": "/images/posts/2026-08/tashkent-customs-inspector-iphone-bribe-01.jpg",
    "width": 1600, "height": 900, "bytes": 235546, "quality": 90
  },
  "status": "ok"
}
```
cropLoss 13.3% — ниже порога 25% для `crop-risky`, вопрос владельцу не нужен.
Апскейл 2.31× — в пределах MAX_UPSCALE=2.5, допустимо (источник из ТГ, публичный
виджет физически не отдаёт больше 800px).

Финальный кадр проверен визуально: полностью в кадре — 10 коробок iPhone, пачки
долларов $3000, декларация, список IMEI; вверху — размытые/тёмные силуэты людей
в кадре съёмки (торсы без лиц, обрезаны по верхней границе кадра) — лиц не видно;
паспорта видны только закрытыми обложками (нижний левый угол), без открытых страниц
с фотографиями.

## Отклонённые варианты
- Полный необрезанный кадр 800×542 напрямую в prepare-image.py — при cropLoss ~17%
  по высоте (реальный расчёт для 800×542 при заливке 1600×900) велик риск, что
  открытые паспортные фото с лицами третьих лиц останутся в кадре — недопустимо
  по требованию reporter'а «лица людей показывать нельзя». Поэтому предварительно
  обрезал зону с паспортными фото вручную, до прогона через официальный скрипт.
- Аватар канала Department_uz (логотип ведомства) — второй `<img>` в HTML поста —
  не брали: это иконка канала 160×160, слишком мал и не иллюстрирует конкретное
  событие (запасной вариант, если бы основного фото не нашлось).
- AI-генерация (Higgsfield) — не понадобилась, т.к. нашлось прямое официальное
  фото вещдоков, полностью подходящее под mainVisualSubject.
