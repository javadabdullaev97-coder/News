# Bild notes: pension-unclaimed-period-24-months (замена главного фото, v2)

## Стратегия: stock (Pexels)

Владелец потребовал заменить исходную картинку — инфографику Минэкономфина,
вписанную в contain-режим с серыми полями по бокам. Инфографика и так
попадает под запрет «Графики, диаграммы, скриншоты таблиц — почти никогда»:
это карточка ведомства с полями, не самодостаточный кадр 16:9.

## Обработка (scripts/prepare-image.py)

```json
{
  "source": {"width": 6240, "height": 4160},
  "fit": {"mode": "cover", "scale": 0.2564, "cropLoss": 0.1562, "offset": [0, 0],
          "upscaled": false, "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому"},
  "output": {"path": "public/images/posts/2026-08/pension-unclaimed-period-24-months-v2-01.jpg",
             "url": "/images/posts/2026-08/pension-unclaimed-period-24-months-v2-01.jpg",
             "width": 1600, "height": 900, "bytes": 206674, "quality": 90},
  "status": "ok", "upscaled": false
}
```

`fit.mode: cover`, `cropLoss: 0.1562` — заливает кадр 1600×900 целиком, без
серых полей, обрезка в пределах требуемых ≤0.25.

## Почему этот кадр

- Живая фотография (не рендер, не инфографика).
- Ландшафтная ориентация, AR 1.5 — покрывает 16:9 без подложки.
- Тематически близко: пожилой человек за столом разбирает квитанции/платёжные
  документы — прямая ассоциация с получением/оформлением пенсионных выплат.
- Лица в кадре нет вообще (только руки и предплечья) — минимальный риск по
  правилу «без крупных опознаваемых лиц частных людей».
- Локация/национальность не выдаются за Узбекистан — это иллюстративный кадр,
  что отражено в alt-тексте (без привязки к конкретному ведомству/стране).

## Отклонённые варианты

- Openverse (`api.openverse.org`, лицензии cc0/pdm): запросы «pension»,
  «elderly hands», «retirement money», «senior citizen bank» и т.п. дали
  в основном нерелевантный архивный Flickr Commons (историческая фотохроника,
  логотипы, не по теме). Отдельно проверена «Elderly Couple» (бронзовая
  статуя в парке, 1024×768, PDM) — отклонена: не документальное фото,
  а скульптура, тематически слабее.
- Pexels-кадры того же фотосета с крупным видимым лицом (id 7545279, 7545298,
  7545307) — отклонены в пользу 7545311 именно из-за лица в кадре: там, где
  можно взять кадр без лица и с тем же сюжетом, лицо в кадре — лишний риск.
- Unsplash/Pexels API без ключа — прямой API недоступен (401/403), сток найден
  через HTML-страницы поиска и прямые CDN-ссылки на изображения.
- Официальных фото о пенсиях в Telegram-канале Минэкономфина нет — только
  служебная аватарка ведомства на обоих релевантных постах.
