# Bild notes: microsoft-patch-tuesday-august-2026

## Стратегия: stock (публичный CC0-банк, Openverse)

Тема техническая, без человека-субъекта (reporter-notes и handoff совпадают:
`mainVisualSubject`/`image-hint` — «экран установки обновлений Windows Update
или обобщённый щит/иконка кибербезопасности», `image-avoid` — «хакер в
капюшоне», лица людей, логотипы источников-СМИ).

## Почему не A (первоисточник)

Все `sources` статьи — это (1) машиночитаемый CVRF-бюллетень MSRC и
JS-рендерящаяся страница advisory (уже отмечено в reporter-notes как
недоступные через WebFetch, там же не изображение, а таблица CVE), (2) NVD —
текстовая база без иллюстраций, (3) Krebs on Security, Tenable, The Hacker
News, Qualys — это СМИ/блоги ИБ-индустрии, не официальные пресс-службы;
их фирменные иллюстрации/лого использовать нельзя (handoff: «без логотипов
сторонних вендоров»). Официального пресс-фото у Patch Tuesday как события
не бывает в природе — переход сразу к стоку.

## Почему не B0 (фототека редакции)

`config/stock-photos.json` содержит только темы `cbu/sum/cash/inflation/
prices/budget/salaries/banking/payments/monetary-policy` — кибербезопасности
и IT-тематики там нет. `node scripts/pick-stock.mjs --topic cybersecurity`
не запускал — по списку тем в манифесте результата не будет.

## Источник картинки

- Поиск через `api.openverse.org` (CC0/PDM, без Wikipedia/Getty/Shutterstock).
- Запрос: `windows update laptop`, фильтр `license=cc0,pdm`, `orientation=wide`.
- Найдено: **«Windows update»** (id `4eea1d55-f4ce-42f9-8818-34513b121419`),
  автор campuscodi, Flickr, лицензия **CC0 1.0**.
  URL: https://live.staticflickr.com/2932/33069346263_95a8c7e965_b.jpg
- Тип: живая фотография физического экрана монитора с процессом установки
  обновлений Windows («Working on updates 4% / Don't turn off your PC») —
  ровно то, что просил `image-hint`. Не рисованная заготовка, не 3D-рендер,
  не скриншот-таблица с мелким текстом.
- Размер оригинала: 1024×768 (соотношение 1,33 — горизонтальный, проходит
  порог «от ~1.3»).

```

  "fit": {
    "mode": "cover",
    "scale": 1.5625,
    "cropLoss": 0.25,
    "offset": [0, 300],
    "upscaled": true,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/microsoft-patch-tuesday-august-2026-01.jpg",
    "url": "/images/posts/2026-08/microsoft-patch-tuesday-august-2026-01.jpg",
    "width": 1600, "height": 900, "bytes": 117628, "quality": 90
  },
  "status": "ok"
}
```

Cover-режим (не contain/подложка) — исходник горизонтальный, что и требуется
правилом от 04.08.2026. Обрезано 25% по высоте (верх/низ), сохранён
текстовый блок «Working on updates 4%» — он остался в кадре целиком и
читаем. `crop-risky` не применяю: это не фотография с животным/человеком/
зданием/документом, где кроп может случайно срезать субъект (§3б), а
экран с текстом, центрированным по вертикали — обрезка полей сверху/снизу
безопасна для смысла кадра.

## Отклонённые варианты

- Wikimedia Commons («Windows 10-11 update screen notice», «Windows 10
  Version 1703 Blue Screen of Death», серверные стойки NERSC) — источник
  в чёрном списке редполитики (Википедия/Wikimedia, раздел 2 SKILL.md),
  не беру вне зависимости от качества и разрешения.
- Rawpixel «Free computer server room image» (1300×731, CC0, датацентр,
  синяя подсветка стоек) — качественный горизонтальный кадр почти точно
  16:9, содержательно подходил бы под «кибербезопасность/серверы», но
  проигрывает по точности теме: материал про патчи Windows конкретно, а не
  про облачную инфраструктуру. Оставлен как запасной вариант, если первый
  кадр забракуют.
- Getty/Reuters/Shutterstock/Depositphotos — не искал намеренно (чёрный
  список платных стоков).
- Higgsfield AI-генерация — недоступна в этом окружении: инструмента
  генерации изображений в наборе тулов нет (тот же вывод, что в прецеденте
  `bild-notes-supreme-court-mobile-reception-tashkent.md`). До неё не дошло,
  т.к. сток нашёлся раньше по порядку попыток.
