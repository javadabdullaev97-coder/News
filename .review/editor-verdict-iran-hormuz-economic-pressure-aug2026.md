## Стилистические правки (применены понижения fact-checker'а + стиль)

- **Понижение №1** (лид) — применено выше.
- **Понижение №2**: «это часть из шести условий Тегерана» → «это часть из шести условий,
  которые, по данным WSJ, выдвинул Мохаммад Багер Зольгадр» — добавил уточнение его роли
  («занимавший на тот момент пост куратора Совета нацбезопасности Ирана»), чтобы имя не
  повисало без контекста до того, как читатель узнаёт о нём в следующем H2.
- **Понижение №3**: «Ранее Резаи публично называл...» → «По данным Financial Times, Резаи
  ранее называл...» — явная атрибуция источнику вместо голого утверждения, раз ни репортёр,
  ни fact-checker не смогли открыть FT напрямую.
- Понижение №4 (возраст Резаи, опциональное) — не применял, см. «Что оставил как есть».
- Пассив → актив: «оно было нарушено» → «Иран нарушил соглашение»; «Право прохода может быть
  закрыто» → «Иран может закрыть право прохода».
- Разбил на два-три предложения пять мест, где было >25 слов: абзац про приватные разговоры
  Трампа (41 слово → два предложения), про цену бензина (26 слов → два), про ограничения
  документа (27 слов → два), про условия Зольгадра (после понижения стало длиннее — тоже
  разбил на два), про биографию Резаи (30 слов → три коротких).
- Убрал «на предмет» канцелярита и AI-slop не потребовалось — в драфте их не было.

- Не трогал frontmatter `publishedAt`/`updatedAt` — их нет в драфте, по прямому указанию
  владельца эти поля не должны появляться на этом этапе конвейера.
