## Условный шаг: разбор кандидатов в источники

Второй приоритет: открывается, только если после основной работы осталось
время.

Смысл один: **смотреть, на кого ссылаются те, кого мы читаем.** Конкурент, ставя в статье ссылку на
ведомство, показывает нам источник, о котором мы не знали, и делает это за
свой счёт. Так каталог пополняется сам, без походов за источниками вслепую.

Копится оно двумя журналами — по одному на вид источника:

| Журнал | Что копит | Кто пишет |
|---|---|---|
| `content/state/channel-candidates.jsonl` | Telegram-каналы из текстов конкурентов | фетчеры, даром |
| `content/state/source-candidates.jsonl` | сайты, на которые ссылаются конкуренты и читаемые каналы | фетчер каналов (даром) и `harvest-source-links.mjs` (8 статей за прогон) |

Если после основной работы осталось время (как с missing-images), разбери
накопленное — оба отчёта:

```bash
node scripts/channel-candidates-report.mjs
node scripts/source-candidates-report.mjs
```

По каждому кандидату реши по контекстам, **какого он типа** — а не «брать
или не брать». Отказ здесь редкость:

- канал называют **официальным** («официальный канал», «расмий канали»,
  «сообщает ведомство в своём канале») → `type: "source"`, приоритет P2,
  `citable: true`, в notes дата и основание;
- пишут **«связывают с…», «близкий к…», «приближённый»** →
  `type: "attributed"` + `attributionFormula` из формулировки;
- **издание, блогер, отраслевой канал, суб-канал конкурента** →
  `type: "signal"`, `citable: false`. Это не отказ, а полноценное
  пополнение: конкурентов мы читаем, чтобы знать повестку, и запрет
  касается только ссылки в нашем тексте. Увидели у них тему — идём
  за первоисточником сами и выпускаем своё. Так `@repostlife` (лайфстайл
  repost.uz) в списке нужен, хотя ссылаться на него нельзя никогда;
- **dismiss только в двух случаях**: канал из `excluded` (полный
  редакционный бан — Ozodlik, Настоящее время, Азон) или это вообще
  не новостной канал (магазин, чат подписчиков, бот поддержки).

Порог наблюдений не нужен: сбор уже отфильтрован от рекламы, самоподписей
и обрывков (см. `lib/channel-candidates.mjs`). Одного упоминания достаточно,
чтобы решить тип.

Решение фиксируй в журнале — иначе кандидат будет копиться вечно:

```bash
node -e "import('./lib/channel-candidates.mjs').then(m =>
  m.markCandidate(process.cwd(), '@handle', 'resolve', { addedAs: 'source' }))"
# или decision 'dismiss' с { reason: '…' }
```

Коммить конфиг и журнал вместе. Новый канал попадает в ротацию фетчера
автоматически. Сомневаешься в статусе канала — оставь копиться, это
бесплатно; не выдумывай тип, которого конкуренты не подтверждали.

### Кандидаты-сайты: то же решение, другая шкала

`source-candidates-report.mjs` отдаёт домены с числом наблюдений, примерами
адресов и контекстом — формулировкой, с которой конкурент на источник
ссылается. По ней и решай, **чем этот сайт является**:

- **ведомство, суд, госкомпания, регулятор** («по данным Минфина», «указано
  на сайте ведомства») → это первоисточник. Заводи в `config/news-sources.json`
  с `citable: true`. Есть RSS — в секцию `rss`; нет — проверь, годится ли
  форма адреса для `htmlScrape`; не годится ни то ни другое — в
  `citableReference`, чтобы право на ссылку зафиксировать даже без забора;
- **международное агентство или профильное издание** → `type: context`,
  `citable` по общему правилу §2 редполитики, обязательно с `bloc`: без
  него запись вне региона отбрасывается фетчером молча;
- **компания, чью новость пересказывает конкурент** → заводи, если это
  повторяющийся источник (банк, оператор, маркетплейс), и пропускай, если
  разовый;
- **dismiss** — перепечатки и агрегаторы без своей редакции, сайты из
  `excluded`, площадки объявлений, магазины, всё, что попало в текст
  рекламой.

**Порог здесь есть, в отличие от каналов.** Одно наблюдение — это, скорее
всего, разовая ссылка в одной заметке; ходовой источник всплывает у разных
конкурентов и в разных статьях. Начинай с `--min=2`, а к одиночкам
возвращайся, когда список двойных разобран:

```bash
node scripts/source-candidates-report.mjs --min=2
```

Решение фиксируй так же, иначе домен будет предлагаться вечно:

```bash
node -e "import('./lib/source-candidates.mjs').then(m =>
  m.markSourceCandidate(process.cwd(), 'lex.uz', 'resolve', { addedAs: 'rss' }))"
# или decision 'dismiss' с { reason: '…' }
```

**Проверять ленту перед заведением обязательно** — тем же способом, что и при
любой правке каталога: `node scripts/check-sources.mjs --id=<новый>`. Адрес,
добавленный без проверки, молча не отдаёт ничего, и обнаруживается это через
неделю по ненаписанной новости.
