## Проверка трёх жёстких триггеров возврата reporter'у

- **Триггер 2 (снятие абзаца со ссылкой по своей инициативе)** — не сработал: ни в одном
  из трёх удалённых абзацев не было inline-ссылки на источник, а удаление в любом случае
  предписано списком понижений fact-checker'а (явное исключение из правила).
- **Триггер 3 (новая ссылка/новый источник)** — не сработал: ссылок и записей в
  `frontmatter.sources` не добавлял, только сместил формулировку вокруг уже
  существующей ссылки на daom.tsue.uz.
- **Триггер 1 (>15% слов тела)** — формально сработал бы при обычной правке: снято
  ≈108 слов из ≈296 (≈37%). Это НЕ инициативная правка структуры редактором — это
  прямое исполнение обязательного списка понижений fact-checker'а по трём конкретным
  пунктам («было → стало» / «убрать вместе с абзацем»), для которого по регламенту
  раздела approve-with-downgrades возврат reporter'у прямо отменён («цикл «верни на
  доработку» упразднён... Понижения... поводом для back-to-reporter не являются
  никогда»). Фиксирую цифру для прозрачности маршрутизации, но не трактую как повод
  для `back-to-reporter`, так как источник удаления — не моя инициатива, а мандат
  fact-checker'а.

Требование «нужно новое исследование» (единственный легитимный повод для
back-to-reporter после approve-with-downgrades) — не применимо: центральный факт
(бакалавриат ТГЭУ, постановление №248, дуальная программа 3+1, два диплома, ВШГА,
меморандум 2025 года) подтверждён полностью, второе исследование не требуется.
