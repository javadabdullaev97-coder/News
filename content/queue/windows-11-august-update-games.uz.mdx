Microsoft 2026-yil 19-avgustda Windows 11 kompyuterlaridagi o'yinlardagi nosozliklarni tekshirayotgani haqida [xabar berdi](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-25h2): tizimning avgust yangilanishidan keyin o'yinlar muallaq qolmoqda, ogohlantirishsiz yopilmoqda yoki kompyuterni qayta ishga tushirib yubormoqda.

Gap 11-avgustda chiqqan KB5121003 yangilanishi haqida bormoqda. U kumulyativ (to'plamli): bunday paket oxirgi safardan beri chiqarilgan barcha Windows tuzatishlarini bir yo'la jamlaydi. KB harflari Knowledge Base — Microsoft'ning har bir yangilanish o'z raqamli maqolasiga ega bo'lgan bilimlar bazasidan olingan. Yangilanish build raqamini — Windows versiyasining ichki identifikatorini — 26100.9168 gacha ko'tardi.

[Windows release health sahifasi](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-25h2)ning ma'lum muammolarga bag'ishlangan bo'limi ma'lumotlariga ko'ra, yangilanish o'rnatilgandan so'ng ba'zi o'yinlar javob berishni to'xtatadi. O'yinlar, shuningdek, "EXCEPTION_ACCESS_VIOLATION" xatosi bilan ogohlantirishsiz yopiladi yoki kompyuterning kutilmagan qayta ishga tushishiga sabab bo'ladi. Microsoft "cheklangan sonli o'yinlar" ta'sirlanganini ma'lum qiladi va ARC Raiders, MARVEL Tōkon: Fighting Souls va The Finals'ni misol qilib keltiradi.

Muammo [Windows 11'ning 25H2 va 24H2 versiyalari](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-24h2)ga, ya'ni foydalanuvchi kompyuterlariga tegishli. Yozuvda ta'kidlanishicha, Windows'ning server nashrlariga u taalluqli emas.

Yozuv holati — «Investigating» («tekshirilmoqda»). Microsoft «bu muammo kompaniya tomonidan amalga oshirilgan harakatlar natijasida yuzaga kelgan-kelmaganini hozirda aniqlashtirayotganini» ma'lum qildi. Kompaniya yangi ma'lumotlar paydo bo'lishi bilanoq ularni taqdim etishini bildirdi.

Microsoft Learn yozuvidan ko'rinishicha, KB5121003 yangilanishi hozircha bekor qilinmagan yoki to'xtatilmagan. Yozuv tuzilmasida na tarqatishni to'xtatish, na tuzatish haqida band mavjud. Kompaniya rasmiy vaqtinchalik yechim ham taklif qilmagan.

Nosozlikka duch kelganlarga Microsoft Feedback Hub ilovasi orqali xabar berishni taklif qiladi. Bu Windows'ga o'rnatilgan, tizim muammolari haqida fikr-mulohaza yuborish uchun mo'ljallangan vosita.

Muammo haqidagi yozuv 19-avgust kuni Tinch okeani vaqti bilan soat 17:50da ochilgan, sahifadagi so'nggi yangilanish esa shu kunning 17:53ida kiritilgan.
