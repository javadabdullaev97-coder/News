Исходник горизонтальный (соотношение 1,5:1), обрезка 15,6% по высоте — ниже порога
0,25 для `crop-risky`, лицо и верх корпуса хокима в кадре целиком, эскалация к
владельцу не требуется. Апскейл 2,0× — в пределах `MAX_UPSCALE=2.5` текущей версии
скрипта (заливка кадра без блюра/подложки по бокам — предпочтительнее contain для
телеграм-исходника ≤800px согласно `image-pipeline.md`). Итог — чистый cover-кроп
1600×900 без подложки, полей и блюра.
