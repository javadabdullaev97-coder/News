# Reporter notes: tashkent-air-pollution-aug21

## Тема
21 августа Узгидромет зафиксировал превышение ПДК по PM10 в воздухе Ташкента
в 1,37 раза (103 мкг/м3 при норме 75 мкг/м3). Это самый высокий утренний/
вечерний замер за последние сутки — 20 августа вечером превышение было
существенно меньше (1,09 раза). PM2,5 в норме.

## Первоисточники (проверенные)
- https://t.me/uzgydromet/22041 (21.08.2026, замер на 09:00) — PM10 103 мкг/м3
  (1,37х ПДК), PM2,5 29 мкг/м3 (в норме). Совпадает дословно с текстом из
  инбокса, узбекский и русский варианты сверены через публичный превью
  t.me/s/uzgydromet.
- https://t.me/uzgydromet/22038 (20.08.2026, замер 18:00) — PM10 82 мкг/м3
  (1,09х ПДК), PM2,5 22 мкг/м3. Использовано для сравнения тренда.
- https://t.me/uzgydromet/22040 (20.08.2026, прогноз на 21.08.2026) —
  температура 36–38°C, ветер 10–12 м/с с порывами, возможны пыльные бури
  в отдельных районах. Использовано как контекст погоды, без причинной
  связи с превышением PM10 — такая связь в источнике не заявлена.

Дополнительно в превью канала видел другие замеры за 19–20 августа (19.08
18:00 — PM10 88 мкг/м3, 1,17х; 20.08 09:00 — PM10 85 мкг/м3, 1,13х), но не
смог зафиксировать точный постоянный URL каждого поста, поэтому в текст их
не включил — использован только один сравнительный пункт с подтверждённой
ссылкой (22038).

## Расхождения с inbox-снипетом
Расхождений не найдено — цифры PM10 (103 мкг/м3, превышение 1,37 раза) и
PM2,5 (29 мкг/м3, без превышения) в первоисточнике совпадают с инбоксом.

Отдельно: снипет Repost.uz (AQI=68, «в три раза выше нормы ВОЗ по PM2,5»)
в статью не включён. Repost.uz — в чёрном списке источников редполитики
LEAP (используется только для мониторинга, не как источник в тексте). Задание
допускало такой вариант отдельной строкой: «если не сможешь корректно
развести два стандарта без путаницы — лучше дать материал только на данных
Узгидромета». Выбран этот вариант.

## Что не вошло в статью
- Сравнение с годовым ориентиром ВОЗ по PM2,5 и индекс AQI — источник только
  Repost.uz (чёрный список), решил не включать.
- «Рекомендации Минздрава при высоком уровне пыли» — не искал, бюджет
  фетчей экономил, задание не требовало обязательно. Возможна отдельная
  заметка при появлении официального релиза санэпидслужбы.
- Возможная связь превышения PM10 с прогнозируемыми пыльными бурями — не
  подтверждена источником, оставлена как параллельный факт без причинной
  связи.
