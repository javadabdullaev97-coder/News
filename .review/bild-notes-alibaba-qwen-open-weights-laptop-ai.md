# Bild notes: alibaba-qwen-open-weights-laptop-ai

## Стратегия: stock (тематический, живая фотография)

## Ход подбора

1. **`mainVisualSubject` из reporter-notes**: явного физического субъекта нет
   (релиз весов модели) — reporter прямо пишет «нейтральная иллюстрация:
   логотип Qwen/Alibaba Cloud рядом с ноутбуком, либо скриншот карточки
   модели на Hugging Face». Handoff (`image-hint`) даёт тот же ориентир:
   логотип + ноутбук/игровой ПК, тема «модель запускается на обычном
   компьютере»; `image-avoid` — стоковые «роботы» и клише нейросетей,
   логотип Meta не крупнее логотипа Qwen.

2. **A — первоисточник**. Проверил карточки моделей на Hugging Face
   (`Qwen/Qwen3.8-2.4T-A95B`, `Qwen/Qwen3.8-27B`) — только квадратный
   аватар организации Qwen, 200×200 (WebP) → меньше `MIN_SOURCE=600`,
   `status: too-small` заведомо. Проверил репозиторий `QwenLM/Qwen3.8` на
   GitHub (README) — есть только бенчмарк-графики (`qwen3.6_27b_score.png`
   и т.п.), это инфографика/диаграммы — по правилу «графики — почти
   никогда» не годится, там всё держится на мелких подписях и легенде,
   без полного кадра нечитаемо. Общий вордмарк `logo_qwen3.png` (3944×1555,
   landscape) нашёл в README `QwenLM/Qwen3` — но это плоский логотип на
   белом фоне без единого содержательного элемента (текст «Qwen3» + значок),
   относится к семейству Qwen3, а не конкретно к Qwen3.8, и как самостоятельный
   герой-кадр выглядит пусто — отклонил. Alibaba Cloud blog (`alibabacloud.com/blog`)
   вернул 503 — недоступен.

3. **B0 — фототека редакции** (`config/stock-photos.json`): темы только
   `cbu/sum/cash/inflation/prices/budget/salaries/payments/banking` — под
   AI/tech ничего нет, `pick-stock.mjs` не запускал, тема явно не входит
   в список.

4. **B1 — Unsplash**. Поиск `laptop-artificial-intelligence` — ничего
   документального по теме (роботы, случайные ноутбуки, чип на плате —
   без прямой связи с «локальный запуск модели на видеокарте»). Поиск
   `gpu-graphics-card` дал прямое попадание: `GEFORCE RTX` в системном
   блоке — буквально то, о чём пишет статья («рабочих станциях и игровых
   ПК с одной видеокартой»), живая фотография, без людей, без стороннего
   бренда-конкурента, документальный стиль, надпись читается полностью.

5. **C — AI-генерация**: не потребовалась, тематический сток прошёл все
   фильтры.

  генерации (это не генерация, а чужой логотип на белом, а не на графитовом/

видеокартой») и проходит все фильтры (живая фотография, горизонтальная
ориентация, свободная лицензия с атрибуцией, без людей, без клише
«робот/нейросеть»). Минус от 100%: это НЕ фото официального релиза
Alibaba/Qwen и не содержит прямой визуальной привязки к бренду Qwen —
связь с темой родовая («модель, которую можно гонять на такой видеокарте»),
а не буквальная («это видеокарта, на которой Alibaba тестировала Qwen3.8»).
