# Bild notes: namangan-new-bridge-katta-namangan-canal (rework iteration 1)

## Стратегия: stock (тематический, разовое смягчение subject-first по решению владельца)

## Контекст: почему сток без строгой геопривязки
Владелец на предыдущей итерации ответил односложно «Стор» на вопрос про
картинку; reporter (см. `.review/rnotes-...md`) интерпретировал это как
опечатку «Сток» и зафиксировал разовое разрешение смягчить правило №1
(subject-first) именно для этой темы: мост физически ещё не построен, точного
кадра нет и не может быть, первоисточник (`t.me/Namanganpress/7`) текстовый,
без медиа. Разрешено взять тематический сток-кадр «канал + мостик» без
привязки к Наманганской области. Беру это прочтение как рабочее, как и
reporter/editor до меня.

## Источник картинки
- Площадка: Unsplash (проверено через прямой CDN-URL `images.unsplash.com`,
  official Unsplash License — свободное коммерческое использование).
- Фото: «A straight canal runs through green fields at sunset»,
  автор Bernd Dittrich (@hdbernd), unsplash.com/photos/xtnNxHJZY_Y.
- Почему это фото: аэросъёмка прямого мелиоративного/дренажного канала,
  который пересекает небольшой пешеходно-автомобильный мостик ровно на
  пересечении асфальтовой и грунтовой дорог — композиционно это именно тот
  тип объекта, о котором статья («мост через канал на пересечении дороги»),
  просто в другой стране (похоже на Германию/Западную Европу, не Узбекистан).
  Это честный тематический сток в духе разрешения владельца, а не попытка
  выдать его за реальный объект — geo-привязки в alt нет, наоборот явно
  оговорено, что это иллюстративный кадр.
- Скачано напрямую по прямой ссылке `images.unsplash.com/photo-1777063012124-...`
  (2400×1399), без API-ключа — то есть «прямая ссылка на фото под Unsplash
  License», что разрешено редполитикой даже без `UNSPLASH_ACCESS_KEY`.

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 2400, "height": 1399},
  "fit": {
    "mode": "cover",
    "scale": 0.6667,
    "cropLoss": 0.035,
    "offset": [0, 0],
    "upscaled": false,
    "note": "обрезано 4% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/namangan-new-bridge-katta-namangan-canal-01.jpg",
    "url": "/images/posts/2026-08/namangan-new-bridge-katta-namangan-canal-01.jpg",
    "width": 1600, "height": 900, "bytes": 335154, "quality": 90
  },
  "status": "ok"
}
```
Исходник горизонтальный (2400×1399, AR≈1.72, близко к 16:9) — cover без
апскейла, обрезка всего 4% по высоте. Подложка (contain) не потребовалась.
cropLoss далеко ниже порога 0.25 для `crop-risky`, и на этом кадре нет
единого хрупкого объекта (лица/животного), который обрезка могла бы
испортить — вопрос владельцу по этой причине не нужен.

## Отклонённые варианты
- `t.me/Namanganpress/7` (единственный первоисточник события) — пост без
  медиа (`?embed=1` → `text_not_supported_wrap`), только аватар канала
  160×160 (too-small, не по теме).
- `president.uz/ru/lists/view/8494` — 7 фото в слайдере, все с другого
  мероприятия (совещание в зале), не канал/мост — не по теме конкретной
  статьи.
- `namangan.uz` — SPA без доступного публичного API под конкретную новость.
- Openverse-кандидаты из Ирландии/Пакистана/Уэльса/Китая («Mullingar Half
  Marathon», «West Cross Mosque, Langzhou» и т.д.) — либо люди крупным
  планом (риск при использовании чужих лиц без повода), либо откровенно
  урбанистический английский канал с лодками-баржами и рекламными
  постерами/граффити в кадре (`BCN Main Line Canal — Wolverhampton») —
  visually слишком специфично «Англия», отвлекает сильнее, чем помогает,
  и хуже по кадрированию (портит смысл сильнее, чем помогает донести тему).
- Unsplash-кандидаты «stone bridge over dried-up creek», «brown concrete
  bridge over river», «concrete stairs beside water» — по описанию не
  показывают именно канал+мост на пересечении дороги (либо пересохшее
  русло, либо просто ступени), выбранный кадр точнее по смыслу.

## Alt-текст
«Небольшой мост через узкий ирригационный канал на пересечении грунтовой и
асфальтовой дорог среди сельских полей на закате — иллюстративный кадр, не

Специально прямым текстом в alt оговорено «не место в Наманганской
области» — чтобы у читателя скринридера/поисковика не создавалось ложное
впечатление, что это фотография конкретного объекта из статьи.

## Уверенность в подборе: 55%
Технически кадр обработан образцово (минимальный кроп, без апскейла,
честная лицензия, прозрачный credit). Понижаю с обычных 80–90% до 55%,
потому что: (1) интерпретация «Стор» → «Сток» ещё не подтверждена
владельцем напрямую, это цепочка выводов reporter'а; (2) кадр не
географически точен и не показывает реальный объект статьи — по духу это
разовое исключение из subject-first, а не штатный подбор. Финальное слово
по картинке в этом rework-цикле в любом случае остаётся за владельцем через
editor-queue (`reason: rework-ready`) — эти notes ему стоит показать вместе
с превью, чтобы решение принималось с полной картиной, а не только по
описанию.
