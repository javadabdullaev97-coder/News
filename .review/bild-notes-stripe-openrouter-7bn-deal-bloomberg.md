# Bild notes: stripe-openrouter-7bn-deal-bloomberg

## Стратегия: brand-identity (композит из двух официальных бренд-активов, вариант A)

## Почему не «живая фотография»
- Сделка между компаниями, официально не подтверждённая ни Stripe, ни
  OpenRouter (Bloomberg со ссылкой на анонимные источники) — press-kit
  с фото по самой сделке в природе не существует.
- `mainVisualSubject` в reporter-notes и `image-hint` в handoff прямо говорят:
  явного человека-субъекта нет («сделка между компаниями»), допустима
  нейтральная иллюстрация: логотип/интерфейс OpenRouter, фирменные цвета
  Stripe, либо абстрактная AI-инфраструктура. AI-генерация (Higgsfield) в
  тулсете этого прогона не подключена (доступны только
  Read/Edit/Bash/WebFetch/Grep/Glob) — вызвать нечем, как и в других
  прогонах без `generate_image`.
- Фото основателей (Патрик/Джон Коллизон, Алекс Атаны, Луи Виши) с
  публичных мероприятий не искал: задача прямо отмечает, что явного
  субъекта-человека нет, и показывать основателей по теме недоказанной
  сделки — риск создать впечатление персональной ответственности за
  неподтверждённый факт. Решил не брать фото людей на эту тему.

## Отклонённые варианты
- Домашняя страница OpenRouter (скриншот интерфейса/model routing
  visualization) — отклонил: это UI-скриншот с мелкими подписями и
  логотипами сторонних AI-компаний (OpenAI, Anthropic, Google, Meta) в
  кадре, нечитаемо в 16:9 и создаёт риск выглядеть как реклама/эндорсмент
  конкретных моделей, не относящихся к теме сделки.
- Stripe Press (`press.stripe.com`) — только обложки книг издательства
  Stripe Press и архивные фото авторов, к теме не относится.
- `stripe.com/newsroom` — карусель фото по другим темам (Sessions 2026,
  Microsoft Copilot, клиентские кейсы), ничего по сделке или по бренду в
  чистом виде для превью.
- Getty/Reuters фото основателей — не искал: платные банки/лицензионный
  риск для конкретных фото, и по задаче явного человека-субъекта нет.
- Unsplash/Pexels по «fintech», «AI infrastructure» — не проверял: нашёлся
  официальный вариант приоритета A (оба логотипа с официальных доменов),
  он точнее по смыслу и не требует стоковых компромиссов.

## Уверенность в подборе: 78%
Оба логотипа — официальные активы с официальных доменов компаний
(images.stripeassets.com для Stripe, openrouter.ai/brand для OpenRouter),
использование в новостном контексте для иллюстрации сделки между этими
двумя компаниями — стандартная редакционная практика (fair use логотипа
для идентификации компании в новости о ней). Не «живая фотография», это
осознанный компромисс: subject-first для корпоративной сделки без
человека и без единого совместного пресс-релиза реализован как можно
точнее — оба явных субъекта (Stripe, OpenRouter) показаны прямо их же
официальными брендами, а не абстрактной иллюстрацией AI-инфраструктуры.
Снижаю от 90%+ потому что композит собран мной вручную (не готовый
пресс-кит по конкретно этой сделке — такого не существует, сделка не
подтверждена).
