# Editor verdict: tashkent-contraband-cigarettes-phones

## Решение: publish

Материал содержательно готов к публикации. **Маршрут при этом — не directPublish**:
единственный источник — Telegram-канал «Xavfsizlik» (`type: "attributed"` в
`config/telegram-channels.json`), а `directPublish.gates.forbiddenSourceTypes`
блокирует прямую публикацию для attributed-источников независимо от вердикта
и confidence (appendix 2.3, п. 4). Финальный маршрут — через владельца
(`content/needs-verification/<slug>.mdx`, `pendingEditorQuestion`,
`reason: "source-doubt"`) — решает планёрка на следующем шаге, не я. См. HANDOFF.

## Применённые понижения fact-checker'а (approve-with-downgrades, 4 шт.)

1. **КРИТИЧНО.** Убрал «данные о задержанных в публикации не указаны» (фактически
   неверно — в источнике есть годы рождения и район причастных лиц, редакция их
   не публикует по своей политике) → заменил на «Личные данные причастных лиц
   издание не приводит до предъявления официального обвинения».
2. Смягчил «конкретная статья Уголовного кодекса… в публикации не указана» →
   «Статью Уголовного кодекса издание не приводит» (без утверждения об
   отсутствии в источнике).
3. Разбил 29-словное первое предложение абзаца 1 на два: лид (25 слов, содержит
   что+где+когда+цифры) + предложение с атрибуцией каналу (дословная формула
   `attributionFormula` сохранена без изменений).
4. Добавил дату («21 августа») во frontmatter `description` и сократил его до
   140–160 символов (было 181 символ — не проходило по длине).

Понижения применены механически, без нового исследования и без возврата
reporter'у — фактчек это прямо разрешает.
