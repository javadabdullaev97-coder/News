# Editor verdict: deepseek-model-vs-anthropic-opus

## Решение: publish

## Изменения в заголовке
**До**: DeepSeek представила тестовую модель ИИ, близкую по качеству к Opus 4.8
**После**: без изменений.
Обоснование: заголовок уже соответствует правилам — 71 символ (60–90), субъект
(DeepSeek) и глагол действия (представила) попадают в первые 60 знаков, нет
CAPS/восклицаний/оценочных слов, названия издания в конце нет. Fact-check
подтвердил чек-лист по заголовку без замечаний — трогать не стал.

## Изменения в лиде
**До**: «DeepSeek 21 августа представила экспериментальную модель искусственного
интеллекта DeepSeek-V4-Flash-Vision-Exp с распознаванием изображений, заявив,
что по агентным задачам с визуальным вводом она приближается к модели Opus 4.8
разработки Anthropic, сообщает Bloomberg» (30 слов, одно предложение).
**После**: «DeepSeek 21 августа представила экспериментальную модель
искусственного интеллекта DeepSeek-V4-Flash-Vision-Exp с распознаванием
изображений, сообщает Bloomberg. Компания заявила, что по агентным задачам
с визуальным вводом новая модель приближается к Opus 4.8 разработки Anthropic.»
(14 + 17 слов).
Обоснование: fact-check отдельно отметил нарушение чек-листа «ни одно
предложение не длиннее 25 слов» — лид в 30 слов был именно таким
предложением. Требование §9 редполитики о максимуме 25 слов на предложение
жёстче формата «лид = одно предложение 25–30 слов» из §4 — оставлять
предложение длиной 30 слов недопустимо, поэтому разбил на два без потери
фактов: дата, субъект, действие (представила), атрибуция (Bloomberg) остались
в первом предложении, сравнение с Opus 4.8 — во втором. Ни одного нового
факта не добавлено.

## Стилистические правки
- Абзац 2: применил обязательное понижение fact-checker'а — убрал слово
  «флагманской» (источник подтверждает только «официальной»/паритет),
  заменил на «текстовой модели DeepSeek-V4-Flash».
- Абзац 3 (бывший, ныне абзац с частотой упоминаний бенчмарков): разбил два
  предложения длиной 27 и 29 слов на четыре предложения по 21/10/15/13 слов —
  нарушение лимита в 25 слов было в обоих. Факты (паритет на текстовых
  задачах, прирост на визуальных бенчмарках, приближение к Opus 4.8) не
  тронуты, только синтаксис.
- Остальные абзацы (бенчмарки-цифры, доступ через API) уже укладывались
  в лимит 25 слов — не трогал.
- Проверил атрибуцию: «заявила», «сообщает», «привела» — нейтральные глаголы,
  оценочных без основания нет. Сравнение с Opus 4.8 везде подано как
  заявление DeepSeek, а не как факт — vendorSpeaksAboutItself соблюдён.
- AI-slop, канцелярит, расщеплённые сказуемые, цепочки родительного падежа —
  не найдены, править нечего.
- Архитектура: новость об одном событии, H2 нет — верно для жанра, концовки
  «Что дальше» нет — так и должно быть (нет названной даты/шага).

## Технологический канал (Telegram)
- `techNeverToMainChannel` явно перечисляет и «анонсы… моделей», и
  «бенчмарки, тесты, сравнения производительности» — обе позиции точно
  описывают этот материал. Ворот `techMainChannelGates` не нашёл: нет
  влияния на пользователей в Узбекистане, нет массового продукта, нет смены
  расклада индустрии или решения регулятора, нет инцидента безопасности.
  `MAIN_CHANNEL_GATE` не проставляю — материал остаётся в технологическом
  канале, это не понижение, а штатный маршрут для такой темы.
- Качественные модификаторы (§Шаг 6 таблица) — ни один не применим:
  не affectsEveryone (не тарифы/транспорт/госуслуги), не actionable (нет
  действия читателя со сроком), не money (нет суммы/тарифа/ставки — только
  баллы бенчмарков), не impactUzbekistan (нет узбекского измерения), не
  exclusive (первоисточник — вендор, но факт уже в Bloomberg, конкуренты
  наверняка тоже написали), не historicalImportance (обычный релиз
  экспериментальной модели, не рекорд/не «впервые за N лет»), не ephemeral
  (это не разовое мероприятие с сроком жизни в часы), не trulyNiche
  (тема ИИ-моделей — не аудитория <5% для tech-читателя). Возвращаю `none`.
