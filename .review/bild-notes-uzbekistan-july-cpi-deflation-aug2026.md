## Обработка
`python3 scripts/prepare-image.py /tmp/original.jpg uzbekistan-july-cpi-deflation-aug2026 --month=2026-08`

```json
{
  "source": {"width": 3000, "height": 1993},
  "fit": {
    "mode": "cover",
    "scale": 0.5333,
    "cropLoss": 0.1533,
    "offset": [0, 163],
    "upscaled": false,
    "note": "обрезано 15% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/uzbekistan-july-cpi-deflation-aug2026-01.jpg",
    "url": "/images/posts/2026-08/uzbekistan-july-cpi-deflation-aug2026-01.jpg",
    "width": 1600, "height": 900, "bytes": 387279, "quality": 82
  },
  "status": "ok",
  "upscaled": false
}
```

cropLoss 15,3% — ниже порога 0,25 (`cropRiskThreshold`), обрезка чисто
вертикальная (немного верхнего баннера палатки и полосы асфальта внизу),
главный сюжет (корзины с товаром, ценники, женщина в кадре) сохранён
полностью. Эскалация `crop-risky` не требуется. Горизонтальный исходник —
подложка/contain не применялись.
