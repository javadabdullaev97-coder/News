## Ключевой вопрос: цитируемость Sputnik Узбекистан

В `config/generated/source-index.json` два объекта Sputnik: `sputnik-uz` (RSS, type context, без citable:true — как ТАСС/РИА, для которых редполитика разрешает только фиксацию официальной позиции РФ) и `sputnikuzbekistan` (Telegram, type signal — «конкурентное СМИ, сигнал, не цитируем»). Ни там ни там citable:true не стоит.

Материал не про фиксацию позиции РФ, а ретрансляция местной узбекской новости для местной аудитории — ровно роль ретранслятора. Дополнительно: anhor.uz/podrobno.uz (которые репортёр приводил как независимые подтверждения) сами в чёрном списке §2 как узбекские СМИ.

**Вывод: абзац про Баходирову и цифра «300+ спортсменов из 29 стран» опираются исключительно на нецитируемый источник — подлежат удалению, а не понижению до атрибуции** (не «живое событие» с плавающей цифрой — статичный факт, для которого либо есть документ, либо утверждение снимается).
