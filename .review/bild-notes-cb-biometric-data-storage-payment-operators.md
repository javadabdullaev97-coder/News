# Bild notes: cb-biometric-data-storage-payment-operators

## Стратегия: primary-source

## Ход поиска
1. `mainVisualSubject` от reporter: явного субъекта нет (тема техническая,
   регуляторная) — предложено здание ЦБ РУз либо нейтральная иллюстрация
   биометрии/цифровой идентификации без человека.
2. Первым делом проверил `sources[0]` — https://t.me/centralbankuzbekistan/13400
   (получил HTML через `?embed=1`, т.к. обычный WebFetch не рендерит медиа
   Telegram-виджета). В посте нашлось приложенное изображение —
   но это не фото, а текстовая карточка-анонс (логотип ЦБ + заголовок
   "Biometrik ma'lumotlarni saqlash bo'yicha yangi talablar joriy etildi"
   на белом фоне, 800×349). Отклонил: это не «живая фотография» и не
   содержательная инфографика с цифрами — чисто текстовый баннер, который
   на 1600×900 при таком соотношении (2.29:1) пришлось бы либо сильно
   растягивать по высоте, либо обрезать логотип/текст. Не подходит под
   subject-first и под правило «графики/текстовые карточки — почти никогда».
3. Перешёл к варианту B из инструкции reporter'а — здание ЦБ РУз.
   Проверил официальный сайт cbu.uz (`og:image` главной страницы) —
   нашёл `https://cbu.uz/upload/media/images/social.jpg`: живое фото
   фасада здания ЦБ Узбекистана (характерные стеклянные шахты лифтовых
   башен), горизонтальное, 1110×740 (соотношение 1.5 — landscape,
   проходит порог ориентации). Это официальное репрезентативное
   изображение самого ЦБ (стоит у него в og:image), явный субъект темы
   (регулятор, издавший постановление) — подходит под правило subject-first
   лучше, чем нейтральная стоковая иллюстрация биометрии.

## Источник картинки
- URL: https://cbu.uz/upload/media/images/social.jpg
- Тип: официальное фото здания ЦБ РУз (og:image главной страницы cbu.uz)
- Размер оригинала: 1110×740 → cover, масштаб 1.4414×, обрезано 15.6% по
  высоте (окно кропа по содержимому, offset [0, 167]) → 1600×900
  (235 347 байт, quality 90)
- `prepare-image.py` output:
  ```json
  {
    "source": {"width": 1110, "height": 740},
    "fit": {
      "mode": "cover", "scale": 1.4414, "cropLoss": 0.1562,
      "offset": [0, 167], "upscaled": true,
      "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.44× ради заливки кадра"
    },
    "output": {
      "path": "public/images/posts/2026-08/cb-biometric-data-storage-payment-operators-01.jpg",
      "url": "/images/posts/2026-08/cb-biometric-data-storage-payment-operators-01.jpg",
      "width": 1600, "height": 900, "bytes": 235347, "quality": 90
    },
    "status": "ok"
  }
  ```
  Апскейл 1.44× — в пределах допуска скрипта (MAX_UPSCALE=2.5), обрезка
  15.6% — в пределах MAX_CROP (0.45) и ниже порога crop-risky (0.25),
  человек оператор не проверял отдельно т.к. это не фото человека/животного
  с риском отрезать лицо, а архитектурный кадр без критичных деталей у
  краёв обрезки (срезано небо сверху/снизу, не сама башня).
- Визуальная проверка результата: башня и фасад полностью в кадре,
  ничего важного не срезано.

## Отклонённые варианты
- Telegram-карточка из первоисточника (800×349) — текстовый баннер-анонс
  с логотипом, не фотография; отклонён как «графика/текстовая карточка»
  по правилу редполитики.
- AI-генерация через Higgsfield не потребовалась — нашлось официальное
  живое фото ЦБ, оно приоритетнее по порядку стратегий (A выше B/C).
