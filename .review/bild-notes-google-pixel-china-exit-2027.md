# Bild notes: google-pixel-china-exit-2027

## Стратегия: primary-source

## Источник картинки
- Страница: https://blog.google/intl/en-in/products/hardware/the-pixel-11-series-your-most-personal-pixel-yet/
  (официальный блог Google The Keyword)
- Прямой URL картинки: https://storage.googleapis.com/gweb-uniblog-publish-prod/images/NFG_Cubs_Frost.width-2000.format-webp.webp
- Тип: официальное пресс-фото Google (product shot Pixel 11 в цвете Frost,
  вид спереди и сзади), без людей, без текста на кадре
- Размер оригинала: 1920×1080 (соотношение 1,78 — горизонтальный кадр)

## Почему это фото, а не завод/конвейер/карта
Тема — перенос производства Pixel из Китая во Вьетнам и Индию, но живого фото
конкретной производственной линии Google/партнёров (Foxconn/BYD Electronics)
в открытом доступе нет — у Nikkei Asia основной текст за пейволлом, фото не
видно. По subject-first при отсутствии фото самого события берём фото
главного продукта темы — смартфон Pixel, прямой узнаваемый визуальный
субъект. Карта Китай/Вьетнам/Индия из handoff была запасным вариантом, но
готового официального продукт-шота оказалось достаточно и он приоритетнее
абстрактной схемы.

## Почему не тот же кадр, что уже стоит у google-pixel-china-exit (без -2027)
Это две мдх-статьи об одной новости (разные слаги, тот же день). У соседней
уже стоит фото ProandProXL с той же страницы blog.google. Чтобы не повторять
кадр в ленте (см. правило про повтор одного снимка на несколько материалов),
взял ДРУГОЙ файл с той же официальной страницы — NFG_Cubs_Frost (другой цвет,
другая компоновка кадра). photo-dupes.mjs подтвердил: кадр за 2 дня не выходил.

## Обработка
python3 scripts/prepare-image.py → cover, scale 0.8333, cropLoss 0.0 (обрезки
нет), upscaled: false, результат 1600×900, 76 692 байт, quality 90.

```json
{
  "source": {"width": 1920, "height": 1080},
  "fit": {"mode": "cover", "scale": 0.8333, "cropLoss": 0.0, "offset": [0,0], "upscaled": false,
          "note": "обрезано 0% по высоте; окно кропа выбрано по содержимому"},
  "output": {"path": "public/images/posts/2026-08/google-pixel-china-exit-2027-01.jpg",
             "url": "/images/posts/2026-08/google-pixel-china-exit-2027-01.jpg",
             "width": 1600, "height": 900, "bytes": 76692, "quality": 90},
  "status": "ok",
  "upscaled": false
}
```

## Проверка на повтор
`node scripts/photo-dupes.mjs --check` на исходнике перед обработкой — «свободен,
за 2 дн. этот кадр не выходил». Дополнительно сверил визуально: не совпадает
ни с google-pixel-china-exit-01.jpg (ProandProXL, другой цвет и ракурс), ни с
google-pixel11-madebygoogle-2026-01.jpg (Family-Shot всех 4 цветов).

## Отклонённые варианты
- The_Pixel_11_Series_ProandProXL.width-1200... — уже использован для
  соседней статьи google-pixel-china-exit (без -2027), пропущен во избежание
  повтора кадра в ленте за один день.
- Pixel-11ProXL_Family-Shot.width-1200... — уже использован ранее для
  google-pixel11-madebygoogle-2026-01.jpg, пропущен по той же причине.
- Карта/схема Китай-Вьетнам-India (упомянута в handoff как альтернатива) —
  не понадобилась, готовое официальное фото продукта приоритетнее
  самодельной схемы.
- Higgsfield-генерация не понадобилась — официальное фото найдено.

## Уверенность в подборе: 80%
Официальный источник (blog.google), subject-first (сам продукт Pixel, о
переносе производства которого статья), горизонтальный кадр без обрезки
(cropLoss 0%), без людей и логотипов конкурентов (соответствует image-avoid
из handoff). Кадр не дублирует уже вышедший в тот же день для соседней
статьи об этой же новости. Минус от максимума — фото не иллюстрирует именно
географию переноса (Вьетнам/Индия/Китай), это ограничение темы: живых фото
по конкретному событию утечки не существует.
