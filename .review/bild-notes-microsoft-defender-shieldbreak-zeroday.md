# Bild notes: microsoft-defender-shieldbreak-zeroday

## Стратегия: stock (Unsplash, живая фотография)

## mainVisualSubject / image-hint
Reporter-notes: «Нет узнаваемого человека или здания — тема про программную
уязвимость. Подойдёт логотип/иконка Windows Defender (щит), экран Windows
Security, либо абстрактная графика с кодом/замком.»
Handoff (image-hint/image-avoid): то же самое + явный запрет на стокового
«хакера в толстовке с капюшоном», логотип Microsoft как основной элемент,
алармистскую подачу («взлом», «атака» на картинке).

## Почему не A (первоисточник)
Все четыре `sources` — текстовые/справочные страницы без иллюстративного
контента: MSRC (SPA, не рендерится через WebFetch — подтверждено ещё
в reporter-notes), NVD и MITRE/CVE.org (машиночитаемые базы данных без
фото), блог исследователя Nightmare Eclipse (403 Forbidden при прямом
доступе, также подтверждено в reporter-notes). У события «уязвимость софта»
официального пресс-фото не существует в природе — сразу переход к стоку.

## Почему не B0 (фототека редакции)
`config/stock-photos.json` содержит только темы cbu/sum/cash/inflation/
prices/budget/salaries/banking/payments/monetary-policy — кибербезопасности
и IT там нет. `pick-stock.mjs` не запускал: по списку тем результата
заведомо не будет (тот же вывод, что в прецеденте
bild-notes-microsoft-patch-tuesday-august-2026.md).

## Источник картинки
- Поиск через публичную выдачу Unsplash (`unsplash.com/s/photos/...`) —
  запросы «cybersecurity code», «computer code screen security».
- Проверено 7 кандидатов на ориентацию и содержание (все landscape,
  соотношение 1.5). Отклонены:
  - фото ноутбука MacBook Pro с кодом (Arnold Francisca) — в кадре виден
    логотип Apple и надпись «MacBook Pro»; сторонний брендинг лишний,
    хотя формально не под прямым запретом (запрет касается Microsoft),
    решил не рисковать отвлекающим элементом;
  - premium/Getty-версии — платный сток, чёрный список;
  - несколько результатов Openverse (windows security shield, network
    security lock) — либо не по теме (полицейские щиты), либо SVG-иконки
    вместо живой фотографии, либо с Wikimedia (чёрный список).
- **Выбран**: Markus Spiske, «Code» — крупный план строк JS-кода на тёмном
  экране в частичном расфокусе (жёлтый/серый/голубой текст на чёрном фоне,
  минимум красного — не алармистски).
  URL: https://images.unsplash.com/photo-1533709752211-118fcaf03312
  Лицензия: Unsplash License (свободное использование).
- Тип: живая фотография экрана монитора (не 3D-рендер, не иконка, не
  скриншот таблицы/презентации — нечитаемый код в расфокусе не несёт
  фактической информации, значит не подпадает под запрет «скриншоты

- Размер оригинала: 5760×3840 (соотношение 1,5 — горизонтальный).

## Отклонённые варианты
- Windows Update screen (кампания «Working on updates») — уже использован
  для другого материала (`microsoft-patch-tuesday-august-2026`), решил не
  повторять один и тот же кадр для соседних тем про Microsoft, чтобы лента
  не выглядела как повтор.
- Скриншот кода в PhpStorm на MacBook (Arnold Francisca) — виден логотип
  и модель стороннего устройства (Apple), отвлекает от темы.
- Скриншот кода в VS Code-подобном редакторе (Juanjo Jaramillo) — чище по
  композиции, но менее «тревожный»/атмосферный для темы уязвимости; выбран
  запасным вариантом на случай отклонения основного.
- Openverse/Wikimedia результаты — чёрный список источников.
- Higgsfield AI-генерация — до неё не дошло, сток найден раньше по порядку
  попыток; инструмента генерации в наборе тулов агента нет (тот же вывод,
  что в прецедентных bild-notes).
