# Fact-check: ms-wmic-removal

## Общий вердикт: APPROVE-WITH-DOWNGRADES

Материал построен на трёх независимых первоисточниках Microsoft (два Learn-релиза + Support) плюс BleepingComputer для угла «как злоупотребляли WMIC». Ядро истории (что удаляется, когда, из каких сборок, что не затронуто, чем заменить) подтверждается дословно и без противоречий. Найдено две проблемы уровня «понижение», ни одна не разваливает центральный факт.

## Проверенные утверждения

Таблица цитат от репортёра (`.review/claims-ms-wmic-removal.md`) была использована как отправная точка. Строки 1–9 (Microsoft Learn/Support) сверены построчно с драфтом — совпадение точное. ## Особый случай: слово с корнем «жертв»

Обобщённое описание модели атаки вымогателей в третьем лице, без конкретного инцидента, без поимённых пострадавших, без уголовного дела. Не является нарушением forbiddenTopics, понижения не требует.

## Список понижений для editor'а (применяет сам, без повторной проверки)

1. Убрать кавычки-ёлочки у фразы «легитимный, но опасный в чужих руках» — это авторское определение, не цитата source. Переформулировать без кавычек или убрать.
2. «обнаруживать и отключать установленные защитные решения» → «обнаруживать и удалять установленные защитные решения» (источник говорит про uninstall).
3. Разбить длинную конструкцию (~58 слов) с двойной прямой цитатой в абзаце 3 на два предложения.
