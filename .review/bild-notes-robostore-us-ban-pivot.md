## Отклонённые варианты
- unitree.com product images #1 (walking, боком) и #3, #5, #7 (в полный рост) — тот же исходник 2740×1720:
  content-aware crop скрипта (центр масс по плотности деталей) стабильно съедал верхние ~10% кадра
  и обрезал голову робота — торс/руки/ноги дают больше "edge energy", чем гладкий шлем с одной
  синей полосой. Проверено на трёх кадрах, результат идентичен (offset [0,104] у всех).
- unitree.com #2 (робот на корточках, выбран как финальный) — та же обрезка 10,4% по высоте
  не задевает голову: в этой позе фигура компактнее по вертикали, голова оказывается ближе к
  геометрическому центру кадра.
- unitree.com hero-баннер 3840×1988 (четвероногий робот в тумане) — не тот субъект: четвероногий,
  не гуманоид, hint явно просит гуманоида.
- unitree.com "Power Inspection" 2744×1596 (два четвероногих робота на дороге) — тоже четвероногие,
  не подходят под hint.
- Ars Technica (og:image статьи) — не удалось загрузить через WebFetch (сайт недоступен для
  инструмента); также источник не входит в список "официальные пресс-службы/агентства с понятной
  лицензией" — copyright-риск, решил не использовать даже при доступности.
- FCC PDF (DA 26-786) и страница Covered List — текстовые документы без фотографий, непригодны.
- Логотип RoboStore/Robo Inc — не рассматривался вообще, по прямому запрету из handoff (image-avoid).
