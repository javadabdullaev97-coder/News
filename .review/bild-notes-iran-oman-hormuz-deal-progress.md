  права не подтверждены.

пропускай если не уверен что открытое использование разрешено») — не взял ни
один, хотя тематически кадр РИА («Суда в Ормузском проливе») был лучшим по

## Путь A2 — DVIDS (public domain, US military): проверил, не подошло

## Обработка — `scripts/prepare-image.py`

```json
{
  "source": {"width": 3000, "height": 2250, "path": "scratchpad/tanker2.jpg"},
  "fit": {
    "mode": "cover",
    "scale": 0.5333,
    "cropLoss": 0.25,
    "offset": [0, 45],
    "upscaled": false,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/iran-oman-hormuz-deal-progress-01.jpg",
    "url": "/images/posts/2026-08/iran-oman-hormuz-deal-progress-01.jpg",
    "width": 1600, "height": 900, "bytes": 380064, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

`cropLoss = 0,25` — ровно на границе `cropRiskThreshold` (0,25 из
`config/newsroom-policy.json`), но не превышает его (правило триггерит
вопрос владельцу строго при `> 0,25`). Дополнительно проверил визуально:
на итоговом кадре 1600×900 судно целиком в кадре (нос, корма, оба
пенных следа от винтов) — обрезаны только верхние и нижние клинья кильватерного
следа на однородной воде, ничего смыслового не потеряно. Не отправляю
в editor-queue — порог формально не пройден, и визуальная проверка это
подтверждает.
