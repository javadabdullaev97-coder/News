  хакатона. Subject-first: показывает именно то мероприятие, о котором статья (снято во

- Тот же кадр уже публиковался под соседним материалом об открытии хакатона
  (`mintrans-national-transport-hackathon-aug2026`, файл
  `public/images/posts/2026-08/mintrans-national-transport-hackathon-aug2026-01.jpg`).
  Так как оба материала — про один и тот же 3-дневный хакатон (открытие vs итоги/победители),
  а в постах именно про итоги фото нет, переиспользование этого кадра — обоснованный
  primary-source выбор, а не эрзац: кадр объективно лучше всего передаёт суть события
  (баннер с названием + участники) из всего, что реально доступно в первоисточниках.
  Другие кадры из того же альбома (спикеры IT Park, Yandex Uzbekistan крупным планом)
  отклонены — они про конкретных выступающих, не про итоги/победителей, и содержат
  крупные лица, что менее уместно для материала о девяти командах-победителях.
- Размер оригинала: 800×449 → `prepare-image.py`: mode=cover, scale=2,0045×, cropLoss=0,22%
  (0,0022), offset [4, 0] → 1600×900 (222 795 байт, quality 90)

### JSON от prepare-image.py
```json
{
  "source": {"width": 800, "height": 449, "path": "post28571_1.jpg"},
  "fit": {
    "mode": "cover",
    "scale": 2.0045,
    "cropLoss": 0.0022,
    "offset": [4, 0],
    "upscaled": true,
    "note": "обрезано 0% по ширине; окно кропа выбрано по содержимому; исходник растянут в 2.00× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/tashkent-transport-hackathon-ai-01.jpg",
    "url": "/images/posts/2026-08/tashkent-transport-hackathon-ai-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 222795,
    "quality": 90
  },
  "status": "ok"
}
```

Апскейл 2,00× — в пределах `MAX_UPSCALE = 2.5`, политика скрипта считает это дешевле,
чем размытая подложка вокруг мелкого фото. Кроп практически нулевой (0,22%) —
`crop-risky` не применяется. Горизонтальный кадр (800×449 ≈ 16:9), подложка не
потребовалась.
