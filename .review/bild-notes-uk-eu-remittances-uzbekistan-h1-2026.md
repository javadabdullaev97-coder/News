# Bild notes: uk-eu-remittances-uzbekistan-h1-2026

## Стратегия: stock (фототека редакции, B0)

## Ход выбора
1. **Первоисточник (шаг A):** оба source-документа ЦБ РУз — прямые PDF-ссылки
   на upload.cbu.uz («Валютные операции физических лиц», «Обзор внутреннего
   валютного рынка»). Reporter notes подтверждают: канонической landing-страницы
   с этим обзором на cbu.uz нет, только upload-ссылки на PDF. Внутри PDF —
   только таблицы/текст, живых фото нет. Telegram-канал ЦБ отдельно не проверял
   под эту конкретную публикацию: обзор не единичный пресс-релиз с сопровождающим
   постом, а плановый квартальный/полугодовой документ, обычно без медиа.
   → Стратегия A не дала результата.
2. **mainVisualSubject из reporter notes:** «нет явного субъекта — тема про
   статистику денежных переводов». Handoff (image-hint) прямо предписывает
   нейтральный образ: банковские карты/p2p-платёж, банкноты, международный
   перевод денег, без привязки к конкретной стране (без флагов UK/EU/US),
   без лиц, без «бизнесменов в костюмах», без логотипов платёжных систем.
3. **Фототека редакции (B0):** тема — денежные переводы/платежи/банкинг —
   ровно тот случай, для которого создана `config/stock-photos.json»
   («темы, где официального фото не бывает в природе»). Запросил скрипт:
   `node scripts/pick-stock.mjs --topic payments` →
   `/images/stock/sum-banknotes-03.jpg` (единственный кадр с тегом `payments`,
   0 использований, ротация в порядке). Кадр уже 547×307 (16:9), обработка
   `prepare-image.py` не требуется, копирование в `posts/` не требуется —
   ссылаемся на общий файл фототеки.

## Почему этот кадр, а не Unsplash/AI
- Handoff явно просит избегать «стоковых бизнесменов» и лиц — типовой Unsplash
  под «money transfer» почти всегда либо лицо, либо руки с телефоном на фоне
  логотипа банка. Кадр из фототеки — банкноты сум на клавиатуре ноутбука —
  нейтрален, без флагов, без лиц, без брендов, соответствует и image-hint,
  и правилу B0 (не плодить новые сток-закупки под темы, где уже есть
  ротация).
- AI-генерация (стратегия C) не потребовалась — фототека закрыла тему без
  риска «разноцветной радуги» и без лишнего шага.

## Отклонённые варианты
- Поиск иллюстрации внутри PDF ЦБ — только таблицы и текст, фото нет.
- Google/Unsplash «money transfer», «remittance» — не проверял вживую:
  handoff прямо запрещает лица и стоковых «бизнесменов», а фототека уже
  дала подходящий нейтральный кадр без этого риска.

## Alt-текст
"Пачка банкнот по 50 000 сумов на клавиатуре ноутбука" (из `stock-photos.json`,
без изменений — описательный, соответствует изображению).

## Уверенность в подборе: 75%
Кадр нейтральный и соответствует image-hint, но тематически привязан к сумовым
банкнотам, а не к самому механизму трансграничного перевода (переводы приходят
в долларах и оседают на картах через p2p, а не наличными сумами). Это
допустимый компромисс: единственный кадр фототеки с тегом `payments`,
альтернативы без риска (флаги/лица/логотипы) не найдено.
