## Применённые понижения фактчека (все 5)

1. **Критическое.** Абзац 2: «Интерфейс проверки транзакций показывает пользователю
   действия агента» удалено, пятым компонентом поставлена поддержка протокола MCP
   (Model Context Protocol) с раскрытием термина при первом упоминании —
   «открытого стандарта, через который сторонние ИИ-приложения подключаются
   к инструментам биржи».
2. **Критическое.** Абзац 5: «до 20 долларов на один платёж через x402» →
   «Платежи через x402 — не больше 20 долларов в день» (суточный лимит).
3. **Критическое.** Абзац 5: предложение «Агенты не получают доступа к личным
   данным пользователя — электронной почте и результатам проверки личности»
   удалено целиком вместе с висевшей на нём ссылкой. Удаление ссылки — не моя
   инициатива, а пункт 3 списка понижений fact-checker'а, поэтому
   back-to-reporter не требуется.
4. Абзац с Kraken/Coinbase: «Аналогичные платформы» → «Похожие инструменты для
   торговли через ИИ-агентов… выпустили» (в источнике продукт Kraken —
   open source command-line tool, не платформа).
5. Лид сокращён с 33 до 27 слов; предложение про дневные лимиты (~35 слов)
   разбито на два (18 и 11 слов).

## Изменения в заголовке
**До**: Binance разрешил ИИ-агентам торговать на бирже от имени пользователя (68 знаков)
**После**: Binance разрешила ИИ-программам торговать за пользователя — за убытки отвечает он сам (85 знаков)
Обоснование: «разрешил» → «разрешила» (биржа), жаргонное «ИИ-агентам» в витрине

главный риск-угол материала. Первые 60 знаков — «Binance разрешила ИИ-программам
торговать за пользователя» (57 знаков) — законченный заголовок с субъектом и глаголом.
