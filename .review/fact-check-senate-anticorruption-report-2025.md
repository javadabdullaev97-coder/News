# Fact-check: senate-anticorruption-report-2025

## Общий вердикт: APPROVE-WITH-DOWNGRADES

## Что удалось сделать сверх reporter'а

Reporter не смог напрямую прочитать `senat.uz/post-5883` и `parliament.gov.uz` (JS-рендер), подтвердил цифры только косвенно — через дословную цитату, извлечённую при фетче статьи kun.uz (конкурент, чёрный список). Повторные попытки (другой путь URL, кэш поисковиков, archive.org) подтвердили JS-стену.

Через поиск найдена прямая статья УзА (`uza.uz`) — государственного национального информагентства (не в чёрном списке СМИ; официальный канал для ведомств). Статья читается полностью и независимо подтверждает все ключевые цифры дословно: 7 517 человек, ущерб >2,9 трлн сумов, нарушения в госзакупках 12,6 трлн сумов, лидирующие отрасли (дошкольное/школьное образование, здравоохранение, хокимияты, коммерческие банки), докладчик — Акмал Бурханов, дата заседания — 8 августа 2026 (новая деталь, отсутствующая в драфте).

Это уже не «опосредованное подтверждение через конкурента», а совпадение двух независимых источников (kun.uz-цитата reporter'а + статья УзА).

Курс ЦБ РУз проверен напрямую на cbu.uz: 11 952,10 сума за доллар на 10 августа 2026 подтверждено дословно.

## Чек-лист редполитики

- Заголовок ~74 символа, без CAPS/«!» — ок
- Лид 25 слов, но без даты заседания
- Цифры подтверждены, но только через источник вне frontmatter.sources (uza.uz) — формальный разрыв
- Абзац «Что дальше» про постановление и адресатов не подтверждён нигде
- Нет ссылок на чёрный список СМИ
- Нет AI-slop фраз
- Суммы в сумах — пересчёт в USD с курсом и датой есть
- Названия ведомств полные при первом упоминании
- Frontmatter валиден, sources = 3 записи

## Проверка чувствительных тем (коррупция/уголовная статистика)

Материал не называет ФИО обвиняемых, не приписывает вину конкретным лицам, оперирует агрегированной официальной статистикой из доклада, уже обсуждённого Сенатом (не расследование в процессе). Нарушений не найдено.

## Список понижений/правок для editor'а

1. В лид добавить дату заседания: «...на пленарном заседании 8 августа 2026 года рассмотрел...» (подтверждена независимо через uza.uz).
2. Абзац «Что дальше»: убрать неподтверждённый список ведомств-адресатов. Было: «Сенат принимает соответствующее постановление с поручениями ведомствам — Агентству по противодействию коррупции, Генеральной прокуратуре и региональным хокимиятам — по устранению названных в докладе системных факторов коррупции» → стало: «По итогам обсуждения Сенат обычно принимает постановление по докладу; его текст на момент публикации на сайте Сената не выложен».
3. Добавить в frontmatter.sources: `{name: "УзА (Национальное информагентство Узбекистана)", url: "https://uza.uz/ru/posts/korrupsiyaga-oid-jinoyatlar-boyicha-7-ming-517-nafar-shaxs-jinoiy-javobgarlikka-tortilgan_892644"}` — единственный человекочитаемый источник с цифрами.
4. Андижанскую деталь (946 человек) — не возвращать, решение reporter'а верное.

## Confidence: 87
