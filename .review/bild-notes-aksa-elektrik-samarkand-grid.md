# Bild notes: aksa-elektrik-samarkand-grid

## Стратегия: stock (thematic)

Main visual subject (по reporter notes / handoff): ЛЭП, подстанция или распределительные
электросети Самаркандской области. Узнаваемого человека в кадре нет; handoff отдельно
просит избегать логотипов Aksa Elektrik/Aksa Enerji и лиц официальных лиц, если фотоповод
встречи не подтверждён.

## A. Первоисточник — почему не сработал

Проверил оба поста `frontmatter.sources` из Telegram Минэнерго через `t.me/s/minenergy_uz`
(сырой HTML, не через WebFetch — виджет грузится динамически):

- `t.me/minenergy_uz/20751` — пост с текстом анонса содержит **1 фото**, но это превью-кадр
  **видео**-интервью (Uzbekiston24), фактический размер **320×180**. На кадре — аэросъёмка
  подстанции с надписью "UZS" на бетоне, тематически в точку, но `prepare-image.py`
  отбраковывает по `MIN_SOURCE=600` (`status: too-small`), апскейл с 320px до 1600px
  — заведомое мыло, не пытался.
- `t.me/minenergy_uz/20752` — тот же видеосюжет, другой стоп-кадр, тоже **320×180**
  (рабочие у распределительного щита в касках) — тот же отказ по размеру.
- Первый URL со страницы `/s/` ошибочно казался фото поста 20751 — на деле принадлежал
  соседнему посту `20741` (семинар-тренинг, переговорная комната, люди за столом) —
  проверил через парсинг `data-post` по блокам, не тот сюжет и не по теме, отбросил.
- Проверил также `t.me/s/SamHETK` (кандидат-источник из reporter notes, не используется
  в `sources` статьи) — пост `39794`, тот же самый ролик, та же картинка 320×180.
  Дубль, тот же отказ.
- `president.uz/ru/lists/view/7767` — 4 фото галереи, 1280×853 (горизонталь, проходит по
  размеру), но это встреча президента с председателем Aksa Enerji **декабря 2024 года**
  (рукопожатие, флаги) — другой информационный повод (инвестиции в газовые станции), не
  про передачу сетей Самарканда. По `image-avoid` из handoff — лица официальных лиц без
  подтверждённого фотоповода не берём; использование ввело бы читателя в заблуждение
  (визуально привязало бы декабрьскую встречу к августовской новости). Отклонено.
- `het.uz`, `minenergy.uz` — проверил на упоминание Aksa напрямую (`curl` по главной) —
  ничего релевантного на первой странице, вглубь не копал (как и reporter, см. notes).

Вывод: у первоисточника нет фото по теме в достаточном разрешении без риска смешения
информационных поводов. Переход к стратегии B.

## B. Тематический сток — что взял

`config/stock-photos.json` — тем `energy`/`grid` там нет (только cbu/sum-темы), пропустил
B0.

Искал через Openverse API (`api.openverse.org`, без ключа; `UNSPLASH_ACCESS_KEY` /
`PEXELS_API_KEY` в окружении нет), фильтр `license=cc0,pdm`, `orientation=wide`, источник
`wikimedia` исключил (чёрный список редполитики).

Выбрано: **"Electric transmission tower power lines"**, rawpixel, CC0 Public Domain —
металлическая опора ЛЭП снизу вверх на фоне чистого синего неба, без текста, без людей,
без водяных знаков.

- Openverse ID: `5f8d022e-0340-4a18-9acd-65ead2fd108e`
- Landing page: https://www.rawpixel.com/image/6025884/photo-image-public-domain-post-technology
- Взял CDN-URL из Openverse API (`editor_1024`, реально отдаёт WebP 1024×683) — сконвертировал
  в JPEG для скрипта, водяного знака нет.
- Прогон через `prepare-image.py`:
```json
{
  "source": {"width": 1024, "height": 683},
  "fit": {
    "mode": "cover", "scale": 1.5625, "cropLoss": 0.1567, "offset": [0, 167],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/aksa-elektrik-samarkand-grid-01.jpg",
    "width": 1600, "height": 900, "bytes": 202146, "quality": 90
  },
  "status": "ok"
}
```
Апскейл 1,56× — в пределах `MAX_UPSCALE=2.5` политики скрипта. `cropLoss` 0,1567 — ниже
порога `crop-risky` (0,25); объект — металлоконструкция/провода, не лицо/животное, обрезка
по высоте (небо) безопасна.

## Отклонённые варианты

- `t.me/minenergy_uz/20751` фото (аэросъёмка подстанции) — 320×180, `too-small`
- `t.me/minenergy_uz/20752` фото (рабочие у щита) — 320×180, `too-small`
- `t.me/s/SamHETK/39794` — тот же ролик, тот же 320×180 кадр, дубль
- `president.uz/ru/lists/view/7767` (4 фото, 1280×853) — рукопожатие Мирзиёева и
  председателя Aksa Enerji, декабрь 2024 — subject mismatch: другой инфоповод (не про
  сегодняшнюю передачу сетей), плюс handoff прямо просит не ставить лица официальных лиц
  без подтверждённого фотоповода
- Openverse rawpixel `82758418` ("Electric transmission tower power lines", 4671×3114,
  с луной в кадре) — decorative/атмосферный кадр, менее нейтральный, чем чистое небо
- Openverse rawpixel `3ced3b08` ("High voltage power lines telephone", 7360×4912) —
  деревянная опора с англоязычной табличкой "HIGH VOLTAGE" в кадре, визуально читается
  как американская сельская инфраструктура — предпочёл более нейтральный кадр без текста
- Фликр-варианты подстанций (Baltimore Gas & Electric и др., соотношение 1.33) — уже
  использованы в похожих материалах (`res-red-category-transformers-sept1` и др. брали
  сток той же тематики), плюс более квадратное соотношение даёт больше обрезки
