Microsoft 11 августа закрыла не менее 398 уязвимостей в Windows и другом поддерживаемом софте в августовском выпуске Patch Tuesday — второй вторник месяца, когда Microsoft выпускает плановые обновления безопасности — одну из брешей уже используют злоумышленники.

Собственный бюллетень компании — [Security Update Guide](https://api.msrc.microsoft.com/cvrf/2026-Aug) — указывает 422 записи CVE для августовского релиза. [Krebs on Security](https://krebsonsecurity.com/2026/08/microsoft-plugs-nearly-400-security-holes/) и [Tenable](https://www.tenable.com/blog/microsofts-august-2026-patch-tuesday-addresses-398-cves-cve-2026-68820) называют более узкую цифру — 398, вероятно, не считая повторных публикаций прошлых месяцев. [Qualys](https://blog.qualys.com/vulnerabilities-threat-research/patch-tuesday/2026/08/11/microsoft-patch-tuesday-august-2026-security-update-review) приводит собственную цифру по общему числу — 421. Критическими источники считают от 42 ([Krebs](https://krebsonsecurity.com/2026/08/microsoft-plugs-nearly-400-security-holes/), [Tenable](https://www.tenable.com/blog/microsofts-august-2026-patch-tuesday-addresses-398-cves-cve-2026-68820)) до 62 уязвимостей ([The Hacker News](https://thehackernews.com/2026/08/microsoft-patches-398-flaws-including.html), [Qualys](https://blog.qualys.com/vulnerabilities-threat-research/patch-tuesday/2026/08/11/microsoft-patch-tuesday-august-2026-security-update-review)).

Уже эксплуатируемая брешь — [CVE-2026-68820](https://msrc.microsoft.com/update-guide/en-US/advisory/CVE-2026-68820) в драйвере Ancillary Function Driver for WinSock (afd.sys), который обрабатывает сетевые подключения Windows. Ошибка use-after-free с оценкой CVSS 7,0 позволяет локально повысить привилегии до уровня SYSTEM. По данным [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-68820), уязвимость включена в каталог активно эксплуатируемых брешей американского агентства CISA. Ведомство рекомендовало устранить её до 25 августа, сообщает [Qualys](https://blog.qualys.com/vulnerabilities-threat-research/patch-tuesday/2026/08/11/microsoft-patch-tuesday-august-2026-security-update-review).

Ещё две уязвимости раскрыли публично до выхода патча, но без подтверждённой эксплуатации. CVE-2026-62832 в службе профилей пользователей Windows получила оценку 7,8 — Microsoft считает её эксплуатацию вероятной. CVE-2026-72971 в драйвере изоляции контейнеров Windows набрала 5,5 балла — здесь компания оценивает эксплуатацию как маловероятную.

## Что делать пользователям

Основная рекомендация не меняется — установить августовские обновления через Центр обновления Windows как можно быстрее, особенно на системах с доступом в интернет. Среди критических исправлений — уязвимости в DNS-сервере Windows и протоколе Microsoft QUIC с оценкой CVSS 9,8. Обе допускают удалённое выполнение кода без аутентификации, сообщает [The Hacker News](https://thehackernews.com/2026/08/microsoft-patches-398-flaws-including.html). Администраторам локальных ферм SharePoint стоит проверить, что установлены оба исправления — июльское и августовское, — иначе уязвимость сохраняется.

Августовский выпуск меньше июльского, рекордного для 2026 года — тогда Microsoft закрыла более 570 уязвимостей, — но вдвое превышает июньский, около 200, сообщает [Krebs on Security](https://krebsonsecurity.com/2026/08/microsoft-plugs-nearly-400-security-holes/).
