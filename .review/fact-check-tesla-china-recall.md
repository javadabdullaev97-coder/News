## Список понижений/правок для editor'а (применяет сам, без повторной проверки)

1. **Последний абзац (GB 48001-2026)**: заменить на «В феврале Китай на уровне регулятора одобрил запрет на скрытые дверные ручки Tesla-типа по соображениям безопасности, пишет Electrek» — убрать номер стандарта, «механический дублёр» и дату 1 января 2027: источник не подтверждает.
2. **Заголовок**: «Tesla отозвала в Китае почти 3 млн машин из-за аварийных дверных ручек» → «SAMR обязал Tesla отозвать в Китае почти 3 млн машин из-за аварийных дверных ручек» — атрибуция регулятору, а не Tesla.
3. **Лид**: «обязало Tesla отозвать 2 975 910 автомобилей Model 3 и Model Y» → «обязало Tesla отозвать 2 975 910 автомобилей, включая Model 3, Model Y, а также часть импортных Model X и Model S».
4. **Абзац 3**: разбить перечисление по моделям (~31 слово) на два предложения.
5. **Абзац про NHTSA**: разбить (~31 слово) на два предложения.
6. Опционально: пересмотреть необходимость H2 «Давление на конструкцию дверей растёт и в США» — по жанру «новость об одном событии» H2 не предусмотрен.
7. Унифицировать ссылку на Nbd.com.cn — свести к одному URL.
