# Фактчекер: чувствительные темы

Открывается, когда в материале есть хоть одно: самоубийство или попытка;
национальность, гражданство, религия, диагноз, судимость; анонимный
источник; формула §10 (первоисточник назван, но недоступен).

**Суицид.** Если материал о самоубийстве или попытке — проверь по правилам
ВОЗ (редполитика §8): нет способа, нет места, нет цитат из записки, нет
упрощённой причины («из-за долгов»), нет фото, нет романтизации, нет оборота
«совершил самоубийство» и «удачная/неудачная попытка». В конце обязателен
блок помощи с действующими телефонами — **сверь номера с сайтом ведомства
перед публикацией**, они меняются. Нет блока помощи — REJECT.

**Национальность, гражданство, религия, диагноз, судимость.** Признак
допустим, только если без него событие непонятно (депортация по гражданству,
межнациональный конфликт, квота, религиозный праздник как повод). Признак
«для колорита» — понижение: удалить.

**Анонимный источник.** Допустим, только если выполнены все три условия
редполитики §6: общественная значимость, невозможность получить открыто
(отправлен запрос — факт зафиксирован в reporter-notes), два независимых
подтверждения. Плюс в тексте должны быть степень осведомлённости источника
и причина анонимности. Безличное «как стало известно LEAP News» без этого —
REJECT.

**Материал по формуле §10** (первоисточник существует, но недоступен).
Проверяешь не сам факт, а соблюдение процедуры: формула понижения стоит
дословно в лиде, в конце есть строка о направленном запросе, в `sources`
первоисточник, а не издания, в reporter-notes перечислены попытки доступа.
Отсутствие проверяемости факта в такой публикации — не повод для REJECT;
отсутствие любого элемента формулы — повод.
