## Попытка A — первоисточник
- `t.me/MyGovUz/3971` — проверил через `t.me/s/MyGovUz/3971` (публичный превью-рендер),
  нашёл конкретный пост (совпадает текст: «Chet tilini bilish darajasini aniqlash test
  sinovlari o'tkaziladi», 5 языков, даты). У поста есть медиа 564×800 (вертикальное,
  `cdn4.telesco.pe/...`). Скачал и посмотрел: это Canva-баннер Агентства по оценке
  знаний и квалификаций — глянцевые клипарт-иконки (мегафон, глобус, флаги, стопка
  книг, паспорт), крупный узбекский текст с деталями регистрации. **Отклонено дважды**:
  (1) рисованная «заготовка» с иконками — тот тип визуала, который редполитика не
  разрешает даже из первоисточника; (2) вертикальная ориентация 564×800 — при
  вписывании в 16:9 либо подложка, либо обрезка съедает большую часть текстовых
  блоков — не самодостаточный кроп. Сохранил как `bild-candidate-original` не стал —
  оба довода достаточны для отказа без сохранения кандидата.
- `my.gov.uz/ru/service/559` — WebFetch нашёл только служебные иконки интерфейса
  (alarmBell.png, флаг-иконки услуг, SVG-пиктограммы паспортного раздела), фото/
  скриншота самого интерфейса услуги на странице нет.
- `gov.uz/ru/uzbmb/pages/about` — WebFetch подтвердил: только герб/флаг/логотип-иконки,
  живых фото здания или сотрудников агентства нет.
- `uzbmb.uz` — недоступен (`curl` вернул `000`, соединение не установлено) — та же
  проблема, что и у reporter'а весь research-цикл; повторная попытка не изменила
  результат.
- App Store / офиц. соцсети my.gov.uz — прямого поиска приложения по id не нашёл
  (404 на предполагаемом id), скриншоты интерфейса тестирования не найдены за разумное
  время поиска.

**Вывод: первоисточники не дают пригодного визуала — только запрещённый тип
клипарт-баннера в неверной ориентации.**
