### Отчёт prepare-image.py

```json
{
  "source": { "width": 600, "height": 800 },
  "fit": {
    "mode": "contain",
    "scale": 1.0,
    "placed": [600, 800],
    "note": "вписано целиком на размытую подложку из самого кадра; заливка кадра потребовала бы растянуть исходник в 2.67×; обрезка съела бы 58% по высоте"
  },
  "output": {
    "path": "public/images/posts/2026-08/tashkent-bus-ac-rules-summer-2026-01.jpg",
    "url": "/images/posts/2026-08/tashkent-bus-ac-rules-summer-2026-01.jpg",
    "width": 1600, "height": 900, "bytes": 174747, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

600×800 → contain, масштаб 1,0 (без пересчёта пикселей), обрезки нет → 1600×900 (171 КБ, q90).

**Почему contain и почему это не дефект.** Публичный виджет Telegram отдаёт максимум 800px
по длинной стороне — все четыре фотографии поста ровно 600×800, вертикальные. Заливка кадра
потребовала бы растянуть оригинал в 2,67×, обрезка съела бы 58% по высоте. Скрипт вписал кадр
целиком на размытую подложку из него же. Апскейла нет, потерь содержимого нет.

**Очередь редактора не задействована.** `crop-risky` заводится по `cropLoss > 0,15`; в режиме
contain обрезки нет вовсе, автобус и салон в кадре целиком — номер маршрута, дверь, пассажиры
ничем не срезаны. Гадать не о чем, повода спрашивать владельца нет.

- **t.me/toshdeptransport/7723**, 800×450 — инфографика госучреждения по мониторингу, среди
  нарушений минимальных требований прямо назван «sovutish tizimi». Формально 16:9 и cover

  с иконками, а не съёмка (`preferRealPhotography`), и она несёт цифры (29 906 / 59 182 / 8,4% →

  материал, которого он не получит.
- **t.me/toshdeptransport/7722**, 800×450 — такая же рисованная карточка и про другое:
  рейды против безбилетного проезда. Не по теме.

- `cropRiskThreshold 0,15` — не сработал, обрезки нет.
- Кадр 1600×900, совпадает с `og:image` в `app/article/[slug]/page.tsx`.

## Люди в кадре

Люди есть: сотрудник в проёме двери и пассажиры в салоне. Ограничение §«не публикуй фото людей»
относится к политически чувствительным материалам — здесь бытовой сервисный текст о температуре
в автобусах, публичных лиц в кадре нет, фотография опубликована самим ведомством. Риска
deepfake-претензий не вижу. Alt намеренно описывает людей по роли и одежде, без домыслов
о личностях и должностях: подписи «инспектор» в посте нет, поэтому в alt — «сотрудник».
