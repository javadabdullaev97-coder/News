# Bild notes: labor-migration-1-4m-stats

## Стратегия: stock (тематический)

## Определение главного визуального субъекта
Reporter (mainVisualSubject) и handoff сходятся: явного субъекта нет — тема
статистическая (обзор ЦБ РУз про 1,4 млн трудовых мигрантов). Handoff
image-hint предложил два направления: аэропорт вылета/зал ожидания либо
инфографика-карта распределения по странам. image-avoid: конкретные лица без
согласия, логотипы конкурентных СМИ, стоковые «бизнесмены» в костюмах.

## Шаг A — первоисточник (не сработал)
- https://cbu.uz/uz/press_center/reviews/4342919/ — карточка обзора на
  cbu.uz, WebFetch не нашёл og:image и содержательных изображений в HTML,
  только структурные логотипы шаблона.
- PDF обзора (sharh.pdf) — по reporter notes, документ без фотоконтента,
  8 страниц узб. текста, не проверял повторно.
- https://t.me/centralbankuzbekistan/13421 — проверил `?embed=1`: пост
  содержит ВИДЕО (`tgme_widget_message_video_thumb`), не фото. Единственный
  `<img>` на странице — аватар канала «Markaziy bank» (стандартная
  подмена, задокументированная в image-pipeline.md), не медиа поста. Путь A
  закрыт.

## Шаг B — тематический сток (сработал)
- Искал на Unsplash горизонтальные (landscape) кадры по теме «airport
  departure hall / migration» — зал аэропорта с пассажирами и багажом,
  как предложено в handoff image-hint.
- Кандидат 1 (Edwin Petrus, «a large group of people waiting for their
  luggage») — зал прилёта/выдачи багажа, крупные узнаваемые лица людей в
  фокусе (не силуэты) — отклонён из-за риска «конкретные лица без
  согласия» (image-avoid).
- Кандидат 2 (Kelvin Zyteng, архитектурный ч/б кадр огромного терминала) —
  люди — мелкие точки, кадр больше про архитектуру аэропорта, чем про
  людей/миграцию — отклонён как менее тематически точный.
- Кандидат 3 (Preston A Larimer, человек у табло вылетов/прилётов) —
  один человек спиной, тема считывается слабее (похоже на обычного
  туриста, не миграцию).
- **Кандидат 4 (выбран): motomoto sc, «People are walking through a busy
  airport terminal»** — зал аэропорта (зона выдачи багажа), на переднем
  плане силуэты нескольких пассажиров с сумками, чемоданом, свёртками —
  идут спиной/в контражуре, лица не читаются → снимает риск «конкретные
  лица без согласия». Живая документальная съёмка, не рендер и не
  инфографика. Горизонтальная ориентация 3000×2000 (AR 1.5).
- Лицензия проверена: фото не помечено Unsplash+ в выдаче поиска (в отличие
  от нескольких Getty/премиум-карточек рядом в той же выдаче) — свободная
  Unsplash License.
- Прямая ссылка: https://images.unsplash.com/photo-1746020681437-bb0a721cf2fa

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 3000, "height": 2000, "path": "/tmp/original.jpg"},
  "fit": {"mode": "cover", "scale": 0.5333, "cropLoss": 0.1562, "offset": [0, 0],
    "upscaled": false, "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому"},
  "output": {"path": "public/images/posts/2026-08/labor-migration-1-4m-stats-01.jpg",
    "url": "/images/posts/2026-08/labor-migration-1-4m-stats-01.jpg",
    "width": 1600, "height": 900, "bytes": 332535, "quality": 90},
  "status": "ok", "upscaled": false
}
```
cropLoss 15,6% — ниже порога 22% (contain не понадобился) и ниже порога 25%
(crop-risky не сработал). Режим cover, силуэты переднего плана с багажом
остались в кадре целиком — не обрезаны.

## Отклонённые варианты
- Edwin Petrus (зал выдачи багажа, крупные лица) — риск «лица без
  согласия», image-avoid прямо это запрещает.
- Kelvin Zyteng (архитектурный кадр терминала) — люди слишком мелкие,
  тема миграции не считывается.
- Preston A Larimer (турист у табло) — тема считывается слабее, похоже на
  обычную туристическую поездку, а не трудовую миграцию.
- Фототека редакции (`config/stock-photos.json`) — проверил `pick-stock.mjs
  --list`: темы cbu/sum/cash/inflation/prices/budget/salaries/banking,
  темы «миграция»/«аэропорт» нет — не применимо к этому материалу.
- AI-генерация (Higgsfield) — не понадобилась: нашёлся подходящий живой
  тематический сток без людей крупным планом и без 3D-рендера.

## Уверенность в подборе: 65%
Кадр не привязан к Узбекистану (снят в юго-восточноазиатском аэропорту,
судя по надписям на индонезийском на исходнике) и не показывает конкретное
событие из статьи — это тематическая иллюстрация к абстрактной статистике
(subject-first здесь недостижим, тема статистическая по признанию reporter и
editor). Плюсы: живая документальная съёмка, силуэты снимают риск
«лица без согласия», тема (пассажиры с багажом в аэропорту) точно
считывается applied к трудовой миграции. Атрибуция — best-effort по имени
автора из карточки поиска Unsplash (прямая страница фото возвращала 404 при
попытке открыть по составленному URL, как и в прошлых случаях с Unsplash).
