# Reporter notes: deepseek-model-vs-anthropic-opus

Тема: DeepSeek 21 августа 2026 года выпустила экспериментальную мультимодальную
модель DeepSeek-V4-Flash-Vision-Exp — версию флагманской текстовой V4-Flash
с добавленным распознаванием изображений. По данным компании, на агентных
задачах с визуальным вводом модель приближается к производительности Opus 4.8
(Anthropic).

**Источник 1 — Bloomberg Technology**
(https://www.bloomberg.com/news/articles/2026-08-21/deepseek-unveils-test-model-to-rival-anthropic-s-opus-4-8):
прямой WebFetch дал HTTP 403 (антибот-защита Bloomberg). Текст восстановлен
через точный снипет из задания (заголовок, ссылка, дата, первый абзац) и через
WebSearch, вернувший развёрнутую выжимку статьи, включая прямую цитату
DeepSeek из X. Сверил с деривативной перепечаткой Deccan Chronicle (в статье
как источник не используется, только для сверки фактов) — расхождений нет.

**Источник 2 — DeepSeek API changelog**
(https://api-docs.deepseek.com/updates/): открыт напрямую через WebFetch без
проблем. Официальная запись от 21 августа 2026 про
DeepSeek-V4-Flash-Vision-Exp. Отсюда взяты точное название модели, способ
доступа (`model='deepseek-v4-flash-vision-exp'`), формулировки о паритете
с V4-Flash на текстовых задачах и о приближении к Opus-4.8 на визуальных
агентных бенчмарках, пять цифр бенчмарков (Terminal-Bench 2.1, NL2Repo,
DeepSWE, DSBench-Hard, Chartography). Это vendor-источник (DeepSeek говорит
о себе) — использован как заявление компании, а не независимое подтверждение
(specialRules.vendorSpeaksAboutItself соблюдено).

Дополнительно пробовал открыть Bloomberg от 24 апреля 2026 (о запуске
флагманской V4) для контекста — тоже HTTP 403. Без прочитанного текста этот
факт в статью не включил.

Расхождений с inbox-снипетом не найдено — снипет короткий и общий, но точный;
название модели и цифры бенчмарков нашлись только в первоисточнике DeepSeek.

**Main visual subject**: нет явного визуального субъекта — событие про релиз
модели ИИ без физического объекта. Нейтральная графика/логотип DeepSeek,
скриншот интерфейса API или инфографика с сопоставлением моделей.

**Отложено на потом**: реакция Anthropic (по доступным источникам её нет);
более широкая конкуренция DeepSeek/Anthropic вокруг AI-агентов (Bloomberg от
12 августа 2026 про WeChat-аккаунт DeepSeek для найма против Claude Code) —
не открывал, отдельная тема.

**Слабые места**: страница Bloomberg физически не открылась, факты из неё
восстановлены из снипета и WebSearch, а не из прямого чтения HTML; все цифры
