## Попытка A — первоисточник
- `t.me/Press_Secretary_Uz/7698` — проверил через WebFetch и через сырой HTML
  (`t.me/Press_Secretary_Uz/7698?embed=1`). У поста есть прикреплённое фото
  (`background-image:url(...jh2Kz5...jpg)`, 800×517), но это не фото Давлатова и не фото
  события — типовая брендированная карточка «PREZIDENT ADMINISTRATSIYASI» с гербом на
  синем фоне, которую канал переиспользует под текстовые анонсы указов. Отклонил: это
  не «живая фотография» и не содержательная инфографика с реальными цифрами — декоративная
  заготовка-леттерхед, не даёт читателю визуальной информации о теме. Второй `og:image` на
  странице — аватар канала 160×160 (тот самый паттерн из `image-pipeline.md`, который
  брать нельзя).
- Проверил всю ленту `t.me/s/Press_Secretary_Uz` (21 вложение) — остальные медиа оказались
  либо той же брендированной карточкой (повторяется), либо превью видео 180×320
  (портретная ориентация, миниатюры видео, не фото).
- `uza.uz` (второй источник) — статья про директора Института социально-духовных
  исследований Олимжона Давлатова. По прямому запрету из `image-avoid` не использовал:
  тождество с назначенным советником Олимом Давлатовичем Давлатовым не подтверждено,
  подписать фото как «Олим Давлатов» было бы нарушением редполитики.

## Попытка B — сток (здание Администрации президента, по фолбэку из notes)
Искал через официальный API Openverse (`api.openverse.org/v1/images`, `license_type=commercial`,
без Wikimedia — запрет редполитики на wikipedia.org/wikimedia.org):
- «Tashkent government building», «Uzbekistan government building», «Tashkent city hall»,
  «Tashkent parliament» — большинство результатов либо на wikimedia.org (отклонено правилом
  чёрного списка), либо не то здание (парк, концертный зал, парламент — не президентская
  администрация), либо вертикальные/мелкие кадры.
- «Uzbekistan presidential» → нашёл **«Presidential Palace, Tashkent, Uzbekistan Sept 2002»**,
  Flickr, автор `sludgegulper`, лицензия **CC BY-SA 2.0**, 1024×683 (альбомная, ratio 1.5).
  Подпись автора на Flickr: «Post-modesty, post-modernism Presidential Palace, Tashkent» —
  здание с золотистым остеклением, колоннадой, флагштоком с флагом Узбекистана и
  государственным гербом на фасаде (не советский герб — снимок постсоветского периода).
  Использовал именно этот кадр.
- Отклонил похожий кадр того же фотосета «Uzbek Government buildings, sept 2002»
  (`3508601500`) — на фасаде виден герб Узбекской ССР (советский), в кадре турист лицом
  к камере крупным планом — устаревшее и визуально нерелевантное здание для новости 2026 года.
- Отклонил «government building, tashkent» (`upyernoz`, 333×500) — вертикальная ориентация
  и ниже MIN_SOURCE.
- Отклонил «Government building» (Francisco Anzola, 810×1024) — вертикальная ориентация,
  правило от 04.08.2026 требует искать горизонталь, а не спасать вертикаль подложкой.

## Оговорка по точности
Название здания на Flickr («Presidential Palace») — авторская подпись стороннего
фотографа, не официальный источник; снимок 2002 года, актуальный вид здания сегодня
может отличаться. Поэтому в `alt` и в тексте не утверждаю категорично «здание
Администрации президента» / «Оксарой» — сформулировано нейтральнее: «здание резиденции
президента Узбекистана в Ташкенте, архивное фото». Это соответствует духу фолбэка из
notes (нейтральное фото профильного здания), без сверхуверенного утверждения там, где
100% подтверждения нет.

## Попытка C — AI-генерация
Инструментов Higgsfield (`generate_image` и т.п.) в наборе тулов этого прогона нет —
не объявлены в доступных функциях, несмотря на упоминание в MCP-инструкциях. Не

## Обработка `scripts/prepare-image.py`
```json
{
  "source": {"width": 1024, "height": 683},
  "fit": {
    "mode": "cover",
    "scale": 1.5625,
    "cropLoss": 0.1567,
    "offset": [0, 109],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/olim-davlatov-presidential-advisor-01.jpg",
    "url": "/images/posts/2026-08/olim-davlatov-presidential-advisor-01.jpg",
    "width": 1600, "height": 900, "bytes": 209680, "quality": 90
  },
  "status": "ok"
}
```
cropLoss 15,67% — под порогом (даже под старым 22%, тем более под текущим 45% в
скрипте). Апскейл 1,56× — в пределах `MAX_UPSCALE=2.5` скрипта. Итог — полнокадровое
фото 1600×900 без подложки/полей, ориентация горизонтальная изначально.
