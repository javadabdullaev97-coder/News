Google on August 20, 2026, added a "Personalized suggestions" tool to its Gboard keyboard on Pixel 11 smartphones. It offers ready-made message options based on chat history and on-screen content, [according to Google's official support page](https://support.google.com/gboard/answer/17470061?hl=en).

Gboard is Google's default Android keyboard, preinstalled on Pixel devices. The new feature is part of the Writing tools section and runs on Gemini Intelligence, Google's platform for artificial intelligence (AI) features across the Pixel lineup.

Personalized suggestions are available only on Pixel 11, [Google's support page confirms](https://support.google.com/gboard/answer/17470061?hl=en). With the user's permission, the keyboard analyzes typing history and a snapshot of on-screen content while it is being used in messaging apps. These include Google Messages (except in the unfolded mode on foldable phones), Google Chat, LINE and other messengers, [according to the same support page](https://support.google.com/gboard/answer/17470061?hl=en).

Data is encrypted and processed in a closed loop — partly on the device, partly in the cloud — using Private AI Compute technology. Google says not even the company itself has access to the content, [the support page states](https://support.google.com/gboard/answer/17470061?hl=en). Before enabling the feature, users must confirm consent on a separate permissions screen.

For example, if a user types a draft message reading "19:00 Spanish restaurant?", the suggestions tab can complete it. The finished version reads: "Sounds like a great plan! How about dinner on Thursday at 19:00 at that Spanish restaurant?" — an example cited by [9to5Google](https://9to5google.com/2026/08/20/pixel-11-personalized-suggestions/).

The feature does not work in countries within the European Economic Area, [9to5Google reports](https://9to5google.com/2026/08/20/pixel-11-personalized-suggestions/).
