## Источник картинки
- URL: https://photo.boxingscene.com/uploads/AnthonyJoshuaKristianPrenga2.webp
  (og:image статьи BoxingScene, один из `sources` статьи)
- Тип: официальное фото пресс-службы Matchroom Boxing (промоутерская компания
  Эдди Хирна) — атрибуция найдена в HTML-разметке страницы BoxingScene рядом
  с фото: "Mark Robinson/Matchroom Boxing". Категория 1 приоритета
  (официальная пресс-служба), не Getty/агентство.
- Содержание: Эдди Хирн выступает в микрофон на пресс-конференции, рядом
  сидит Энтони Джошуа (Лондон, 1 июня 2026, по подписи og:image:alt
  на BoxingScene). Прямое попадание в subject-first: Хирн — главный герой
  этой статьи (это он делает заявление об иске), Джошуа — участник
  несостоявшегося боя.
- Обработка: python3 scripts/prepare-image.py, JSON-отчёт:
```json
{
  "source": {"width": 1200, "height": 800},
  "fit": {
    "mode": "cover",
    "scale": 1.3333,
    "cropLoss": 0.1562,
    "offset": [0, 133],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.33× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/fury-joshua-venue-dispute-escalation-01.jpg",
    "url": "/images/posts/2026-08/fury-joshua-venue-dispute-escalation-01.jpg",
    "width": 1600, "height": 900, "bytes": 177355, "quality": 90
  },
  "status": "ok"
}
```
  Примечание: коэффициент 1.33 — фактический апскейл. Сверился с текущим
  исходным кодом `scripts/prepare-image.py` (не только с кратким описанием
  в плейбуке): `MAX_UPSCALE = 2.5`, комментарий в коде явно фиксирует
  решение владельца от 03.08.2026 — умеренный апскейл ради заливки кадра
  предпочтительнее блюр-подложки. 1.33× укладывается в этот действующий
  лимит, крупных артефактов на выходном кадре не видно (проверено визуально).
  Кроп 15.6% — тоже в пределах текущего MAX_CROP=0.45 (в коде, поднят
  с прежних 0.22).
- Проверка на повтор: `node scripts/photo-dupes.mjs --check` — свободен,
  за 2 дня этот кадр не выходил.
