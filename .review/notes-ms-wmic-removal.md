# Заметки reporter — ms-wmic-removal

**Тема.** Microsoft удаляет из Windows 11 инструмент командной строки WMIC — устаревшую утилиту, которую годами использовали вымогатели и другие киберпреступники для скрытных атак (LOLBin). Зафиксировано в примечаниях к обновлению KB5120998 (14 августа, Release Preview, версии 24H2/25H2) и к тестовой сборке Beta Preview 26220.9202 (17 августа).

**Проверенные первоисточники:**
- `learn.microsoft.com/.../build-26100-9267-26200-9267` — примечания к KB5120998, дата 14 августа 2026, дословная цитата об удалении WMIC из 24H2/25H2 и об отсутствии Feature on Demand, подтверждение, что WMI не затронута.
- `learn.microsoft.com/.../preview-build-26220-9202` — примечания к Beta Preview 26220.9202, дата 17 августа 2026, отдельный раздел про удаление WMIC.
- `support.microsoft.com/.../wmic-removal-from-windows` — сводная страница поддержки: полная хронология 2016–2026, причина («secure and harden your environment»), рекомендация PowerShell, подтверждение сохранности WMI.
- `bleepingcomputer.com` — использован только для угла «как злоупотребляли WMIC» (удаление теневых копий, отключение антивирусов, исключения Defender, термин LOLBin); факты об удалении самого инструмента взяты напрямую у Microsoft, а не у BleepingComputer.

**Расхождения с inbox-снипетом:** не найдено — снипет точно описал версии и таймфрейм (24H2, 25H2, бета-сборки этой недели).

**Сознательно не использовано:**
- Версия Windows 11 26H2 как точный срок полного удаления WMIC — встречается в поисковой выдаче (Neowin, Windowslatest), но дословно на странице поддержки Microsoft этого номера нет, там только «next Windows feature update». В драфт и claims-таблицу номер версии не включён.
- Сборка 28020.2731 (канал Beta 26H1) — упоминалась в сниппетах поиска, страницу напрямую через WebFetch не открывал, дословно не проверил, в текст не включил.

**Main visual subject:** экран Windows 11 / терминал командной строки — явного человека-субъекта в теме нет, подойдёт продуктовая иллюстрация или нейтральная инфографика Windows 11.

**Что не вошло:** полный список прочих изменений сборки 26220.9202 (Drag Tray, File Explorer, эмодзи 17.0) — не по теме безопасности, не включал. Возможная отдельная тема про статистику LOLBin-атак в Узбекистане/СНГ — местного источника нет, узбекский угол специально не притягивал (по правилу редполитики).

**Флаги для fact-checker'а:** строки 10–12 в claims-таблице (BleepingComputer: удаление теневых копий, обход антивируса, исключения в Defender, термин LOLBin) восстановлены из summary WebFetch, а не выверены вручную по дословному тексту статьи — стоит переоткрыть её и сверить формулировки буквально. Отсутствие номера версии для финального удаления WMIC — не пробел в работе, а точная передача первоисточника.

**Уверенность: 88%.** Три независимых страницы Microsoft (два Learn-релиза + Support) согласуются между собой без противоречий; единственная неопределённость — не названный Microsoft номер будущей версии полного удаления WMIC, сознательно не додуманный сверх источника.
