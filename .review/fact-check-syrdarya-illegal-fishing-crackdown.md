## Проверенные утверждения
Центральный факт (Экополиция задержала двух человек 5 августа за незаконный лов рыбы острогой
в махалле «Тараккиёт», изъяты лодка/острога/насос/вёсла, улов 8 змееголовых+амур+карась,
протокол по ст. 90 ч.4 КоАО) — CONFIRMED дословно по gov.uz/ru/eco/news/view/202432.

Расхождения:
- «двух жителей Сырдарьинского района» — источник говорит просто «граждан», резидентство не
  подтверждено — PARTIAL.
- «Главное управление экологии» — источник без слова «Главное» — PARTIAL.
- узбекское название «илонбашара» — UNSUPPORTED, ни один источник не приводит термин, форма
  нестандартна.
- «материалы направлены в суд по уголовным делам» — источник сам содержит это противоречие
  (административная статья → уголовный суд), драфт корректно подаёт это как атрибутированную
  неясность самого ведомства, а не как факт LEAP — не нарушение §8 (нет ФИО, нет обвинения
  конкретного лица). Второго независимого источника по передаче дела в суд нет.

## Персональные данные
Нет ФИО, нет возраста — только «двое мужчин»/«граждан»/«нарушителей». Соответствует §6, §8.

## Список понижений (применяет editor)
1. «двух жителей Сырдарьинского района» → «двух граждан».
2. Сократить лид с 38 до 25–30 слов.
3. «Главного управления экологии Сырдарьинской области» → «Управления экологии Сырдарьинской
   области».
4. Убрать «(илонбашара)» — оставить только «змееголовых».
5. Сохранить оговорку «Ведомство не пояснило, почему...» — не убирать, это добросовестная
   атрибуция неясности источника, не AI-slop.

публикация без ручной проверки владельца не рекомендуется, несмотря на высокий confidence —
