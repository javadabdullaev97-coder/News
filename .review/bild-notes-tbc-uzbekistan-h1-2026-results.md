# Bild notes: tbc-uzbekistan-h1-2026-results

## Стратегия: primary-source (официальная айдентика продукта)

## Как искал
1. **mainVisualSubject** от reporter: явного человека-субъекта нет, годится
   скриншот приложения / карта TBC Salom-Osmon / фирменная айдентика.
2. Проверил `tbcbank.uz/ru/news/articles/news-article-50/` (первоисточник
   пресс-релиза) — сайт SPA, HTML без JS-рендера отдаёт только соцсети-иконки
   и QR-коды; `og:image` страницы указывает на `minio-test.tbcbank.uz` (dev-
   поддомен) и отдаёт 403 — использовать нельзя.
3. Проверил официальные Telegram-каналы TBC (`t.me/tbc_bank_uzb`, публичный
   канал банка в Узбекистане) — за 6 августа релевантных постов с фото
   результатов не нашлось, канал ведёт потребительский маркетинг (акции,
   кешбэк), не пресс-релизы.
4. Проверил официальные страницы продуктов на `tbcbank.uz`:
   - `/ru/product/debit-card/` (TBC Salom) → `og:image`:
     `https://minio.tbcbank.uz/prod-tbcbankuz-new/uploads/Salom_Card_RU_443d416505.webp`
     — доступен, 1200×630, официальный брендовый баннер с логотипом TBC Bank
     и дизайном карты TBC Salom.
   - `/ru/product/credit-card/` (TBC Osmon) → аналогичный баннер
     `Osmon_Card_RU_04b398ffc6.webp` — тоже доступен, но карта TBC Salom
     (1,2 млн карт, +129% год к году) более заметна в тексте статьи, чем
     TBC Osmon (212 тыс., +200%), выбрал Salom как основной визуальный
     субъект.
5. Это не сток и не 3D-рендер финансового графика (запрещённый тип) — это
   собственный фирменный промо-баннер банка с реальным дизайном карты и
   логотипом, взятый напрямую с официального сайта продукта.

## Источник картинки
- URL: https://minio.tbcbank.uz/prod-tbcbankuz-new/uploads/Salom_Card_RU_443d416505.webp
  (og:image страницы https://tbcbank.uz/ru/product/debit-card/)
- Тип: официальный промо-баннер TBC Bank UZ (карта TBC Salom, логотип банка)
- Размер оригинала: 1200×630 (webp) → JPEG 1200×630 → cover, масштаб 1,4286,
  обрезано 6,67% по ширине (окно кропа по содержимому), исходник растянут
  в 1,43× ради заливки кадра 1600×900 (в пределах MAX_UPSCALE=2.5 из
  prepare-image.py) → итог 1600×900, 92 834 байт, quality 90

### Полный JSON prepare-image.py
```json
{
  "source": {"width": 1200, "height": 630, "path": "/tmp/tbc-salom-original.jpg"},
  "fit": {
    "mode": "cover",
    "scale": 1.4286,
    "cropLoss": 0.0667,
    "offset": [0, 0],
    "upscaled": true,
    "note": "обрезано 7% по ширине; окно кропа выбрано по содержимому; исходник растянут в 1.43× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/tbc-uzbekistan-h1-2026-results-01.jpg",
    "url": "/images/posts/2026-08/tbc-uzbekistan-h1-2026-results-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 92834,
    "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

cropLoss 6,67% — далеко ниже порога 0,25 для эскалации `crop-risky`; на
брендовом баннере (не фотография с уязвимым субъектом типа лица/животного)
этот порог тем более неприменим.

## Отклонённые варианты
- og:image статьи-первоисточника (`minio-test.tbcbank.uz/.../map_Image_...png`)
  — dev-поддомен, HTTP 403, недоступен.
- Скриншоты Google Play — не нашёл верного package id узбекского приложения
  TBC (поиск выдавал грузинские TBC-приложения), не стал гадать.
- Баннер карты TBC Osmon — рабочий запасной вариант, отклонён в пользу
  Salom Card как более заметного продукта в тексте статьи.
- 3D-рендер финансового графика — не искал целенаправленно, запрещён
  редполитикой независимо от источника.
