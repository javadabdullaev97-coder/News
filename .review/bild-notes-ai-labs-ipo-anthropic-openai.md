## Стратегия: primary-source (официальные логотипы, парный кадр)

## Ход отбора
1. Прочитал `HANDOFF_PATH`: image-hint — «логотипы Anthropic (Claude) и OpenAI
   парным кадром либо логотип Anthropic на светлом фоне; допустима
   биржевая/торговая площадка как фон темы IPO». image-avoid — сгенерированные
   «нейросетевые мозги», роботы, синие сети, стоковые «бизнесмены у графиков»,
   логотип SpaceX как главный объект. Явного человека-субъекта нет.
2. `NOTES_PATH` (Main visual subject) подтверждает то же: логотип Anthropic на
   светлом фоне, парный кадр с OpenAI — допустимая альтернатива.
3. Материал — парный сюжет (Anthropic + OpenAI), но Anthropic первичный
   субъект (заголовок, первый абзац) → выбрал именно парный вариант с явным
   приоритетом Anthropic по размеру и позиции.

- `anthropic.com/news/series-h` — открылся. og:image/hero — шаблонный

  нейтральный логотип, а «стрелки вверх»-подобная заготовка.
  Скриншот-превью сохранён в скретчпаде для référence, в репозиторий не
  копировал.
- CNBC — не проверял отдельно (в задаче предупреждено про 403, Bloomberg
  уже подтвердил паттерн).

## Источник картинки
- Вместо готового кадра собрал парный логотип-кард из двух официальных
  брендовых элементов (аналогично методу из
  `.review/bild-notes-anthropic-revenue-ipo-2026-08.md`, где wordmark
  извлекался напрямую из HTML первоисточника):
  - **Anthropic** — inline SVG wordmark, извлечён напрямую из HTML
    `https://www.anthropic.com/news/series-h` (`<svg aria-label="Anthropic">`,
    viewBox 0 0 570 64) — официальный, актуальный на дату публикации.
  - **OpenAI** — официальный логомарк-«узел», взят из аватара официального
    GitHub-аккаунта компании (`avatars.githubusercontent.com/u/14957082`,
    org `github.com/openai`) — тот же графический знак, что используется
    OpenAI как favicon/app-icon повсеместно; путь SVG сверен с открытым
    репозиторием simple-icons (`cdn.jsdelivr.net/npm/simple-icons/icons/openai.svg`,
    путь идентичен). Название «OpenAI» добавлено обычным текстом рядом со
    знаком (openai.com отдаёт 403 и не открылся напрямую для оф. wordmark-SVG).
- Собрано в SVG-канве 2400×1350 (16:9): Anthropic — крупно, в верхней части
  (primary/больше), тонкая разделительная линия в брендовом акценте LEAP
  (`#FF4D2E`), OpenAI — знак + текст мельче, в нижней части (secondary).
  Фон `#F4F4EB` — тот же нейтральный тёплый оттенок, что и в прежних
  материалах об Anthropic (согласуется с их собственной палитрой и с
  песочным тоном LEAP `#F5EFE8`).
- Рендер: cairosvg → PNG 2400×1350 → JPG (source для prepare-image.py).
- Проверка на повтор: `node scripts/photo-dupes.mjs --check` на исходнике —
  свободен, за 2 дня не выходил.
- Обработка: `python3 scripts/prepare-image.py`. Результат:
  ```json
  {
    "fit": {"mode": "cover", "scale": 0.6667, "cropLoss": 0.0, "upscaled": false},
    "output": {"width": 1600, "height": 900, "bytes": 51821, "quality": 90}
  }
  ```
  Обрезки нет (канва уже собрана в 16:9), апскейла нет.

## Отклонённые варианты
- og:image `anthropic.com/news/series-h` — рисованная doodle-«лестница
  роста», по духу совпадает с забракованным ранее типом абстрактных
  growth-иллюстраций (см. выше) — не живая фотография, отклонено.
- Bloomberg / CNBC — 403 на всех проверенных URL, недоступны как источник
  изображений.
- Единый логотип только Anthropic (без OpenAI) — рассматривал (это и есть
  вторая опция из image-hint), но материал явно парный (заголовок и текст
  сравнивают сроки IPO обеих компаний) — парный кадр точнее отражает суть
  статьи, при этом Anthropic сохраняет визуальный приоритет.
- «Биржевая/торговая площадка» как фон (допустимо по handoff) — не
  использовал: прямое отображение обоих субъектов (логотипы) точнее
  правилу subject-first, чем обобщённый символ биржи.

Оба знака — точное воспроизведение официальных брендовых элементов
(Anthropic — прямо с их сайта, OpenAI — с их официального GitHub-аватара),
не сток и не рисованная заготовка. Кадр точно отражает парный субъект
статьи с сохранением приоритета Anthropic. Не идеален по духу «только живая
фотография» (правило №2), но тема без человека-субъекта и без пригодного
живого фото в первоисточниках — построенный из подлинных официальных
элементов логотип-кард лучше соответствует subject-first, чем биржевая
площадка или единственный логотип без OpenAI.
