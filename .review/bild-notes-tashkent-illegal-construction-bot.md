# Bild notes: tashkent-illegal-construction-bot

## Стратегия: stock

## Почему не первоисточник
Это rework. В прошлом цикле редактор попросил фото постройки; reporter повторно проверил
оба первоисточника (t.me/toshkentprokuraturasi/132989, t.me/poytaxt_uz/51542) — фотографий
конкретных построек там нет, только логотип/аватар канала. Путь "фото из первоисточника"
исчерпан и подтверждён дважды владельцем задачи — третью проверку тех же постов не делал,
сразу перешёл к fallback.

Официальный сайт прокуратуры (prokuratura.uz) — недоступен по таймауту (curl timeout 20с).

Higgsfield (AI-генерация) в тулсете этого запуска не подключён (только Read/Edit/Bash/
WebFetch/Grep/Glob) — пропустил стадию C.

Фототека редакции (config/stock-photos.json) не покрывает тему стройки/незаконной
застройки — только ЦБ, курс сума, наличные, инфляция. `pick-stock.mjs` не вызывал: по теме
однозначно ничего нет (топики cbu/sum/cash/inflation/banking/payments не подходят).

## Источник картинки
- Платформа: Unsplash, permalink: https://unsplash.com/photos/VAayq4Eh0uM
  ("a construction site is seen through a chain link fence")
- Прямой файл: https://images.unsplash.com/photo-1681783165858-4c4b3eb8c756
- Автор: Brad (@minimdesignco), лицензия — Unsplash License (подтверждено на странице фото)
- Тип: реальная фотография (не рендер) — металлический каркас строящегося здания и башенный
  кран, снятые через сетчатый забор стройплощадки; в правом нижнем углу едва различим
  безликий силуэт рабочего в жилете — не идентифицируемое лицо, не риск deepfake-обвинений
- Место съёмки по EXIF/метаданным страницы — Bentonville, AR, США; в самом кадре нет
  опознавательных надписей, номеров домов, брендов, названий улиц — подходит как
  нейтральная иллюстрация "стройплощадка за забором", без привязки к конкретному объекту
  или адресу, что прямо соответствует image-avoid из handoff
- Размер оригинала: 2400×1600 → cover, масштаб 0,6667, обрезано 15,6% по высоте
  (окно кропа по содержимому, offset y=82) → 1600×900 (324 КБ, JPEG q90)

### Полный вывод prepare-image.py
```json
{
  "source": {"width": 2400, "height": 1600, "path": "/tmp/.../original.jpg"},
  "fit": {
    "mode": "cover",
    "scale": 0.6667,
    "cropLoss": 0.1562,
    "offset": [0, 82],
    "upscaled": false,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/tashkent-illegal-construction-bot-01.jpg",
    "url": "/images/posts/2026-08/tashkent-illegal-construction-bot-01.jpg",
    "width": 1600, "height": 900, "bytes": 323975, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```
cropLoss 0,1562 чуть выше мягкого порога 0,15, но сильно ниже жёсткого лимита 0,22 —
эскалацию не завожу: обрезка срезала только верх и низ кадра (небо и часть нижнего яруса
конструкции), центральная композиция (забор, каркас, кран) не пострадала — проверено
визуально по итоговому файлу.

Проверка на повтор (`photo-dupes.mjs --check`) — файл свободен, за 2 дня не выходил.

## Уверенность в подборе: 65%

Кадр не из Ташкента и не привязан к теме бота дословно, но точно попадает в
image-hint ("стройплощадка/забор самовольной застройки рядом с жилыми домами") и
прямо соблюдает image-avoid (не выдаёт конкретный дом за нарушителя). Ограничитель —
не нашлось официального фото здания ведомства и не было доступа к AI-генерации в
фирменной палитре, которая могла бы точнее передать местный контекст.
