Crypto exchange Binance launched Agent OS on August 20 — a system that connects AI agents, autonomous software programs, to its trading platform and lets them execute trades on behalf of users, [the project's page says](https://binance.com/agent-os).

Agent OS combines five elements of Binance's infrastructure, [the exchange said in a press release](https://www.prnewswire.com/news-releases/binance-introduces-agent-os-to-connect-ai-applications-to-financial-infrastructure-302856306.html). These are: the exchange's application programming interface (API) — a set of commands through which third-party software connects directly to Binance's systems; the Wallet Agentic Hub, a wallet that holds funds and executes blockchain transactions; support for the Model Context Protocol (MCP), an open standard through which third-party AI applications connect to the exchange's tools; the x402 payment facilitator, which lets agents and services settle payments with each other without human involvement; and Skill Hub, a catalog of ready-made modules ("skills") for routine agent tasks.

The system also works with external AI applications such as ChatGPT, Claude Code and Cursor: users connect them to their Binance account, [TechCrunch reports](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/).

Users set each agent's permissions themselves — access to market data, account information and trades, [the Agent OS page says](https://binance.com/agent-os). An agent can be tied to a separate sub-account to keep its funds and operations separate from the main balance. By default, an agent cannot withdraw funds from the exchange. Users can require manual confirmation for every trade or allow the agent to act independently, [TechCrunch writes](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/).

Daily limits apply to an agent's wallet operations, [TechCrunch reports](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/). Token swaps — trades of digital assets on the blockchain — are capped at $50,000 a day, and transactions in decentralized finance services at $100,000 a day. Payments through x402 cannot exceed $20 a day.

## Who Is Liable for an Agent's Losses

The Agent OS page explicitly shifts responsibility for outcomes away from the exchange: "You are solely responsible for your investment decisions; Binance is not liable for losses," [the page states](https://binance.com/agent-os). It also states that users bear full responsibility for every command ("prompt") they give an agent.

Binance Vice President of Product Jeff Li told TechCrunch that the exchange cannot see the logic behind an agent's decisions. "We really can't see the reasoning behind the user's action," [Li said](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/). He said that instead of giving the agent full autonomy, the exchange gave users detailed access controls.

Similar tools for trading through AI agents were already rolled out in 2026 by Kraken in March and Coinbase in June, [TechCrunch notes](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/).
