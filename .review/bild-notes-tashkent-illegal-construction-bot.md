Reporter-notes также проверял `@uzbprokuratura` (пост про этот бот не

## Почему не B (сток)

- `config/stock-photos.json` / `pick-stock.mjs --list` — темы фототеки
  только денежно-кредитные (`cbu`, `sum`, `cash`, `inflation`, `prices`,
  `budget`, `salaries`, `payments`, `banking`), под застройку/прокуратуру
  ничего нет — не пробовал `pick-stock.mjs`, тема не входит в список.
- Openverse API (`license=cc0,pdm`):
  - «Tashkent apartment courtyard» → 0 результатов
  - «Tashkent soviet apartment building» → 0 результатов
  - «Uzbekistan apartment building» → 0 результатов
  - «Tashkent» (общий запрос) → 240 результатов, но релевантные по теме —
    все хостятся на `upload.wikimedia.org` (чёрный список редполитики,
    раздел 2: «Википедия — не источник»), остальное — метро, вокзал,
    театр, карта — не по теме двора/самостроя.
- Официальный сайт прокуратуры `prokuratura.uz` — Vue SPA (`<div id=app>`,
  контент рендерится JS), curl/WebFetch отдают пустую оболочку без фото.
- `poytaxt.uz` (сайт хокимията) — `getaddrinfo ENOTFOUND`, не резолвится
  из этой среды.

Общая проблема темы: она специфична (конкретное ведомство/город), а не
абстрактная — родовой сток «стройка» без привязки к Ташкенту выдал бы
читателю чужую локацию под видом узбекской, это подмена факта. Двор с
самостроем без верификации локации тоже рискован — легко случайно
указать на конкретный дом, чего просит избегать handoff
(`image-avoid`: «конкретные адреса/дома как обвинение»).

## Почему не C (AI-генерация)

Инструментов Higgsfield в наборе тулов этого прогона нет — только
`Read/Edit/WebFetch/Bash/Grep/Glob`, ни один `generate_image`/аналог не
объявлен как вызываемая функция, несмотря на упоминание в MCP-инструкциях
системного промпта. По существу для будущего прогона: подошла бы
нейтральная иллюстрация — типовой многоквартирный дом / фасад
представительского здания в узбекской архитектуре, без людей, без
конкретных вывесок/адресов, в фирменной палитре (`#FF4D2E` акцент,

`credit: "AI generated (LEAP News)"` — но физически недоступна в этом
окружении.
