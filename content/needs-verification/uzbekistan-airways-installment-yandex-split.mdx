Uzbekistan Airways 3 августа 2026 года [запустила](https://t.me/uzbekistanairways/8751) на сайте uzairways.com и в мобильном приложении оплату авиабилетов частями через сервис Yandex Split, который определяет условия рассрочки индивидуально для каждого клиента.

## Как оформить рассрочку

Авиакомпания описывает покупку в три шага: выбрать рейс на uzairways.com, при оформлении оплаты нажать «Оплата в рассрочку» и авторизоваться по номеру Yandex. После этого [Yandex Split сам рассчитывает](https://t.me/uzbekistanairways/8751) персональный график платежей — без справок о доходах и без долгого ожидания.

Uzbekistan Airways не назвала в анонсе конкретное число платежей, размер комиссии, минимальную или максимальную сумму покупки и перечень направлений, на которые распространяется рассрочка — эти параметры сервис определяет индивидуально для каждого клиента при оформлении.

## Как устроен Yandex Split

По [условиям сервиса](https://yandex.uz/support/split/ru/conditions), Yandex Split — это не кредит: данные о рассрочке не передаются в бюро кредитных историй. Первый платёж списывается сразу при оформлении заказа, остальные — по фиксированному графику, который нельзя изменить после подтверждения покупки. Пользователь может закрыть часть платежей или всю сумму досрочно. Лимит рассрочки формируется индивидуально для каждого клиента сервиса.
