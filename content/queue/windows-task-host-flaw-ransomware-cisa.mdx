Агентство кибербезопасности и защиты инфраструктуры США (CISA) обновило каталог известных эксплуатируемых уязвимостей: брешь в Windows, добавленную в список 13 апреля 2026 года, по данным каталога, теперь используют вымогатели.

Речь о Host Process for Windows Tasks (`taskhostw.exe`) — системном процессе Windows. Он запускает часть фоновых задач по расписанию и корректно закрывает их при выключении компьютера, чтобы не терять данные. Уязвимости присвоен номер [CVE-2025-60710](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2025-60710) — так уязвимости отмечают в международном реестре — и оценка опасности 7,8 из 10 по шкале CVSS, [сообщает Microsoft Security Response Center](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2025-60710).

Ошибка связана с некорректной обработкой символических ссылок. Злоумышленник с обычной, непривилегированной учётной записью может заставить процесс Task Host обратиться не к тому файлу и получить права SYSTEM — максимальный уровень доступа в Windows. Для эксплуатации нужен уже имеющийся доступ к компьютеру, поэтому брешь опасна не сама по себе, а как второй шаг атаки. После того как злоумышленники проникают в сеть компании — например, через фишинговое письмо, — уязвимость позволяет им закрепиться и получить полный контроль над машиной. Затем они запускают программу-вымогатель и шифруют данные.

## Как развивалась история уязвимости

Microsoft устранила уязвимость 11 ноября 2025 года — исправление вышло для Windows 11 версий 24H2 и 25H2, а также Windows Server 2025, [говорится в бюллетене MSRC](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2025-60710). На момент выпуска патча компания оценивала вероятность эксплуатации как низкую.

13 апреля 2026 года CISA включила CVE-2025-60710 в каталог известных эксплуатируемых уязвимостей (KEV) — это означает, что атаки на непропатченные системы уже фиксировались. CISA обязала федеральные ведомства США устранить брешь до 27 апреля 2026 года.

На этой неделе CISA обновила ту же запись каталога, отметив, что уязвимость используют и группировки вымогателей — атаки с шифрованием данных и требованием выкупа. Страница CISA на момент публикации не открывалась; эту отметку подтверждает независимое зеркало каталога KEV.

Для организаций с Windows Server 2025, которые ещё не установили обновление, Microsoft предлагает временную меру. Нужно отключить в Планировщике заданий задачу `\Microsoft\Windows\WindowsAI\Recall\PolicyConfiguration`, пока патч не установлен, [указано в бюллетене MSRC](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2025-60710).
