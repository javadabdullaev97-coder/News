# Bild notes: state-banks-npl-share-70pct

## Стратегия: primary-source

## Почему не building-фото ЦБ через обычные разделы сайта
Прошёлся по cbu.uz/ru, /ru/about/, /ru/contacts/, /uz/statistics/bankstats/... —
ни на одной из этих страниц нет фотографии здания (только логотипы, иконки
регионов, графики курса). Лента "Новости"/"Пресс-релизы" на главной содержит
только фото встреч и мероприятий, не экстерьер здания.

## Источник картинки
- URL: https://cbu.uz/upload/media/images/social.jpg
- Тип: официальное og:image самого cbu.uz (стоит в <meta property="og:image">
  на странице пресс-релиза о заседании Правления от 29.07.2026 и на самой
  странице статистики NPL за 1 июня — то есть это институциональное
  дефолтное изображение сайта ЦБ, не сторонний сток).
- Содержание: фасад здания ЦБ РУз в Ташкенте, вид снизу на характерные
  стеклянные цилиндрические башни-лифты на фоне неба. Узнаваемая
  архитектурная деталь именно этого здания.
- Обработка: python3 scripts/prepare-image.py — исходник 1110×740 (соотношение
  1.5, горизонтальный, требование по ориентации соблюдено).

```json
{
  "source": {"width": 1110, "height": 740},
  "fit": {
    "mode": "cover",
    "scale": 1.4414,
    "cropLoss": 0.1562,
    "offset": [0, 167],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.44× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/state-banks-npl-share-70pct-01.jpg",
    "url": "/images/posts/2026-08/state-banks-npl-share-70pct-01.jpg",
    "width": 1600, "height": 900, "bytes": 235347, "quality": 90
  },
  "status": "ok"
}
```

cropLoss 0.156 — ниже порога crop-risky (0.25), режим cover без подложки.
Апскейл 1.44× — в пределах MAX_UPSCALE скрипта (2.5), визуально приемлемо,
на превью после обработки все четыре башни целиком видны, композиция не
пострадала.

## Отклонённые варианты
- Логотипы/иконки регионов на /ru/contacts/ — не фото, не подходит.
- Фото встреч/переговоров с сайта cbu.uz (Standard Chartered, IFSB и т.д.) —
  не по теме материала (статья не про конкретную встречу), и там есть люди —
  на статистической/экономической теме избегаем "банкиры за столом" (запрет
  из handoff).
- Unsplash "Tashkent" landscape — только общие виды города без привязки
  к банковской теме (колесо обозрения, купола) — не subject-first, misleading
  относительно темы.
- AI-генерация (Higgsfield) не потребовалась — нашёлся официальный
  институциональный кадр здания-первоисточника данных.

кадра на сайте ЦБ (credit дан как "Пресс-служба ЦБ РУз" по институциональной
