## Что делать reporter'у (правка, не новый репортаж)

**Сними раздел «Уголовное дело» целиком** — вместе с упоминаниями ст. 257 и 192-11 УК,
фразой «а по факту происшествия возбуждено уголовное дело» в лиде, и ссылкой на
t.me/HShamsutdinov в sources. Материал остаётся легитимной новостью и без этого раздела —
три подтверждённых факта: обрушение котлована 2 августа, один пострадавший (с уточнением
версии хокимията), причина (неосторожность подрядчика), спецкомиссия по расследованию.

Дополнительно:
1. Убрать из description фразу «Генпрокуратура завела дело против должностных лиц застройщика».
2. Переформулировать заголовок и лид без упоминания уголовного дела — фокус на самом
   происшествии и расследовании причин комиссией.
3. НЕ добавлять publishedAt/updatedAt — их проставит публикатор при выпуске из очереди
   (fact-checker предложил их добавить — это неверно на данной стадии конвейера LEAP,
   игнорировать эту часть его отчёта).
4. Опционально: свериться с точным русским названием Инспекции по стройконтролю.

это отдельная тема для needs-verification recheck, не блокирует публикацию текущей заметки
о самом происшествии.
