## Шаг 1 — первоисточник (отклонён)
- Telegram-пост Нацкомстата (`t.me/uzstataxborot/69171`) содержит собственное
  медиа 800×420 (`cdn4.telesco.pe/...`) — это типовая **сток-заготовка**:
  столбики монет + белые стрелки роста поверх денег. Ровно тот паттерн, что
  редполитика запрещает даже из первоисточника («не берём даже из
  первоисточника: пресс-службы часто украшают релизы именно ими»).
  **Отклонено.**
- Второй URL в HTML поста — аватар канала 160×160 (как и предупреждает
  `image-pipeline.md`) — не годится и не по размеру, и не по содержанию.
- Пресс-релиз на `stat.uz` — при обходе через WebFetch изображений/og:image
  в разметке не найдено.
- Итог: официального фото по теме нет, у релиза есть только 3D/стоковая
  заготовка → первоисточник отклонён целиком.

## Шаг 2 — тематический сток (использован)
Reporter в notes указал: «нет явного (статистика) — нейтральная инфографика
или стройплощадка». По задаче от оркестратора — искать реальное фото
стройплощадки/промышленного объекта в Узбекистане.

Рассмотрены кандидаты (Unsplash, все проверены на реальную фотографию, не
рендер):

1. **Кран + флаги Узбекистана + недостроенное здание** (Sodikjon Akhmedov,
   Tashkent) — сильнее всего подходит по теме («стройплощадка в
   Узбекистане» буквально), но исходник 4377×3502 (соотношение 1,25) даёт
   `cropLoss 0,297` (30% по высоте) в `prepare-image.py`. Это выше порога
   0,25, при котором редполитика требует уточнения у человека для фото с
   явным объектом (здание/кран). Визуально проверил результат (см. тестовый
   прогон) — крадётся только небо над краном, флаги и здание не срезаны,
   но по формальному порогу это `crop-risky`. Чтобы не блокировать
   публикацию статьи ради уточнения по картинке, которая не является
   единственным вариантом (эксклюзива нет, есть равноценная замена без
   риска) — **отклонил в пользу более безопасного кадра**, не стал уходить
   в очередь `editor-queue`.
2. **Железнодорожный вокзал Ташкента** (Sodikjon Akhmedov, @sakhmedoff,
   Unsplash) — реальная фотография, соотношение 1,5 (5472×3648), `cropLoss`
   у `prepare-image.py` всего 0,156 (16% по высоте, безопасно ниже порога
   0,25). Явно узнаваемый объект — Ташкент (вывески «Toshkent», «Vokzal»),
   инфраструктурный объект, визуальная аллюзия на капитальные вложения в
   инфраструктуру Узбекистана. **Выбран.**
3. Прочие рассмотренные и отклонённые (не Узбекистан / не по теме / плохой
   контекст): краны на закате (Nicolas Beuret, ratio 1.78 — идеальный кроп,
   но без привязки к Узбекистану, отложен как запасной вариант); заброшенное
   здание с вывеской «Yoshing muborak, O'zbekistonim!» (Damir Semirkhanov) —
   формально Узбекистан, но по содержанию — ветхое, заброшенное здание,
   визуально противоречит смыслу новости о росте инвестиций; локомотив-музей
   на фоне жилого дома (Slava Denisov) — декоративная сцена, слабая связь с
   темой инвестиций.
