# Bild notes: design-code-tashkent-reversal

## Стратегия: none → очередь редактора (reason `no-image`)

STATUS: fallback-needed

## Задача от поручения (handoff)
`image-hint`: обновлённый фасад торгового павильона/кафе в Ташкенте с новой
вывеской/витриной по дизайн-коду; альтернатива — здание хокимията Ташкента.
`image-avoid`: лица конкретных предпринимателей без согласия; логотипы
конкретных рекламно-производственных компаний.

## Шаг A — первоисточник (tashkent.uz, новость 7424)

`sources` в драфте — обе языковые версии одной новости хокимията (ru/uz).
Первый `curl` без актуального `User-Agent` вернул статичный HTML с *другой*
новостью («Уточнён график приёма граждан», id 7423) — сайт, похоже,
кеширует/отдаёт разный контент в зависимости от заголовков. Повторный запрос
с `User-Agent` браузера и cache-busting параметром дал правильную страницу
(заголовок «Подход к внедрению дизайн-кода скорректирован...», текст совпадает
с драфтом).

- **Тело статьи** — только текст (эмодзи-буллиты), без единого `<img>` внутри
  `dangerouslySetInnerHTML`-блока. Инлайн-фото в материале нет.
- **og:image** — единственная картинка, привязанная к новости 7424:
  `https://api.tashkent.uz/upload/news/speaking/2026/08/Сни‌ghghghh‌мок.JPG`
  (имя файла — обфусцированное «Снимок.JPG», т.е. буквально «скриншот»).
  Скачал и просмотрел (1796×1017): это **скриншот эфира телеканала
  «O'zbekiston 24»** — в кадре плашка канала (лого справа сверху), таймкод
  15:10 и гео-метка "Toshkent shahri" слева сверху, красная плашка
  «AXBOROT 24» и синяя плашка заголовка «DIZAYN-KOD: PESHLAVHALAR TARTIBGA
  SOLINMOQDA», плюс нижняя бегущая строка про логистику через порт Дуррес
  (Албания) — вообще не по теме статьи. Сам центральный кадр (вывески
  «ATELE» и «NOTARIUS» на фасаде) в целом релевантен теме (регулирование
  вывесок), но использовать нельзя:
  1. это фактически ретрансляция чужого телеэфира без атрибуции и без
     проверенного права на повторную публикацию;
  2. кадр перегружен чужим брендингом и нерелевантной бегущей строкой —
     убрать оверлеи кропом нельзя: логотип и таймкод сверху, две плашки и
     бегущая строка снизу перекрывают такую долю кадра, что обрезка
     гарантированно вышла бы за лимит `prepare-image.py` (≤22%).
  3. Такое же по типу имя файла («Сни***мок.JPG» с разными вставками —
     `klklkkl`, `gdgdgdg`, `ioioiooi`, `ghghghh`) встречается у превью
     нескольких *других*, не связанных по теме новостей хокимията в блоке
     «Похожие новости» — похоже, сайт массово использует такие
     теле-скриншоты как дефолтные превью, это не редакционное фото
     конкретно для нашей статьи.
- Главная страница `tashkent.uz/ru` — `og:image` только `logo.svg`, живого
  фото здания хокимията на главной нет.
- Поиск по сайту (`tashkent.uz/ru/search?q=дизайн-код`) — результаты
  рендерятся через JS, в статичном HTML нет карточек с превью для проверки.

- Unsplash: `tashkent-street-shop-signage` → 2 результата, оба нерелевантны
  теме (уличная табличка с названием улицы и номером дома — не коммерческая
  вывеска; жилой дом с бельём на верёвках). Второй кандидат (табличка
  «Alisher Navoiy ko'chasi, 16», Azizbek Sayidov) — вертикальная (1600×2133)
  и по содержанию не про фасад/витрину бизнеса, отклонён.
- Unsplash: `uzbekistan-storefront` → 0 результатов.
- Unsplash: `tashkent-city-hall` → 0 результатов (альтернативный субъект из
  handoff — здание хокимията).
- Pexels: `tashkent street`, `shop facade sign` → релевантных по географии
  результатов нет; выдача — Япония/Китай/Корея/Амстердам/США. Использовать
  такие кадры для материала о Ташкенте — подмена места действия, отклонил.
- Openverse (`api.openverse.org`, `license=cc0,pdm`):
  - «Tashkent street», «Tashkent building» → только `upload.wikimedia.org` —
    чёрный список редполитики (раздел 2, Wikipedia не источник). Не беру.
  - «Tashkent hokimiyat», «Tashkent city hall», «Uzbekistan shop sign» →
    0 результатов.
  - «storefront sign street» → 160 результатов, но география — города США
    (Marion N.C., Mebane N.C., Madison N.C. и т.д.), не Узбекистан.
  Совпадает с выводом прежнего прогона по соседней теме
  (`bild-notes-tashkent-hokimiyat-advisor-appeals-chief.md`): официального
  живого фото здания хокимията в открытом доступе физически нет, Wikimedia —
  единственный формальный источник и он в чёрном списке.

## Шаг C — AI-генерация

Инструмент `generate_image`/Higgsfield не подключён к тулсету этого прогона
(доступны только Read/Edit/WebFetch/Bash/Grep/Glob) — прецедент подтверждён
в `bild-notes-supreme-court-mobile-reception-tashkent.md` и
`bild-notes-tashkent-hokimiyat-advisor-appeals-chief.md`. Физически
недоступно, не отвергнуто по существу.

По существу для будущего прогона с рабочим Higgsfield: подошла бы нейтральная
иллюстрация — обновлённый фасад торгового павильона/кафе с абстрактной
нечитаемой вывеской (без реальных брендов/логотипов рекламно-производственных
компаний), без людей, документальный стиль, фирменная палитра (`#FF4D2E`
акцент, графит `#1A1A1A`, песочный `#F5EFE8`, приглушённый синий `#2C3E50`),
`credit: "AI generated (LEAP News)"`.
