# Reporter notes: yangiyol-tuya-bogiz-electricity-debt-582m

## Тема
Заместитель Генпрокурора С. Самадов проверил состояние энергоснабжения в махалле
«Туя-бўғиз» Янгиюльского района Ташкентской области. Выявлена задолженность
1 166 абонентов за электроэнергию на 582,1 млн сумов. Район отнесён к «жёлтой»
категории энергоснабжения.

## Первоисточники (проверенные)
- [t.me/uzbprokuratura/87841](https://t.me/uzbprokuratura/87841) — единственный
  первоисточник по теме. Пост Генеральной прокуратуры РУз (P1, `type: source`
  в `config/telegram-channels.json`). Извлекал текст через WebFetch трижды
  отдельными запросами (общая сводка, точные цифры/цитата про «жёлтую» категорию,
  детали про 23 счётчика/101 абонента/ответственных лиц) — цифры совпали во всех
  прогонах: 582,1 млн сумов, 1 166 абонентов (1 152 физлица + 14 юрлиц),
  23 счётчика без связи, 101 абонент с потреблением до 50 кВт·ч.
- [cbu.uz архив курсов USD](https://cbu.uz/ru/arkhiv-kursov-valyut/json/USD/2026-08-08/) —
  курс 11 915,64 сума/доллар на 7 августа 2026 (JSON API вернул дату 07.08, при
  запросе на 08.08 — видимо, последний зафиксированный торговый день). Использован
  для пересчёта суммы долга в доллары (≈49 тыс. долларов).

## Расхождения с inbox-снипетом

## Что не вошло в статью
- **Более широкий контекст**: Янгиюльский район с 27 июля 2026 — пилотный
  район по реформе электро- и газоснабжения (по сообщениям СМИ-конкурентов —
  gazeta.uz, sputniknews.uz — президент объявил на совещании, создан штаб во
  главе с министром энергетики Ш. Ходжаевым, опыт планируют распространить на
  13 других районов к 1 октября). Это, вероятно, прямо объясняет, почему именно
  в Янгиюле идёт усиленная прокурорская проверка энергоснабжения по «жёлтой»
  категории. НЕ включил в статью, потому что не нашёл первоисточник из белого
  списка: искал на `president.uz` (русский и узбекский разделы, несколько
  релевантных ID вокруг конца июля — ни один не подошёл по содержанию), проверил
  `t.me/s/minenergy_uz` (Минэнерго, официальный канал из конфига) — поста про
  Янгиюль в доступной ленте не нашлось. Тема встречается только у gazeta.uz
  (чёрный список) и sputniknews.uz (не первоисточник, репортаж конкурента) —
  цитировать нельзя.
  **Рекомендация**: отдельная статья про сам пилотный проект Янгиюля, когда
  найдётся первоисточник (стенограмма совещания на president.uz или пресс-релиз
  Минэнерго) — тогда эта заметка про «Туя-бўғиз» станет частью более крупной
  картины с перелинковкой.
- «Кто именно отвечает за взыскание долга» (РЭС / хокимият / энергокомпания) —
  в посте прокуратуры не названо конкретное ведомство, только общая формулировка
  «масъул ташкилотлар» (ответственные организации). Не выдумывал; можно уточнить
  отдельным запросом у прокуратуры Ташкентской области (@toshkentprokuraturasi)
  или Минэнерго.
- Параллели по другим махаллям в рамках той же кампании — в доступной части
  ленты @uzbprokuratura на момент проверки других постов про энергозадолженность
  не встретилось. Возможно, появятся позже — тема для мониторинга.

## Самопроверка при вычитке
При первом черновике по ошибке дописал полные имена (Санжарбек Самадов,
Абдулла Мирзаев) вместо инициалов первоисточника «С.Самадов» и «А.Мирзаев» —
для Самадова беглый поиск нашёл правдоподобное совпадение (Салом Самадов,
первый замгенпрокурора) только в источниках вне белого списка (gazeta.uz,
oyina.uz), для Мирзаева совпадения не нашлось вообще. Откатил оба имени к
инициалам, как в первоисточнике — не хочу приписывать ФИО без подтверждения
официальным ресурсом. Fact-checker может отдельно уточнить полные имена через
prokuratura.uz, если это важно для публикации.

## Пропуски и слабые места
- Детали про «23 счётчика без связи» и «101 абонент с потреблением до 50 кВт·ч»
  извлечены через WebFetch (AI-суммаризация HTML-страницы t.me/s/...), не через
  прямое построчное чтение исходного текста поста. При одном из промежуточных
  запросов инструмент один раз выдал явно ошибочный (галлюцинированный) ответ не
  по теме (перепутал с постом про Андижан) — этот ответ отброшен, не использован.
  Устойчивые данные (582,1 млн сумов, 1 166 абонентов, «жёлтая» категория, 23
  счётчика, 101 абонент) подтвердились по два-три раза отдельными запросами,
  поэтому доверяю, но fact-checker'у стоит перепроверить два последних числа
  вручную при возможности прямого просмотра поста.
- Курс ЦБ датирован 7 августа, а не днём события (8 августа) — JSON API архива
  на дату 08.08 вернул запись с полем `Date: 07.08.2026`, видимо это последний
  зафиксированный торговый день на момент запроса. В тексте указано честно
  «на 7 августа», без подмены дат.
- Сроки исполнения поставленных прокуратурой задач в первоисточнике отсутствуют —
  это не пропуск с моей стороны, в посте их просто нет.
