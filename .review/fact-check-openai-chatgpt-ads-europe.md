## Блокер репортёра — что удалось выяснить

Официальный анонс OpenAI (`https://openai.com/index/chatgpt-ads-expands-across-europe/`)
не открылся и у фактчекера — WebFetch снова вернул HTTP 403. Дополнительно
проверена `https://openai.com/chatgpt/pricing/` (другая страница того же домена) —
тоже 403, значит блокировка не точечная, а на уровне всего домена openai.com для
автоматических запросов; `web.archive.org` инструменту также недоступен. Итого
3 попытки фактчекера + 4 попытки репортёра = 7 неудачных заходов за цикл.

Вывод: домен `openai.com` заблокирован для наших фетчеров технически, это не
повод считать анонс несуществующим — он назван, процитирован дословно AFP и
подтверждён множеством СМИ. Поскольку AFP (международное агентство из белого
списка) приводит прямые цитаты OpenAI, AFP выступает самостоятельным легитимным
первоисточником по §1.2 редполитики, и материал в целом НЕ обязан уходить в
форму понижения по Приложению 10.1.

Приложение 10.1 релевантно для одной конкретной детали (находка №10) — там оно,
наоборот, не выполняется, поэтому деталь не публикуется даже с понижением,
а убирается.

## Список понижений для editor'а (применяет сам, без повторной проверки)

1. Абзац 5, «С тех пор сервис расширился ещё на восемь регионов мира.» —
   **удалить целиком**. Единственная опора — недоступный openai.com; ни AFP,
   ни один источник из белого списка это число не подтверждают. Условия
   Приложения 10.1 не выполнены — значит не понижаем формулировку, а убираем факт.

2. Абзац 2, «Реклама не затронет подписки Plus, Pro и Enterprise» → «Реклама не
   затронет премиум-подписки ChatGPT». Соответствует дословной формулировке AFP
   «premium subscription services»; поимённый список тарифов в цитируемом
   источнике не назван, страница тарифов недоступна.

3. Абзац 4 (цитата OpenAI с атрибуцией) — ≈29 слов, длиннее лимита. Разбить на
   два предложения, вынести атрибуцию отдельным коротким предложением.

4. Опционально: при первом упоминании дать полное название «Agence France-Presse
   (AFP)».

Пункты про 31 страну и про «Узбекистана в списке нет» правок не требуют — обе
формулировки корректно ограничены пределами подтверждённого.
