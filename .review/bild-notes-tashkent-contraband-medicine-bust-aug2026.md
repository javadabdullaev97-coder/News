## Стратегия: stock

## Почему не первоисточник
Единственный источник факта — attributed Telegram-канал «Xavfsizlik» (t.me/xavfsizlik_uz/2448),
принадлежность СГБ официально не подтверждена. Материал о незавершённом уголовном
расследовании: подозреваемые не осуждены. По прямому указанию поручения — никаких фото
подозреваемых, их домовладений, задержания или вещдоков с опознаваемыми деталями (лица,
номера домов), даже если такие кадры есть в самом посте канала. Проверка поста через
WebFetch (`t.me/s/xavfsizlik_uz/2448`) не дала доступа к самим медиафайлам поста для
безопасной оценки содержимого — рисковать не стал, к посту как источнику фото не обращался.

State Customs Committee (customs.uz) — SPA/JS-рендер, HTML отдаёт только заголовок вкладки
без og:image и вообще без картинок (подтверждено WebFetch), совпадает с выводом reporter'а
о недоступности сайта. Здание ведомства через сайт не достать.

### Про cropLoss 0,156 (выше порога 0,15) — решил не эскалировать
Формально порог `imagery.cropRiskThreshold` (0,15) превышен на 0,006. Но эскалация
`crop-risky` предполагается для фото с **единичным явным объектом** (лицо, животное,
здание, документ), где обрезка может «обезглавить» кадр. Здесь предмет съёмки — не единичный
объект, а горизонтальный ряд из полутора десятков флаконов, заполняющий кадр по всей ширине;
обрезка (15,6% по высоте) срезала только пустую стену над бутылками и край нижней полки —
визуально проверил итоговый файл: ни одна этикетка, ни одна крышка не обрезаны, композиция
не пострадала. Решил не заводить `crop-risky`, но фиксирую цифру и рассуждение здесь для
прозрачности — при появлении опровержения владелец может пересмотреть.
