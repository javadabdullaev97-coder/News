# Fact-check: nevada-robotaxis-tesla-uber-waymo

## Общий вердикт: APPROVE-WITH-DOWNGRADES

Центральный факт (одобрение NTA разрешений Tesla/Uber/Waymo на до 8000 роботакси, разбивка по
компаниям) подтверждён прямой проверкой TechCrunch — устоял. Применение §10.1 содержит
методологическую неточность (см. ниже), плюс найдена одна фактическая ошибка в имени и одна
формулировка, прямо противоречащая источнику. Всё лечится точечными правками без повторной
проверки.

## Особое замечание: корректность применения §10.1

1. Первоисточник назван и совпадает — да, сертификат NTA/Tesla Robotaxi LLC AVNC-002. ✓
2. **Не выполнено для центрального факта**: об одобрении 20 августа (8000/5000/1000/1000/100)
   сообщает только TechCrunch. Electrek и Axios подтверждают независимо только другой, более
   ранний эпизод (тестовое разрешение на 10 машин) — отдельный факт, не событие 20 августа. Лид
   и description статьи формулируют это как «по сведениям, которые приводят несколько изданий» —
   overclaim применительно к событию 20 августа: фактически это одноисточниковая (TechCrunch)
   новость.
3. Попытки получить первоисточник сами — выполнено (PDF, новостная страница NTA, реестр
   tsa1.nv.gov — 503, запрос оформлен). ✓
4. Событие проверяемо задним числом. ✓

Вывод: условие 2 не выполнено буквально для события 20 августа — не основание для REJECT (факт
подтверждён прямой проверкой TechCrunch), но требует понижения атрибуции с «несколько изданий»
на «TechCrunch» именно в частях про 20 августа. Июльская часть (Electrek+Axios) уже
атрибутирована корректно.
