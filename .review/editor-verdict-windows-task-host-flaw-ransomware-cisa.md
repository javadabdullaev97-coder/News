## Применённые понижения (по списку fact-checker'а)

1. **Заголовок**: смягчена прямая атрибуция CISA → атрибуция каталогу.
   `Власти США подтвердили: брешь в Windows теперь используют вымогатели`
   → `Каталог CISA: уязвимость Windows теперь используют вымогатели`.
   Причина: страница cisa.gov недоступна и репортёру, и фактчекеру (403);
   флаг «используется вымогателями» подтверждён только одним сторонним
   зеркалом каталога KEV (cyber.trackr.live), не самой CISA напрямую.
2. **Тело статьи**: в абзаце про обновление записи каталога («На этой
   неделе CISA обновила...») добавлено предложение о прозрачности
   источника: «Страница CISA на момент публикации не открывалась; эту
   отметку подтверждает независимое зеркало каталога KEV.» Название
   стороннего зеркала в текст не выносил и ссылку на него не добавлял —
   это была бы новая непроверенная fact-checker'ом ссылка (запрещено
   редполитикой).
3. **Лид** приведён в соответствие с новой, более осторожной рамкой
   заголовка: было «CISA обновило каталог... теперь используют группировки
   вымогателей» (безусловное утверждение), стало «...по данным каталога,
   теперь используют вымогатели» (хедж). Факт не добавлен и не убран —
   только атрибуция.
