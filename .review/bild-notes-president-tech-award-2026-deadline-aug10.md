## Обработка
SVG-логотип не подать в `prepare-image.py` напрямую (только растровые форматы).
Рендерил SVG в PNG через `cairosvg` (scale=6, чтобы текст остался чётким) —
2400×612, RGBA с прозрачным фоном. Прямая заливка (cover) такого широкого лого
в кадр 1600×900 обрезала бы текст по бокам, поэтому по аналогии с сестринской
статьёй собрал промежуточный кадр вручную: логотип вписан целиком (без
изменения содержимого — не перекрашивал, не дорисовывал), по центру, на
сплошную графитовую подложку `#1A1A1A` (синхронизирована с `SOLID_BG_COLOR`
из `prepare-image.py`, не изобретённый цвет). Ширина логотипа — 72% от ширины
канвы, вертикально отцентрован — пропорции близки к сестринской статье.
Композит уже ровно 1600×900, прогнан через `prepare-image.py` штатно:

```json
{
  "source": {"width": 1600, "height": 900},
  "fit": {"mode": "cover", "scale": 1.0, "cropLoss": 0.0, "offset": [0, 0], "upscaled": false,
          "note": "обрезано 0% по высоте; окно кропа выбрано по содержимому"},
  "output": {"path": "public/images/posts/2026-08/president-tech-award-2026-deadline-aug10-01.jpg",
             "url": "/images/posts/2026-08/president-tech-award-2026-deadline-aug10-01.jpg",
             "width": 1600, "height": 900, "bytes": 42798, "quality": 90},
  "status": "ok",
  "upscaled": false
}
```

Ноль обрезки, ноль апскейла — подложка законна, потому что это не спасение
вертикального кадра, а штатный контейнер для широкого логотипа с прозрачным
фоном (тот же приём, что в сестринской статье 07.08).
