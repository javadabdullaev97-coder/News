# Reporter notes: anthropic-record-ipo

**Тема**: Anthropic готовится к IPO, объём которого может сравняться с рекордным
размещением SpaceX (86,2 млрд долларов, июнь 2026) или превзойти его. Источник —
Bloomberg со ссылкой на анонимные источники, официального подтверждения от Anthropic нет.

**Первоисточники (проверенные)**:
- vedomosti.ru/investments/news/2026/08/21/1222804-anthropic-nadeetsya-prevzoiti —
  успешно открыт WebFetch. Дал полный набор цифр: SpaceX 75 млрд / 86,2 млрд долларов
  с overallotment, IPO SpaceX в середине июня 2026; банки-андеррайтеры Anthropic
  (Morgan Stanley, Goldman Sachs, JPMorgan Chase); раунд Anthropic в мае — 65 млрд
  долларов при оценке 965 млрд; выручка Q2 >11,5 млрд долларов против 787 млн годом
  ранее; run rate на конец июля — 65 млрд долларов; заявка на IPO ожидается в конце
  августа; параметры сделки не финальны; конкуренция с OpenAI (IPO не раньше 2027).
  Статья сама явно ссылается на Bloomberg.
- bloomberg.com/news/articles/2026-08-20/anthropic-expects-to-match-spacex-s-record-ipo-size-or-top-it —
  URL подтверждён через WebSearch (реальная статья, заголовок и содержание совпадают
  с пересказом «Ведомостей»). Прямой WebFetch вернул HTTP 403 (пейволл). Контент в
  текст напрямую не брался — все цифры сверены через citable-источник, который сам
  открыто цитирует Bloomberg с теми же цифрами.
- Видеосюжет Bloomberg "Daybreak Europe 8/21/2026" (исходный block 2 из задания) —
  WebFetch вернул 403. В статье не использован, заменён на текстовую статью Bloomberg
  с тем же сюжетом.

**Расхождения с inbox-снипетом**: нет — снипет «Ведомостей» точно соответствует
содержанию открытой статьи.

**Main visual subject**: Дарио Амодеи (CEO Anthropic) на публичном выступлении, либо

**Что не вошло в статью**:
- Оценка при самом IPO ($1–2 трлн, по неподтверждённым прогнозам FT/инвесторов) —
  только в невыверенных агрегаторах, FT напрямую не фетчил (бюджет ограничен).
- Прогноз выручки на 2028 год ($190–200 млрд, со ссылкой на FT) — та же причина.
- Supervoting-акции для Амодеи и сооснователей — встречалось только в неверифицированном
  пересказе (beincrypto), не взято.
- Возможная отдельная тема: реакция рынка, если Anthropic официально подаст S-1 — ждём
  подтверждения.

**Пропуски и слабые места**: вся фактура держится на анонимных источниках Bloomberg без
официального подтверждения Anthropic (отражено в тексте прямо); первоисточник Bloomberg
не открылся напрямую (403), компенсировано вторым citable-источником; совпадение цифры
65 млрд долларов в двух разных контекстах (майский раунд и июльский run rate) — стоит
перепроверить fact-checker'у, не перепутаны ли они в исходнике.

**Уверенность: 65%** — фактура согласована в двух citable-источниках, но вся история —
pre-IPO слух с хорошей атрибуцией, а не подтверждённый факт.
