# Bild notes: grade10-to-technicum-transfer-rule

## Стратегия: stock

## Явного визуального субъекта нет
handoff (`image-hint`) и reporter-notes (`Main visual subject`) совпадают: у темы
(регуляторный акт Кабмина о порядке перевода) нет конкретного события/лица —
предложены на выбор «ученики/студенты техникума на занятии либо здание колледжа»,
запасной вариант — здание Кабмина. `image-avoid` отдельно предупреждает: нельзя
показывать конкретные лица/классы несовершеннолетних без согласия — десятиклассники
и учащиеся техникумов формально несовершеннолетние.

```json
  },
  "output": {
    "path": "public/images/posts/2026-08/grade10-to-technicum-transfer-rule-01.jpg",
    "url": "/images/posts/2026-08/grade10-to-technicum-transfer-rule-01.jpg",
    "width": 1600, "height": 900, "bytes": 261523, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```
cropLoss 0,1562 — ниже порога `crop-risky` (0,25), в очередь материал не уходит.
