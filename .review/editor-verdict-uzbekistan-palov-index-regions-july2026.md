# Editor verdict: uzbekistan-palov-index-regions-july2026

## Решение: publish

## Изменения в заголовке
**До**: «Нацкомстат: плов подорожал до 128,7 тысячи сумов за кг в Ташкенте»
**После**: без изменений.
Обоснование: 65 символов, в первых 40 — суть события («плов подорожал»), число цифрой,
без CAPS/«!»/оценочных слов. Fact-checker подтвердил заголовок как соответствующий
редполитике — трогать не было причины.

## Изменения в лиде
**До**: «Национальный комитет Республики Узбекистан по статистике 5 августа опубликовал
стоимость продуктов для приготовления 1 килограмма плова по регионам за июль — от 107,4
тысячи сумов в Каракалпакстане до 128,7 тысячи сумов в Ташкенте.» (32 слова)
**После**: «Национальный комитет Республики Узбекистан по статистике 5 августа опубликовал
стоимость ингредиентов для 1 кг плова по регионам за июль — от 107,4 тысячи сумов в
Каракалпакстане до 128,7 тысячи в Ташкенте.» (30 слов)
Обоснование: понижение №3 из фактчека — лид был 32 слова, норма 25–30. Убрал повторы
(«продуктов для приготовления» → «ингредиентов», второе «сумов» перед Ташкентом избыточно
на фоне уже названной валюты). Полное официальное имя ведомства и оба крайних региона
(что/кто/когда/где) сохранены — full name Нацкомстата в лиде остаётся точкой первого
упоминания, дальше по тексту используется короткая форма.

## Применённые понижения fact-checker'а
1. **Атрибуция расчётного среднего** (абзац после списка регионов): было
   «Среднее значение по всем 14 регионам — около 119 200 сумов (≈10,03 доллара) за
   килограмм» → стало «Если посчитать простое среднее по данным Нацкомстата за все 14
   регионов, получится около 119 200 сумов (≈10,03 доллара) за килограмм — этот показатель
   ведомство отдельно не публикует». Формулировка взята из фактчека дословно (с точечной
   адаптацией под контекст абзаца).
2. **Снятие неатрибутированной причинной гипотезы про мясо/рис**: было «Плов дорожает,
   несмотря на общее удешевление продуктов, — вероятно, за счёт роста цен на мясо и рис,
   которые Нацкомстат не детализирует отдельно от прочих ингредиентов» → стало «Плов
   дорожает, несмотря на общее удешевление продуктов. Причины этого расхождения Нацкомстат
   отдельно не поясняет — ведомство не детализирует вклад мяса и риса в стоимость набора».
   Выбрал вариант «переформулировать без утвердительной интонации» (второй вариант из
   списка фактчека) вместо полного удаления — предложение не несёт отдельной ссылки на
   источник, факт (нет детализации) остаётся, причинность снята.
3. **Лид сокращён** — см. выше.

Повторная фактчек-проверка не запускалась: ни один пункт не добавляет новых фактов, все три —
атрибуция, снятие гипотезы, длина лида.

- **Новая inline-ссылка или новая запись в `sources`**: не добавлял. `frontmatter.sources`

## Стилистические правки
- Убрал избыточное повторение «сумов» в конце лида («128,7 тысячи сумов» → «128,7 тысячи»,
  валюта уже названа раньше в предложении).
- «продуктов для приготовления 1 килограмма плова» → «ингредиентов для 1 кг плова» — короче,
  без канцелярита, «кг» единообразно с остальным текстом (в теле статьи везде «кг»).
- Остальной текст (структура H2, список регионов, курс ЦБ, проценты роста, состав набора
  ингредиентов) не трогал — он уже соответствовал редполитике по чек-листу фактчека.

## Что оставил как есть
- Заголовок — уже в норме, менять не было оснований.
- Description (155 символов) — точный, без оценочных слов, укладывается в 140–160.
- Структура из двух H2 («Разброс цен по регионам», «Рост за месяц и на фоне дефляции
  продуктов») — соответствует правилу «детали события → контекст», третий H2 не нужен:
  материал не предполагает «что дальше» (это регулярный ежемесячный релиз без дедлайнов).
- Список из 12 регионов — оставил как маркированный список, не переписывал в прозу: так
  быстрее считывается, чем перечисление 12 чисел в одном предложении.
