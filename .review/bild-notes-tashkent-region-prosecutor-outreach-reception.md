# Bild notes: tashkent-region-prosecutor-outreach-reception

## Стратегия: primary-source

## Источник картинки
- Пост первоисточника: https://t.me/uzbprokuratura/87928 (Telegram-канал Генеральной прокуратуры РУз)
- Заметка reporter'а гласила «явного визуального субъекта нет, рутинный приём без фотоотчёта» —
  это оказалось неточно: у поста есть grouped media из 5 живых фото приёма (проверено через
  `t.me/uzbprokuratura/87928?embed=1`, `background-image:url(...)` в HTML виджета).
- Отсмотрены все 5 фото: 2 портрета прокурора А. Мирзаева за столом, общий план приёма
  (прокурор + 2 заявителя, флаг Узбекистана и эмблема прокуратуры на фоне), портрет заявителя
  (мужчина с документами) с двух ракурсов, групповой снимок сотрудников с блокнотами.
- Выбран кадр «мужчина с документами на приёме» (800×457, самый широкий из пяти — 1,75 к 1,
  ближе всего к целевым 16:9) — единственный, где `cropLoss` уверенно низкий.

## Обработка
`scripts/prepare-image.py`, JSON:
```json
{
  "source": {"width": 800, "height": 457},
  "fit": {
    "mode": "cover",
    "scale": 2.0,
    "cropLoss": 0.0153,
    "offset": [0, 0],
    "upscaled": true,
    "note": "обрезано 2% по высоте; окно кропа выбрано по содержимому; исходник растянут в 2.00× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/tashkent-region-prosecutor-outreach-reception-01.jpg",
    "width": 1600, "height": 900, "bytes": 120003, "quality": 90
  },
  "status": "ok"
}
```
Апскейл 2× — ожидаемо для Telegram-исходника (публичный виджет отдаёт максимум 800px по
длинной стороне), укладывается в допустимый потолок скрипта.

## Отклонённые варианты
- Общий план приёма (прокурор + 2 заявителя, эмблема+флаг) — визуально самый содержательный,
  но `cropLoss = 0,2525` — чуть выше порога 0,25 для фото с явными людьми в кадре. Хотя
  визуальная проверка результата (сгенерировал тестовый рендер) не показала обрезанных лиц,
  предпочёл не спорить с порогом и взял кадр с надёжным запасом по обрезке.
- Портрет прокурора А. Мирзаева за столом (с нашивкой «MIRZAYEV A.E.») — та же проблема:
  исходник 800×602, `cropLoss = 0,2525`, тот же риск по правилу.
- Групповой снимок сотрудников с блокнотами — не по теме (не заявители и не прокурор
  за приёмом), отклонён по релевантности.

## Alt-текст

описывает содержимое кадра (заявитель с бумагами за столом приёма), не дублирует заголовок.

## Уверенность в подборе: 75%
Кадр подлинный, с самого разбираемого события (grouped media поста первоисточника), с надёжным
запасом по crop-loss. Минус к уверенности: на кадре не виден сам прокурор Мирзаев — центральный
субъект заголовка — только один из заявителей; более иллюстративный общий план (с прокурором,
эмблемой и флагом) отклонён из-за пограничного `cropLoss` 0,2525 (нужен человеческий контроль по
инварианту cropLoss > 0,25 из инструкции), а не по содержанию.
