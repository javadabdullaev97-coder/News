# Fact-check: anthropic-openai-revenue

## Общий вердикт: APPROVE-WITH-DOWNGRADES

Центральный факт (Anthropic впервые обошла OpenAI по выручке, $11,6 млрд vs $6,7 млрд) прочно подтверждён тремя источниками. Два открытых вопроса: (1) драфт замалчивает реальное противоречие источников по темпу роста Anthropic — SiliconANGLE даёт «более чем на 50%», The Decoder и PYMNTS дают «удвоение»; (2) не выполнена формула-оговорка §10.1 для недоступного первоисточника WSJ.

## Разрешение противоречия по темпу роста Anthropic

Все три источника проверены напрямую. SiliconANGLE прямо и недвусмысленно называет другой темп роста («jumped by more than 50%») для того же перехода Q1→Q2, привязывая его к цифре $11,6 млрд — это не опечатка. Ни один источник не даёт точную Q1-выручку Anthropic, арбитрировать нечем. Это случай §10 «цифра из источников не совпадает, не живое событие» → цитировать обе версии с атрибуцией, а не молчаливо выбирать одну.
