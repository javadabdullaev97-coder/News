# Bild notes: supreme-court-anticorruption-law-analysis

## Стратегия: stock (Unsplash)

## Определение субъекта
Reporter notes (`mainVisualSubject`): здание Верховного суда РУз в Ташкенте или зал
судебных заседаний; альтернатива — нейтральная инфографика с текстом закона/кодекса.
Явного человека-субъекта нет — материал про закон и его нормы, а не про конкретное
должностное лицо. Editor verdict без дополнительной подсказки по картинке.

## Путь A — первоисточники: не сработал
- `t.me/oliysuduz/51349` — сам пост оказался **видео** (разбор судей Кашкадарьинского
  облсуда), не фото. Постер видео вытянут через `?embed=1`: 320×180 px — студийная
  заставка новостного канала «Qashqadaryo TV» (полосы, цифры, синий фон), не здание
  и не зал суда. Отклонён по двум причинам: (1) 320 px по длинной стороне < 600 px
  порога `too-small`; (2) даже если бы прошёл по размеру — не относится к
  mainVisualSubject, это генерическая TV-заставка.
- Лента `t.me/s/oliysuduz` (публичный виджет, последние ~12 постов) проверена целиком:
  единственные фотопосты — 51328 (без текста, тип не поддерживается виджетом) и 51334
  (приём граждан председателем Верховного суда Р. Махмудовой) — оба **не по теме
  статьи** (не про закон о коррупции, другой информационный повод) и содержат
  конкретное неназванное в статье лицо крупным планом — отклонены по релевантности,
  без привязки к тексту такое фото ввело бы читателя в заблуждение.
- `lex.uz/uz/docs/8282286...` — официальный текст закона, HTML. `og:image` отсутствует,
  на странице только логотипы/иконки интерфейса — контента для фото нет.
- `anticorruption.uz/uz/article/...` — HTML статьи Агентства. `og:image` отсутствует,
  в `<img>` только логотипы, иконки соцсетей и SVG — контента для фото нет.
- Официальный сайт `sud.uz` (и поддомены) — сеть недоступна через прокси
  (`connect_rejected`/таймаут на всех попытках, включая http и https), сайт не
  открылся ни разу за несколько попыток. Не удалось проверить фото здания оттуда.

## Путь B — Unsplash: использован
Искал `courtroom, orientation=landscape` (WebFetch на странице поиска, т.к. прямой
`napi`-запрос отдаёт 401 без ключа). Из 20 кандидатов отбор шёл по трём фильтрам:
живая фотография (не 3D-рендер), горизонтальная ориентация, отсутствие узнаваемой
принадлежности к конкретной стране/учреждению, которое могло бы запутать читателя.

Выбрано фото Dragon White Munthe (`unsplash.com/photos/Bh6u25Qv9qA`) — пустой
исторический зал судебных заседаний: деревянные панели, колонны с капителями,
сводчатый потолок, кафедра судьи с гербом на заднем плане (герб мелкий, нечитаем
после кропа — не идентифицируется как герб конкретной страны на итоговом кадре).
Прямой URL: `https://images.unsplash.com/photo-1711003596872-aa68f08a4b8e`.
Unsplash License (свободное использование). Соотношение сторон исходника 4:3
(4032×3024) — горизонтальное, апскейл не требуется.

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 4032, "height": 3024},
  "fit": {
    "mode": "cover",
    "scale": 0.3968,
    "cropLoss": 0.25,
    "offset": [0, 0],
    "upscaled": false,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/supreme-court-anticorruption-law-analysis-01.jpg",
    "url": "/images/posts/2026-08/supreme-court-anticorruption-law-analysis-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 214476,
    "quality": 90
  },
  "status": "ok"
}
```
cropLoss ровно 0,25 — на границе порога `crop-risky` (>0,25), не превышает его,
эскалация не требуется. Кроме того, порог рассчитан на кадры с одним чётким
объектом (человек/животное/здание/документ), который можно случайно обезглавить;
здесь кроп срезал только нижнюю пустую часть кадра (пол, ступени зрительских мест)
и сохранил целиком верхнюю смысловую часть — свод, колонны, кафедру судьи с гербом.
Визуально проверил итоговый файл (Read) — композиция цельная, ничего важного не
срезано.

## Уверенность в подборе: 62%
Плюс: живая фотография (не рендер, не скриншот), горизонтальная ориентация без
подложки, свободная лицензия, атрибуция понятна, тематически соответствует
альтернативному mainVisualSubject («зал судебных заседаний»).
Минус: это не здание/зал именно Верховного суда Узбекистана — основной вариант
subject-first (реальное узбекское здание/зал) недостижим: первоисточники не дали
подходящего фото, а официальный сайт `sud.uz` недоступен из текущей сети. На гербе
кафедры остаётся минимальный риск, что внимательный читатель распознает
неузбекское происхождение кадра — смягчено явной пометкой «иллюстративное фото»
в alt-тексте.
