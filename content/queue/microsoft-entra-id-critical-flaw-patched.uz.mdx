Microsoft 21 avgustda tashkilotlar xodimlarining Microsoft 365 va Azure tizimlariga kirishi uchun mo'ljallangan bulutli Entra ID xizmatida maksimal xavf darajasiga ega kritik zaiflik aniqlanganini ma'lum qildi. Xavf darajasi — zaifliklarning jiddiyligini baholovchi xalqaro tizim bo'lgan CVSS shkalasi bo'yicha 10 balldan 10 balli, va Microsoft ma'lumotlariga ko'ra, undan hujumlarda allaqachon foydalanilgan. Kompaniya hujumlar ko'lami va manbasini oshkor qilmadi.

Zaiflikka xalqaro zaifliklar reyestridagi identifikator — CVE-2026-69836 raqami berilgan. Sababi — ma'lumotlarni qayta ishlashdagi xato: xizmat maxsus shakllantirilgan paketlarni tekshiruvsiz qabul qilib, ularni ishchi obyektlarga aylantirgan. Shu sababli tajovuzkor parolsiz va foydalanuvchi ishtirokisiz serverda masofadan turib kod bajarishi mumkin bo'lgan, [deb aytiladi Microsoft xavfsizlik byulletenining bayonida](https://thehackernews.com/2026/08/microsoft-entra-id-flaw-cvss-100.html).

Zaiflik Entra ID — sobiq Azure Active Directory, ya'ni Microsoft 365, Azure va boshqa korporativ ilovalarga kirish uchun mo'ljallangan xizmatga taalluqli bo'ldi. Bu xizmatdan butun dunyo bo'ylab tashkilotlar foydalanadi. [Microsoft ma'lumotlariga ko'ra](https://thehackernews.com/2026/08/microsoft-entra-id-flaw-cvss-100.html), zaiflik kompaniya tomonidan allaqachon to'liq bartaraf etilgan: yamoq Entra ID serverlarida avtomatik o'rnatilgan, chunki bu to'liq boshqariladigan bulutli xizmat hisoblanadi. Foydalanuvchilar hech narsa yuklab olishi yoki sozlamalarni o'zgartirishi shart emas.

Microsoft na jabrlangan tashkilotlar sonini, na hujumning texnik zanjirini oshkor qildi — kompaniya Entra ID'dan foydalanuvchilarga umumiy ogohlantirish bilan cheklandi.
