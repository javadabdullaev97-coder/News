## Путь A — первоисточники (Bloomberg/AJ/Interfax/Kommersant): проверил, отклонил
- **Al Jazeera** (`hormuz-deal-close-...`) — нашёл ДВА изображения:
  1. og:image — фото AFP «Vessels anchored in the Strait of Hormuz off
     Khasab on Oman's Musandam Peninsula» (afp_6a724e61f27c). Полный
     размер 3402×2268, горизонтальное, prepare-image.py дал бы cover,
     cropLoss 0,156 — технически чистый результат. **Не взял**: кадр
     агентский (AFP), лицензия не подтверждена — тот же риск, из-за
     которого агентские фото уже трижды отклонялись в этом сюжете
     (см. bild-notes `iran-oman-hormuz-deal-progress`, `trump-halts-
     iran-strikes-hormuz-deal`). Плюс композиционно почти дублирует уже
     использованный в серии кадр 08-03 «грузовые суда на рейде в дымке
     у скалистого берега».
  2. **Интерактивная карта AJ Labs** «Strait of Hormuz» (обновлена
     05.03.2026) — именно то, что просило задание: подписаны Iran, Oman,
     UAE, «Strait of Hormuz», территориальные воды, врезка-локатор на
     глобусе. Лицензия CC BY-NC-SA (не платная, атрибуция AJ Labs) —
     содержательно и по правам лучший кандидат. **Отклонил по одной
     причине: ориентация.** Оригинал 1081×1351 (портрет, 0,80). Прогнал
     через `prepare-image.py` — скрипт сам ушёл в `contain` с подложкой
     (`"note": "вписано целиком... вертикальный исходник... заливка кадра
     16:9 срезала бы большую часть снимка"`). Подложка не по правилу:
     легитимна только для эксклюзивного кадра очевидца, у карты есть
     горизонтальная альтернатива (ниже) — по правилу владельца от
     04.08 вернулся на шаг назад и не стал её принимать.

## Обработка — `scripts/prepare-image.py`

```json
{
  "source": {"width": 3000, "height": 1995, "path": "/tmp/unsplash-map1.jpg"},
  "fit": {
    "mode": "cover",
    "scale": 0.5333,
    "cropLoss": 0.1541,
    "offset": [0, 0],
    "upscaled": false,
    "note": "обрезано 15% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/iran-oman-hormuz-deal-agreed-in-principle-01.jpg",
    "url": "/images/posts/2026-08/iran-oman-hormuz-deal-agreed-in-principle-01.jpg",
    "width": 1600, "height": 900, "bytes": 357988, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

`cropLoss = 0,1541` — ниже порога 0,25 из `config/newsroom-policy.json →
imagery.cropRiskThreshold`, `crop-risky` не применяется. Визуально
проверил готовый кадр: Iran/Tehrān, U.A.E., Muscat и сам пролив (узкая
белая полоса воды у метки «KT») остаются в кадре и читаются; обрезаны
верх (Чёрное море/юг России) и низ (Судан/юг Красного моря) — не
смысловая часть.
