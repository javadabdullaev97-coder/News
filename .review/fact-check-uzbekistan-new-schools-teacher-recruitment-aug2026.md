## Список понижений для editor'а
1. Заголовок «...кандидатов сдали тесты...» → «...кандидатов прошли тестирование...» (или «...претендовали на вакансии...») — устраняет противоречие с телом текста, где прямо сказано, что итоги тестирования не объявлены.
2. (Опционально) meta description чуть длиннее рекомендованных 140–160 символов — можно сократить, не критично.
