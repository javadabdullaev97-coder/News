## Проверка триггеров возврата reporter'у
- **>15% слов от тела статьи удалено?** Да, удалено ≈30% исходного тела (абзац о Баходировой
  + сопутствующие вставки). Триггер формально сработал бы, **но** все удаления — прямое
  выполнение обязательного списка понижений fact-checker'а (ISSUES_CRITICAL), а не
  инициатива editor'а. По правилам это исключение: «Правка из списка понижений
  fact-checker'а... не твоё решение, а его вердикт, применяй без возврата». Reporter не
  привлекается.
- **Снят абзац со ссылкой на источник по своей инициативе?** Нет — абзац снят по прямому
  указанию fact-checker'а (Sputnik нецитируем), а не по инициативе editor'а. Исключение
  применимо.
- **Добавлена новая inline-ссылка или новая запись sources?** Нет. Только удаление одной
  записи (Sputnik), явно предписанное fact-checker'ом. Новых URL не добавлено.

Ни один триггер не требует back-to-reporter по существу; расхождение по % слов полностью
объясняется механическим применением обязательных понижений, а не редакторским рерайтом.
