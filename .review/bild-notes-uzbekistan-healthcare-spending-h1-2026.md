## Обработка — scripts/prepare-image.py

```json
{
  "source": {"width": 2400, "height": 1800},
  "fit": {
    "mode": "cover",
    "scale": 0.6667,
    "cropLoss": 0.25,
    "offset": [0, 126],
    "upscaled": false,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/uzbekistan-healthcare-spending-h1-2026-01.jpg",
    "url": "/images/posts/2026-08/uzbekistan-healthcare-spending-h1-2026-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 177347,
    "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

Cover-режим, без подложки/полей — обрезка ровно 25% по высоте (потолок и
пол), центральная часть кадра (кресла, двери, таблички) сохранена
целиком. cropLoss = 0.25, не превышает порог crop-risky (>0.25) — и в
любом случае это архитектурный кадр без единого «уязвимого» объекта
(лица/головы/документа), который могло бы обрезать неудачно. Спрашивать
владельца не требуется.
