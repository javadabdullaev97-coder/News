# LEAP News — MVP

Новостной сайт на Next.js 15 + Tailwind CSS. MVP-каркас для дальнейшего развития.

## Что внутри

- Главная страница с hero-блоком, лентой и блоком «Сейчас читают»
- Страница статьи с AI-саммари «Прочитать за 30 секунд», кнопкой «Слушать», тегами, related-блоком
- Страницы рубрик (8 рубрик)
- Тёмная тема с системной синхронизацией
- Переключатель языков RU / UZ / EN (UI, без локализации контента)
- Подкаст-блок «LEAP за 5 минут» на главной
- Адаптивная вёрстка, sticky-хедер с горизонтальным меню рубрик на мобильных

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Структура

```
app/
  layout.tsx           — общий лейаут, шрифты, тема
  page.tsx             — главная
  article/[slug]/      — страница статьи
  rubric/[slug]/       — страница рубрики
  globals.css
components/
  Header.tsx
  Footer.tsx
  ArticleCard.tsx      — карточка с вариантами hero / default / compact
  ThemeToggle.tsx
lib/
  data.ts              — моковые статьи и рубрики
```
