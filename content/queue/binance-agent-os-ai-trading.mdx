Криптобиржа Binance 20 августа запустила Agent OS — систему, которая подключает к её торгам ИИ-агентов, самостоятельные программы, и позволяет им заключать сделки за пользователя, [говорится на странице проекта](https://binance.com/agent-os).

Agent OS объединяет пять элементов инфраструктуры Binance, [сообщила биржа в пресс-релизе](https://www.prnewswire.com/news-releases/binance-introduces-agent-os-to-connect-ai-applications-to-financial-infrastructure-302856306.html). Это программный интерфейс биржи (API) — набор команд, через который сторонние программы подключаются напрямую к системам Binance. Кошелёк Wallet Agentic Hub хранит средства и проводит операции в блокчейне. Поддержка протокола MCP (Model Context Protocol) — открытого стандарта, через который сторонние ИИ-приложения подключаются к инструментам биржи. Платёжный посредник x402 позволяет агентам и сервисам рассчитываться между собой без участия человека. Skill Hub — каталог готовых модулей («навыков») для типовых задач агента.

Система работает в том числе с внешними ИИ-приложениями ChatGPT, Claude Code и Cursor: пользователь подключает их к своему аккаунту Binance, [сообщает TechCrunch](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/).

Пользователь сам определяет права каждого агента — доступ к рыночным данным, к информации об аккаунте и к сделкам, [говорится на странице Agent OS](https://binance.com/agent-os). Агента можно привязать к отдельному субсчёту, чтобы отделить его средства и операции от основного баланса. По умолчанию агент не может выводить средства с биржи. Пользователь вправе включить подтверждение каждой сделки вручную или разрешить агенту действовать самостоятельно, [пишет TechCrunch](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/).

На операции агента через кошелёк действуют дневные лимиты, [сообщает TechCrunch](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/). Обмен токенов, то есть цифровых активов в блокчейне, ограничен 50&nbsp;000 долларов в день, операции в децентрализованных финансовых сервисах — 100&nbsp;000 долларов. Платежи через x402 — не больше 20 долларов в день.

## Кто отвечает за убытки агента

Страница Agent OS прямо снимает с биржи ответственность за результат: «Вы несёте единоличную ответственность за свои инвестиционные решения, Binance не отвечает за убытки», — [говорится в тексте](https://binance.com/agent-os). Там же указано, что пользователь полностью отвечает за все команды («промпты»), которые он даёт агенту.

Вице-президент Binance по продукту Джефф Ли сообщил TechCrunch, что биржа не видит логику решений агента. «Мы действительно не можем видеть рассуждение, стоящее за действием пользователя», — [сказал Ли](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/). По его словам, вместо полной самостоятельности агента биржа передала пользователю детальный контроль доступа.

Похожие инструменты для торговли через ИИ-агентов в 2026 году уже выпустили Kraken в марте и Coinbase в июне, [отмечает TechCrunch](https://techcrunch.com/2026/08/20/binance-now-lets-ai-agents-trade-but-keeping-them-in-check-is-largely-up-to-users/).
