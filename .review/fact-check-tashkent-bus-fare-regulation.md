# Fact-check: tashkent-bus-fare-regulation

## Общий вердикт: APPROVE-WITH-DOWNGRADES

Все центральные факты (дата 1 сентября 2026, механизм оплаты при входе, статус
безбилетника, способы оплаты, отсутствие суммы штрафа, охват — все города на
брутто-контракте) подтверждены прямым чтением ПКМ №276 и ПП-59 на lex.uz и совпадают
с постом Минтранса (type: source, P2 — не attributed). Confidence 90.

## Список понижений/правок для editor'а

1. Абзац «Что именно меняется»: убрать/смягчить «Кондукторов на брутто-маршрутах давно
   нет — эту роль выполняют валидаторы у дверей» — ни один источник это прямо не
   подтверждает. Либо удалить, либо переформулировать без категоричного «давно нет».
2. Абзац «Что будет при неоплате»: «Ответственность... уже предусмотрена Кодексом об
   административной ответственности» — прямой ссылки на статью КоАО в источниках нет.
   Убрать конкретизацию «Кодексом об административной ответственности», оставить общее
   «административная ответственность уже предусмотрена действующим законодательством».
3. МВД — при первом упоминании расшифровать полностью: «Министерство внутренних дел (МВД)».
4. Заголовок — рассмотреть более точную формулировку: не «Проезд... станет обязательным»
   (обязательной становится оплата при входе, не сама поездка) — например «Оплата проезда
   при входе в автобус станет обязательной с 1 сентября». Стилевая правка, не блокирующая.
5. Опционально — уточнить, что запуск единой системы оплаты «электричка-автобус/метро»
   идёт совместно с Минфином, УТЖ и оператором платежей, не только Минтрансом.
