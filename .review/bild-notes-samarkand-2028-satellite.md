## Главный визуальный субъект
Из задания: первый снимок со спутника (если найдётся в t.me/uzcosmos_official/2682),
иначе кадр запуска ракеты с морской платформы, иначе спутник/иллюстрация.

## Что нашёл в t.me/uzcosmos_official/2682
Пост реально содержит фото первого снимка (Афины из космоса) —
`https://cdn4.telesco.pe/file/uq3eGTfP...84fg.jpg`, 640×800 (портрет, соотношение 0,80).
Первая ссылка в HTML виджета (`TZYIIh...` 160×160) — известная ловушка: это аватар
канала, не фото поста (см. `image-pipeline.md`), пропустил её сразу.

Прогнал реальный снимок Афин через `prepare-image.py`:
```json
{
  "source": {"width": 640, "height": 800},
  "fit": {"mode": "contain", "scale": 1.0, "placed": [640, 800],
          "note": "вписано целиком на solid тёмно-графитовый фон бренда; вертикальный
                   исходник 640×800 (соотношение 0.80) — заливка кадра 16:9 срезала бы
                   большую часть снимка"},
  "output": {"width": 1600, "height": 900, "status": "ok"}
}
```
Результат — подложка с полями по бокам. По правилу владельца от 04.08.2026 подложка —
красный флаг, не штатный приём: вернулся на шаг назад и стал искать горизонтальную
альтернативу вместо того, чтобы принять этот результат. Единственный законный случай
для подложки — эксклюзивный кадр без горизонтальной замены; здесь замена нашлась
(см. ниже), значит подложку использовать было нельзя.

## Финальный источник картинки
- URL: https://news.cgtn.com/news/2026-08-05/China-launches-hyperspectral-satellites-serving-global-partners-1PmkKoWmmXK/img/a57d33e4fd30431493129bf0eaacf13b/a57d33e4fd30431493129bf0eaacf13b-1280.png
- Найден как `og:image` статьи CGTN — это тот же URL, что уже указан четвёртым
  первоисточником в `frontmatter.sources` статьи (та же статья CGTN о запуске).
- Тип: живое фото пресс-службы/агентства — момент старта ракеты-носителя Smart Dragon-3
  со спутниками Samarkand-2028 и Lampung-1 с морской платформы у Хайяна, дневной свет,
  дым и пламя видны отчётливо. Не рендер, не сток, не инфографика.
- Размер оригинала: 1280×719 — почти точное соотношение 16:9 (1,78), горизонтальный.

Обработка (JSON из `scripts/prepare-image.py`):
```json
{
  "source": {"width": 1280, "height": 719},
  "fit": {"mode": "cover", "scale": 1.2517, "cropLoss": 0.0014, "offset": [0, 0],
          "note": "обрезано 0% по ширине; окно кропа выбрано по содержимому; исходник
                   растянут в 1.25x ради заливки кадра"},
  "output": {"path": "public/images/posts/2026-08/samarkand-2028-satellite-01.jpg",
             "url": "/images/posts/2026-08/samarkand-2028-satellite-01.jpg",
             "width": 1600, "height": 900, "bytes": 89724, "quality": 90},
  "status": "ok",
  "upscaled": false
}
```
Итог: 1280×719 → cover, обрезка практически 0% (cropLoss 0,0014, далеко ниже порога
0,25) → 1600×900 (88 КБ, q90). Никакой подложки, кадр полный, без полей.

## Отклонённые варианты

  ловушка публичного ТГ-виджета, ниже `MIN_SOURCE` 600px, не фото поста.

  не рендерится статикой) и `video.cgtn.com/.../wu_....png` (1090×1942, вертикальный
  плейсхолдер мобильного плеера, не относится к теме) — оба не подошли.
