# Fact-check: supermicro-ceo-smuggling-cleared

## Общий вердикт: REJECT

**Причина:** материал построен по правилу §10.1 («первоисточник назван, но недоступен — понижение вместо молчания»), но раздел про уголовное дело Уолли Ляу — категория, для которой §10.1 прямо исключает своё применение: «Не применяем это правило к темам раздела 6 (обвинения в преступлениях, персональные данные, экстремизм) — там пороги прежние». §6 требует по обвинениям в преступлениях либо вступившее в силу решение суда, либо официальное заявление прокуратуры — ни того, ни другого нет: justice.gov вернул 401 и репортёру, и фактчекеру при повторной проверке; запрос на подтверждение отправлен только в Supermicro, в Минюст США — нет. Три вторичных издания не заменяют требуемый официальный источник для этой категории фактов.

Без раздела про уголовное дело рушится центральный сюжетный узел статьи. Это reject: «нарушает §6 редполитики» и «после понижений от новости ничего не остаётся».

## Проверка §10.1 по частям

- Формула в лиде — дословное совпадение с требуемой. ✓
- Строка о запросе в конце — адресована только Supermicro, не Минюсту США — процедура §10.1 для блока про уголовное дело не пройдена даже формально.
- Условие «Не применяем это правило к темам раздела 6» — нарушено: блок про обвинения Ляу является ровно такой темой.

## Проверенные утверждения

Часть про решение совета директоров (заявление совета, кадровые решения, отсутствие вины Ляна) — допустима по §10.1, три независимых издания подтверждают, процедура соблюдена.

Часть про уголовное дело (обвинения трём людям включая Ляу, сумма $2,5 млрд в привязке к обвинению, дата суда) — UNSUPPORTED, блокирующее: обвинение в преступлении названного человека без официального источника.

## Что нужно для повторной подачи

1. Убрать полностью раздел «Уголовное дело сооснователя ещё не закрыто» до появления официального источника (DOJ/US Attorney заявление, обвинительное заключение).
2. Направить отдельный запрос в пресс-службу Минюста США / US Attorney's Office, если материал решат подавать по §10.1 для этой части.
3. Часть про board investigation можно публиковать по §10.1 уже сейчас — не входит в категорию §6.
4. Переписать лид и заголовок без раздела о деле Ляу; сократить лид до 25–30 слов.
