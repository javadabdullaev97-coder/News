Microsoft [said](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-25h2) on August 19, 2026, that it is investigating game crashes on Windows 11 computers: after the system's August update, games freeze, close without warning, or restart the computer.

The update in question is KB5121003, released on August 11. It's cumulative: this kind of package bundles all the Windows fixes issued since the previous one into a single release. The letters KB stand for Knowledge Base, Microsoft's knowledge base where each update has its own numbered article. The update raised the build number — Windows' internal version identifier — to 26100.9168.

According to the [Windows release health page](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-25h2) on known issues, some games stop responding after the update is installed. Games also close without warning with an "EXCEPTION_ACCESS_VIOLATION" error or cause the computer to restart unexpectedly. Microsoft says a "limited number of games" are affected and cites ARC Raiders, MARVEL Tōkon: Fighting Souls and The Finals as examples.

The issue affects [Windows 11 versions 25H2 and 24H2](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-24h2) on consumer PCs. It does not extend to Windows server editions, according to the entry.

The entry's status is "Investigating." Microsoft stated it "is currently determining whether this issue was caused by an action on Microsoft's part." The company said it would provide updates as they become available.

Judging by the Microsoft Learn entry, the KB5121003 update has not been recalled or paused so far. The entry's structure contains neither a rollout-pause item nor a fix item. The company has not offered an official workaround either.

Microsoft is asking those who encounter the problem to report it through the Feedback Hub app, a tool built into Windows for submitting reports on system issues.

The entry on the issue was opened on August 19 at 17:50 Pacific Time; the page's last update was at 17:53 the same day.
