# Reporter notes: state-assets-auction-aug3-2026

## Тема
Агентство по управлению государственными активами РУз провело 3 августа 2026 года
очередной онлайн-аукцион госактивов: продано 645 из 1307 выставленных лотов на
сумму 103,6 млрд сумов при стартовой цене 108,2 млрд сумов. Рутинный ежедневный/
еженедельный бюллетень ведомства, без признаков большой значимости.

## Первоисточники (проверенные)
- https://t.me/davaktivuz/6191 — основные цифры: 1307 выставлено, 645 продано,
  стартовая цена 108,2 млрд сумов, сумма реализации 103,6 млрд сумов, 1668
  участников (юр. и физ. лица). Тот же пост содержит данные предыдущего аукциона
  (31 июля): 848 выставлено, 461 продано, 128,8 млрд сумов реализации при старте
  113,3 млрд сумов, 1043 участника.
- https://davaktiv.uz/ru — официальный сайт агентства, использован для проверки
  полного названия ведомства (через WebSearch, не отдельный факт-URL).
- Курс ЦБ РУз на 3 августа 2026 (11 960,18 сума/USD) — взят через архив курсов
  cbu.uz (json-эндпоинт), для пересчёта суммы в доллары.

## Расхождения с inbox-снипетом
Инбокс-сигнал (645 лотов, 103,6 млрд сумов) полностью совпал с данными
первоисточника. Расхождений не найдено.

## Main visual subject
Нет явного визуального субъекта — новость про итоги электронного аукциона без
конкретного здания/лица в центре сюжета. Можно использовать скриншот/логотип
электронной площадки davaktiv.uz или нейтральную инфографику с цифрами торгов,
либо здание Агентства по управлению госактивами, если есть в фотобанке.

## Что не вошло в статью
- Детальная разбивка проданных лотов по категориям (гособъекты/аренда/земля/
  сельхозземли/суд/прочее) для аукциона 3 августа — в первоисточнике агрегированные
  цифры не давали чёткой построчной разбивки именно по этой дате, решил не
  приводить категории отдельно, чтобы не давать непроверенные числа. Если
  редактор захочет разбивку — нужно свериться напрямую с постом в браузере.
- Отдельная тема «как принять участие в следующих торгах» — справочный материал,
  не развивал.

## Пропуски и слабые места
- Цифры извлечены через WebFetch-обработку HTML-страницы t.me/s/davaktivuz —
  инструмент интерпретирует контент через промежуточную модель, прямого доступа
  к сырому HTML нет. Числа проверены на внутреннюю непротиворечивость (для
  31 июля категории складываются точно в 461 лот), но fact-checker'у стоит по
  возможности свериться напрямую через t.me/davaktivuz/6191 в браузере.
- Один из промежуточных ответов инструмента ошибочно указал год «2024» —
  расценил это как артефакт модели-парсера и не учитывал; в статье используется
  дата из задания (3 августа 2026).
- Курс ЦБ на 3 августа получен тем же методом (WebFetch-парсинг), стоит
  перепроверить fact-checker'у напрямую на cbu.uz.
- Кандидатов на добавление в мониторинг (новые Telegram-каналы у конкурентов) в
  ходе research не встречено — запись в candidate-sources.jsonl не делалась.

## Уверенность в статье: 62%
Основные цифры (645 лотов, 103,6 млрд сумов) подтверждены и совпадают с брифом,
но извлечение данных шло через AI-парсинг веб-страницы Telegram без прямого
просмотра сырого текста поста, а курс USD и сравнение с 31 июля стоит
перепроверить вручную перед публикацией — тема низкоприоритетная, ошибка в
деталях не критична, но аккуратность проверки цифр всё равно нужна.
