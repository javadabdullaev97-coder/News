## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 800, "height": 600},
  "fit": {
    "mode": "cover",
    "scale": 2.0,
    "cropLoss": 0.25,
    "offset": [0, 205],
    "upscaled": true,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому; исходник растянут в 2.00× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/tahiatash-water-treatment-reconstruction-01.jpg",
    "url": "/images/posts/2026-08/tahiatash-water-treatment-reconstruction-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 254084,
    "quality": 90
  },
  "status": "ok"
}
```
Проверка результата глазами: обрезка сняла верхнюю полосу неба и нижнюю полосу земли —
ни одна фигура, лицо или значимый объект в кадре не срезаны (см. итоговый файл). cropLoss
0,25 — на границе порога crop-risky (>0,25), но в данном случае содержательно безопасен:
не спрашиваю владельца, т.к. ничего важного не потеряно визуально.
Апскейл 2,0× — на уровне текущей версии `prepare-image.py` (MAX_UPSCALE=2.5, актуальный
код скрипта уже отличается от описания в `image-pipeline.md`, которое называет апскейл
запрещённым; ориентировался на фактическое поведение скрипта и визуальную проверку
результата — картинка не выглядит замыленной при 1600×900, q90, 254 КБ).
