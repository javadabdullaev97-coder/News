## Проверка первоисточников (стратегия A)
- **t.me/uzcert_live/1357** — пост содержит фото (проверено скачиванием, md5 идентично
  фото из второго канала). Изображение — постановочная AI-сгенерированная/3D-рендер
  «командная комната кибербезопасности»: голографическая карта мира с красными линиями
  атак, неоновые панели, вымышленная статистика («1 284 536 заблокированных попыток»),
  фигуры сотрудников спиной к камере, логотип UZCERT в углу. Классический глянцевый
  3D-рендер/«заготовка» — прямо запрещён редполитикой (rejectStockRenders), даже если
  это собственная графика ведомства. Отклонено.
- **t.me/cyber_csec_uz/2601** — тот же файл (md5 b48e685278afc3eef534d39af68cab2d),
  продублирован из первого канала. Тоже отклонено по той же причине.
- **uzcert.uz/ru/about/** — только логотип и декоративный SVG/webp-графика услуг,
  фото здания/офиса нет.
- **csec.uz** — сайт на JS (SPA), WebFetch отдаёт только заголовок страницы без
  контента; фото здания Центра кибербезопасности (ул. Тараса Шевченко, 20) через
  доступные инструменты не нашлось. Раздел «Пресс-центр» с новостями рендерится
  клиентским JS, недоступен для скрапинга в этом окружении.

Официального живого фото нет → переход к стратегии B.

## Стратегия B — сток
### Отклонённые варианты
- Unsplash, Kevin Ache — "a rack of servers in a server room": при просмотре оказалось
  фото стойки аудио/радиооборудования (Sennheiser IEM-приёмники, аналоговые процессоры)
  на фоне сценического света — это стойка вещательного/сценического оборудования, а не
  серверная госсистемы; вводящее в заблуждение название на Unsplash. Отклонено.
- Unsplash, İsmail Enes Ayhan — "server room aisle with metal equipment racks": на деле
  цех сборки электрощитового оборудования (промышленное производство, не дата-центр).
  Отклонено по той же причине — не то, что заявлено в названии.
- Unsplash, Kier in Sight Archives — "a close-up of a server room": на деле светодиодная
  видеостена (LED-панели ROE Carbon 5) со сценическими фермами — не серверная. Отклонено.
- Unsplash, Alex Shuper — "server room with rows of servers": по прошлому опыту (см.
  bild-notes другой статьи) при проверке оказался 3D-рендером — не проверял повторно,
  исключил заранее по тому же основанию.

## Уверенность в подборе: 70%
Фото реальное, живое, горизонтальное, без людей, без 3D-рендера, без клише «замок в
облаках» — все жёсткие запреты соблюдены. Официальный визуал первоисточника (UZCERT/
Центр кибербезопасности) пришлось отклонить: единственное доступное изображение —
дублированный на обоих каналах AI-сгенерированный «ситуационный центр» с вымышленными
цифрами и голографической картой — классический glossy-рендер, прямо под запретом.
Building-фото Центра кибербезопасности не нашлось (SPA-сайт, JS-контент недоступен
WebFetch). Минус варианта: фото общее по теме «дата-центр/сеть» вообще, не показывает
специфику Узбекистана или RDP-атаки конкретно — ожидаемо для материала без явного
субъекта. Higgsfield MCP-инструменты в этом прогоне не были доступны в наборе
инструментов агента — AI-генерация (стратегия C) физически не опробована.
