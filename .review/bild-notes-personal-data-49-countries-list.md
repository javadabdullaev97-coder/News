# Bild notes: personal-data-49-countries-list

## Стратегия: stock

Тема — постановление Кабмина №415 о списке из 49 стран для упрощённой трансграничной
передачи персональных данных. Явного визуального субъекта нет: не человек, не здание,
не конкретное событие — чисто регуляторная тема. Reporter-notes для этого slug в `.review/`
отсутствует (файл не создавался), но задача явно указала: `mainVisualSubject` не задан,
тема регуляторная. Editor-verdict тематической подсказки для картинки не содержит
(редактор фокусировался на тексте, блок про imagery не упоминает).

## Порядок попыток

### A. Официальный источник — ОТКЛОНЕНО (изображений нет)
- `lex.uz/docs/8369688` (текст постановления №415) — страница отдаёт только встроенный PDF
  документа; `og:image` отсутствует в HTML, картинок для использования нет.
- Пытался найти профильное ведомство — уполномоченный орган по постановлению это
  «Департамент миграции и персонализации при МВД». Проверил кандидатов на домен:
  `migration.uz` резолвится, но это другое ведомство («Миграционное агентство» /
  Агентство внешней трудовой миграции, домен `/uz/about` подтверждает это в `<title>`) —
  не тот орган, который ведёт реестр стран. `mvd.uz` не резолвится (DNS ESERVFAIL),
  `dmp.mvd.uz`, `pdp.uz` (запаркован на Tilda, 402), `gdpr.uz`, `shaxsiy.uz`,
  `personaldata.uz`, `e-fuqaro.uz` — не найдены/недоступны. Поиск через Google/DuckDuckGo
  не дал результатов (страницы отдают CAPTCHA/заглушки, не индексируемый контент через
  WebFetch). МВД Telegram (`t.me/s/mvd_uz`) и `gov.uz` поиск по новостям — не отдали
  релевантного материала с изображением через WebFetch.
- Вывод: официального фото к этому конкретному постановлению или к профильному ведомству
  найти не удалось за разумное время поиска.

### B. Тематический сток (Pexels) — ИСПОЛЬЗОВАНО
Искал документальную фотографию на тему «паспорт / документ / трансграничная передача
данных» — без клише в духе замков и бинарного кода, без людей крупным планом (лиц).
- Первый кандидат `pexels-photo-29402988` («European passports on world map background») —
  тематически идеальный (паспорта на фоне карты мира), но при проверке реальных пикселей
  оказался вертикальным (4640×6960, AR 0,67) — отклонён по правилу «ищи горизонталь, а не
  спасай вертикаль» (04.08.2026): не стал подгонять под подложку, вернулся к поиску.
  Важно: WebFetch-описание страницы ошибочно назвало этот кадр «горизонтальным» — проверка
  фактических пикселей через Pillow после скачивания оказалась обязательной, на глаз/по
  тексту страницы не определить.
- Проверил реальные пропорции ещё нескольких кандидатов через уменьшенные превью
  (`?w=…&h=400`) до скачивания полного размера — экономия трафика:
  `30851143` (0,75, вертикальный) и `29485309` (0,67, вертикальный) — отклонены;
  `32081456`, `32081457`, `8061986` — все горизонтальные (AR 1.5).
- `8061986` («Ukrainian passports on white surface») — тематически ок, но конкретно
  Украина не входит и не упоминается в перечне 49 стран статьи — визуальная привязка к
  стране, не связанной с материалом, может ввести в заблуждение. Отклонил.
- `32081457` («Portuguese passport and citizen card close-up») — один паспорт одной страны,
  слабее как иллюстрация многостороннего списка из 49 государств.
- **Выбрано: `32081456`** («European passports and ID cards close-up», автор Marta Branco) —
  паспорта Австрии и Португалии + ID-карта Болгарии в одном кадре: наглядно передаёт идею
  «несколько стран ЕС», а весь Евросоюз — крупнейший блок из перечня 49 стран в постановлении.
  Живая макросъёмка документов, без лиц, без рендера/инфографики/радуги.
- Лицензия: Pexels License (свободное использование, коммерческое и некоммерческое,
  атрибуция не обязательна юридически, указываю по редполитике).

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 6960, "height": 4640},
  "fit": {"mode": "cover", "scale": 0.2299, "cropLoss": 0.1562, "offset": [0, 167],
          "upscaled": false, "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому"},
  "output": {"path": "public/images/posts/2026-08/personal-data-49-countries-list-01.jpg",
             "url": "/images/posts/2026-08/personal-data-49-countries-list-01.jpg",
             "width": 1600, "height": 900, "bytes": 408556, "quality": 90},
  "status": "ok", "upscaled": false
}
```
Исходник 6960×4640 (полноразмерный Pexels-файл, AR 1.5) → cover, масштаб 0,23×, обрезка
15,6% по высоте (окно кропа по содержимому, offset [0, 167]) → 1600×900, 409 КБ, quality 90.
`cropLoss` 0,1562 — ниже порога `crop-risky` 0,25; к тому же это макросъёмка документов на
столе, не портрет/лицо/животное, риск смыслового среза минимален (визуально проверено после
обработки — все три документа и надписи остались полностью в кадре, обрезаны только края
серого фона сверху и снизу). Апскейла нет.

- `pexels-photo-32081457` — один паспорт (Португалия), слабее как иллюстрация

- Официальные источники (lex.uz, migration.uz, mvd.uz и производные) — картинок нет либо
