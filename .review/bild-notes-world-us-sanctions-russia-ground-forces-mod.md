# Bild notes: world-us-sanctions-russia-ground-forces-mod

## Стратегия: stock (Openverse/Flickr, CC BY-SA) — реальное фото главного субъекта

## Main visual subject (из reporter-notes)
«Нет явного визуального субъекта — либо здание Госдепартамента США, либо нейтральная
иллюстрация Сухопутных войск РФ (техника/учения)». Выбрано первое: здание —
конкретный, узнаваемый, subject-first объект (ведомство, которое ввело санкции),
в отличие от абстрактной «техники вообще».

## Порядок попыток

### A. Первоисточники (frontmatter.sources)
- `federalregister.gov/d/2026-15759` — сама страница документа недоступна из этого
  окружения (proxy возвращает страницу `Request Access` / антибот-стену на всех
  попытках через curl и WebFetch). Даже если бы открылась — Federal Register это
  текст закона/уведомления, без фото по природе жанра.
- `state.gov` (любые пути: `/`, `/press-releases/`, `/harry-s-truman-building/`) —
  все запросы через curl (с `User-Agent: Mozilla/5.0`) возвращают одну и ту же
  страницу-заглушку `<title>Technical Difficulties</title>` (659508 байт,
  идентичный размер на разных URL) — домен фактически недоступен целиком в этом
  прогоне. WebFetch подтверждает то же самое.
- `interfax.ru/world/1107277` — проверено через WebFetch: в самой статье
  изображений нет, только фото у несвязанных новостей в блоке «Ещё» (Ормузский
  пролив, Турция, Венесуэла, иск штатов США) — не по теме.
- `kommersant.ru/doc/8861937` — проверено: изображений в теле статьи нет, только
  рекламный `adv.gif`.
- `structure.mil.ru` (Минобороны РФ, для иллюстрации Сухопутных войск) — домен
  недоступен из этого окружения (`curl` вернул `HTTP:000`, таймаут/блокировка).

### B. Сток — Openverse API (CC0/CC BY/CC BY-SA, без Wikimedia)
Unsplash и Pexels по прежним прогонам недоступны в этой среде без API-ключа
(см. `bild-notes-trump-halts-iran-strikes-hormuz-deal.md`,
`bild-notes-fergana-dui-killed-traffic-police-aug2026.md`) — не тратил время на
повторную проверку, сразу пошёл в Openverse, у которого есть публичный API без ключа.

**Ветка «Сухопутные войска РФ / танк» — отклонена целиком:**

  два реальных кадра колонны Т-90С на репетиции парада в Москве (~2011–2012).
  Отклонены: на обоих чётко видны лица экипажа в люках (нарушение «никаких людей

  парадного образца — слишком «триумфальная»/патриотическая эстетика для

- `T-14 Armata tank.` (Andrey Petrov, Flickr, id `d7d11df3…`) — открыл файл:
  это **LEGO-модель танка**, не фотография техники, плюс подпись
  «Created by Andrey Petrov» в кадре. Отклонено сразу — не «живая фотография»

- Остальные релевантные результаты по T-72/T-90/BMPT Terminator/BTR-80 — почти

  читателя в заблуждение о принадлежности техники).

  - Прямая ссылка: `https://live.staticflickr.com/5523/14299552757_bea1de2598_b.jpg`
  - Страница на Flickr: `https://www.flickr.com/photos/75683070@N00/14299552757`
  - Автор — Ken Lund, известный travel-фотограф на Flickr с большим архивом

### C. AI-генерация (Higgsfield)
Не понадобилась — нашлось подходящее реальное фото. Инструмент `generate_image`
в тулсете этого прогона недоступен (см. аналогичную оговорку в
`bild-notes-fergana-dui-killed-traffic-police-aug2026.md`), но это не повлияло
на решение: реальная фотография всё равно приоритетнее генерации по политике.

## Обработка — scripts/prepare-image.py
```json
{
  "source": {"width": 1024, "height": 768},
  "fit": {
    "mode": "cover",
    "scale": 1.5625,
    "cropLoss": 0.25,
    "offset": [0, 270],
    "upscaled": true,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/world-us-sanctions-russia-ground-forces-mod-01.jpg",
    "url": "/images/posts/2026-08/world-us-sanctions-russia-ground-forces-mod-01.jpg",
    "width": 1600, "height": 900, "bytes": 285724, "quality": 90
  },
  "status": "ok"
}
```

## Проверка cropLoss (порог 0,25 из `config/newsroom-policy.json`)
`cropLoss = 0.25` — ровно на пороге, не превышает его (`> 0.25` не выполняется),
формально `crop-risky` не наступает. Тем не менее объект — здание, то есть
попадает в категорию, для которой порог вообще применяется, поэтому открыл
готовый файл 1600×900 и проверил визуально: обрезка ушла в небо сверху и в
асфальт/бордюр снизу, сам фасад здания с характерным рядом окон и пилонов
не пострадал, ничего значимого не срезано. В очередь не эскалирую — порог не
превышен и субъект визуально цел.

Отдельно апскейл ×1,56 (источник 1024×768, максимум публично доступный на
Flickr без API-ключа) — на итоговом кадре заметно небольшое смягчение резкости,
но без явных артефактов/пикселизации, в пределах приемлемого для превью-карточки
и Telegram (где итоговое отображение обычно ≤800px по стороне).

## Уверенность в подборе: 80%
Subject-first соблюдён: это реальное фото именно того ведомства, которое ввело
санкции (Госдепартамент США, Гарри С. Трумэн Билдинг), не абстрактная картинка.
Лицензия чистая и подтверждена через API, автор указан, credit прозрачен.
Минусы: (1) снимок не привязан к конкретной дате уведомления, это иллюстративное
архивное фото здания; (2) источник — 1024×768, потребовался апскейл ×1,56
(в пределах политики, но не идеальная резкость); (3) альтернативная подсказка
reporter'а («Сухопутные войска РФ, техника/учения») не реализована — ни одного
кадра, отвечающего одновременно требованиям «реальная российская техника» +
«без людей» + «без Wikimedia» + «без парадной/пропагандистской эстетики», найти
не удалось за разумное время поиска.
