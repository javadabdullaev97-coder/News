## Обработка `scripts/prepare-image.py`
```json
{
  "source": {"width": 1024, "height": 768},
  "fit": {
    "mode": "cover",
    "scale": 1.5625,
    "cropLoss": 0.25,
    "offset": [0, 300],
    "upscaled": true,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/minvuz-mandate-results-2026-2027-01.jpg",
    "url": "/images/posts/2026-08/minvuz-mandate-results-2026-2027-01.jpg",
    "width": 1600, "height": 900, "bytes": 355993, "quality": 90
  },
  "status": "ok"
}
```
cropLoss ровно 0,25 — не превышает порог эскалации в человека (`> 0,25`,
раздел «Когда спрашивать человека»), и ниже `MAX_CROP=0,45` скрипта, поэтому
ушло в `cover`, без подложки. Апскейл 1,56× — в пределах `MAX_UPSCALE=2.5`.
Табличка с названием вуза и колоннада остались в кадре целиком — обрезка
съела верхний карниз с надписью «Kuch, bilim va tafakkur» и часть ступеней,
не критичный для читаемости контент.
