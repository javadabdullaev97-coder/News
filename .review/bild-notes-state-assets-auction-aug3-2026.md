## Обработка (scripts/prepare-image.py)
Исходник 586×800 (портретная ориентация, соотношение 0,73 < PORTRAIT_AR 0,95) →
режим `contain` на тёмно-графитовой подложке бренда (#1A1A1A), без обрезки и без апскейла
(апскейл до cover потребовал бы 2,73× при лимите 2,5×, плюс портретная ориентация сама по
себе исключает cover). Итог 1600×900, 126 649 байт, quality 90.

```json
{
  "source": {"width": 586, "height": 800, "path": "/tmp/davaktiv_original.jpg"},
  "fit": {
    "mode": "contain",
    "scale": 1.0,
    "placed": [586, 800],
    "note": "вписано целиком на solid тёмно-графитовый фон бренда; вертикальный исходник 586×800 (соотношение 0.73) — заливка кадра 16:9 срезала бы большую часть снимка; заливка кадра потребовала бы растянуть исходник в 2.73× при допустимых 2.5×"
  },
  "output": {
    "path": "public/images/posts/2026-08/state-assets-auction-aug3-2026-01.jpg",
    "url": "/images/posts/2026-08/state-assets-auction-aug3-2026-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 126649,
    "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```
