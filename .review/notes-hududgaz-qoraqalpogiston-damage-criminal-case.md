# Reporter notes: hududgaz-qoraqalpogiston-damage-criminal-case

## Тема
Департамент по борьбе с экономическими преступлениями при Генеральной прокуратуре Узбекистана
(управление по Республике Каракалпакстан) выявил ущерб на 251,5 млрд сумов в АО «Худудгаз
Каракалпакстан». Причина — необъяснённое расхождение между принятым и поставленным объёмом
природного газа, списанное как обычная потеря. Возбуждено уголовное дело по статьям 167 и 205 УК.
