## Что оставил как есть

- Пассивные конструкции без явного субъекта («введена в эксплуатацию»,
  «отмечено на презентации», «обсуждена работа советников») — источник
  (президентский релиз) сам не называет конкретного исполнителя для этих
  действий, придумывать субъект («Узбекистан ввёл...») означало бы добавить
  факт, которого нет в первоисточнике. Оставил нейтральную безличную форму.
- Структуру на 4 H2 — статья мультитематическая (рейтинг, инфраструктура,
  кадры, международное сотрудничество), длина ~410 слов оправдывает деление,
  жёсткой схемы «событие/контекст/что дальше» тут нет, потому что материал —
  пересказ одной комплексной презентации, а не единичного события с
  предысторией.
- description и tags категорию `economy` — соответствуют заданию, не менял.
- 3 источника, два из которых — тизеры того же голоса (пресс-служба
