## Ход поиска
- `frontmatter.sources` — два источника: PDF-инфографика ЦБ
  (`cbu.uz/upload/medialibrary/.../depozit_uz.pdf`) и живая страница статистики
  ставок (`cbu.uz/ru/statistics/rates/`). Ни то ни другое не годится напрямую как
  картинка кадра: PDF — инфографика (таблицы/графики, обрезка 16:9 неизбежно
  срежет часть значений), страница статистики — обычный HTML без иллюстрации.
  Графики/скриншоты таблиц как источник картинки исключены правилом
  «Графики, диаграммы, скриншоты таблиц — почти никогда»: обрезка кадра 16:9
  из PDF-инфографики отрезала бы часть подписей/значений, значит не годится.
- Тема без явного персонажа/события (правило subject-first разрешает в этом
  случае здание ведомства). Проверил `cbu.uz` на предмет официального фото
  здания — совпадает с уже использованным сегодня в двух других материалах о ЦБ
  РУз (`cbu-extends-fx-exchange-trading-hours`, `cbu-bank-consumer-protection-rules`):
  `https://cbu.uz/upload/media/images/social.jpg` — сайт-вайд og:image ЦБ РУз,
  фасад здания с характерными стеклянными цилиндрическими шахтами лифтов.
  Живая фотография (не рендер, не сток-заготовка), subject соответствует теме
  (материал целиком о деятельности ЦБ РУз).
- Решил не генерировать AI-иллюстрацию: официальное живое фото учреждения,
  прямо связанного с темой статьи, приоритетнее нейтральной абстрактной
  генерации (стратегия C — только если нет уместного фото/стока).

cropLoss 0.1562 — ниже порога эскалации 0.25 для фото с явным объектом (здание),
эскалация в `editor-queue` не требуется. Визуально обрезка пришлась на верхнюю
часть неба, все четыре стеклянные шахты с навершиями видны целиком — главный
объект кадра не пострадал. Ориентация горизонтальная, подложка (contain) не
использовалась.

## Отклонённые варианты
- PDF-инфографика ЦБ (`depozit_uz.pdf`) — источник статьи, но это таблицы и
  графики ставок; обрезка до 16:9 отрезала бы часть значений/легенды —
  не годится по правилу «графики почти никогда».
- Страница `cbu.uz/ru/statistics/rates/` — обычный HTML-раздел без иллюстрации.
- AI-генерация (Higgsfield) не запускал — нашлось уместное официальное живое
  фото по теме (здание ЦБ РУз), оно приоритетнее генерации по правилам порядка
  попыток (A > B > C).
