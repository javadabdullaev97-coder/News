```json
  },
  "output": {
    "path": "public/images/posts/2026-08/tashkent-pharmacy-raid-uncertified-drugs-01.jpg",
    "url": "/images/posts/2026-08/tashkent-pharmacy-raid-uncertified-drugs-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 381317,
    "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```
cropLoss 0.25 — режим cover, апскейла нет. Порог crop-risky (0.25+) в этом случае
не применяется: кадр без единого явного субъекта (лица/животного), которому обрезка
могла бы навредить — это ряды полок, обрезка по высоте безобидна для содержания кадра.
