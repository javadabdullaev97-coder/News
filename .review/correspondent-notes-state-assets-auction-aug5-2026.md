# Reporter notes: state-assets-auction-aug5-2026

## Тема
Агентство по управлению государственными активами РУз 5 августа провело очередной ежедневный онлайн-аукцион: 237 из 619 лотов продано на 54,2 млрд сумов при старте 53,2 млрд. Два лота с арендой ушли в разы выше стартовой цены — кухня в здании университета мировых языков в Ангрене (Ташкентская область) и кухня школы в Алтыарыкском районе Ферганской области.

## Первоисточники (проверенные)
- https://t.me/DAVAKTIVUZ/6193 — пост от 5 августа с итогами аукциона: 619 выставлено / 237 продано, сумма 54,2 млрд сумов при старте 53,2 млрд, 421 участник, разбивка по 6 категориям лотов (сумма по категориям сходится с общим итогом — внутренняя проверка пройдена), два лота-исключения (Ангрен, Фергана).
- https://cbu.uz/ru/arkhiv-kursov-valyut/ (через JSON-эндпоинт arkhiv-kursov-valyut/json/all/2026-08-05/) — официальный курс USD на 5 августа: 11 942,21 сума/доллар. Стандартный HTML-архив на дату не грузится через WebFetch (JS-рендеринг), пришлось использовать публичный JSON API ЦБ.
- Проверен также davaktiv.uz (редиректит на gov.uz/davaktiv) — отдельного пресс-релиза с деталями аукциона от 5 августа на сайте агентства не найдено, только TG-канал даёт полную статистику по дням. Это совпадает с паттерном двух предыдущих материалов серии (3 и 4 августа), где источником тоже был только TG.

## Расхождения с inbox-снипетом
Инбоксный бриф указывал на офис/помещение в Ангрене как на главный сюжет с ростом «в разы» — это подтвердилось (14,35 раза, округлено до «более чем в 14 раз»). Уточнение: это не «офис», а кухня в здании на балансе Узбекистанского государственного университета мировых языков.

Важное дополнение, которого не было в брифе: в том же посте есть второй лот с ЕЩЁ БОЛЬШИМ ростом — кухня школы в Алтыарыкском районе Ферганской области, рост более чем в 31 раз (6 млн → 190 млн сумов), то есть почти вдвое выше по кратности, чем ангренский лот. Решил не скрывать это расхождение и вынести оба лота в один блок, не называя ангренский лот единственным/самым заметным — только «наибольший разрыв среди лотов с арендой» (это верно для крупных объектов; далее в тексте explicitly показан больший рост по Фергане). Если редактор хочет вынести Фергану в заголовок вместо Ангрена — это решение на его усмотрение, фактура для этого в тексте есть.

Технический риск при research: инструмент WebFetch на странице t.me/s/DAVAKTIVUZ/6193 иногда подмешивал данные из соседних постов канала (например, бухарский медцентр из поста 6192 за 4 августа). Отдельно проверил номера постов (data-post) — подтвердил, что Ангрен и Фергана оба относятся именно к посту 6193 (5 августа), а Бухара — к посту 6192 (уже опубликовано вчера, использовано только в сравнительном абзаце со ссылкой на прошлую статью LEAP).

## Что не вошло в статью
- Победители торгов по обоим лотам (Ангрен, Фергана) не названы агентством — если появятся в открытых реестрах, может выйти отдельная заметка.
- Разбивка по категориям дана в тексте компактной прозой; в дальнейшем можно сделать отдельный аналитический материал с динамикой по категориям за неделю (3-5 августа), если редакция сочтёт нужным.
- Программа «Dolzarb 40 kun», которую агентство также освещает в канале в те же дни — отдельная, не относящаяся к аукционам тема, не включена.

## Пропуски и слабые места
- Курс ЦБ на 5 августа взят через нестандартный путь (JSON API вместо HTML-страницы архива) — fact-checker должен перепроверить значение 11 942,21 напрямую по cbu.uz для 05.08.2026, если есть доступ к иному методу рендеринга.
- Разбивка по категориям лотов (6 категорий с count+start+end) взята из одного WebFetch-прогона; арифметическая сверка (сумма количеств = 237, сумма стартовых ≈53,2 млрд, сумма итоговых = 54,2 млрд) сошлась, что снижает риск, но дословный текст поста не удалось получить через инструмент (Telegram/Claude отказывается воспроизводить пост дословно как «копирайт-контент») — все цифры получены через несколько независимых сфокусированных запросов с перекрёстной проверкой, а не единой цитатой.
- Название вуза дано как «Узбекистанский государственный университет мировых языков» — официальное русское название учреждения стоит сверить дополнительно (в разных фетчах встречались варианты перевода узбекского «Ўзбекистон давлат жаҳон тиллари университети»).
- Название района — «Алтыарыкский район» (Oltiariq tumani) — стандартная русская транслитерация, но стоит сверить с официальным написанием хокимията Ферганской области.

## Уверенность в статье: 72%
Основные цифры (итоги аукциона, курс, оба заметных лота) перепроверены по несколько раз и сходятся арифметически, но дословную цитату из поста получить не удалось из-за ограничений инструмента WebFetch на копирование текста Telegram-постов — это не позволяет дать fact-checker'у прямую цитату для сверки один-в-один, только пересказ с цифрами. Рекомендую fact-checker'у попытаться открыть пост напрямую иным методом для финальной сверки точных формулировок (особенно названий вуза и района).
