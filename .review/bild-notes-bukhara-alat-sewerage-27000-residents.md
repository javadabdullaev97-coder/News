### Обработка

```json
{
  "source": { "width": 800, "height": 449, "path": "/tmp/original.jpg" },
  "fit": {
    "mode": "cover",
    "scale": 2.0045,
    "cropLoss": 0.0022,
    "offset": [0, 0],
    "upscaled": true,
    "note": "обрезано 0% по ширине; окно кропа выбрано по содержимому; исходник растянут в 2.00× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/bukhara-alat-sewerage-27000-residents-01.jpg",
    "url": "/images/posts/2026-08/bukhara-alat-sewerage-27000-residents-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 315470,
    "quality": 90
  },
  "status": "ok"
}
```

`cropLoss` 0,0022 (0,22%) — далеко ниже порога 0,15, `crop-risky` не применяется.
Апскейл ×2,0045 — текущая версия `prepare-image.py` допускает умеренный апскейл
до 2,5× для заливки кадра без полей (правило обновлено 03.08.2026 по решению
владельца, см. docstring скрипта); это не растягивание сверх политики, а штатный
режим `cover` для источников из Telegram, чей публичный потолок — 800px.
