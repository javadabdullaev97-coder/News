# Fact-check: copilot-cosnitch-meta-hacking-flaw

## Общий вердикт: APPROVE-WITH-DOWNGRADES

Ядро материала подтверждается источниками полностью и точно — три уязвимости CoSnitch, техника «мета-хакинга», пример украденного пароля, даты раскрытия/патча, молчание Microsoft, различие Copilot Personal / Microsoft 365 Copilot. Найдено два реальных, но не фатальных изъяна: одна цитата привязана не к тому источнику (ссылка ведёт на The Register, хотя фраза дословно взята из блога Varonis), и одна фраза оформлена как дословная цитата в «ёлочках», хотя таковой не является. Оба лечатся точечной правкой без повторной проверки фактов. Также два предложения превышают лимит в 25 слов, а лид длиннее нормы — это уже епархия editor'а, фиксирую для полноты чек-листа.

## Список понижений для editor'а (применяет сам, без повторной проверки)

1. Абзац «В индустрии такой обман называют джейлбрейком…»: ссылку на цитату «Уверенность Copilot в собственной безопасности и стала механизмом, через который он раскрыл, как его скомпрометировать» — перенаправить с URL The Register на `https://www.varonis.com/blog/cosnitch` (фраза дословно найдена там, не в статье Register).
2. В абзаце про эксфильтрацию: убрать «ёлочки» вокруг «как будто просто пересказывает содержимое страницы» — это пересказ репортёра, а не дословная цитата источника (в источнике: «identical to any legitimate URL fetch Copilot performs when summarizing a webpage»). Оставить как описательную фразу без кавычек, либо заменить на точный перевод с кавычками.
3. Сократить предложение «В случае Copilot исследователи довели ИИ до того, что он сам описал собственные защитные механизмы и объяснил, почему один из скрытых параметров запроса «больше не работает» — тем самым подтвердив его существование» (31 слово) — разбить на два предложения.
4. Сократить предложение «Вредоносный запрос заставлял ИИ закодировать найденные данные и вставить их в ссылку на внешний сервер — Copilot переходил по ней сам, «как будто просто пересказывает содержимое страницы», и тем самым отправлял украденное злоумышленнику» (32 слова) — разбить на два предложения.
5. Сократить лид (первый абзац, ~38 слов суммарно) до 25–30 слов либо разбить на лид + отдельное предложение с датой публикации отчёта.
