## Условный шаг: добор переводов архива

Второй приоритет: открывается, только если после основной работы осталось
время.

Свежие материалы переводятся при выпуске (§Шаг 5). Архив переводится
постепенно — этим шагом. Если после основной работы осталось время:

```bash
node scripts/translation-gaps.mjs --limit=6
```

Скрипт возвращает непереведённые материалы от свежих к старым. Возьми
из выдачи **до трёх** и запусти по ним `translator` (по вызову на язык,
все параллельно одним сообщением). Больше трёх за прогон не бери:
перевод архива не должен вытеснять сегодняшнюю повестку.

После перевода — **обязательно** прогони линтер переводов, он чинит
то, на чём переводчики систематически расходятся (проценты, апостроф,
номера актов):

```bash
node scripts/i18n-lint.mjs --fix
```

`out_path` — тот же путь с суффиксом языка: `<...>/<slug>.uz.mdx`.
Переводы уже вышедших материалов кладутся прямо в `content/posts/<день>/`
(не в очередь — материал давно на сайте, публиковать заново нечего),
коммитятся обычным пушем. Языковая версия появится на сайте после
ближайшей пересборки, переключатель на статье её подхватит сам.
