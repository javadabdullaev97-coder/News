# Reporter notes: initiative-budget-july-monitoring-2165-projects

**Тема.** Минэкономфин РУз отчитался в Telegram об итогах мониторинга программы «Инициативный бюджет» за июль 2026 года: выездные проверки прошли на 2 165 строящихся объектах, ещё 257 объектов из прошлых сезонов сдали в эксплуатацию. Отдельным постом ведомство привело примеры объектов в регионах.

**Первоисточники (проверены через `t.me/s/minecofinuz/...`):**
- `t.me/minecofinuz/16198` — 2 165 объектов на выездном мониторинге (стройки ещё идут), 257 объектов из прошлых сезонов завершены и сданы в июле. Ссылка на `openbudget.uz/mobile-monitoring/list/53` дана в самом посте.
- `t.me/minecofinuz/16216` — примеры: школа №15 в Ургенче (Хорезм, 97 видов оборудования, 585 млн сумов); дорога в Дехканабадском районе (Кашкадарья, 2,89 км); спортзал в Чусте (Наманган); асфальт в Элликкалинском районе (Каракалпакстан); Шофирконский район (Бухара) — план 21,4 км, идут работы на 3,2 км; школа №18 в Мирзачульском районе (Джизак, проект 2-го сезона 2025).
- `lex.uz/ru/docs/6429855` — постановление президента ПП-117 от 10.04.2023 (оператор программы — Минэкономфин).
- `lex.uz/ru/docs/3879207` — базовый акт ПП-3917 от 22.08.2018 (найден через поисковый сниппет, не открывал напрямую — использован только для одной фоновой фразы).
- Курс ЦБ USD/UZS на 7 августа 2026 — 11 915,64 сума/доллар (для пересчёта 585 млн сумов).
- Собственный материал LEAP от 04.08.2026 (`content/posts/2026-08-04/tashabbusli-byudjet-2026-otbor-nachalsya.mdx`) — для разграничения: июльский мониторинг про уже отобранные объекты прошлых сезонов, а не про текущий отбор нового сезона (23 551 заявка, отбор 4–18 августа).

**Расхождения с брифом.** Бриф соответствовал первоисточнику по основным цифрам. Важный нюанс: при первой попытке WebFetch по ссылке 16198 инструмент сам домыслил цифры («693 инициативы», разбивку 285/132/105, «163 проекта в Кашкадарье») — при перепроверке через WebSearch они нигде не подтвердились и не совпадают с реальными сезонными данными (21 049 / 23 551 заявок). Признано галлюцинацией инструмента — в статью НЕ включено. **Fact-checker: обязательно перепроверь основные цифры (2 165, 257) заново независимым запросом — источник этого черновика уже один раз давал галлюцинированные числа при первом заходе.**

**Main visual subject.** Явного единого субъекта нет — ведомственный отчёт о множестве строек. Подойдёт фото одного из объектов (асфальтирование дороги, учебное оборудование в классе) или скриншот раздела «Мобильный мониторинг» на openbudget.uz.

**Что не вошло:** агрегированные цифры второго сезона (23 551 заявка, 2 трлн 187,7 млрд сумов, лидеры по регионам) — только у Sputnik Ўзбекистон, не подтверждены официально, не использованы; полный список всех 2 165/257 объектов недоступен (SPA-портал); реакция получателей — не публиковалась.

**Слабые места:** точная дата публикации постов 16198/16216 не извлекается через `t.me/s/` (только время без даты); транслитерация махаллей (Бешкутон, Богормос, Паттахон) — прямая, без независимого русскоязычного подтверждения; курс ЦБ взят на ближайшую доступную дату (7 августа), не на точную дату события.

**Уверенность: 82%.** Ключевые цифры подтверждены дословно первоисточником; снижение из-за отсутствия точных дат постов и неподтверждённой транслитерации топонимов третьего порядка.
