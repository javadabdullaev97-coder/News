## Стилистические правки
- Применил рекомендацию fact-checker'а: «опубликовал» → «сообщил о разработке» (лид).
- Применил рекомендацию fact-checker'а: «автодома» → «автокемперы» (термин источника,
  абзац про таможенные льготы).
- Полное название «Комитет по туризму Республики Узбекистан» при первом упоминании (лид).
- Пассив → актив: «Документ разработан Комитетом по туризму...» → «Комитет по туризму
  разработал документ...» (абзац 2).
- Устранил модально нейтральное, но двусмысленное «Ведомству хотят передать» →
  «Ведомству предложено передать» — единообразная модальность «предложено» по всему
  разделу о регуляторе малой авиации.
- H2 «Малая авиация получит своего регулятора» (утвердительная конструкция, implies
  решённый факт) → «Регулятор для малой авиации» (нейтральная именная конструкция,
  как и остальные заголовки раздела).
- H2 «Где будут развивать активный туризм» (будущее время, implies решённый факт) →
  «Где предлагают развивать активный туризм» — модальность приведена в соответствие
  со статусом документа (проект, не принят).
- Обновил frontmatter: title, description (146 симв., с датой 4 августа), updatedAt,
  authors (+editor), tags (убрал общий «экономика», добавил «активный туризм» и
  «таможенные льготы» — конкретные сущности материала).
