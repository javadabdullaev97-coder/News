# Reporter notes: microsoft-defender-shieldbreak-zeroday

**Тема.** 14 августа 2026 года Microsoft официально подтвердила уязвимость нулевого дня ShieldBreak (CVE-2026-69414) в Malware Protection Engine (движок Defender), раскрытую 11 августа исследователем «Nightmare Eclipse» без предварительного уведомления вендора. Уязвимость обходит патч для более ранней проблемы RoguePlanet (CVE-2026-50656, закрыта 8 июля) и позволяет повысить локальные права до SYSTEM. Патча на момент публикации нет.

**Первоисточники (проверенные):**
- msrc.microsoft.com/update-guide/vulnerability/CVE-2026-69414 — страница MSRC не рендерится через WebFetch (SPA на JS, отдаёт только заголовок). Содержание восстановлено косвенно: дословная цитата MSRC («Microsoft is aware of an elevation of privilege in the Microsoft Malware Protection Engine in Microsoft Defender publicly referred to as "ShieldBreak"», «working to provide a high quality security update») совпала в нескольких независимых заходах — через фетч NVD и через прямую цитату в статье BleepingComputer.
- nvd.nist.gov/vuln/detail/CVE-2026-69414 — CVSS 3.1 base score 7,8 (AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H), опубликовано 14 августа 2026.
- cveawg.mitre.org/api/cve/CVE-2026-69414 (официальный API CVE.org/MITRE, та же запись, что и cve.org/CVERecord?id=CVE-2026-69414 в sources) — state: PUBLISHED, dateReserved 2026-08-03, datePublished 2026-08-14, dateUpdated 2026-08-16.
- blog.projectnightcrawler.dev/posts/2026-08-11-shieldbreak-august-2026-disclosure/ (публикация Nightmare Eclipse) — прямой WebFetch вернул 403 Forbidden. Технические детали (cfapi callback-хук, тест на Windows 11 25H2 и Windows Server 2025, заявленный 100% success rate) взяты из пересказов минимум трёх независимых технических изданий (BleepingComputer, TheHackerNews, GBHackers/CyberKendra), совпадающих между собой. Репозиторий с PoC (git.projectnightcrawler.dev) тоже вернул 403 — не использован как ссылка в тексте.

**Расхождения с inbox-снипетом.** Не найдены — CVE-номер, название ShieldBreak, причастность Nightmare Eclipse и статус «патч готовится» подтверждены официальными записями CVE/NVD/MSRC. Отдельно: часть техизданий называет это «десятым» нулевым днём Nightmare Eclipse с апреля 2026, часть — «девятью». В тексте использована формулировка «как минимум девятая».

**Main visual subject.** Нет узнаваемого человека или здания — тема про программную уязвимость. Подойдёт логотип/иконка Windows Defender (щит), экран Windows Security, либо абстрактная графика с кодом/замком.

**Что не вошло в статью:**
- Детальные инструкции по мониторингу от конкретных вендоров кибербезопасности (например, детекция через wermgr.exe от Tanium) — не включены, чтобы не выглядело как продвижение продукта.
- Конфликт Nightmare Eclipse и Microsoft вокруг угрозы «юридических последствий» — упомянут фактом наличия спора о bug bounty, без цитирования конкретных заявлений (прямого заявления Microsoft с такой формулировкой не нашла).
- Подробная история RoguePlanet — дана одной фразой контекста, отдельный разбор не входит.

**Пропуски и слабые места:**
- MSRC-страница не рендерится напрямую — fact-checker может попробовать открыть её другим способом для финальной сверки цитаты.
- Публикация и репозиторий исследователя недоступны напрямую (403) — механизм эксплойта описан по пересказам техизданий, не по прямому чтению первоисточника.
- Нет подтверждённых случаев активной эксплуатации «в дикой природе» — в тексте это не утверждается.

**Уверенность в статье: 78%.** Ключевые факты подтверждены официальными реестрами NVD и MITRE/CVE.org, дублирующими друг друга. Слабина — часть технических деталей эксплойта опирается на пересказы техизданий, а не на прямое чтение блога исследователя (403 при фетче).
