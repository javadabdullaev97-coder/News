# Bild notes: iran-oman-hormuz-shipping-route-agreement

## Стратегия: stock (Unsplash)

## mainVisualSubject (из reporter-notes / задания)
Танкеры/грузовые суда в Ормузском проливе (вид с воды), либо официальный
представитель МИД Ирана Исмаил Багаи на пресс-конференции, либо карта пролива.
Выбран первый вариант — прямая живая фотография судов, subject-first без
абстракции и без повторного лица.

## Почему не Багаи (вариант 2)
Тот же субъект уже использован в материале серии `iran-denies-trump-hormuz-talks-claim`
(04.08, стоп-кадр брифинга 3 августа). Третье подряд появление одного и того же
спикера в разных материалах одного сюжета — не ошибка по правилам, но снижает
визуальное разнообразие ленты. Проверил официальный Telegram-канал МИД Ирана
(`t.me/s/mfairan`) на случай свежего кадра именно с брифинга 5 августа (пост
36346, 14:58, текст совпадает дословно с цитатой Багаи в статье) — но
единственное изображение в посте оказалось аватаркой канала 160×160
(тот самый паттерн из `image-pipeline.md`: «второй URL в HTML — аватар канала,
его брать нельзя»). Видео-посты с явным Багаи за трибуной в это же утро были
на другую тему (Ирак, Пакистан-Саудия, санкции США, ИИ, Хамас) — не про Ормуз.
Реального нового кадра Багаи с этого брифинга не нашлось → не использовал.

## Почему не карта (вариант 3)
Reporter/editor прямо ссылаются на живой прецедент-ошибку 02.08.2026 (тема
Трамп-Ормуз вышла с фото Земли из космоса вместо субъекта). Проверил
Unsplash по запросу «strait of hormuz» — единственный тематически точный
результат («Strait of hormuz between Iran and Oman», Planet Volumes,
`8koWngCqqzM`) оказался спутниковым/топографическим рендером с
цветовой заливкой — визуально ближе к отвергнутому классу «абстрактная
карта/вид из космоса», чем к живой фотографии. Не взял.

## Путь A — первоисточники: не пробовал предметно
The Guardian/Al Jazeera/SCMP/CNBC/The National — новостные издания, не
пресс-службы; агентские фото (Reuters/AP/AFP) на таких материалах уже дважды
проверялись и отклонялись в этом же сюжете (`iran-oman-hormuz-deal-progress`,
`iran-denies-trump-hormuz-talks-claim`) как неподтверждённые по лицензии.
Не стал повторно тратить попытки на тот же результат — сразу пошёл в Unsplash.

## Путь B — Unsplash: использован
Искал `cargo ship persian gulf`, `orientation=landscape`. Рассмотрел кандидатов:
- Kayvan Mazhar, `jJ_tcWt3kdY` — торговые суда-дау (традиционные иранские
  каботажные/грузовые лодки) у причала, остров **Кешм** (Qeshm), Иран —
  сам остров лежит непосредственно в Ормузском проливе, географически точнее
  «типового танкера» из соседнего материала. Вечерняя/ночная съёмка, длинная
  выдержка, туманная дымка, отражения в воде. 3000×2000 (соотношение 1,5),
  реальная фотография, не рендер.
- Mohsen L, `9hUK49ZtYuA` — ряд лодок-дау у берега, Персидский залив, дневной
  свет, виден иранский флаг, горы на фоне (похоже на Хормозган). 3000×2253
  (соотношение 1,33). Визуально ярче и «репортажнее», но при прогоне
  `prepare-image.py` cropLoss = 0,251 — **выше** порога 0,25 из
  `config/newsroom-policy.json → imagery.cropRiskThreshold`. Формально
  требовал бы `crop-risky`-эскалации. Не стал усложнять: кадр Mazhar дал
  безопасный кроп и не менее точный субъект (тот же класс судов, тот же
  регион пролива), поэтому выбрал его вместо похода в editor-queue.

Выбран **Kayvan Mazhar, `jJ_tcWt3kdY`** — прямой URL:
`https://images.unsplash.com/photo-1583082760952-0a87cc88f865`.
Локация по подписи автора — Кешм, Иран. Unsplash License (свободное
использование, коммерческое и некоммерческое, атрибуция желательна —
проставлена).

## Обработка — `scripts/prepare-image.py`

```json
{
  "source": {"width": 3000, "height": 2000, "path": "scratchpad/qeshm.jpg"},
  "fit": {
    "mode": "cover",
    "scale": 0.5333,
    "cropLoss": 0.1562,
    "offset": [0, 35],
    "upscaled": false,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/iran-oman-hormuz-shipping-route-agreement-01.jpg",
    "url": "/images/posts/2026-08/iran-oman-hormuz-shipping-route-agreement-01.jpg",
    "width": 1600, "height": 900, "bytes": 156116, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

`cropLoss = 0,1562` — ниже порога 0,25, `crop-risky` не применяется.
Визуально проверил готовый кадр: все три судна-дау и лодка на переднем плане
целиком в кадре, обрезана только верхняя полоса неба — ничего смыслового
не потеряно.

## Отклонённые варианты

- Агентские фото (Reuters/AP/AFP) из og:image источников статьи — не
  проверял предметно повторно: в двух предыдущих материалах этого сюжета
  такие кадры уже отклонялись по неподтверждённой лицензии.
- AI-генерация (Higgsfield) — не понадобилась, нашлось живое фото с чистой
