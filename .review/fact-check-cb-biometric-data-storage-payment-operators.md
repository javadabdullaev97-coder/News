## Чек-лист редполитики

- Заголовок 60–90 символов, без CAPS/«!» — 78 символов, ок.
- Лид 25–30 слов, есть дата — 28 слов, дата «1 августа 2026 года», ок.
- Каждая цифра в тексте есть в источниках — подтверждено.
- Действия госоргана подтверждены первоисточником — «ЦБ обязал» подтверждено собственным Telegram-каналом ЦБ.
- Нет ссылок на чёрный список СМИ.
- Нет AI-slop фраз и неатрибутированных оценочных прилагательных.
- Названия ведомств полные при первом упоминании — «Минюст» дан сокращённо без расшифровки «Министерство юстиции» (мелкое нарушение §5, не фактическая ошибка).
- Frontmatter: `sources` содержит 2 записи.
- `image.url: null` — нормально для стадии до editor/bild.

## Список понижений для editor'а

1. Абзац «Почему требование выделили отдельно», предложение про О‘РҚ-1125: заменить категоричное утверждение о содержании поправки на атрибутированную форму, например: «...законом от 26 марта 2026 года (О‘РҚ-1125), по данным lex.uz, смягчили это требование, сузив обязательную локализацию до отдельных категорий данных — в частности биометрических». Причина: дословный текст части 3 ст. 27¹ и текст самой поправки через lex.uz извлечь не удалось. Понижение силы утверждения, новых фактов не добавляет — повторная проверка не нужна.
2. Фраза «раньше все персональные данные граждан требовалось хранить только на серверах внутри страны» — смягчить до «прежде общее требование локализации распространялось на персональные данные шире, чем сейчас» (не блокирующая правка).
3. Стилевая: при первом упоминании «Минюст» дать полную форму «Министерство юстиции» (сокращённо — Минюст) по §5 редполитики.
