# Bild notes: us-state-dept-fiscal-transparency-uzbekistan

## Стратегия: fallback-needed (эскалация владельцу)

## Main visual subject
Из reporter notes: «Нет однозначного человека-героя». Editor (handoff) дал
конкретную подсказку: здание Госдепа США (Foggy Bottom / Harry S. Truman
Building) или официальная обложка доклада 2026 Fiscal Transparency Report;
альтернатива — здание Минэкономфина РУз в Ташкенте. Избегать: флаги/символику
как единственный визуал (штамп), конкретных чиновников без подтверждённой
личной цитаты.

## Что проверено

### A. Первоисточник (state.gov)
- Прямой WebFetch на state.gov, как и у reporter, отдаёт заглушку
  «Technical Difficulties». Через `curl` с обычным User-Agent страницы
  отдаются нормально (HTTP 200, реальный HTML) — значит блокировка была
  специфична для WebFetch-инструмента, а не для сети.
- Проверены все 4 URL из `sources`: страница по Узбекистану, сводная
  страница доклада, пресс-релиз, доклад за 2025 год.
- `og:image` на всех трёх уникальных страницах — это либо общий шаблон
  пресс-релиза `Press_Release_Alabaster.png` (1200×628, дженерик для любого
  пресс-релиза Госдепа, не по теме), либо `Seal_only-1.png` — печать/герб
  ведомства. Второе прямо попадает под «image-avoid» из handoff (символика
  как единственный визуал).
- В `<img>`-тегах на этих страницах — только логотип флага США (SVG) и
  логотип ведомства (SVG) в шапке сайта, реальных фотографий здания или
  обложки доклада нет. PDF доклада на странице не нашёл (нет `.pdf`
  ссылок в HTML).
- Вывод: у первоисточника нет фото по теме, только штамповая символика.

### B0. Фототека редакции (config/stock-photos.json)
Темы манифеста: cbu, monetary-policy, fx, sum, inflation, banking, payments.
Тема доклада (фискальная прозрачность, госдолг, госзакупки) под них не
подходит содержательно, а editor прямо просил не ставить деньги/сток вместо
здания — не запрашивал pick-stock.mjs.

### B. Здание Минэкономфина РУз (mineconomy.uz)
- Сайт mineconomy.uz — Nuxt SPA (`_nuxt/img/*`), контент подгружается через
  клиентский JS. `curl` отдаёт только шапку сайта: иконки соцсетей, флажок
  языка, логотипы госуслуг (ЕПИГУ и т.д.) — ни одной фотографии здания.
  Без headless-браузера (недоступен в среде) достать реальный контент со
  страниц ведомства не получилось. minfin.uz / mof.uz — не резолвятся
  (первый: истёкший TLS-сертификат на стороне сайта, второй — нет ответа).

### B1. Публичные банки (Unsplash / Pexels / Flickr)
- Прямой API Unsplash недоступен без ключа (нет в env/конфиге репозитория).
- Через WebFetch по страницам поиска Unsplash/Pexels на запросы «US State
  Department building», «Harry S. Truman building», «Foggy Bottom» —
  ни разу не нашлось фото, подписанного как именно это здание. Есть похожие
  по типу фото федеральных зданий Вашингтона (Treasury, Agriculture,
  Commerce, generic «classic government building»), но подписывать их как
  «здание Госдепартамента США» было бы фактической неточностью — это не то
  здание.
- Flickr: нашёлся один кадр «Harry S. Truman building (State Department
  headquarters) evacuation drill» (id 6331359845), но разрешение всего
  640×480 (4:3, не landscape под 1600×900), лицензия/авторство не
  проверяемы (обычный пользовательский аккаунт, не официальный @statephotos),
  содержание — эвакуационные учения, а не здание само по себе. Отклонил:
  риск по лицензии + низкое разрешение + не совсем то, что нужно.
- GSA (управляет зданием, официальная пресс-служба) — страница о здании
  вернула 404, нет alternate og:image по теме.

### C. AI-генерация (Higgsfield)
Согласованный в задаче fallback («используй генерацию (Higgsfield), нейтральную
иллюстрацию по теме») — в этом прогоне инструмент технически не подключён к
сессии (нет в списке доступных tools, нет обвязки в scripts/). Сгенерировать
не могу. Прецедент такой же эскалации уже был:
`content/needs-verification/tashkent-mahalla-improvement-dolzarb-40-kunlik.mdx`
(причина «no-image», тот же технический блокер с Higgsfield).

## Отклонённые варианты
- state.gov og:image `Press_Release_Alabaster.png` — дженерик-шаблон, не по теме
- state.gov og:image `Seal_only-1.png` — печать/герб, попадает под image-avoid
- Pexels 32017626 / 36671563 / 5691305 — «generic government building»,
  не подтверждено что это здание Госдепа, риск фактической неточности
  (Treasury/Agriculture/Commerce тоже среди похожих находок — легко перепутать)
- Flickr 6331359845 — низкое разрешение (640×480), непроверенная лицензия,
  тема кадра (эвакуация) не совпадает с задачей

## Решение
Материал перемещён в `content/needs-verification/`, добавлены
`awaitingEditor: true` и `pendingEditorQuestion` (reason: `no-image`) с
описанием проблемы и просьбой прислать фото здания Госдепа / обложку доклада /
фото здания Минэкономфина РУз, либо подтвердить генерацию через Higgsfield.
Текст статьи не менял.
