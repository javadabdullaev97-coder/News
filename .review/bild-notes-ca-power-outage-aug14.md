# Bild notes: ca-power-outage-aug14

## Стратегия: stock

## mainVisualSubject (reporter notes)
Явного человека-протагониста в сюжете нет. Указан объект энергоинфраструктуры
(подстанция, ЛЭП высокого напряжения) или карта/схема энергосистемы ЦА.
Handoff editor'а (image-hint) повторяет то же самое, плюс image-avoid: не
воспроизводить конкретные номера ЛЭП/цифры МВт на инфографике (они убраны
из текста как неподтверждённые).

## Попытка A — первоисточник (Минэнерго РУз, t.me/minenergy_uz)
Проверены все три поста из `frontmatter.sources`:
- `t.me/minenergy_uz/20737` — вложенное фото 800×565: брендированная карточка
  "Rasmiy xabar" (узб. «Официальное сообщение») с силуэтами опор ЛЭП на фоне
  и гербом/логотипом министерства. Это шаблонная текстовая карточка-заглушка,
  не фотография события и не инфографика с данными — отклонена: не несёт
  предметного визуала, только текст на узбекском не по формату статьи.
- `t.me/minenergy_uz/20738`, `/20739` — превью-картинки 90×64 (эмодзи-иконки
  из HTML, не фото поста), непригодны по размеру (`too-small`, ниже MIN_SOURCE=600).
- og:image / meta не заданы отдельно — второй URL в HTML подтверждённо аватар
  канала 160×160 (см. `image-pipeline.md`), не брать.
Итог: у Минэнерго РУз для этого инцидента нет пригодного фото.
