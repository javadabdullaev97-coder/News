# Image pipeline — техническая справка

Вынесено из `.claude/agents/bild.md`, чтобы промпт bild-агента не
разбухал техническими подробностями (было 460 строк). Bild-агент
подгружает этот файл при работе с картинкой, если ему нужна деталь
кроп-эвристики, лимитов Telegram или API prepare-image.py.

## scripts/prepare-image.py

Единственный допустимый способ обработки картинки. ImageMagick на
runner-е нет, Pillow есть.

Использование:

```bash
curl -sL "$SOURCE_URL" -o /tmp/original.jpg
python3 scripts/prepare-image.py /tmp/original.jpg <slug> --month=2026-08
```

Скрипт печатает JSON с итогом обработки: какой режим выбран
(`cover` или `contain`), коэффициент масштабирования, сколько
обрезано, итоговый вес и quality. Этот JSON копируется целиком в
`.review/bild-notes-<slug>.md`.

## Что делает скрипт и почему это важно знать

- **Апскейла нет никогда.** Коэффициент ограничен единицей. Если
  исходник меньше кадра, он вписывается целиком на размытую подложку
  из самого себя, а не растягивается. Прежнее правило
  `-resize '1200x630^' -extent` растягивало квадратную карточку
  госканала 800×800 в 1,5 раза и срезало 47% высоты — вместе с
  заголовком и подписью на карточке.
- **Обрезка ограничена 22%.** Если по любой оси теряется больше —
  скрипт сам переключается на `contain`. Решать, «терпимо ли
  срезать», тебе не нужно.
- **Слишком мелкий исходник отбраковывается.** Меньше 600px по
  длинной стороне → `status: too-small`, выход с кодом 2. Это сигнал
  искать другой источник, а не повод обработать что есть.

## Кадр статьи

**1600×900** — совпадает с `og:image` в
`app/article/[slug]/page.tsx`. Раньше здесь стояло 1200×630, и
объявленный размер расходился с фактическим.

## Telegram отдельно

Публичный виджет отдаёт максимум **800px** по длинной стороне —
проверено на `t.me/<slug>/<id>?embed=1`, второй URL в HTML это аватар
канала 160×160, его брать нельзя. Больше 800px из публичного канала
не достать без Bot API. Поэтому картинка из ТГ почти всегда пойдёт
в `contain` — это нормально и правильно, не пытайся «починить» это
растягиванием.

Если скачивание упало (403, 404, timeout) — переходи к следующей
стратегии в `bild.md`, к разделу «Порядок попыток».
