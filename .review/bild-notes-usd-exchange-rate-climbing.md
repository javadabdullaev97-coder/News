# Bild notes: usd-exchange-rate-climbing

## Стратегия: primary-source

## Main visual subject
Тема — курс доллара США к суму, двухдневный отскок после снижения. Явного
физического субъекта нет (человек/событие/здание в самом смысле новости не
фигурирует) — все 4 источника в `frontmatter.sources` это JSON-эндпоинты
архива курсов cbu.uz, фотографий не отдают. Задание прямо подтверждает это
("тема про число/курс").

Для такого класса тем (курс ЦБ, ставка, инфляция без иного субъекта) в редакции
уже устоялась практика: институциональный субъект — само здание ЦБ РУз,
фирменный кадр с `og:image` домена регулятора. Проверил по истории
`.review/bild-notes-*.md`: тот же файл уже использовался для
`cb-cash-fx-500-usd-no-passport`, `cbu-extends-fx-exchange-trading-hours`,
`uzbekistan-usd-rate-rising-aug2026`, `usd-uzs-rate-lowest-since-dec-2025` —
не разовая находка, а устоявшийся фирменный визуал учреждения.

## Ход поиска

### A. Первоисточник (cbu.uz)
- Проверил `https://cbu.uz/ru/` (главная), `/ru/about/`, `/ru/press_center/news/`,
  `/ru/arkhiv-kursov-valyut/` — свежих новостных материалов о курсе/валютном рынке
  с фото нет; лента — репо-аукционы, меморандумы, партнёрства. Карусель главной
  страницы отдаёт фото 400×255 (ниже MIN_SOURCE=600px), к тому же на снимках люди
  на встречах/подписаниях — не по теме курса.
- `/upload/iblock/df0/.../photo_2023_11_07_14_28_16.jpg` на странице «О банке» —
  баннер образовательного проекта finlit.uz, 300×500, портретная ориентация,
  не по теме. Отклонён.
- Нашёл `og:image` самого сайта cbu.uz — `https://cbu.uz/upload/media/images/social.jpg`,
  1110×740 (landscape, AR≈1.5), 233 КБ. Фирменное официальное фото фасада здания
  ЦБ РУз в Ташкенте (характерные стеклянные цилиндрические лифтовые шахты, ракурс
  снизу вверх). Живая фотография, не рендер и не диаграмма, без людей и политиков —
  под все правила imagery.preferRealPhotography подходит, subject-first
  (здание ЦБ — прямой институциональный субъект темы о курсе, который ЦБ и
  устанавливает).
- Stock (Unsplash/Pexels) и Higgsfield-генерация — не потребовались, порядок
  попыток A→B→C остановился на шаге A с приемлемым результатом (тот же файл,
  что и в четырёх предыдущих материалах этой тематики).

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 1110, "height": 740},
  "fit": {
    "mode": "cover",
    "scale": 1.4414,
    "cropLoss": 0.1562,
    "offset": [0, 167],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.44× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/usd-exchange-rate-climbing-01.jpg",
    "url": "/images/posts/2026-08/usd-exchange-rate-climbing-01.jpg",
    "width": 1600, "height": 900, "bytes": 235347, "quality": 90
  },
  "status": "ok"

```

## Про cropLoss и порог crop-risky
`cropLoss = 0.1562`, порог `imagery.cropRiskThreshold` в `config/newsroom-policy.json`
проверен на момент публикации — `0.25`. 0,1562 < 0,25 — порог не превышен,
эскалация к владельцу не требуется. Визуально: обрезается только полоса неба
над зданием, все четыре стеклянные шахты и фасад видны целиком.

## Ориентация кадра
Исходник 1110×740 — горизонтальный (AR≈1,5), правило «ищи горизонталь, а не
спасай вертикаль» соблюдено, подложка (contain) не потребовалась.

## Отклонённые варианты
- Карусель `cbu.uz` главной (`/upload/imager/*.jpg`, 400×255) — меньше MIN_SOURCE=600px,
  плюс люди на встречах/подписаниях, не по теме курса.
- `/upload/iblock/df0/.../photo_2023_11_07_14_28_16.jpg` — портретный баннер
  финграмотности, 300×500, не по теме.
- Stock (Unsplash/Pexels) и AI-генерация (Higgsfield) — не понадобились, порядок
  попыток остановился на первоисточнике (A).

Плюс: официальный источник, subject-first (здание ЦБ РУз — институциональный
субъект темы о курсе), живая фотография, без людей и политиков, атрибуция
однозначна, cropLoss в пределах порога (0,1562 < 0,25), полностью

тот же файл уже стоит на нескольких других материалах о ЦБ РУз за последние
дни — повторное использование снижает уникальность именно этой статьи в
ленте, но альтернативной живой фотографии по теме в первоисточнике нет.
