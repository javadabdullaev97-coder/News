# Editor verdict: state-assets-auction-aug3-2026

## Решение: publish

## Изменения в заголовке
**До**: На онлайн-аукционе госактивов 3 августа продали 645 лотов на 103,6 млрд сумов
**После**: Агентство госактивов продало 645 лотов на аукционе 3 августа за 103,6 млрд сумов

Обоснование: старый заголовок в первых 40 символах давал только тему («на онлайн-аукционе
госактивов 3 августа») без действия и числа — в ленте это выглядело бы как заголовок ни о чём.
Новый вариант выносит действие («продало») и ключевую цифру («645 лотов») в первые 38 символов.
Длина 80 символов — в диапазоне 60–90.

## Изменения в лиде
**До**: «Агентство по управлению государственными активами Республики Узбекистан 3 августа
реализовало на онлайн-аукционе 645 из 1 307 выставленных лотов на сумму 103,6 млрд сумов
(≈8,66 млн долларов по курсу ЦБ 11 960,18 сума за доллар на 3 августа).» (37 слов)

**После**: «Агентство по управлению государственными активами Республики Узбекистан 3 августа
реализовало на онлайн-аукционе 645 из 1 307 выставленных лотов на сумму 103,6 млрд сумов при
стартовой цене 108,2 млрд сумов.» (29 слов)

Обоснование: fact-check указал превышение нормы 25–30 слов. Долларовый пересчёт вынесен в первый
абзац тела (там же, где он логически привязан к итоговой сумме сделки), а на освободившееся место
добавлена стартовая цена — она уже фигурировала в теле статьи, это не новый факт.

## Стилистические правки (применены понижения fact-checker'а)
1. Убрана непроверенная фраза «в среднем несколько раз в неделю» → заменена на нейтральное
   «Агентство по управлению госактивами регулярно проводит онлайн-аукционы через собственную
   электронную площадку» (пункт 1 списка понижений).
2. Лид сокращён с 37 до 29 слов, долларовый эквивалент перенесён в первый абзац раздела
   «Что продали» (пункт 2).
3. Фраза «Агентство не привело в публикации детальную разбивку числа проданных лотов по каждой
   из категорий» смягчена до «Агентство перечислило эти категории без детализации числа лотов
   по каждой из них» — без приписывания конкретных цифр категориям (пункт 3).
4. В `frontmatter.sources` добавлен источник курса — «Центральный банк Республики Узбекистан —
   архив курсов валют» (cbu.uz) — по прямому указанию fact-checker'а, курс уже подтверждён им
   через JSON-архив cbu.uz (пункт 4). Это санкционированное исключение из правила «не добавлять
   новые источники самостоятельно»: источник уже проверен fact-checker'ом, я его не добавлял по
   собственной инициативе.
5. В description «1307» исправлено на «1 307» — разделитель разрядов расставлен (пункт 5).
   Технически используется обычный пробел, тот же, что и в теле статьи (единообразие
   форматирования по всему документу); я не смог гарантированно вставить типографский
   неразрывный пробел через доступный инструментарий редактирования текста — фиксирую это
   как известное ограничение, не блокирующее публикацию.
6. Из frontmatter полностью удалены строки `publishedAt` и `updatedAt` — по указанию, эти поля
   проставляет публикатор при выходе на сайт (пункт 6).
7. `authors` дополнен значением `"editor"` рядом с `"reporter"`.

## Три жёстких триггера — проверка
- Слов в теле статьи (без frontmatter) до правки: ~177. После правки: ~174. Чистое изменение
  ~2%, что кратно меньше порога 15% — триггер 1 не сработал.
- Ни один абзац со ссылкой на источник не снят: ссылки в лиде («реализовало на онлайн-аукционе»),
  в абзаце про итоги торгов («сообщило») и в абзаце сравнения («выставило») сохранены на месте —
  триггер 2 не сработал.
- Единственный добавленный источник (cbu.uz) — прямое указание fact-checker'а из списка
  понижений, а не инициатива редактора; это явное исключение, прописанное в правилах — триггер 3
  не сработал.

## Что оставил как есть
- Структуру статьи (лид без H2, затем «Что продали» и «Для сравнения») не менял — она логична
  и соответствует редполитике (детали события → контекст/сравнение).
- Раздел «что дальше» не добавлял — тема рутинная, следующих шагов с датами в источниках нет.
- Абзац-сравнение с 31 июля оставил без изменений — цифры подтверждены, стиль уже соответствует
  требованиям (активный залог, цифры с разделителями).

fact-checker'ом напрямую по первоисточникам, все понижения применены без выхода за пределы

(не критично для публикации).
