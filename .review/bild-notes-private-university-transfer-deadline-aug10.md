# Bild notes: private-university-transfer-deadline-aug10

## Что проверено сначала (первоисточник)
- Единственный `sources` — Telegram-пост Минвуза `https://t.me/eduuz/50135`. Скачал
  HTML через `curl "...?embed=1"`, вытащил `background-image` фото поста:
  `https://cdn4.telesco.pe/file/oyIP9Bq-...jpg` — 800×800, JPEG.
- Просмотрел изображение: типовая брендированная карточка-«объявление» министерства
  («DIQQAT, E'LON! / ВНИМАНИЕ, ОБЪЯВЛЕНИЕ!») с гербом ведомства и стилизованным
  силуэтом здания на градиентном синем фоне. Отклонил по двум причинам:
  1. Квадрат 1:1 (соотношение 1.0) — жёстко ниже требуемой горизонтали (~1.3+,
     правило владельца от 04.08.2026); при подгонке под 1600×900 обрезка по высоте
     потребовала бы ~44%, что кратно превышает лимит `prepare-image.py` (22%) и увело
     бы в `contain`-подложку — как раз тот «красный флаг», который правило запрещает
     принимать как штатный результат.
  2. Это универсальный шаблон-заготовка ведомства для любых объявлений (не фото
     события/здания/студентов конкретно этой новости) — по духу близко к
     «рисованной 3D-заготовке», хоть и не буквально бизнес-рендер.
- Явного `mainVisualSubject` в reporter-notes нет (файл notes для этого слага не
  сохранился/не создавался) — тема административная (продление срока приёма
  заявлений), без единого физического субъекта (человек/здание/событие).

- Источник: Unsplash, фотограф Vitaly Gariev (@silverkblack), Unsplash License.
- Прямая ссылка: `https://images.unsplash.com/photo-1758270704524-596810e891b5`
  (оригинал 3800×2138, соотношение 1.777 — почти точно совпадает с 1600×900).
- Содержание: лекционная аудитория, пятеро студентов за партами с тетрадями,
  без опознаваемых вывесок, текста или логотипов конкретного вуза/страны —
  нейтральная иллюстрация «студенческой аудитории», как и предполагал fallback-путь
  задания.

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 3800, "height": 2138},
  "fit": {"mode": "cover", "scale": 0.4211, "cropLoss": 0.0002, "offset": [0, 0],
          "upscaled": false, "note": "обрезано 0% по высоте"},
  "output": {"path": "public/images/posts/2026-08/private-university-transfer-deadline-aug10-01.jpg",
             "url": "/images/posts/2026-08/private-university-transfer-deadline-aug10-01.jpg",
             "width": 1600, "height": 900, "bytes": 175035, "quality": 90},
  "status": "ok",
  "upscaled": false
}
```
`cropLoss` 0,0002 — практически нулевая обрезка, `crop-risky` не применяется.

## Уверенность в подборе: 55%

Честная, нейтральная, тематически подходящая фотография без вводящих в заблуждение
деталей — но не subject-first в строгом смысле (нет реальной связи с конкретным
эпизодом, вузом или порталом transfer.edu.uz/my.uzbmb.uz). У темы нет единого
физического субъекта (административный дедлайн по всей стране), а единственная
фотография первоисточника оказалась непригодна (квадратный шаблон). AI-генерацию
через Higgsfield не пробовал — сток дал чистый, безопасный результат без риска
«разноцветной радуги» или глянцевого рендера, которого требовалось бы избегать при
генерации; предпочёл его как более быстрый и такой же нейтральный путь.
