OpenAI on August 20 released an Apple Messages plugin for the ChatGPT app on Mac — it searches, analyzes and sends iMessage, SMS and RCS messages on the user's behalf, [the company's documentation says](https://learn.chatgpt.com/docs/plugins?surface=app).

The plugin works only within two ChatGPT work modes — Codex, OpenAI's agentic tool for coding, and ChatGPT Work, the enterprise version of the assistant for work tasks. The plugin does not work in the regular ChatGPT chat, the web version, on mobile, or in the code editor extension, according to the documentation.

The feature is currently available only on Macs with Apple Silicon processors — Apple's own M1–M4 chip lineup. The plugin is not available to owners of Intel-based Macs. OpenAI specifies that the restriction applies "for this release," without naming a date for expanded support. Access to the plugin is open on all ChatGPT plans for the desktop app on macOS.

RCS is a messaging standard that is gradually replacing SMS and supports group chats and large attachments. iMessage and RCS on Mac are handled by the system Messages app.

By default, ChatGPT shows a draft message and waits for the user's approval before each send. Users can choose "Allow once" for a specific message or "Always allow sending in this chat." In the second case, the assistant will send messages in the selected conversation without additional confirmations, according to OpenAI's documentation. The standing permission can be revoked in the app's settings.

According to [TechCrunch](https://techcrunch.com/2026/08/20/chatgpt-can-now-send-texts-for-you-with-new-apple-messages-plugin/), OpenAI told Bloomberg that the plugin processes conversations locally on the user's computer and does not create a combined index of all their messages.
