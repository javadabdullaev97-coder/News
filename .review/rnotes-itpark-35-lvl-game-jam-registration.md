# Reporter notes: itpark-35-lvl-game-jam-registration

## Тема
IT-Park Uzbekistan открыл регистрацию на геймджем «35 LVL Game Jam» — трёхдневный хакатон для разработчиков игр 21-23 августа 2026 года. Организаторы: IT-Park Uzbekistan, School 21, сообщество East Games. Формат смешанный: офлайн на кампусе School 21 в Ташкенте плюс онлайн-участие по всему Узбекистану.

## Первоисточники (проверенные)
- https://t.me/itpark_uz/20586 — основной источник. Даты (21-23 августа), организаторы (IT-Park, School 21, East Games), формат (офлайн School 21 Ташкент + онлайн по стране), суть джема (превратить идею игры в прототип за 3 дня), темы объявляются в начале мероприятия, ссылка на регистрацию и на отдельный Telegram-чат для зарегистрированных участников. Канал `itpark_uz` — P2, `type: source` в `config/telegram-channels.json`.
- https://startupbase.uz/uz/events/35-lvl-game-jam — страница регистрации, на которую ссылается сам пост IT-Park. WebFetch отдал только общий шаблон сайта (страница рендерится через JS, детали ивента не вытянулись), но URL существует и подтверждён как официальная точка регистрации из первоисточника. Использован как второй источник для факта регистрации, не для дополнительных деталей.

## Проверка на дополнительные источники
Проверил каналы двух других организаторов на предмет параллельного анонса с более полными деталями (призовой фонд, дедлайн, требования):
- School 21 Uzbekistan (`skd21school`, найден через WebSearch) — постов про 35 LVL Game Jam на момент проверки нет.
- East Games Uz (`EastGamesUz`, найден через WebSearch) — постов про это мероприятие тоже нет, только про другие геймдев-события (Turkic Game Jam, GameDev Goethe и т.д.).

Оба канала обнаружены через прямой WebSearch, не через гиперссылки в статьях конкурентов — по правилам шага 4.5 это не триггер для записи в candidate-sources.jsonl, запись не сделана.

Расхождений в цифрах и фактах не найдено — у первоисточника просто меньше деталей, чем обычно бывает в ивент-анонсах (нет призового фонда, нет дедлайна регистрации, нет требований к участникам). Это зафиксировано в тексте статьи явно, без додумывания.

## Пропуски и слабые места
- Призовой фонд, дедлайн регистрации, требования к участникам — в первоисточнике не указаны вообще. Это реальный пробел в самом анонсе IT-Park, статья прямо говорит об отсутствии этих деталей.
- Дата публикации самого поста `t.me/itpark_uz/20586` не извлеклась через WebFetch (виджет не отдаёт метаданные о времени поста) — в лиде намеренно не указана точная дата публикации анонса, только дата события (21-23 августа), подтверждённая текстом поста.
- `startupbase.uz` — вторичный источник в основном для факта существования формы регистрации, не для деталей ивента.

## Уверенность в статье: 62%
Факты, которые есть (даты, организаторы, формат, суть, регистрация), подтверждены напрямую официальным P2-источником. Уверенность снижена не из-за сомнений в точности, а из-за скромного объёма самостоятельной новостной фактуры — по сути это анонс календарного события с минимумом деталей, без призового фонда и дедлайна, которые обычно составляют основную фактуру такой новости.
