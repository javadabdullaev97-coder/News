## Стилистические правки
1. **(Критическая, обязательная фактчеком)** Абзац «Гражданство и шансы на
   экстрадицию»: убрал предложение «Гражданство Франции и ОАЭ по законам обеих стран
   затрудняет его выдачу России» целиком — непроверяемый правовой вывод без источника.
   У предложения не было своей ссылки, соседний абзац источник не теряет.
2. Абзац 2 («Днём раньше...»): при первом упоминании ФСБ дал полное название
   «Центр общественных связей Федеральной службы безопасности (ФСБ) России» —
   правка №4 фактчека. Далее по тексту — короткая форма «ФСБ».
3. Абзац 3 (26 слов, правка №2 фактчека): разбил на два предложения —
   «Включение в перечень означает для Дурова заморозку счетов и имущества в России»
   / «Банкам также запрещено обслуживать его операции, кроме выплат по налогам,
   зарплате и возмещению ущерба».
4. Абзац 2 попутно тоже содержал предложение в 24 слова («предъявил обвинение...
   и объявил в розыск»), после расширения названия ФСБ оно выросло бы до 28 слов —
   разбил на два предложения по той же логике (>25 слов режем всегда, раздел 4
   редполитики), сохранив атрибуцию «Коммерсантъ» на обеих частях: обвинение и розыск —
   де-факто два разных факта из одной статьи Коммерсанта, оба должны быть подписаны
   отдельно, а не только второй.
5. При разбиении абзацев 2 и 3 не убирал и не переставлял существующие ссылки —
   там, где расщепление сняло бы ссылку с одного из двух фактов, продублировал ту же
   уже проверенную fact-checker'ом ссылку (Коммерсантъ на оба факта абзаца 2; РИА
   на факт заморозки счетов в абзаце 3, где ранее ссылка стояла только на список
   запретов дальше по тексту, хотя источник по reporter-notes покрывает оба факта).
   Новых URL не добавлял — все ссылки уже были в `frontmatter.sources`.

## Что оставил как есть

  основание для «подчеркнуло» есть.
- Гражданства (Россия, Сент-Китс и Невис, ОАЭ, Франция) и год получения французского —
  факт, а не вывод, оставил без изменений.
- description и tags — уже соответствуют требованиям (140–141 символ, 4 конкретных тега),
  не трогал.
