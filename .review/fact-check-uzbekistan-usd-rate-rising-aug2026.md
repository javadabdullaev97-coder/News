# Fact-check: uzbekistan-usd-rate-rising-aug2026

## Общий вердикт: NEEDS-FIX (мелкие правки)

Все цифры в драфте проверены напрямую через JSON API cbu.uz — совпадают до сотых. Причина роста курса нигде не выдумана. Заголовок и лид не драматизируют разворот.

## Проблемы

1. **[Критично, но мелко]** Три значения курса (28, 30, 31 июля), используемые в тексте, не подкреплены отдельными ссылками в `frontmatter.sources` — там есть только общая ссылка-хаб `https://cbu.uz/ru/arkhiv-kursov-valyut/`, которая по §3 редполитики не считается «конкретной записью». Нужно добавить:
   - `https://cbu.uz/ru/arkhiv-kursov-valyut/json/USD/2026-07-30/` (Rate 12035.26)
   - `https://cbu.uz/ru/arkhiv-kursov-valyut/json/USD/2026-07-31/` (Rate 12006.39)
   - `https://cbu.uz/ru/arkhiv-kursov-valyut/json/USD/2026-07-28/` (Rate 11988.92)
   и убрать/заменить общую ссылку на архив-хаб.
2. Некритично: «почти на 90 сумов» — фактически 90,16, чуть больше 90, не «почти» снизу. Заменить на «более чем на 90 сумов».
3. Некритично: meta `description` чуть длиннее рекомендованных 140–160 симв. — можно слегка сократить.

## Чек-лист §9
