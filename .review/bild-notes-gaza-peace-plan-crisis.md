# Bild notes: gaza-peace-plan-crisis (rework, iteration 1)

## Контекст
Повторный проход. В прошлой итерации материал ушёл в needs-verification с
reason: no-image (subject-first фото Кушнера/Нетаньяху/освобождённых
заключённых в открытом бесплатном доступе не нашлось). Владелец ответил
прямым указанием: «Найди картинку по газа в интернете и используй её» —
не требует жёсткой привязки к конкретному кадру события, тема та же.

## Стратегия: stock (Unsplash, публичный банк)

### Что проверил по порядку (A → B0 → B1)
- **A. Первоисточник.** `mofa.gov.ae` (совместное заявление МИД восьми стран) —
  открыл страницу через WebFetch и curl, в HTML только логотип ведомства
  (`mofaicuaelogo2023.png`), фотографии события нет. Не годится.
- Al Jazeera (все 5 ссылок в sources) — у статьи про Кушнера есть hero-фото,
  но кредит `Eyad Baba/AFP` — платное агентство, использовать без лицензии
  нельзя (правило «пропускай если не уверен, что открытое использование
  разрешено»). Отклонил.
- **B0. Фототека редакции** (`config/stock-photos.json`) — только темы cbu/
  sum/inflation/prices/salaries/banking, для Газы записей нет. Скрипт не
  запускал, тема явно вне охвата фототеки.
- **B1. Публичный сток (Unsplash).** Искал `unsplash.com/s/photos/gaza` и
  `unsplash.com/s/photos/palestinian-flag`. Большая часть выдачи по «gaza» —
  фото руин и людей на завалах (Mohammed Ibrahim, Emad El Byed) — отклонил:
  либо дети в кадре среди разрушений, либо слишком тяжёлая сцена для темы
  «дипломатия/переговоры», к тому же handoff прямо просит нейтральный
  запасной вариант, а не сцены разрушений.
  Выбрал фото Ahmed Abu Hameeda — молодой человек в куфии держит поднятый
  флаг Палестины на холме над городским кварталом, съёмка со спины, без
  лиц крупным планом, без насилия/крови/тел. Соответствует нейтральному
  fallback-варианту из handoff («флаг Палестины на фоне сектора Газа») —
  ближайшее визуально доступное решение при отсутствии subject-first фото
  конкретных участников события.

## Источник картинки
- Страница поиска: https://unsplash.com/s/photos/gaza
- Прямая ссылка на файл: https://images.unsplash.com/photo-1448964899744-8929e9d992d7
- Автор (по данным страницы поиска Unsplash): Ahmed Abu Hameeda
- Лицензия: Unsplash License (стандартная для всех загрузок на Unsplash)
- Тип: живая фотография, не постановочный сток и не 3D-рендер
- Размер оригинала (запрошен q=90&fm=jpg&w=3000): 3000×2250

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 3000, "height": 2250},
  "fit": {
    "mode": "cover",
    "scale": 0.5333,
    "cropLoss": 0.25,
    "offset": [0, 300],
    "upscaled": false,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/gaza-peace-plan-crisis-01.jpg",
    "url": "/images/posts/2026-08/gaza-peace-plan-crisis-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 390027,
    "quality": 86
  },
  "status": "ok"
}
```
cropLoss 0.25 — стандартная и ожидаемая обрезка для перевода фото формата
4:3 в 16:9, ниже порога crop-risky (нужно строго больше 0,25). Смарт-кроп
срезал верхнюю полосу неба/грозовых туч, фигура и флаг остались в кадре
полностью — проверил визуально по итоговому файлу.

## Отклонённые варианты
- mofa.gov.ae — только логотип ведомства, не фото события.
- Al Jazeera / AFP (Eyad Baba) — платный агентский кредит, лицензия не
  подтверждена, риск copyright.
- Unsplash, фото Mohammed Ibrahim / Emad El Byed (руины, люди на завалах,
  дети среди обломков) — слишком тяжёлая сцена для дипломатической темы,
  риск нарушить `image-avoid` («без крови, тел и сцен насилия») по духу
  правила, хотя формально крови/тел на кадрах нет.

## Уверенность в подборе: 55%
Subject-first правило выполнено не полностью: на фото нет ни одного из
конкретных действующих лиц материала (главы МИД, Кушнер, Нетаньяху,
освобождённые заключённые) — таких фото в свободном доступе не нашлось,
поэтому взят нейтральный тематический символ (флаг Палестины), который
handoff прямо называет допустимым запасным вариантом. Изображение живое,
горизонтальное, без насилия и без 3D-рендера — по остальным критериям
уверенность высокая.
