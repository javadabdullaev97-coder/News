# Bild notes: uzhydromet-flood-warning-aug22-23

## Стратегия: stock (Unsplash)

## Ход поиска
1. Первоисточник (t.me/uzgydromet/22043) — чисто текстовое экстренное сообщение,
   фото не приложено. Проверил ленту канала @uzgydromet целиком — фото гор/рек/
   селей там не публикуют, только текст и графики загрязнения воздуха.
2. Попробовал найти официальные фото похожих сюжетов у МЧС Узбекистана —
   не удалось надёжно определить действующий Telegram-канал ведомства и
   получить доступ к его посту-медиа через WebFetch, поэтому официальный
   источник фото не подтверждён и не использован (риск ошибиться с атрибуцией).
3. Фототека редакции (`config/stock-photos.json`) — тем «горы/паводок/сель»
   в ключевых словах нет, темы закрывают только ЦБ/сум/инфляцию. `pick-stock.mjs`
   не запускал, т.к. тема явно не входит в список.
4. Unsplash API — искал по запросам «uzbekistan mountains», «chimgan mountains»,
   «mountain gorge river central asia», «mountain storm clouds valley». Большинство
   результатов — заснеженные горы/горнолыжки (не по сезону, статья про август) или
   виды без привязки к Узбекистану. Нашёл серию фото Farkhod Saydullaev
   «Kok-Suv river in Tashkent region, Uzbekistan» — река Кок-Суу в ущелье
   Ташкентской области (эта область прямо упомянута в предупреждении Узгидромета
   как одна из семи, с районом Бустанлык поблизости).
