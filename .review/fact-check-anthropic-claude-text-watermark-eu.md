# Fact-check: anthropic-claude-text-watermark-eu

## Общий вердикт: APPROVE-WITH-DOWNGRADES

Центральный факт статьи (Anthropic 14 августа объяснила механизм невидимых водяных меток в Claude в рамках требований статьи 50 EU AI Act) подтверждён напрямую и без нюансов. Проблемы — два второстепенных статичных факта в блоке про Google DeepMind, не подтверждённых ни одним из указанных источников, плюс один оценочный глагол атрибуции без основания. Всё лечится точечными понижениями/удалениями, без потери сюжета.

## Список понижений для editor'а (применяет сам, без повторной проверки)

1. «...опубликовала в статье в журнале Nature **в октябре 2024 года**» → «...опубликовала в статье в журнале Nature **в 2024 году**» (месяц не подтверждён).
2. «Код метода открыт и доступен **в библиотеке Hugging Face Transformers**» → убрать конкретизацию; заменить на подтверждённое источником «через обновлённый Responsible Generative AI Toolkit» (Google DeepMind: «we'll open-source SynthID text watermarking through our updated Responsible Generative AI Toolkit»).
3. Ссылка-якорь «[Google DeepMind опубликовала]» сейчас ведёт на майский блог-пост DeepMind, который не подтверждает Nature/октябрь/тесты на Gemini — эти детали в действительности подтверждает sources[0] (Anthropic). Перепривязать якорь на sources[0] либо добавить «по данным Anthropic» перед предложением.
4. «Публичный API для проверки метки компания **обещает** выпустить позже» → «компания **сообщила о планах** выпустить» (источник не даёт срока: «We're in the process of working out the details»).
5. (Минорно) «На коротких текстах и фактических фрагментах — например, **датах**» — пример добавлен репортёром, в источнике не встречается; убрать пример или смягчить.
