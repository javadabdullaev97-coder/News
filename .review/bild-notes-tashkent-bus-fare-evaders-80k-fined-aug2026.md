## Ориентация — почему принята подложка (contain), а не найден горизонтальный кадр
Источник вертикальный, 640×800 (соотношение 0.80), то есть портретный по правилам скрипта
(`PORTRAIT_AR = 0.95`). Прежде чем принять подложку, проверил:
- Все 4 фото рейда в грид-посте /28419 — все 640×800, одно и то же соотношение.
- Соседние посты канала /28417, /28418, /28420, /28421 — /28420 и /28421 оказались
  языковыми копиями того же релиза (те же 4 фото, идентичный визуал, только перекодированы
  Telegram под новые CDN-ссылки). Новых кадров не нашлось.
- Дайджест-пост /28616 (второй источник статьи) — там только автарка-коллаж канала
  320×180, ниже MIN_SOURCE, не годится ни для чего.
- Попытки найти горизонтальную альтернативу в открытых источниках (поиск по spot.uz,
  сайт mintrans.uz) результата не дали — поисковые движки через доступный инструментарий
  не отдали релевантных прямых ссылок, mintrans.uz/news отдаёт неактуальный кэш без этой
  новости.
- Тематический сток (Unsplash, landscape) по «bus ticket inspector» — либо premium
  (Unsplash+, платный, не берём), либо не про Ташкент/Узбекистан и не показывает нужный
  сюжет (проверка транспортной карты кондуктором на входе в автобус).
- AI-генерация через Higgsfield — инструмент недоступен в этой сессии (три попытки вызова
  `generate_image` под разными именами инструмента вернули «No such tool available»),
  запасной путь C технически не выполним сейчас.

**Горизонтальной альтернативы нет, потому что** единственный источник, где вообще есть
фотография именно этого рейда (Минтранс, /28419), публикует только вертикальные карточки
формата stories 640×800 — это и есть эксклюзивный кадр события, других открытых фото
рейда не существует. Поэтому подложка (contain, тёмно-графитовый бренд-фон) в этом случае
законна по правилу владельца от 04.08.2026 (раздел «эксклюзивный кадр»).
