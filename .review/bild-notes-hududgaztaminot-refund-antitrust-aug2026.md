## Попытки скачивания
1. Сначала взял версию из Telegram-поста (https://t.me/RaqobatGovUz/12542, og:image
   виджета t.me/s/) — 800×642, единственный размер, доступный из публичного TG-виджета.
   prepare-image.py дал `cover`, scale=2.0 (апскейл до предела MAX_UPSCALE=2.5), cropLoss=0.30.
   Апскейл 2× заметно мылил фото счётчика — отклонил в пользу более чёткого источника.
2. Нашёл ту же карточку на raqobat.gov.uz в исходном разрешении 2000×1607 (og:image страницы,
   файл `10.00.jpg`) — тот же кадр, без апскейла. Использован этот вариант.

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 2000, "height": 1607},
  "fit": {
    "mode": "cover",
    "scale": 0.8,
    "cropLoss": 0.2999,
    "offset": [0, 242],
    "upscaled": false,
    "note": "обрезано 30% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/hududgaztaminot-refund-antitrust-aug2026-01.jpg",
    "url": "/images/posts/2026-08/hududgaztaminot-refund-antitrust-aug2026-01.jpg",
    "width": 1600, "height": 900, "bytes": 150155, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```
Обрезка только по высоте (по ширине кадр залит целиком, банер и фото счётчика не обрезаны по
горизонтали). Умный кроп срезал верхнюю зону (эмблема Комитета) и нижнюю полосу (иконки
соцсетей), при этом сам счётчик и его показания в кадре сохранены полностью — не crop-risky:
30% меньше порога MAX_CROP=0.45, а содержательная часть (прибор учёта) не задета обрезкой.

## Примечание про Uzbek-текст на баннере
Карточка — фирменный шаблон пресс-службы Комитета: левая часть — заголовок на узбекском и
эмблема ведомства, правая — реальное фото счётчика. Текст баннера не переведён и не убран
(картинка используется как есть, без ручной постобработки в обход prepare-image.py). Решил
оставить: баннер — часть официального визуала первоисточника, ключевой для статьи объект
(счётчик) отчётливо виден и не пострадал при обрезке; риска дезинформации нет — credit
прозрачно указывает на пресс-службу Комитета.
