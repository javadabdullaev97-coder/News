## Ход подбора

### A — первоисточник (z.ai/blog/glm-5.3)
Страница — SPA на JS-рендере, отдаёт пустой `<div id="root">` при прямом
запросе, при запросе с UA `facebookexternalhit` и `Twitterbot` — тот же
пустой HTML без `og:image`. Проверил оба бандла (`glm-5.3-BCnx8T5_.js`,
30 КБ, и `src-B5Cf4vl5.js`, 216 КБ) на прямые ссылки на изображения:
единственная найденная картинка — `z-icon.svg` (родовой SVG-значок бренда
Z.ai, 130×130 в футере) и `z-icon.png` для превью в WeChat. Ни фото, ни
предметной иллюстрации к посту о GLM-5.3 нет — есть только текст и
benchmark-таблица (текстовая, не картинка). GitHub-организация `zai-org`
отдала 403 на прямой запрос — недоступна без рендеринга браузера.
Источник отклонён: нет пригодного изображения вообще (SVG-логотип общий
для всего бренда, не по теме конкретного релиза, и слишком мал/не фото).

```bash
curl -sL "https://images.unsplash.com/photo-1461749280684-dccba630e2f6?q=90&w=3000&auto=format&fit=max" -o /tmp/original.jpg
```

`cropLoss 0.1575` — ниже общего лимита 0.22 и ниже порога `crop-risky`
(0.25); правило `crop-risky` не применяется — нет одного явного физического
объекта (человек/животное/здание/документ), это текстовая сцена. Проверил
итоговый кадр визуально: все видимые строки кода читаются полностью, ни
одна не обрезана по горизонтали, левая часть с номерами строк на месте.

  материале `alibaba-qwen-license-large-companies`, во избежание визуального
  повтора в ленте не брал.
- `photo-1526374965328-7f61d4dc18c5` (Matrix movie still) — клише
  «взлом/Матрица», слишком близко к запрещённому «хакер в капюшоне».
- Higgsfield-генерация — инструмент недоступен в этом прогоне (нет ни
  MCP-тула, ни скрипта).
