## Что проверил

Видео-thumbnail (`tgme_widget_message_video_thumb`) — **320×180px**, меньше MIN_SOURCE=600px
по длинной стороне → отбраковано без прогона через prepare-image.py.

Пост оказался репостом из t.me/Rasmiy_axborot_official/17437 — проверил и его: тот же
видео-файл, тот же 320×180 thumbnail. Второй источник не даёт.

Публичный виджет Telegram отдаёт максимум ~320–800px по длинной стороне без Bot API —
известное ограничение (см. `image-pipeline.md`), других медиа в посте нет.

### B. islomkarimov.uz (официальный сайт комплекса)
- `/ru/page/kompleks-haqida` — статичный HTML без контентных `<img>`/фоновых картинок.
- `/ru/photogallery` — альбомы 2017–2021 гг., все про личность/биографию Каримова
  («Неделя памяти», «Сердце, вместившее Вселенную» и т.д.), не про здание/территорию
  комплекса. Проверил 3 файла: 889×1200 (портрет), 600×800 (портрет), 468×701 (портрет) —
  всё вертикальное, тематически не подходит (не территория/парк).
- `/ru` (главная) → ссылка `/panovr` с превью `/images/panovr.jpg` — **найдено**: широкая

  с деревьями и цветниками вокруг). Съёмка Canon EOS 5D Mark III. Это прямое попадание в
  mainVisualSubject — показывает и здание, и прилегающую парковую территорию, о которой
  статья. **Единственный найденный горизонтальный кадр с сайта.**
  - Размер: 1200×408 (соотношение ~2.94:1 — панорама шире, чем 16:9)
  - Проверил `/panovr` страницу отдельно — это JS-вьюер 360°, статичных доп. изображений

## Почему ушло на подтверждение (crop-risky)

`cropLoss = 0.3956` — превышает порог 0,25 для фотографий с явным объектом (здесь —
здание/памятник). Несмотря на то что визуальная проверка результата не показала проблем
(см. выше), правило устанавливает порог как обязательный триггер запроса владельцу,
без исключений по собственной оценке качества кропа. Это единственный найденный
горизонтальный источник, подходящий по теме и разрешению — альтернативы искал (см. раздел
«Что проверил»), других горизонтальных фото здания/территории на islomkarimov.uz и в
Telegram-постах первоисточников нет.

Действие:
- `frontmatter.image` заполнен текущим лучшим кандидатом (на случай, если владелец
  подтвердит кадр как есть).
- `awaitingEditor: true` + `pendingEditorQuestion` (reason: crop-risky) добавлены.
- Файл статьи перемещён: `content/posts/2026-08-05/tashkent-karimov-memorial-park.mdx`
