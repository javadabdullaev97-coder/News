Microsoft 14 августа 2026 года подтвердила уязвимость нулевого дня в Defender под названием ShieldBreak — ей присвоен номер [CVE-2026-69414](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-69414), она позволяет получить права SYSTEM в обход ранее выпущенного патча.

Уязвимость 11 августа раскрыл исследователь под псевдонимом Nightmare Eclipse в собственной [публикации](https://blog.projectnightcrawler.dev/posts/2026-08-11-shieldbreak-august-2026-disclosure/) с кодом эксплойта — по данным нескольких технических изданий, без предварительного уведомления Microsoft. Компания [сообщила](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-69414), что «работает над качественным обновлением безопасности» для устранения проблемы. По состоянию на 17 августа патч не выпущен.

Уязвимость затрагивает Malware Protection Engine — ядро сканирования Defender, встроенное по умолчанию во все актуальные версии Windows. Национальная база данных уязвимостей США ([NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-69414)) оценила её в 7,8 балла из 10 по шкале CVSS 3.1 — это высокий уровень опасности.

По словам исследователя, ShieldBreak обходит патч для другой уязвимости Defender — RoguePlanet (CVE-2026-50656), которую Microsoft закрыла 8 июля 2026 года. Nightmare Eclipse сообщил, что эксплойт сработал на полностью обновлённых Windows 11 25H2 и Windows Server 2025 со стопроцентным результатом в его тестах.

## Как это работает

Эксплойт использует пользовательский callback-хук, который подменяет содержимое файла во время облачного сканирования Defender через Cloud Filter API (cfapi) — так исследователь описывает механизм в своей публикации.

## Что это значит для пользователей

ShieldBreak требует, чтобы у атакующего уже был локальный доступ к системе с правами обычного пользователя. CVSS-вектор уязвимости — локальный вектор атаки, низкий уровень требуемых привилегий, без участия пользователя. Это означает, что эксплойт не открывает удалённый вход в компьютер. Он повышает права уже после того, как злоумышленник проник в систему другим способом — например, через вредоносный файл или фишинг.

Обходных решений от Microsoft пока нет. Компания рекомендует дождаться обновления Malware Protection Engine — оно устанавливается автоматически через Windows Update без участия пользователя, отдельных действий от домашних пользователей не требуется. Организациям стоит учитывать эксплойт при мониторинге конечных точек до выхода патча.

По данным нескольких технических изданий, ShieldBreak — как минимум девятая уязвимость нулевого дня, которую Nightmare Eclipse раскрыл с апреля 2026 года. Раскрытия идут на фоне публичного спора исследователя с Microsoft о правилах программы вознаграждений за уязвимости и о порядке раскрытия информации. Дата выхода патча для ShieldBreak пока не названа.
