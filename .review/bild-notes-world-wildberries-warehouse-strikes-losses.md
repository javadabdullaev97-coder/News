## Путь A — первоисточники: отклонён

Проверил все три заметки Интерфакса из `frontmatter.sources` напрямую curl'ом
(не WebFetch — нужен точный og:image/figcaption, а не суммаризация):

- Владимирская область (`interfax.ru/russia/1107203`) — `og:image` ведёт на
  `aspimg/1107203.jpg`, это карточка-заголовок (текст на тёмном фоне), не фото.
- Ленинградская область (`interfax.ru/russia/1107307`) — фото `voz1200.jpg`,
  подпись `Фото: Владимир Астапкович/РИА Новости`. Скачал и открыл: крупный
  план пожарного с брандспойтом (лицо частично закрыто маской/каской, но это
  архивный/стоковый снимок агентства РИА Новости — копирайт, лицензия на
  переиздание не подтверждена). Отклонил по правилу «ТАСС и РИА — осторожно»
  + общая осторожность с агентскими фото без подтверждённой лицензии
  (тот же принцип, что и для Reuters/Getty).
- Тверская область (`interfax.ru/russia/1107316`) — фото `wb1200.jpg`,
  подпись `Фото: Ведомости/ТАСС`. Скачал и открыл: это вывеска магазина
  Wildberries крупным планом (розово-красный неон), не имеет отношения к
  складскому пожару и тоже копирайт ТАСС. Отклонил по обеим причинам —
  не по теме и лицензия не подтверждена.

Проверил официальный Telegram-канал `@rwb_press_service` (компания сама
ссылалась на него в Интерфаксе, `t.me/rwb_press_service/1674`) — прошёлся по
всем постам за последние сутки (`t.me/s/rwb_press_service`) включая посты
про Владимирскую область (1672–1673) и Красный Бор (1674–1675): текстовые,
без фото. Есть несколько видео у постов на другие темы (Коледино, Рязань),
но не у постов про инциденты 3–4 августа. Фото от официального источника
компании нет.

Bloomberg / BBC / DW / Al Jazeera — международные агентства, фото по
правилу «пропускай если не уверен, что открытое использование разрешено» —
не проверял отдельно, поскольку Интерфакс уже дал релевантный визуал по теме
(хоть и неподходящий), а профильные агентства почти наверняка используют
Getty/Reuters/собственные копирайт-фото так же, как в прошлых материалах
этого кластера тем (см. `bild-notes-world-ceuta-migrant-crisis.md`).

## Путь B — сток (выбран)

Ключей Unsplash/Pexels API в окружении нет (как и в прошлых материалах) —
искал через WebFetch по поисковым страницам `pexels.com/search/...` и
`unsplash.com/s/photos/...`.

Unsplash по запросу «warehouse fire» — ничего релевантного (пустые склады,
пожарные лестницы на кирпичных фасадах, ни одного реального пожара).

Pexels по запросу «warehouse fire» дал несколько кандидатов:

- `pexels.com/photo/11574597` (Tom Fisk) — аэросъёмка пожара амбара с
  тюками сена в Миннесоте, снег на земле. Отклонил: это сельский амбар, а
  не промышленный/складской комплекс, плюс зимний снег визуально не вяжется
  с темой логистического склада — вводит в заблуждение о характере объекта.
- `pexels.com/photo/11574637` (Tom Fisk) — тот же пожар амбара, вид точно
  сверху (в надир). Отклонил по той же причине.
- `pexels.com/photo/22589119` (фотограф «K», `@kelly`) — **выбран.**
  Аэрофотоснимок промышленной зоны в Чаттануге (Теннесси): столб чёрного
  дыма над складским комплексом, слева виден синий металлический
  склад-ангар, пожарная техника у очага, город на заднем плане. Разрешение
  5272×2962. Free to use (Pexels License), без указания обязательной
  атрибуции — credit ставим для прозрачности.
- `pexels.com/photo/22589124` — тот же пожар, другой ракурс, не понадобился.

```json
  "fit": {

    "scale": 0.3038,
    "cropLoss": 0.0012,
    "offset": [0, 0],
    "upscaled": false,
    "note": "обрезано 0% по ширине; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/world-wildberries-warehouse-strikes-losses-01.jpg",
    "url": "/images/posts/2026-08/world-wildberries-warehouse-strikes-losses-01.jpg",
    "width": 1600, "height": 900, "bytes": 352908, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

`cropLoss = 0,0012` — далеко ниже порога 0,15, `crop-risky` не применяется.
Кадр содержит инфографически явный объект (дым, склад), но обрезка почти
нулевая — визуально ничего не потеряно.
