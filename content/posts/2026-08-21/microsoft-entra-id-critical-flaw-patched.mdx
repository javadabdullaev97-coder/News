Microsoft 21 августа сообщила о критической уязвимости с максимальной оценкой риска в облачном сервисе Entra ID для входа сотрудников организаций в Microsoft 365 и Azure. Оценка риска — 10 баллов из 10 по шкале CVSS, международной системе оценки серьёзности уязвимостей, и, по данным Microsoft, её уже использовали для атак. Компания не раскрыла масштаб атак и их источник.

Уязвимости присвоен номер CVE-2026-69836 — идентификатор в международном реестре уязвимостей. Причина — ошибка при обработке данных: сервис принимал специально сформированные пакеты без проверки и превращал их в рабочие объекты. Из-за этого злоумышленник мог удалённо выполнить код на сервере без пароля и участия пользователя, [говорится в пересказе бюллетеня безопасности Microsoft](https://thehackernews.com/2026/08/microsoft-entra-id-flaw-cvss-100.html).

Уязвимость затронула Entra ID — бывший Azure Active Directory, сервис для входа в Microsoft 365, Azure и сторонние корпоративные приложения. Сервисом пользуются организации по всему миру. [По данным Microsoft](https://thehackernews.com/2026/08/microsoft-entra-id-flaw-cvss-100.html), уязвимость уже полностью устранена на стороне компании: патч установлен автоматически на серверах Entra ID, поскольку это полностью управляемый облачный сервис. Пользователям не нужно ничего скачивать или менять в настройках.

Microsoft не раскрыла ни число пострадавших организаций, ни техническую цепочку атаки — компания ограничилась общим предупреждением тем, кто использует Entra ID.
