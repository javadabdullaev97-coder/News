## Порядок поиска

  `text_not_supported_wrap` — это текстовый пост **без изображения** (только фрагмент
  текста на узбекском про Бюро принудительного исполнения РК, сверен с reporter-notes —
  совпадает дословно). `og:image` страницы — аватар канала (логотип Генпрокуратуры),
  брать нельзя (не относится к конкретной публикации).
- Проверен также второй источник (`cbu.uz`) — это JSON API курса валют, изображений
  не содержит в принципе.
- Дополнительно проверен смежный официальный канал `t.me/mib_faoliyatidan` (Бюро
  принудительного исполнения, тот же канал уже использовался в
  `bild-notes-tashkent-region-water-debt-recovery-bpi.md`):
  - Пост от 03.08.2026 (`mib_faoliyatidan/18585`) с фото 800×600 — **другая история**

  - Пост от 04.08.2026 про Каракалпакстанское управление Бюро (рубрика "Maxsus reportaj",
    ТВ-сюжет) — есть только превью видео 320×178, ниже порога `MIN_SOURCE=600px`
    (`status: too-small` при проверке). Отклонён.
  - Сайт `mib.uz` — не отвечает (timeout за 15 с), подтверждает прежние записи в
    `bild-notes-tashkent-region-water-debt-recovery-bpi.md` о недоступности домена.
- Официального фото здания хокимията/суда/Бюро принудительного исполнения Республики
  Каракалпакстан в открытых источниках не нашлось за разумное время поиска.

### B. Тематический сток
Искал через официальный API Openverse (`api.openverse.org/v1/images`,
`license=cc0,pdm`) по запросам `water pipe`, `water tap`, `water meter`, `water bill`,
`water utility pipes`, `Nukus Uzbekistan`, `Karakalpakstan`, `gavel court`, `courthouse`.
- Водная тематика (трубы, счётчики, квитанции) дала нерелевантные или предметно слабые
  кадры: американское фермерское ирригационное оборудование, ржавая крышка счётчика
  в траве без читаемой связи с темой, нерелевантные снимки (пеликан, МКС).
- Здания судов/хокимиятов — в выдаче только зарубежные (США) курт-хаусы, географически
  и институционально не подходят (запрещено выдавать чужую страну за узбекский орган).
- Karakalpakstan-специфичные снимки — карта региона, мечеть в Нукусе, IT-парк — ни один
  не связан с темой взыскания долгов, брать не стал (subject-first требует прямой связи
  с темой, а не просто с географией).
- Выбрал **«Gavel, court hammer»** (rawpixel, CC0 1.0, через Openverse) — судейский
  молоток на подставке на фоне раскрытой книги. Это живая предметная фотография (не
  рисованный 3D-сток), тематически прямо связана с механизмом новости: взыскание идёт
  по судебным решениям через исполнительные листы, то есть «принудительное исполнение
  судебного акта» — ровно то, что показывает кадр. Географической и институциональной
  лжи нет: молоток не выдаётся за атрибут суда Узбекистана, alt сформулирован нейтрально
  («символ исполнения судебного решения»).
- AI-генерация (Higgsfield) не понадобилась — нашёлся приемлемый живой сток с чистой
  лицензией, по правилам это приоритетнее генерации.
