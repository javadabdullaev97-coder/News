## A. Первоисточник — отклонён (stock-render, не публикуем даже с сайта ведомства)
- `https://t.me/Department_uz/12947` — единственное медиа поста: `cdn4.telesco.pe/file/edlU9...jpg`,
  800×533. WebFetch (текстовый рендер) картинку не показал — нашёл её прямым разбором HTML
  виджета (`background-image:url(...)` в `.tgme_widget_message_photo`).
- Открыл — это не документальная фотография, а designed-коллаж: рваная бумага, несколько
  круглых вставок (экскаватор+самосвал у реки, крупный план щебня, растрескавшаяся сухая земля),
  плюс поверх смонтированы **весы правосудия, мешок с долларом, красный запрещающий знак,
  судейский молоток, наручники, конверт с деньгами в руке**, две фигуры сотрудников со спины
  с эмблемой прокуратуры на форме.
- Отклонил по тем же двум причинам, что уже задокументированы в прецеденте
  `bild-notes-tashkent-gas-meters-19-9bn-embezzlement.md` (наручники/молоток/деньги того же
  ведомственного канала): (1) презумпция невиновности — коллаж визуально выносит приговор
  раньше суда; (2) `imagery.rejectStockRenders` — иконки правосудия/денег/наручников являются
  типовой пресс-службной «заготовкой», такое не берём даже из первоисточника, даже если внутри
  коллажа есть узнаваемые фотореалистичные фрагменты (экскаватор у воды).
  Кроп только этого фрагмента невозможен без ручной сборки в обход `prepare-image.py`
  (фрагмент — часть смонтированной композиции с белыми полями-кругами и рваными краями,
  не самостоятельный кадр) — не делал.
- Других постов с фото по этому конкретному делу на канале `@Department_uz` не нашёл (проверил

- Wikimedia/Wikipedia — пропущены по прямому запрету политики, даже когда попадались точные

- Openverse (`api.openverse.org`, без ключа, `license=cc0,pdm`, `excluded_source=wikimedia`) —

  `sand quarry`, `riverbed gravel`, `sand barge river`, `sand dredging river boat` и т.д. Ничего
  подходящего без Wikimedia не нашлось (либо не в тему — щебёнка/жуки/озёра, либо мелкое
  разрешение, либо не CC0).
- StockSnap.io — поиск (`/search/...`) отдаёт HTTP 403 (Cloudflare), как и в прецеденте
  gas-meters; прямых карточек по теме не нашёл.
- **Pexels** (WebFetch по `pexels.com/search/...`, прямой `og:image`-URL со страницы фото —
  без API-ключа) — нашёл несколько документальных аэрофото песчано-гравийных карьеров
  (Volker Braun, Lio Voo, Tom Fisk). Выбрал:
  - **`pexels.com/photo/aerial-view-of-sand-and-gravel-quarry-operation-32507739/`**
    (Volker Braun) — аэрофотоснимок сортировочно-обогатительной площадки: жёлтые бункеры/силос,
    конвейер и веерные насыпи песка и гравия двух разных фракций/цветов. Живая документальная
    фотография (не рендер), без людей, без опознаваемых логотипов/номеров, без вывесок —
    предметная иллюстрация темы (песчано-гравийная смесь — именно то, что по сообщению
    Департамента незаконно добывали), а не документ конкретного события на Чирчике. Тот же
    принцип допущения, что уже применялся к «испанский приют / ташкентский приют» и к
    «StockSnap-счётчики не из Узбекистана» в прецедентах.
  - Оригинал 8000×6000 (соотношение 4:3 = 1,33, входит в требование «горизонталь от ~1,3»).

## Обработка (`scripts/prepare-image.py`)

```json
{
  "source": { "width": 8000, "height": 6000, "path": "/tmp/.../pexels1_full.jpg" },
  "fit": {
    "mode": "cover",
    "scale": 0.2,
    "cropLoss": 0.25,
    "offset": [0, 0],
    "upscaled": false,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/chirchik-illegal-sand-gravel-1-9trln-damage-01.jpg",
    "url": "/images/posts/2026-08/chirchik-illegal-sand-gravel-1-9trln-damage-01.jpg",
    "width": 1600, "height": 900, "bytes": 408436, "quality": 82
  },
  "status": "ok",
  "upscaled": false
}
```

`cropLoss` 0,25 — ниже актуального `MAX_CROP` скрипта (0,45, поднят с 0,22 по решению
владельца, см. комментарий в `prepare-image.py`), апскейла нет. Порог `crop-risky` (>0,25)
не превышен (равен, не больше), и в любом случае неприменим строго: это не одиночный
узнаваемый субъект (лицо/животное/здание), а равномерно распределённая по кадру
аэросъёмка сортировочной площадки — обрезка сверху/снизу не срезает ничего значимого,
насыпи и конвейер остаются полностью в кадре после кропа (проверено визуально).
