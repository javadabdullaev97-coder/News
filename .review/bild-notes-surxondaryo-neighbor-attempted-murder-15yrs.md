## Стратегия: stock (Unsplash, живая фотография)

## mainVisualSubject (из reporter-notes)
Явного субъекта нет — личности фигурантов не раскрыты источником, фото людей
использовать нельзя (уголовное дело, ст. 8 редполитики: до отмены/подтверждения
статуса приговора — никаких узнаваемых лиц фигурантов, а их фото и не существует
в первоисточнике). Reporter предложил нейтральный вариант: здание Верховного суда
РУз, весы правосудия либо здание облсуда Сурхандарьинской области.

## Шаг A — официальное фото (не сработало)

  зафиксировал `connect_rejected` и для зеркала `supremecourt.uz`); ранее reporter
  уже фиксировал HTTP 503. Официального фотоматериала оттуда получить не удалось.
- `oliysud.uz`, `supcourt.uz` — не резолвятся (000).
- `t.me/oliysuduz` (канал-источник) — сам пост 51348 без прикреплённого фото
  (только видео по словам reporter, без содержательного стоп-кадра для скачивания).
  У канала есть единственное статичное изображение — официальная эмблема
  "O'zbekiston Respublikasi Oliy sudi" (весы правосудия на гербе), но она отдаётся
  только в 320×320 — ниже порога `prepare-image.py` (`min 600px по длинной стороне`,
  апскейл запрещён). Использовать нельзя технически (`status: too-small`).
- `gov.uz` (страница о судебной системе) — текстовая, без фото здания.

## Шаг B — тематический сток (сработало)
Unsplash, поиск по фразе «scales of justice» (через веб-поиск страницы результатов,
API-ключа `UNSPLASH_ACCESS_KEY` в окружении нет — `api.unsplash.com` отдаёт 401,
прямые `images.unsplash.com` URL при этом открываются без ключа, это разрешённый
способ по правилам bild: "через официальный API или прямые ссылки на CC0 /
Unsplash License").

Из 5 кандидатов в выдаче горизонтальными (требование ≥1.3) оказались только 2:
- `photo-1589994965851-a8f479c573a9` (Tingey Injury Law Firm) — 1600×1067, но
  выглядит как настольная фигурка/сувенир (продуктовая съёмка) — отклонено,
  меньше подходит по тону для судебной темы.
- `photo-1734640672449-0d65faceb323` (Gaétan Marceau Caron, @gmarceau) — 1600×1067
  (полный размер 2400×1600), уличная бронзовая статуя Фемиды с весами на фоне
  пасмурного неба, много воздуха в кадре, документальный тон, без узнаваемых людей.
  **Выбрано.**

Остальные 3 кандидата (Elena Mozhvilo, Tingey Injury Law Firm молоток судьи,
Elena Mozhvilo весы) — вертикальные (1600×1971, 1600×2400, 1600×2240), отклонены
по правилу «ищи горизонталь, а не спасай вертикаль».

Alt-текст со страницы поиска Unsplash подтверждает содержание кадра: "A statue of
lady justice holding a scale of justice" — совпадает с тем, что видно на фото.

пьедестал снизу).

## Отклонённые варианты
- Эмблема Верховного суда с канала `@oliysuduz` (320×320) — `status: too-small`,
  апскейл запрещён инвариантом скрипта.
- `photo-1589994965851-a8f479c573a9` — горизонтальный, прошёл бы технически, но
  визуально это настольная фигурка/продуктовая съёмка, менее уместна по тону, чем
  уличный монумент.
- 3 вертикальных кандидата Unsplash — отклонены по ориентации до скачивания
  (проверены размеры по `file`/Pillow).
- 3D-рендеры/иконки весов правосудия из типового стока не рассматривались —
  запрещены правилом №2 (только живая фотография); выбранный кадр — реальная
  фотосъёмка бронзовой скульптуры, не рендер.
- Фото фигурантов дела — не рассматривались вовсе: их нет в первоисточнике, и
  правило раздела 8 редполитики прямо запрещает публиковать узнаваемые лица по
  неподтверждённому статусу приговора.
