# Bild notes: walmart-apple-pay-google-pay

## Стратегия: stock (Unsplash)

## Ход отбора
1. Прочитан `HANDOFF_PATH` — image-hint: смартфон над платёжным терминалом на
   кассе Walmart / логотипы Apple Pay и Google Pay рядом с вывеской Walmart,
   явного персонажа-события нет. image-avoid: логотипы конкурентов ритейла,
   стоковые «бизнесмены», официальные пресс-фото Apple/Google (партнёрский
   визуал не подтверждён).
2. Проверены оба официальных первоисточника (WebFetch):
   - `corporate.walmart.com` — пресс-релиз без og:image и без иллюстраций в
     теле, только логотипы Walmart/Sam's Club (SVG, для карточки не годятся).
   - `blog.google` (Google Pay) — тоже без og:image; на странице только
     превью связанных постов не по теме (Google Wallet для детей, TSA
     PreCheck и т.д.), к материалу отношения не имеют.
   → Официального фото нет ни у одной стороны, стратегия A не сработала.
3. Проверены MacRumors и 9to5Mac — у обоих есть «hero»-картинки
   (`Apple-Pay-Walmart-Feature.jpg`, `Apple-Pay-walmart@0.5x.jpg`), но это
   собственные editorial-графики изданий, а не официальные фото пресс-служб
   и не входят в разрешённый список приоритетных источников (пресс-служба /
   Telegram ведомства / агентство с открытой лицензией) — использовать их
   значило бы брать чужой редакционный визуал без прав, пропущено.
4. Фототека редакции (`config/stock-photos.json`) проверена и признана
   нерелевантной: там только кадры под узбекские монетарные темы (здание ЦБ,
   сумовые банкноты) — для американской ритейл-новости не подходят по
   содержанию, `pick-stock.mjs` не запускался.
5. Найден кадр на Unsplash по запросу "contactless payment phone":
   `https://images.unsplash.com/photo-1599050751795-6cdaafbc2319` —
   смартфон (iPhone) с открытым экраном Apple Pay «Hold Near Reader»
   поднесён к платёжному терминалу. Автор — CardMapr.nl. Содержимое
   проверено визуально: без логотипов конкурентов ритейла, без узнаваемых
   людей (лицо не в кадре), без вывески Walmart — нейтральный визуал темы
   бесконтактной оплаты, что соответствует image-hint и image-avoid.

## Отклонённые варианты
- Пресс-релиз Walmart (corporate.walmart.com) — нет og:image и фото в теле,
  только SVG-логотипы.
- Блог Google Pay (blog.google) — нет og:image и фото по теме, только
  превью несвязанных постов.
- MacRumors / 9to5Mac hero-изображения — собственная editorial-графика
  изданий, не официальный пресс-визуал и не разрешённый источник по
  приоритетному списку, риск использования чужого редакционного контента.
- Фототека редакции (`config/stock-photos.json`) — только узбекские
  монетарные темы (ЦБ, сум), к материалу не по теме.
