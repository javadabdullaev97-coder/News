# Bild notes: andijan-khojaobad-industrial-water-supply

## Стратегия: primary-source

## Источник картинки
- URL: https://t.me/uzsuvandijon/20633 (региональный Telegram-канал «Андижон сув таъминоти»)
- Тип: живая фотография с площадки (не аватар канала, не заготовка/график)
- Как найдено: WebFetch на `?embed=1` изначально вернул URL аватара канала
  (160×160 у обоих постов uzsuv/45338 и uzsuvandijon/20633) — это ловушка,
  описанная в image-pipeline.md. Скачал HTML напрямую curl'ом и вытащил
  реальный `background-image:url(...)` из `tgme_widget_message_photo_wrap`:
  - пост uzsuv/45338 (нацканал) → фото 320×180 (траншея без людей) — меньше
    MIN_SOURCE=600px по длинной стороне, отбраковано бы скриптом (`too-small`)
  - пост uzsuvandijon/20633 (региональный) → фото 800×533 (рабочие в касках
    и жилетах на фоне экскаватора у траншеи) — выбрано как источник

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 800, "height": 533},
  "fit": {
    "mode": "cover",
    "scale": 2.0,
    "cropLoss": 0.1557,
    "offset": [0, 59],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 2.00× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/andijan-khojaobad-industrial-water-supply-01.jpg",
    "url": "/images/posts/2026-08/andijan-khojaobad-industrial-water-supply-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 238997,
    "quality": 90
  },
  "status": "ok"
}
```
Апскейл 2.0× — в пределах текущего MAX_UPSCALE=2.5 скрипта (правило про
запрет апскейла обновлено владельцем позже написания политики bild;
актуальная логика — в docstring `prepare-image.py`). cropLoss 15.6% —
ниже порога crop-risky (0.25), визуально проверил результат: оба человека
и техника в кадре целиком, ничего не срезано криво.

## Отклонённые варианты
- Фото из поста нацканала (uzsuv/45338) — 320×180, ниже MIN_SOURCE, брак
- og:image / первый `<meta>` у обоих постов — оказался аватаром канала
  160×160 (известная ловушка Telegram embed), не использовал
- AI-генерация (Higgsfield) — не понадобилась, нашлось подходящее живое фото

## Почему это subject-first
Тема без персонального героя (не человек/компания/здание), но есть
предметный субъект — стройка водопровода. Фото показывает именно это:
рабочих на объекте прокладки водопровода/бурения в промзоне Ходжаобадского
района, с техникой — прямое визуальное соответствие теме статьи, а не
абстрактная замена (карта, труба на белом фоне и т.п.).
