### B. Сток
- Unsplash, Pexels — по прямому поиску «Gianni Infantino» / «FIFA headquarters» —
  ничего релевантного (алгоритмические нерелевантные результаты, как и ожидалось
  для конкретного публичного лица на стоках общего назначения).
- Openverse API (`api.openverse.org`) — основной источник. Прямой запрос
  «Gianni Infantino» вернул много результатов, но подавляющее большинство —
  `provider: wikimedia` (upload.wikimedia.org / commons.wikimedia.org) —
  пропущены по прямому запрету редполитики на wikipedia.org/Wikimedia Commons.
  Повторный запрос с фильтром `source=flickr&license=by,by-sa` дал чистую
  Flickr-выдачу:
  - Paul Kagame (президент Руанды, серия фото с Инфантино) — лицензия
    `by-nc-nd` (некоммерческая, без производных) — не подходит для
    коммерческого использования и обрезки.
  - DrabikPany (Piotr Drabik), CC BY 2.0 — серия фото Инфантино 2011 года
    (тогда генсек УЕФА, играл жеребьёвку Euro 2012) — рассмотрены как запасной
    вариант, но устарели (за 5 лет до президентства в ФИФА).
  - **Doha Stadium Plus**, CC BY 2.0 — серия фото Инфантино на пресс-конференции
    (после избрания президентом ФИФА, судя по ID диапазону Flickr ~2017) —
    **выбрано** фото `33035671455`: Инфантино с микрофоном, задумчивое
    выражение лица, фирменный синий фон ФИФА-мероприятия. Композиция и тон
    (сосредоточенный, не триумфальный) хорошо ложатся на тему кризисной статьи.
    - Прямая ссылка: `https://live.staticflickr.com/2646/33035671455_e04a90b721_b.jpg`
    - Страница: `https://www.flickr.com/photos/66463488@N06/33035671455`
    - Лицензия подтверждена через Openverse API (`license: by`, `license_version: 2.0`).
    - Не агентство (Reuters/AP/Getty) — независимый Flickr-аккаунт спортивного
      фотоагентства из Дохи, лицензионных рисков не несёт.

### C. AI-генерация (Higgsfield)
Не понадобилась — нашлось подходящее реальное фото subject-first. Инструмент
`generate_image` в тулсете этого прогона недоступен, но реальное фото и так
приоритетнее, к тому же Инфантино — публичное лицо/политик, генерировать его
изображение запрещено политикой («никаких политиков и известных лиц»).

## Обработка — scripts/prepare-image.py
```json
{
  "source": {"width": 1024, "height": 726},
  "fit": {
    "mode": "cover",
    "scale": 1.5625,
    "cropLoss": 0.2066,
    "offset": [0, 234],
    "upscaled": true,
    "note": "обрезано 21% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/fifa-infantino-crisis-morocco-meeting-01.jpg",
    "url": "/images/posts/2026-08/fifa-infantino-crisis-morocco-meeting-01.jpg",
    "width": 1600, "height": 900, "bytes": 163413, "quality": 90
  },
  "status": "ok"
}
```

## Проверка cropLoss (порог 0,25 из `config/newsroom-policy.json`)
`cropLoss = 0,2066` — ниже порога `0,25`, `crop-risky` формально не наступает.
Тем не менее объект — человек (явный субъект), порог применим буквально, поэтому
открыл готовый файл 1600×900 и проверил визуально: обрезка ушла в размытый фон
сверху и в плечо/пиджак снизу; лицо, глаза, рука с микрофоном — всё целиком в
кадре, ничего значимого не срезано. В очередь не эскалирую.

Апскейл ×1,56 (источник 1024×726) — в пределах `MAX_UPSCALE`, на итоговом кадре
заметно небольшое смягчение резкости, но без явных артефактов — приемлемо для
превью-карточки и Telegram.
