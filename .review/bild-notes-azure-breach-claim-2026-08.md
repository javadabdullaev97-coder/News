## Стратегия: stock (Unsplash, живая фотография)

## mainVisualSubject / image-hint
Reporter-notes: «Нет явного визуального субъекта (утверждение хакера, не
физическое событие). Предлагаю нейтральную иллюстрацию: экран входа/логотип
Microsoft Azure или абстрактная графика облачной инфраструктуры и учётных
данных. Фото хакера или конкретных офисов компаний нет и быть не может —
личность продавца не установлена.»
Handoff (image-hint/image-avoid): облачная инфраструктура/кибербезопасность —
логотип Azure/Microsoft уместен как нейтральная иллюстрация продукта, не как
обвинение компании. Запрет: лица «хакеров», логотипы McDonald's/Vodafone/TCS
и других перечисленных компаний как будто они признали взлом.

## Почему не A (первоисточник)
Оба `sources` — BleepingComputer и SecurityWeek, издания, не пресс-службы, —
формально не «официальный первоисточник» в смысле правила A (госорган/
компания-эмитент). Проверил featured-изображения обеих статей:
- BleepingComputer — WebFetch вернул 403 Forbidden, изображение недоступно.
- SecurityWeek — og:image получен:
  https://www.securityweek.com/wp-content/uploads/2024/08/Microsoft-Azure.jpeg
  (1200×675). Открыл файл — это не живая фотография, а векторная заготовка:
  логотип Microsoft Azure на фоне декоративной сетки из разноцветных узлов
  (красный/зелёный/синий/жёлтый), тот же жанр, что и запрещённые «разноцветные
  столбики диаграмм» — ничего не сообщает о конкретном инциденте, используется
  SecurityWeek декоративно для любых Azure-материалов. Отклонено по правилу
  «только живая фотография» / rejectStockRenders.
- Microsoft (сам вендор) новости не выпускал — реакции по теме не найдено
  (подтверждено ещё в reporter-notes: MSRC блог не содержит поста по теме).

  живое фото, rainbow-узлы.

## Уверенность в подборе: 80%
Живая фотография, горизонтальная, subject-first (прямой визуальный субъект —
Microsoft, продукт которого фигурирует в заявлении хакера), без людей, без
3D-рендера/rainbow-графики, без хакерских клише, без логотипов пострадавших
компаний — все ограничения из handoff и задания соблюдены. Снижение с 100%:
кадр не показывает конкретно Azure (только материнский бренд Microsoft) и не
из первоисточника статьи — ожидаемо для темы без физического события;
единственное найденное «официальное» изображение (у SecurityWeek) оказалось
запрещённой декоративной 3D/vector-заготовкой. Higgsfield-генерация
(стратегия C) не использовалась: стоковый вариант найден раньше по порядку
попыток и полностью закрывает subject-first требование лучше, чем
абстрактная AI-иллюстрация без узнаваемого субъекта.
