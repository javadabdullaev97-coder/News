# Fact-check: kuvonchbek-ismoilov-u20-world-champion

## Общий вердикт: APPROVE

## Проверка ключевой неопределённости (соперник в финале)

Репортёр пометил это место как самое слабое — сделал два фетча одной страницы
с разным результатом (сначала ошибочно принял квалификационный раунд за
финал, затем перепроверил и получил «Gold Medal Final: KAZMAKHOV Salim
(Russia), 9-7»). Fact-checker перепроверил страницу `uww.org/athletes/ismoilov-kuvonchbek`
независимо, тремя отдельными заходами.

Вывод: сам факт-экстрактор (WebFetch) ненадёжно определяет подпись раунда на
турнирной таблице (путает порядок строк между заходами), но пара
«соперник — счёт» для финала — Kazmakhov Salim (Россия), 9:7 — воспроизводится
идентично в двух независимых фетчах (репортёра и фактчекера) и подкреплена
косвенно: вторичные (непервичные) сводки называли финалиста «Салим Кармахов» —
то есть независимо подтверждают, что в финале был россиянин по имени Салим.
Турнирная арифметика (4 победы по пути к финалу — Китай/Финляндия/Азербайджан/
Эквадор) непротиворечиво реконструируется только при финале против Kazmakhov.

Написание фамилии на первоисточнике (UWW) устойчиво во всех фетчах —
KAZMAKHOV, с «z». Использованное в драфте «Казмахов» — корректная
транслитерация. «Кармахов» из вторичных СМИ в тексте статьи не используется.

Дополнительно проверен риск ложной тревоги: статья UWW «Yoshida Wins
First-Ever Greco-Roman U20 World Title for Japan» (17 августа) — другая
весовая категория (87 кг), с золотом Исмоилова (63 кг) не пересекается.
