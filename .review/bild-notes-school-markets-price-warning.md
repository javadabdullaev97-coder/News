# Bild notes: school-markets-price-warning

## Стратегия: stock (свободная лицензия, не редакционная фототека)

## Ход поиска

1. **Первоисточник (Telegram @RaqobatGovUz, посты 12608 и 12600).**
   Проверил через `t.me/s/RaqobatGovUz/12608` и `/12600` — оба поста
   текстовые, единственное изображение на странице предпросмотра —
   аватар канала (герб/логотип Комитета), не фото по теме. WebFetch на
   `raqobat.gov.uz/ru/` и `/ru/about/` тоже не дал фото здания —
   только `og:image` с гербом (`gerb-2.png`) и логотип
   (`253h130.png`). Живой фотографии по теме и здания ведомства
   в открытом доступе не нашлось.

2. **Фототека редакции (`config/stock-photos.json`).**
   `node scripts/pick-stock.mjs --topic school` → пусто (тема не
   покрыта). `--topic prices` вернул `sum-banknotes-01.jpg` (пачка
   купюр), но это абстрактная картинка «сум/деньги», а не «прилавок со
   школьными товарами» из image-hint — по правилу subject-first не
   стал ставить: тема имеет предметный визуальный субъект (учебники,
   форма, канцтовары на прилавке), абстрактная пачка денег для неё —
   именно тот «последний ресорт», которого пока не требуется.

3. **AI-генерация (Higgsfield).** Инструмент `generate_image`
   недоступен в этой сессии (`No such tool available`) — попытка
   вызова вернула ошибку. Fallback через AI отпал технически, не по
   решению редактора.

4. **Публичный банк свободных изображений.** Unsplash/Pexels недоступны
   для скрейпинга напрямую (поиск на unsplash.com отдаёт пустой JS-рендер,
   pexels.com отдаёт 403 без API-ключа, ключей в окружении нет). Использовал
   Openverse (api.openverse.org, агрегатор CC-лицензированных фото, включая
   Flickr) — легитимный источник свободных лицензий, тот же принцип, что
   Unsplash/Pexels.
   Запрос «school supplies market/bazaar» дал фото прилавка с тетрадями,
   канцтоварами и детской одеждой на рынке в Шеки (Азербайджан),
   лицензия CC BY 2.0, автор shankar s. (Flickr). Дополнительно проверил
   запросы с Ташкентом/Узбекистаном и Чорсу-базаром — по школьным товарам
   в Openverse ничего релевантного не нашлось (Чорсу выдаёт только
   продуктовые ряды).

## Источник картинки
- URL оригинала: https://live.staticflickr.com/4451/37260509196_c992e3ae1d_b.jpg
- Страница: https://www.flickr.com/photos/77742560@N06/37260509196
- Автор: shankar s., лицензия CC BY 2.0 (https://creativecommons.org/licenses/by/2.0/)
- Тип: живая документальная фотография (не сток-3D, не рисованная заготовка)
- Локация на фото — рынок в Шеки, Азербайджан, НЕ Узбекистан. В alt и
  подписи это не выдаю за узбекский рынок — фото иллюстративное, честно
  помечено как таковое.
- Проверка на повтор: `node scripts/photo-dupes.mjs --check` → свободен.
- Обработка `scripts/prepare-image.py`:
  ```json
  {
    "source": {"width": 1024, "height": 768},
    "fit": {"mode": "cover", "scale": 1.5625, "cropLoss": 0.25, "offset": [0, 300], "upscaled": true,
      "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"},
    "output": {"path": "public/images/posts/2026-08/school-markets-price-warning-01.jpg",
      "url": "/images/posts/2026-08/school-markets-price-warning-01.jpg", "width": 1600, "height": 900,
      "bytes": 379683, "quality": 86},
    "status": "ok"
  }
  ```
  Апскейл 1.56× и обрезка 25% укладываются в текущие пороги скрипта
  (MAX_UPSCALE=2.5, MAX_CROP=0.45 — см. докстринг `prepare-image.py`,
  пороги были подняты умышленно, чтобы не уходить в подложку). Итоговый
  кроп по контенту убрал лица обоих людей в кадре (продавца и мальчика) —
  в финальном 1600×900 видны только руки/спины, лиц не осталось, что
  дополнительно снимает вопрос по image-avoid («лица продавцов/покупателей»).

## Отклонённые варианты
- Аватар/герб канала и логотип Комитета (raqobat.gov.uz) — это графический
  логотип, не живое фото, и не по теме материала.
- `/images/stock/sum-banknotes-01.jpg` (редакционная фототека, topic=prices) —
  абстрактный кадр с деньгами, не показывает предметный субъект
  (школьные товары/рынок) из image-hint; отложил как последний ресорт,
  не понадобился.
- Openverse: «Stationary for stationery» (5421869134) — витрина с обилием
  лицензионных персонажей Disney/Mickey и детьми лицом к камере сзади —
  отклонил из-за брендов и из-за прямого нарушения image-avoid (логотипы
  торговых марок).
- Higgsfield AI-генерация — недоступна технически (инструмент не
  подключён в сессии), иначе была бы следующим шагом при отсутствии
  живого фото.

## Уверенность в подборе: 55%
Фото по существу подходящее и живое (не заготовка, не абстракция),
предметно показывает именно то, что просит image-hint — прилавок со
школьными товарами. Держу оценку ниже 70%, потому что: (1) снято не в
Узбекистане, а в Азербайджане — географическое соответствие условное,
это иллюстрация, не репортажный кадр события; (2) кроп после
prepare-image.py потребовал заметного апскейла (1.56×) и обрезки четверти
кадра — картинка не в идеальном разрешении для 1600×900. Возвращать
материал владельцу не стал: фото живое, тематически точное, лицензия
чистая (CC BY 2.0 с атрибуцией), лиц после кропа не видно — риски
не выше тех, что редполитика допускает для стока категории B1.
