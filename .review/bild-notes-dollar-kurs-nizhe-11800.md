## Проверка bild-gate.mjs
- Первый прогон с дефолтным путём notes упал: `reason: "нет notes репортёра — визуальный субъект неизвестен"`.
  Причина — файл называется `.review/notes-dollar-kurs-nizhe-11800.md`, а не
  `.review/reporter-notes-<slug>.md`, которого гейт ждёт по умолчанию (в `.review/` лежит
  служебный файл `xyz-dollar-kurs-nizhe-11800.md`, который сам указывает на правильные заметки).
- Перезапуск с `--notes .review/notes-dollar-kurs-nizhe-11800.md`: гейт всё равно вернул
  `skip: false`, т.к. строка в notes — «Нет явного визуального субъекта» (с вставленным
  словом «визуального»), а регэксп гейта ищет буквально «нет явного субъекта|no clear subject».
  Формальное совпадение не сработало, но по смыслу заметка репортёра однозначно говорит об
  отсутствии явного субъекта — это совпадает с ручным выводом по тексту и handoff.
- Проверил тему и маркеры вручную по `config/stock-photos.json`: `neverStockMarkers`
  (президент, министр, глава ЦБ и т.п.) в статье не встречаются, тема попадает в фототеку
  (topicKeywords `fx`: «курс доллара», «курс сума», «валютный рынок», «валюта» — все есть в
  заголовке/тегах). Формально решение гейта (не skip) — из-за узкого regex, а не из-за
  реального наличия субъекта; по факту материал — ровно кейс фототеки.
