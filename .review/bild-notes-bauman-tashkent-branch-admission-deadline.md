## Что проверено

### A. Первоисточники
- `https://t.me/poytaxt_uz/51283` (пресс-служба хокимията Ташкента, пост 7 августа 08:00) —
  через `t.me/s/poytaxt_uz/51283` нашёл единственное медиа поста: 800×600 (соотношение 1,33,
  горизонтальное). Скачал и просмотрел визуально:
  **это рекламный баннер приёмной кампании**, не документальная фотография. В кадре: лого и
  название филиала сверху слева, крупный слоган «XALQARO DARAJADAGI MUHANDISLIK TA'LIMI ENDI
  TOSHKENTDA!», плашка «QABUL OCHIQ 2026/2027», блок дат приёма, три пиктограммы, адрес,
  значки рейтингов QS #318 / THE #301-350 / RAEX #2, QR-код и телефоны. Фоном справа —
  фото стеклянного здания с круглым куполообразным элементом — это не подтверждённо реальное
  здание временной площадки филиала (2-я Чимбай, 96, Алмазарский район), похоже на типовой
  архитектурный сток, использованный дизайнером баннера. Текст и иконки занимают весь кадр,
  чистого прямоугольника с одним лишь зданием без надписей нет — обрезать под 16:9 без потери
  сути баннера (или с сохранением надписей, которые нечитаемы в превью) невозможно.
  → Отклонено по правилу «Графики, диаграммы, скриншоты... почти никогда» / только живая
  фотография — это дизайнерский рекламный коллаж, а не документальная съёмка события/здания.
- `https://t.me/bmstu_uz/51` (канал самого филиала, пост от 6 августа, помечен «Reklama»,
  форвард из стороннего канала `Xushnudbek.uz`) — при попытке достать медиа поста получил
  **тот же самый файл-баннер** (идентичный по пикселям 800×600). Второго изображения в этом
  посте нет.
- В том же фиде `poytaxt_uz` рядом (id 51284/51285) есть сгруппированные фото, но это медиа
  **другого поста того же канала** — про встречу с активистками хокимията, не про МГТУ
  Баумана. Не подходит по теме, не использован.

### B. Официальный сайт филиала
- `bmstu.ru/branch_Tashkent` редиректит на `mirror.bmstu.ru/branch_Tashkent` — JS-приложение
  (React/Next), в исходном HTML только `<meta charset>`, `<meta viewport>`, логотип-иконка
  32×32 и трекеры (Яндекс.Метрика, Matomo). `og:image` отсутствует. `priem.bmstu.ru` — то же
  самое, подтверждено ещё и reporter'ом в notes (пустой HTML через WebFetch).

### C. Публичные банки (Unsplash / Pexels)
- Unsplash: `unsplash.com/s/photos/...` отдаёт страницу анти-бот-защиты Anubis
  (proof-of-work challenge для curl/без JS) — доступа без ключа/браузера нет.
  `api.unsplash.com/search/photos` → HTTP 401 (нет ключа в окружении, проверил `env`).
- Pexels: `api.pexels.com/v1/search?query=university` неожиданно вернул 200 с валидными
  данными несколько раз подряд, но тот же эндпоинт с любыми другими параметрами
  (`orientation=landscape`, другой `query`, `%20` вместо `+`) стабильно возвращает
  `401 Missing API key`. Похоже на разовый закешированный прокси-ответ на конкретную строку
  запроса, а не легитимный проходящий доступ — не считаю это официальным API-доступом по
  политике («только через официальный API»), не стал тащить оттуда картинку.

## Почему не взял рекламный баннер «как есть»
Совпадает с примером из редполитики про 3D-график ВВП на клавиатуре: формально изображение
с сайта первоисточника есть, но по факту это типовой промо-коллаж (лого + слоган + рейтинговые
плашки + QR-код), не документальная съёмка. Использовать его — значит повторить ту самую
ошибку, которую редполитика прямо называет примером «что не работает». Отдельно баннер
использует стоковую (предположительно не относящуюся к реальной временной площадке в
Алмазарском районе) фотографию здания — риск ввести читателя в заблуждение по subject-first.
