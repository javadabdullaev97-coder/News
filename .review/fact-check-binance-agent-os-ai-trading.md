## Список понижений для editor'а (применяет сам, без повторной проверки)

1. **Абзац 2**, «Интерфейс проверки транзакций показывает пользователю действия
   агента» — убрать или заменить. Пятый компонент платформы — поддержка **MCP
   (Model Context Protocol)**. Замена: «Поддержка протокола MCP (Model Context
   Protocol, открытый стандарт, через который сторонние ИИ-приложения
   подключаются к инструментам Binance)». Термин раскрыть при первом упоминании.

2. **Абзац 4**: «до 20 долларов на один платёж через x402» → «до 20 долларов
   **в день** на платежи через x402». Источник: «x402 payments are limited to
   $20 a day».

3. **Абзац 4**, последнее предложение про недоступ агентов к email и KYC —
   убрать целиком. Источник не подтверждает. Публиковать без ссылки нельзя.

4. **Абзац 5 (Kraken)**: смягчить «платформы» — TechCrunch описывает продукт
   Kraken как «open source command-line tool». Заменить на «похожие инструменты
   для агентской торговли». (Желательно, не обязательно.)

5. (Стиль) Сократить лид до 25–30 слов; разбить предложение про дневные лимиты
   (~35 слов) на два.
