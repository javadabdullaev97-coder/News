# Почему инструкция редактора написана так

Читать агенту не нужно: `.claude/agents/editor.md` он читает на каждом
материале. Здесь — обоснования, замеры и инциденты, по которым правила
появились.

## `handoff-<slug>.md` вместо полного вердикта

Вердикт пишется для человека и для разбора: в среднем 8,4 КБ обоснований.
`bild` и `seo` читали его целиком, хотя нужны им оттуда две вещи —
тематическая подсказка для картинки и категория. Восемь килобайт дважды
на каждый материал уходили на то, чтобы достать две строки.

Полный вердикт никуда не делся: он остаётся для разбора и для владельца.

## Отмена цикла «верни на доработку»

Решение владельца от 04.08.2026. У fact-checker'а больше нет вердикта
`needs-fix`: вместо возврата он отдаёт готовый список понижений
формулировок, и редактор применяет их сам. Повторная проверка после
применения не запускается — понижение не добавляет новых фактов.

Возврат корреспонденту остался ровно для одного случая: материалу нужно
новое исследование.

## Маршрут `needs-verification` для материалов по формуле §10

В августе 2026 отправка таких материалов в `content/needs-verification/`
по причине «нет первоисточника» похоронила два сюжета недели: тема жила
часы, а материал ждал подтверждения сутки. Поэтому §10 даёт понижение
формулировок вместо отправки в отстойник, а `needs-verification` остался
для низкой уверенности и для тем, не проходящих четыре условия §10.

## Три триггера возврата корреспонденту

Инцидент: в статье про ВВП редактор снял абзац про производный показатель
+19,1% и переписал вывод про регулятор. По объёму это уже research,
а не косметика, и проверенная доказательная база материала изменилась
после фактчека.

## Первые 60 знаков заголовка

Замер корпуса за июль–август 2026: в 60 знаков укладывался только 1% наших
заголовков при медиане 74. Ровно 60 знаков показывает поисковая выдача.

## Длина предложений

Замер на тот же корпус: у нас 19,0 слова в среднем и каждое пятое
предложение длиннее 25 слов — хуже всех конкурентов, кроме Yuz.uz.
У Gazeta.uz 15,9 слова и 10%.

## Структура по жанру

Самая частая наша ошибка формы: 59,4% простых новостей написаны разбором
по пунктам. У Gazeta.uz в том же жанре 77,8% — перевёрнутая пирамида.

Блок «Что дальше» стоял в 42,6% материалов, то есть по умолчанию; чек-лист
«Что делать», единственно уместный для объяснителя, — в 1,7%.

## Frontmatter финализирует editor, а не seo

До 17.08.2026 следом вызывался отдельный агент `seo`: он заново читал
статью, заново читал редполитику и правил ровно те же поля. Дублировалась
не работа, а чтение — статья и политика уже в контексте редактора.

## Балл рассылки считает скрипт, а не модель

17.08.2026 при переводе подсчёта в `scripts/tg-score.mjs` нашлись две ошибки
разом: имя «Интер» засчитывалось внутри слова «интервью», а вложенные группы
списка имён не читались вовсе. Арифметика по данным — не работа модели.
