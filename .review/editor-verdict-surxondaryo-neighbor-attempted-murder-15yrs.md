1. Удалил из frontmatter `publishedAt` и `updatedAt` — эти поля не в компетенции

2. Добавил в раздел «Что сообщил Верховный суд» оговорку: точная дата публикации поста
   не отображается (видна только время «11:06»), «5 августа» — оценка по положению

   Не повод для reject.
4. Лид удлинён до нормы (см. выше) — попутно с пунктом про дату.
