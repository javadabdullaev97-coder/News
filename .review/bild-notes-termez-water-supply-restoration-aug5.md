```json
{
  "source": {"width": 800, "height": 600},
  "fit": {
    "mode": "cover",
    "scale": 2.0,
    "cropLoss": 0.25,
    "offset": [0, 88],
    "upscaled": true,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому; исходник растянут в 2.00× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/termez-water-supply-restoration-aug5-01.jpg",
    "url": "/images/posts/2026-08/termez-water-supply-restoration-aug5-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 319978,
    "quality": 90
  },
  "status": "ok"
}
```

Проверка `crop-risky`: `cropLoss = 0.25`, порог для эскалации — **строго
больше** 0.25, то есть граница не превышена. Визуально проверил итоговый
кадр (1600×900): и труба, и ковш экскаватора остаются полностью в кадре,
ничего значимого не срезано (обрезка ушла в верхнюю часть с грунтом/веткой,
не в объект съёмки). Апскейл 2.0× — в пределах текущего `MAX_UPSCALE=2.5`
скрипта (актуальная версия `prepare-image.py`, а не устаревшее «≤1» из
общей инструкции). Эскалация не нужна.
