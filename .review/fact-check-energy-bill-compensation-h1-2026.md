# Fact-check: energy-bill-compensation-h1-2026

## Общий вердикт: APPROVE-WITH-DOWNGRADES

Центральный факт (92,1 млрд сумов компенсации 562 918 семьям за I полугодие 2026,
разбивка по газу/электричеству) подтверждён дословно первоисточником — Telegram
Минэнерго. Ключевые критерии права на компенсацию из ПП-134 (категории получателей,
нормативы 150 кВт·ч / 250–150 м³, конечная дата 1 апреля 2027) тоже подтвердились при
прямой проверке текста на lex.uz. Проблемы — во втором эшелоне: исторический блок про
постановление №204/2024 (сумма 270 тыс. сумов, период «ноябрь–февраль»), дата начала
действия ПП-134 («с мая 2025») и формулировка «без отдельного обращения» не находят
прямого подтверждения при независимой проверке.

   период по акту определяют регионы).
3. «Мера действует с мая 2025 года» → «Мера действует с 2025 года (постановление
   вступило в силу 5 апреля 2025-го)».
4. «Без отдельного обращения» → смягчить до «по данным Минэнерго, для семей из
   реестра предусмотрен упрощённый порядок начисления (на основе показаний
   счётчиков)».
5. Сократить лид с ~36 до 25-30 слов — вынести USD-конверсию из основного
   предложения в следующее.

7. Анкор «my.gov.uz» — заменить текст ссылки на «постановление №848» (URL остаётся
