# Bild notes: pakistan-swat-suicide-bombing-14-dead

## Стратегия: stock (Wikimedia Commons, CC BY-SA) — нейтральный географический кадр

Тема — теракт с массовыми жертвами. Сцена события (взрыв, разрушения,
пострадавшие, силовики на месте) не генерируется и не иллюстрируется: любой
синтетический кадр читатель прочтёт как фотографию с места. Поэтому AI-генерация
исключена сразу, а из реальных вариантов взят контекстный кадр без сцены
происшествия — панорама города, в округе которого произошёл взрыв.

## Шаг B — что отвергнуто по правам

- **Al Jazeera, «Интерфакс», «Коммерсантъ»** (все три `frontmatter.sources`) —
  фотографии агентств, права не наши. Не скачивал.
- **Reuters / AP / AFP / Dawn** — то же.
- **Стоковые 3D-заготовки** («концепция безопасности», силуэты с оружием,
  красные метки на карте) — запрещены `imagery.rejectStockRenders` в
  `config/newsroom-policy.json`, и для темы с 14 погибшими это вдвойне неуместно.
- **AI-генерация (Higgsfield)** — не применялась намеренно. Сгенерированный кадр
  реально произошедшего теракта выдаёт синтетику за документальную съёмку.
- **`wikipedia.org` как источник** — запрещён редполитикой (§2). Файл взят не со
  статьи Википедии, а из хранилища Wikimedia Commons, где у него явная
  CC-лицензия и указанный автор; лицензия и автор приведены в `credit` дословно.

короткое имя лицензии стоят в `credit` дословно. Обрезка до кадра 1600×900 —
производное произведение, оно наследует CC BY-SA 3.0; на публикацию с указанной
атрибуцией это не влияет, но при повторном использовании кадра лицензию нужно
сохранять.

## Обработка — `scripts/prepare-image.py`

```json
{
  "source": {
    "width": 5692,
    "height": 3664,
    "path": "/tmp/.../o3.jpg"
  },
  "fit": {
    "mode": "cover",
    "scale": 0.2811,
    "cropLoss": 0.1262,
    "offset": [0, 130],
    "upscaled": false,
    "note": "обрезано 13% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "path": "public/images/posts/2026-08/pakistan-swat-suicide-bombing-14-dead-01.jpg",
    "url": "/images/posts/2026-08/pakistan-swat-suicide-bombing-14-dead-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 372170,
    "quality": 82
  },
  "status": "ok",
  "upscaled": false
}
```

Размер оригинала: 5692×3664 → cover, масштаб 0,2811, обрезано 13% по высоте
→ 1600×900 (363 КБ, q82). Апскейла нет.

**`cropLoss` = 0,1262 — ниже порога 0,15** (`imagery.cropRiskThreshold`), эскалация
`crop-risky` не требуется. Порог здесь и по смыслу не применяется: кадр —
городская панорама, а не фотография с одним явным объектом; обрезка сняла полосу
неба сверху, застройка и горная гряда в кадре целиком. Результат проверен
визуально.

- `File:Nishat Chowk Mingora.jpg` (2560×1920, CC BY-SA 4.0, ImSajidHussain) и

  читается как туристическая открытка. Плюс в описании файла место названо
  «Канджо», а не «Кабал». Отклонён по тону.
- `File:Kabal Swat valley.JPG`, `File:Kabal rural side swat valley.jpg`
  (3216×2136, CC BY-SA 3.0, Power22) — террасные поля, привязка в описании

- `File:Beautiful Mingora, Swat Valley.jpg` (4965×3310, CC BY-SA 3.0, Usman Sharif) —
  закатное поле у реки, к городу и к теме привязки почти нет. Отклонён.

  соотношение 4,55:1, обрезка до 16:9 съела бы больше 60% ширины, скрипт ушёл бы

- Мотивы «Калам», «Габин-Джабба», водопады, изумруды из шахты Мингоры — туристическая
  и минералогическая съёмка, к теме отношения не имеет. Не рассматривал всерьёз.
