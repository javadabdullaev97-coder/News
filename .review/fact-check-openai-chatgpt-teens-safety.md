# Fact-check: openai-chatgpt-teens-safety

## Общий вердикт: APPROVE-WITH-DOWNGRADES

## Особый случай, применённый к материалу

Первоисточник (`https://openai.com/index/chatgpt-for-teens/`) назван и указан в `frontmatter.sources`, но его страница трижды не открылась (дважды у репортёра, один раз при проверке — тот же HTTP 403). Проверено по приложению 10.1 редполитики («первоисточник назван, но недоступен»).

Проверка четырёх условий приложения 10.1:

1. **Первоисточник назван** — ✓ (openai.com/index/chatgpt-for-teens/, назван в MacRumors и TechCrunch).
2. **≥3 независимых издания со ссылкой на один и тот же первоисточник** — выполняется только для факта самого запуска 18 августа: MacRumors и TechCrunch называют дату напрямую, и Engadget независимо пишет «On Tuesday, OpenAI released ChatGPT for Teens» (опубликовано 21 августа — тот же вторник, 18 августа). Три независимых упоминания сходятся. Для остальных деталей продукта (тарифы/регионы, дата для Австралии, функции, родительская привязка) — только ОДНО пересказывающее издание на факт — условие 2 не выполнено.
3. **Оформленный запрос в пресс-службу OpenAI** — в notes репортёра такого запроса нет, только неудачные попытки открыть страницу. Условие не выполнено.
4. **Событие проверяемо задним числом** — да, продукт публичный, страница рано или поздно откроется.

Вывод: полной формулы приложения 10.1 материал не заслуживает — условия 2 и 3 не закрыты для части фактов. Но это не повод для reject: центральный факт материала — скепсис экспертов Common Sense Media и Fairplay — подтверждён напрямую через Engadget (проверено, цитаты совпадают дословно) и не зависит от доступности openai.com. Решение — понижение конкретных продуктовых деталей до атрибутированной формы (ступень 2 лестницы утверждений), без блокировки публикации.
