## Чек-лист редполитики

- Заголовок 81 символ — в диапазоне 60–90, без CAPS и «!»
- Субъект и глагол действия в первых 60 знаках — да
- Лид ~25 слов, есть дата, отвечает на что-кто-когда — да
- Предложение длиннее 25 слов: абзац про $800 млн ARR (27 слов) — стилевая правка для editor'а
- Атрибуция нейтральна («объявила», «заявил», «оценивает»)
- Архитектура: два H2 («Комментарии сторон», «Что дальше») в новости об одном событии — решение по жанру за editor'ом
- Блок «Что дальше» содержит дату (сентябрь 2026) — не пустая формула
- Не каждая цифра прямо в источнике: величина флота ~250 — расчётная, нужен даунгрейд
- Нет ссылок на чёрный список СМИ, нет AI-slop, frontmatter валиден, sources — 2 записи

## Список понижений для editor'а (применяет сам, без повторной проверки)

1. Абзац 3 (флот): «сейчас в эксплуатации у Einride около 250 машин» → «по оценке Electrek, сейчас в эксплуатации у Einride около 250 машин» — цифра не названа в пресс-релизе Einride напрямую, нужна атрибуция.
