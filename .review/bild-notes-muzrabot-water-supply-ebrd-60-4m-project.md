# Bild notes: muzrabot-water-supply-ebrd-60-4m-project

## Стратегия: stock (Public Domain)

Strategy A (первоисточник) отработана полностью и не дала ни одного пригодного кадра —
подробности ниже. Higgsfield (`generate_image` и т.д.) в тулсете этого прогона недоступен
(только Bash/Read/Edit/Grep/Glob/WebFetch), поэтому AI-генерация как fallback технически
невозможна. Так как материал идёт directPublish и картинка обязательна, закрыл вопрос
живым документальным фото насосной станции из общедоступного банка Public Domain (Openverse/
Flickr), а не оставил `null` и не увёл в очередь.

## A. Первоисточник — исчерпан безрезультатно

- **`t.me/uzsuv/45530`** (пост-триггер) — это не альбом фото, а одиночное видео (1:30).
  Публичный виджет `t.me/s/uzsuv/45530` отдаёт только `video_thumb` 320×180 (аэросъёмка
  бирюзового водохранилища в горах с водяным знаком ТВ-канала и таймкодом «00:06») —
  ниже `MIN_SOURCE=600`, `too-small`, к тому же по содержанию похоже на архивный кадр
  водохранилища (не Октош/Пошхурт), а не на стройплощадку Музрабадского водопровода.
  Прямого `<video src=...mp4>` в HTML для этого поста нет — класс `not_supported`
  («Media is too big»), в отличие от соседнего поста `45529`, у которого src есть, но это
  видео совсем другой темы (#Mutaxassis_minbari про замену насосного оборудования).
  Соседние посты канала за 09.08 (`45516`, `45523`, `45524`, `45525`) — тоже не по теме
  (Нукус/Хиджаяли, водопад в Сариасии, инструктаж по ЧС, визит зам. председателя в Бухару).
- **`lex.uz/ru/docs/-6139620`** (ПП-342) — текст НПА, изображений не содержит.
- **`ebrd.com/.../psd/50979.html`** — на самой странице нет `og:image`/фото проекта (только
  логотип сайта); PDF-паспорт проекта (`surkhandarya-water-project-uzbek.pdf`, скачан и
  прочитан целиком) — 6 страниц чистого текста, без единой иллюстрации.
- **`president.uz/oz/lists/view/8980`** и **`.../8974`** — скачаны и просмотрены все 14
  фото из слайдеров обеих страниц (`_lists_slider_8980.jpg` ×7, `_lists_slider_8974.jpg` ×7).
  Все — протокольная съёмка видеоконференции/поездки: трибуна, зал с делегатами, экран
  с картой ГЭС Тупаланга, макет ГЭС, брифинг у карты ГИС, солнечная электростанция,
  геоинформационный центр, рукопожатия с ветеранами. **Ни одного кадра стройки водопровода,
  труб, насосной станции или водозабора** — совещание было про комплексное развитие области
  и гидроэнергетику (Тупаланг), не про конкретно Музрабадский водопровод.
- **`uzsuv.uz/uz`** — Nuxt SPA, отдаёт только shell, `og:image` = дефолтная иконка сайта.
- Веб-поиск (DuckDuckGo html) по узбекским ключевым словам нашёл `surxontongi.uz` (местная
  газета, "Ichimlik suvi ta'minoti yaxshilanadi", даёт полезный факт "479,2 км труб, 2
  водозаборные станции", но без единой фотографии) и `raqobat.gov.uz` (тоже без фото,
  только SVG-плейсхолдер).

## B. Сток

- **Unsplash/Pexels API** — ключей (`UNSPLASH_ACCESS_KEY`, `PEXELS_API_KEY`) в окружении нет.
- **Openverse** (`api.openverse.org`, без ключа, `license=cc0,pdm`) — перебрано ~15 запросов
  (`water pipeline construction`, `water pump station`, `water treatment plant pipes`,
  `underground water pipe laying`, `pipe trench excavator`, `water main installation`,
  `water supply pipe` и т.д.). Основные отказы:
  - Кадры USDA/NRCS с явными американскими сельскими маркерами (пикапы, номерные знаки,
    дорожные знаки, работники на грядках) — геоконтекст вводит в заблуждение, тот же класс
    отказа, что в `bild-notes-bukhara-alat-sewerage-27000-residents.md`.
  - Лиловые («purple pipe») задвижки полива — в США это стандартная маркировка сетей
    оборотной/непитьевой воды, тематически не про питьевой водопровод, вводит в заблуждение.
  - Wikimedia Commons — по правилу редполитики не берём (лицензии требуют отдельной валидации
    атрибуции).
  - Чёрно-белый штабель гофрированных труб на поле (Flickr, `pdm`) — рассматривался, но
    выбранный кадр насосной станции точнее совпадает с `mainVisualSubject` («насосная
    станция») и не требует пояснять, что это дренажные, а не водопроводные трубы.
  - **Выбран**: `20130618-RD-LSC-0238` (USDA Rural Development, Flickr) — интерьер насосной
    станции водоснабжения: синие трубы, задвижки, электродвигатели насосов на бетонных
    постаментах, металлическое здание цеха. Людей, транспорта, вывесок, номеров, флагов
    в кадре нет — ничего, что явно привязывало бы кадр к конкретной стране. Лицензия —
    Public Domain Mark 1.0 (подтверждено в детальной карточке Openverse). Прямо
    иллюстрирует `mainVisualSubject` из reporter notes («насосная станция, резервуар»).

## Обработка

```json
{
  "source": { "width": 1024, "height": 680, "path": "/tmp/original.jpg" },
  "fit": {
    "mode": "cover",
    "scale": 1.5625,
    "cropLoss": 0.1529,
    "offset": [0, 0],
    "upscaled": true,
    "note": "обрезано 15% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/muzrabot-water-supply-ebrd-60-4m-project-01.jpg",
    "url": "/images/posts/2026-08/muzrabot-water-supply-ebrd-60-4m-project-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 379865,
    "quality": 90
  },
  "status": "ok"
}
```

Апскейл 1.56× — в пределах `MAX_UPSCALE` (2.5×). Обрезка 15,3% по высоте (срезаны верх
крыши цеха и часть пола) — далеко ниже порога `crop-risky` (0,25) и ниже `MAX_CROP`
скрипта (0,45); основной объект (трубы, насосы, моторы) остаётся в кадре целиком,
подложка (contain) не потребовалась. Горизонтальный исходник 1024×680 (1,51:1),
дополнительной проверки на «portrait» не требовалось.
