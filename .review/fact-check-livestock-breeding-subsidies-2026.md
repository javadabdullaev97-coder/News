## Проверка ПП-293 (главный вопрос)

Повторил путь reporter'а независимо:

1. `lex.uz/ru/docs/8377591` подтверждён напрямую: страница реальна, метаданные
   (№ПП-293, дата 05.08.2026, дата вступления в силу 06.08.2026) совпадают с
   notes reporter'а.
2. Скачал сам PDF (`lex.uz/pdffile/8377591`) напрямую — это изображение (JPEG
   внутри PDF), 1237×1755px, без текстового слоя. Подтверждаю: OCR-слоя
   действительно нет, извлечь текст постатейно нельзя.
3. `regulation.gov.uz` — документ не нашёлся (портал обсуждения проектов НПА,
   не архив принятых постановлений).
4. Перепроверка через norma.uz дала цифры 1,5/2/1/1 млн, совпадающие с
   reporter'ом, но при повторном запросе к тому же URL всплыла противоречащая
   деталь: одна выборка дала «максимум на одну племенную корову — 5,5 млн
   сумов», другая — без этой фразы. Итоговая максимальная сумма (4 млн)
   имеет неразрешённое расхождение с альтернативной цифрой 5,5 млн.
5. Ссылку на Spot.uz, использованную reporter'ом для кросс-проверки,
   независимо проверить не удалось (404).

**Вывод по ПП-293**: reporter корректно охарактеризовал источник (скан без
OCR подтверждаю сам). Цифры 1,5/2/1/1 млн правдоподобны и дважды всплывают в
независимых пересказах, но: (а) итоговый «максимум 4 млн» имеет неустранённое
расхождение с 5,5 млн; (б) во frontmatter единственный источник для этих
цифр — lex.uz, хотя текст реально не прочитан оттуда, а восстановлен через
два вторичных пересказа, один из которых (spot.uz) — в чёрном списке
редполитики как источник.
