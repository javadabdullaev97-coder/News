## Обработка
Исходник 2000×1333 (ar 1.5, горизонтальный) → `scripts/prepare-image.py`:
```json
{
  "fit": {
    "mode": "cover",
    "scale": 0.8,
    "cropLoss": 0.156,
    "offset": [0, 165],
    "upscaled": false,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому"
  },
  "output": {
    "width": 1600, "height": 900, "bytes": 211396, "quality": 90
  },
  "status": "ok"
}
```
Обрезка 15.6% — ниже порога `crop-risky` (0.25), режим `cover` без подложки,
без апскейла. Проверил результат визуально — весы, завязанные глаза и лицо
статуи в кадре полностью, ничего значимого не срезано.
