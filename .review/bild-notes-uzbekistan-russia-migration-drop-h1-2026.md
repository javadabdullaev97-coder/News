# Bild notes: uzbekistan-russia-migration-drop-h1-2026

## Стратегия: primary-source (официальная инфографика ЦБ РУз)

## Main visual subject (из reporter-notes)
«Трудовые мигранты с сумками/чемоданами в очереди на паспортном контроле в
аэропорту или на границе (нет конкретного узнаваемого человека)». Fallback,
указанный самим reporter'ом: «инфографика/график ЦБ РУз с динамикой числа
мигрантов по патентам (рис. 9 обзора)».

## Что пробовал по порядку

1. **Первоисточник — «Ведомости» (frontmatter.sources[0]).** Через WebFetch
   нашёл главное фото статьи: https://cdn5.vedomosti.ru/image/2026/61/1clh72/original-1qzb.jpg
   (1200×675, готовая горизонталь 16:9, содержательно — узбекский трудовой
   мигрант на дорожных работах в оранжевом жилете, ровно по теме). **Отклонил
   несмотря на идеальное визуальное соответствие**: фото подписано
   «Александра Астахова / Ведомости» — это собственная съёмка штатного
   фотографа газеты, не пресс-релиз госоргана и не Telegram-пост ведомства.
   Vedomosti в редполитике разрешена только как источник текста/цитат
   («российские деловые СМИ — для контекста»), про переиспользование их
   фотографий ничего не сказано — трактую как обычную коммерческую
   редакционную фотографию без открытой лицензии, риск та же категория,
   что Getty/Shutterstock. Решил не рисковать («при сомнении в лицензии —
   выбирай другой источник»).

2. **CBU PDF (frontmatter.sources[1]) — фото/визуал в самом отчёте.**
   Отчёт «Mehnat bozori sharhi» не содержит фотографий, только таблицы и
   диаграммы. Прочитал весь 10-страничный PDF через рендер страниц в PNG.
   Таблицы 5-rasm/6-rasm (тепловые карты по отраслям) — отбраковал сразу:
   мелкий текст, десятки ячеек, нечитаемо в любом кропе (правило про
   скриншоты таблиц). **9-rasm** («Rossiyada patent asosida ishlayotgan
   O'zbekiston fuqarolari soni, ming kishi») — то самое, на что напрямую
   ссылается текст статьи и что предложил reporter как fallback: столбчатая
   диаграмма поквартальной динамики числа патентов 2019–2026, с подписанными
   осями, значением последнего столбца (1337) и источником (Rosstat).
   Проверил на самодостаточность в кадре — да, при плотном кропе (без
   соседнего 10-rasm про Турцию) в кадр входят заголовок, оси, все столбцы
   и подпись источника, ничего не обрезано.

3. **Сток (Unsplash/Pexels)** — искал «migrant workers», «passport control
   queue», «border crossing», «train station luggage». Все относящиеся к
   теме результаты давали географически неверный контекст (немецкая улица
   с граффити и экскаватором «Zeppelin» — Mika Baumeister; тайваньский/
   китайский аэропорт с иероглифами на табло — Kenneth Surillo/Pexels;
   вокзал в Авейру, Португалия — Ivan Cheremisin) — вводили бы читателя в
   заблуждение о месте действия (Россия/Узбекистан). Отклонил все три как
   source-doubt по соответствию тексту, не как лицензионный риск.

## Итоговый выбор: 9-rasm из отчёта ЦБ РУз

- Источник: `frontmatter.sources[1]` (тот же PDF, что уже процитирован в
  тексте статьи, абзац «Почему сокращается поток»).
- Официальная инфографика с реальными цифрами — по правилу это годится,
  не «заготовка» вроде 3D-рендера.
- Кроп вручную (только панель 9-rasm, без соседней 10-rasm) → PNG
  1080×1270 → `prepare-image.py`.

## Обработка (scripts/prepare-image.py)

```json
{
  "source": { "width": 1080, "height": 1270 },
  "fit": {
    "mode": "contain",
    "scale": 0.7087,
    "placed": [765, 900],
    "note": "вписано целиком на solid тёмно-графитовый фон бренда; вертикальный исходник 1080×1270 (соотношение 0.85) — заливка кадра 16:9 срезала бы большую часть снимка"
  },
  "output": {
    "path": "public/images/posts/2026-08/uzbekistan-russia-migration-drop-h1-2026-01.jpg",
    "url": "/images/posts/2026-08/uzbekistan-russia-migration-drop-h1-2026-01.jpg",
    "width": 1600, "height": 900, "bytes": 97182, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

**Горизонтальной альтернативы нет, потому что** это единственная официальная
диаграмма ЦБ РУз с этими данными (число узбекских патентов в РФ по
кварталам) — она существует только в исходной портретной вёрстке отчёта,
переиздания в ландшафтном формате не существует. Обрезка (`cover`) убрала
бы заголовок и/или подпись источника — скрипт сам корректно переключился
на `contain` вместо этого, данные и подписи не пострадали. cropLoss = 0
(режим contain, не crop) — эскалация `crop-risky` не требуется.

## Отклонённые варианты

- Фото Vedomosti (Александра Астахова) — идеальное визуальное совпадение,
  отклонено из-за неясной лицензии (собственная съёмка конкурентного СМИ).
- Unsplash «group of men in orange suit» (Mika Baumeister) — германский
  уличный контекст (граффити, экскаватор Zeppelin), вводит в заблуждение.
- Pexels «bustling airport check-in» (Kenneth Surillo) — китайские/
  тайваньские иероглифы на табло, географически не подходит.
- Unsplash «people with luggage waiting for a train» (Ivan Cheremisin) —
  снято в Авейру, Португалия, не подходит по контексту.
- Таблицы 5-rasm/6-rasm из отчёта ЦБ — тепловые карты с мелким текстом,
  нечитаемы в кадре 16:9, отбракованы сразу.
