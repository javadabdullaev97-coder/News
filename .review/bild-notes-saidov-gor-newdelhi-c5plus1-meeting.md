# Bild notes: saidov-gor-newdelhi-c5plus1-meeting

## Стратегия: primary-source

## Источник картинки
- Пост: https://t.me/Bakhtiyor_Saidov/4334 (официальный Telegram-канал главы МИД, тот же пост,
  что уже в frontmatter.sources)
- Пост оказался альбомом (grouped media) из двух кадров. Первый og:image, отдаваемый
  embed-страницей (`?embed=1`), — это квадратный портрет Саидова из архива канала,
  не относится к встрече — отклонён.
- В HTML embed-страницы нашлись ещё два кадра из `tgme_widget_message_grouped_layer`
  (background-image в стилях) — это и есть фактические фото встречи с Гором:
  1. рукопожатие Саидова и Гора на фоне флагов США/Узбекистана — **использован**
  2. оба сидят в креслах на фоне флагов и фотогалереи — отклонён (менее выразителен,
     чем рукопожатие; тот же контекст)
- Текст поста (уз/анг/рус) на 100% совпадает с содержанием статьи (упомянуты Гор,
  Нью-Дели, C5+1, «сегодня») — визуальный субъект подтверждён текстуально, не только
  по подписи.
- Размер исходника: 800×533 (телеграм-виджет отдаёт максимум 800px по длинной
  стороне — см. image-pipeline.md, апскейл до кадра статьи ожидаем и разрешён
  политикой скрипта).

## Обработка (scripts/prepare-image.py)
```json
{
  "source": {"width": 800, "height": 533},
  "fit": {
    "mode": "cover",
    "scale": 2.0,
    "cropLoss": 0.1557,
    "offset": [0, 0],
    "upscaled": true,
    "note": "обрезано 16% по высоте; окно кропа выбрано по содержимому; исходник растянут в 2.00× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/saidov-gor-newdelhi-c5plus1-meeting-01.jpg",
    "url": "/images/posts/2026-08/saidov-gor-newdelhi-c5plus1-meeting-01.jpg",
    "width": 1600, "height": 900, "bytes": 197965, "quality": 90
  },
  "status": "ok"
}
```
Апскейл 2.00× укладывается в MAX_UPSCALE=2.5 текущей версии скрипта; cropLoss 15.57%
ниже порога crop-risky (0.25) — обрезка снизу/сверху, лица и рукопожатие в кадре
целиком, дополнительного подтверждения не требуется.

## Отклонённые варианты
- og:image embed-страницы (портрет Саидова в одиночку, из архива канала) — не
  отражает конкретную встречу с Гором, formально не «главный визуальный субъект».
- Второй кадр альбома (сидят в креслах) — рабочий запасной, но рукопожатие
  выразительнее для превью/карточки.
- portal_gov_uz (t.me/portal_gov_uz/42781) не проверялся отдельно — свой кадр с
  участниками встречи уже нашёлся в основном источнике, дублировать поиск не
  требовалось.
- gov.uz (бизнес-форум) — другая тема (не встреча с Гором), не подходит по
  mainVisualSubject.

## Уверенность в подборе: 92%
Прямое фото именно этой встречи (не архивное, не generic), горизонтальная
ориентация, subject-first выполнен буквально — оба участника видны, узнаваемы,
рукопожатие. Снижение с 100% — за счёт умеренного апскейла исходника (Telegram
не отдаёт публично выше 800px) и того, что альтернативный кадр (сидя) не
проверялся на предмет более высокого разрешения в других источниках.
