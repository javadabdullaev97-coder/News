# Рекламные креативы

Сюда складываются изображения для рекламных слотов, которые подключены
через `lib/ads.ts`.

## Текущие креативы

| Файл | Слот | Размер |
|------|------|--------|
| `geely-ex5.webp` | `home-top-billboard` (главная, верх) | 1170×270 |

## Как добавить новый креатив

1. Положи изображение в эту папку с понятным именем (`brand-product.jpg`)
2. В `lib/ads.ts` опиши новый объект в `ads` (id, image path, href, alt, width, height)
3. В `slotToCreative` свяжи нужный slotId с id креатива
4. Запушь — Cloudflare Pages пересоберёт и подставит картинку
