## Что оставил как есть
- Заголовок номера акта «Постановление Кабмина №105» — не тронул формат
  (не привёл к виду «ПП-105»/«ПКМ-105»): глоссарий терминологии
  (`docs/terminology-glossary.md`) даёт таблицу префиксов только для указов
  и постановлений президента и законов, отдельного правила для постановлений
  Кабмина нет. Менять номер без проверки первоисточника — риск внести ошибку,
  которую некому перепроверить (это второстепенный источник, fact-check
  по нему не запускался).
- Абзац с честной оговоркой «Конкретные параметры... в опубликованном тексте
  новости комитета не раскрыты» — ядро материала, не трогал ни слова. Это
  ровно то, что делает заголовок и лид не переобещающими.
- Список из шести направлений пакета мер в одном предложении — оставил как
  перечисление (стандартный приём для списков в этом стиле), не резал.
- Не добавлял новых ссылок и не менял `frontmatter.sources` — оба источника
  из драфта reporter'а сохранены без изменений.
