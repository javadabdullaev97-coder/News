## Стратегия: stock

## Почему не первоисточник
- `gov.uz/ru/imv/news/view/206361` — WebFetch (RU и EN версии) нашёл только служебную графику портала (герб, флаг, логотип gov.uz), og:image отсутствует, фото с открытого диалога в министерстве в HTML нет.
- `t.me/minecofinuz/16259` (embed=1) — единственный найденный img-URL оказался аватаром канала 160×160 (cdn4.telesco.pe), после скачивания подтверждено: `160x160` — это ровно тот случай из image-pipeline.md «второй URL — аватар канала, брать нельзя». Полноразмерного медиа поста без Bot API не достать.
- Официального фото нет ни у одного из четырёх источников статьи (включая lex.uz и cbu.uz — там фото по определению нет). Персонажа/спикера в тексте тоже нет (reporter отдельно отметил: имя/должность спикера не установлены) — subject-first здесь не про человека, а про физический объект «жилая застройка».

## Уверенность в подборе: 70%
Живое фото, горизонтальное, тематически точное (жилая застройка), но точная локация (конкретно Ташкент, а не другой город Узбекистана) не подтверждена метаданными Unsplash — доступ к странице фото и API поиска заблокирован анти-бот защитой (Anubis), проверка велась только через WebFetch-рендер страницы поиска. Alt-текст сознательно не утверждает "в Ташкенте" как факт, только "типовая застройка в Узбекистане", чтобы не вводить читателя в заблуждение неподтверждённой географией.
