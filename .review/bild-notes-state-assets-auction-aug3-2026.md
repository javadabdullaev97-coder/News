## ОБНОВЛЕНИЕ 04.08.2026 — замена фото по требованию владельца

Владелец потребовал заменить инфографику E-AUKSION: «нужно поменять фото на
что то полностью покрывающее форму фото, чтобы не было серых границ» —
исходная инфографика была портретной (586×800), уходила в режим `contain`

редполитики (подложка — красный флаг, не штатный приём).

### Новая стратегия: stock (тематический)
Явного визуального субъекта у новости нет (см. `mainVisualSubject` в
reporter-notes — «нет явного визуального субъекта»), инфографика ведомства
единственная в первоисточнике и она портретная. Официальный сайт/канал
davaktiv.uz других фото (зданий, объектов торгов) не публикует — только
логотип/герб (проверено повторно 04.08.2026, gov.uz/davaktiv и t.me/s/davaktivuz:
все посты содержат только профильную аватарку агентства). Поэтому — тематический
тон вниз по цепочке B (Unsplash, landscape).

## Обработка (scripts/prepare-image.py)
Исходник 586×800 (портретная ориентация, соотношение 0,73 < PORTRAIT_AR 0,95) →
режим `contain` на тёмно-графитовой подложке бренда (#1A1A1A), без обрезки и без апскейла
(апскейл до cover потребовал бы 2,73× при лимите 2,5×, плюс портретная ориентация сама по
себе исключает cover). Итог 1600×900, 126 649 байт, quality 90.

```json
{
  "source": {"width": 586, "height": 800, "path": "/tmp/davaktiv_original.jpg"},
  "fit": {
    "mode": "contain",
    "scale": 1.0,
    "placed": [586, 800],
    "note": "вписано целиком на solid тёмно-графитовый фон бренда; вертикальный исходник 586×800 (соотношение 0.73) — заливка кадра 16:9 срезала бы большую часть снимка; заливка кадра потребовала бы растянуть исходник в 2.73× при допустимых 2.5×"
  },
  "output": {
    "path": "public/images/posts/2026-08/state-assets-auction-aug3-2026-01.jpg",
    "url": "/images/posts/2026-08/state-assets-auction-aug3-2026-01.jpg",
    "width": 1600,
    "height": 900,
    "bytes": 126649,
    "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```
