  (найдена как основное изображение статьи на https://president.uz/ru/lists/view/9491,
  первый источник в frontmatter.sources)
- Тип: официальная графика пресс-службы президента РУз — портретные фото Мирзиёева
  и Трампа на фоне национальных флагов, герб Узбекистана сверху, иконка телефонного
  звонка между портретами. Стандартный формат, которым президент.уз сопровождает
  анонсы именно телефонных разговоров (не встреч).
- Соответствие mainVisualSubject из reporter-notes: полное — в кадре оба субъекта
  материала (Мирзиёев и Трамп), а иконка телефона прямо передаёт формат события
  (звонок, не личная встреча), что снимает риск ложного впечатления о совместном фото.
- Размер оригинала: 1280×828 (альбомная ориентация, 600px+ по длинной стороне — проходит).
- Обработка `scripts/prepare-image.py`:
  ```json
  {
    "source": {"width": 1280, "height": 828},
    "fit": {
      "mode": "cover",
      "scale": 1.25,
      "cropLoss": 0.1304,
      "offset": [0, 135],
      "upscaled": true,
      "note": "обрезано 13% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.25× ради заливки кадра"
    },
    "output": {
      "path": "public/images/posts/2026-08/mirziyoyev-trump-phone-call-aug2026-01.jpg",
      "url": "/images/posts/2026-08/mirziyoyev-trump-phone-call-aug2026-01.jpg",
      "width": 1600, "height": 900, "bytes": 144523, "quality": 90
    },
    "status": "ok"
  }
  ```
  Апскейл 1.25× и обрезка 13% — в пределах текущих констант скрипта
  (`MAX_UPSCALE = 2.5`, `MAX_CROP = 0.45`, см. docstring `prepare-image.py`
  и обоснование там же: старое правило «апскейла нет никогда» — это
  предыдущая версия политики, явно указана как замененная владельцем).
  Обрезка пришлась на верх/низ синего фона с орнаментом, ни один из
  портретов, флагов, подписей или иконки звонка не задет — проверено
  визуально на итоговом файле.
- Проверка на «рисованную 3D-заготовку» (правило про сток-графики):
  это НЕ 3D-рендер/диаграмма/скриншот таблицы — это композиция из двух
  живых портретных фотографий (лица, а не иконки) на брендированном фоне
  ведомства с реальными подписями (имена, должности). Проходит фильтр
  «инфографика самого ведомства с реальным содержанием — годится».
- Ориентация: горизонтальная (1280×828, AR 1.55) — соответствует правилу
  «ищи горизонталь». Других (более горизонтальных) кадров к этому релизу
  на president.uz и в связанном Telegram-посте не найдено — сайт отдаёт
  ровно один графический баннер на эту новость, Telegram-версия поста
  (t.me/shmirziyoyev/35029) недоступна для парсинга через WebFetch
  (динамическая подгрузка виджета), альтернативных фото не проверял
  отдельно, т.к. основной баннер уже полностью закрывает потребность.
