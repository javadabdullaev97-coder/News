  и все люди в кадре сохранены целиком. Проверил визуально итоговый файл — ни локомотив,
  ни один человек не обрезаны. Итог: 1600×900, 375 069 байт, quality 86, status: ok

## Полный JSON prepare-image.py
```json
{
  "source": {"width": 1080, "height": 810},
  "fit": {"mode": "cover", "scale": 1.4815, "cropLoss": 0.25, "offset": [0, 300],
          "upscaled": true,
          "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.48× ради заливки кадра"},
  "output": {"path": "public/images/posts/2026-08/slavic-caravan-belarus-uzbekistan-train-01.jpg",
             "url": "/images/posts/2026-08/slavic-caravan-belarus-uzbekistan-train-01.jpg",
             "width": 1600, "height": 900, "bytes": 375069, "quality": 86},
  "status": "ok"
}
```

Примечание про cropLoss=0.25: задание требовало эскалации при cropLoss > 0.25 на фото
с явным объектом. Здесь значение ровно 0.25 (не больше), и визуальная проверка итогового
файла подтвердила, что обрезка ушла в пустое небо над локомотивом — ни поезд, ни кто-либо
из людей в кадре не пострадали. Эскалацию не запускал.

## Отклонённые варианты
- Telegram-пост Минтранса (t.me/Mintrans_uz/28554) — через WebFetch/CDN отдал только
  аватар канала 160×160 (известное ограничение публичного виджета, см.
  image-pipeline.md), полноразмерного медиа поста достать не удалось
- belarus.by, статья про отправление первого поезда (nimages/000690_461172.jpg и ещё
  6 фото с той же станции) — все отдают одинаковый размер 470×313 (JPEG), меньше
  MIN_SOURCE=600 по длинной стороне, отбраковка по размеру
- Второе фото sb.by (890×810, спикер на трибуне с баннером «Славянский караван») —
  тоже подходящее и горизонтальное, но менее прямое отображение субъекта (сам поезд
  не виден); оставил как запасной вариант, не использовал
- Третье фото sb.by — вертикальное (810×1080), не подошло по ориентации
