### JSON обработки (scripts/prepare-image.py)

```json
{
  "source": { "width": 1024, "height": 768 },
  "fit": {
    "mode": "cover",
    "scale": 1.5625,
    "cropLoss": 0.25,
    "offset": [0, 185],
    "upscaled": true,
    "note": "обрезано 25% по высоте; окно кропа выбрано по содержимому; исходник растянут в 1.56× ради заливки кадра"
  },
  "output": {
    "path": "public/images/posts/2026-08/uzbekistan-new-schools-teacher-recruitment-aug2026-01.jpg",
    "url": "/images/posts/2026-08/uzbekistan-new-schools-teacher-recruitment-aug2026-01.jpg",
    "width": 1600, "height": 900, "bytes": 269907, "quality": 90
  },
  "status": "ok",
  "upscaled": false
}
```

Размер оригинала 1024×768 (4:3) → cover, апскейл 1,56× (в пределах допустимых 2,5×),
обрезано 25% по высоте (окно кропа подобрано по содержимому — срезаны верх с
потолком/подсветкой и немного низ, ряды мониторов и парт остались в кадре целиком) →
1600×900 (270 КБ, q90).

`cropLoss = 0.25` — ровно на границе, но **не превышает** порог `crop-risky` (> 0.25 из
`config/newsroom-policy.json`), поэтому в очередь на подтверждение не уходит. Кроме того,
на кадре нет одного «явного объекта» (человека/животного/здания/документа), для которого
правило `crop-risky` вообще предназначено — это интерьер с равномерно распределёнными по
кадру партами и мониторами, обрезка верх/низ не срезает смысловой центр.
