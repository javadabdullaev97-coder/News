## Стилистические правки
- Убрал канцелярит «принято во исполнение статьи 27¹» → «опирается на статью 27¹... она делит»

- Разбил 6 предложений длиной 33–53 слова на 2–3 более коротких, не убирая ни одного факта
  и не трогая ни одной ссылки (абзацы про автоматическую передачу, про утечки, про список стран,
  про Конвенцию Совета Европы, про поручения ведомствам, про поправки ЗРУ-1125).

  упоминании — раньше шло сразу «МИД» без расшифровки.
- Заменил пассив «Контроль... возложен на министра» → «Контролировать исполнение документа
  будет министр внутренних дел Абдусалом Ташпулатов» (активный залог).
- Заменил пассивную канцелярскую конструкцию «дано два месяца на приведение... в соответствие»

- Разбил перечисление стран на два предложения (страны ЕС и соседи / остальные) для читаемости —

  ключевой актор постановления, конкретная сущность вместо расплывчатого набора из 3 тегов).

## Что оставил как есть

  но это стандартная формулировка описания нормы постановления («документ определяет X»),
  переписывать в активный залог означало бы придумывать субъект действия, которого в тексте
  нет («Кабмин определил» — источник этого прямо не формулирует так же явно). Оставил.
- Предложение про США (26 слов, чуть выше нормы) — техническая формулировка EU-US Data Privacy
  Framework не режется без потери точности.
- `frontmatter.sources` — не менял, оба источника (постановление №415 и ЗРУ-1125) остаются,
  ни один абзац с их ссылками не удалён.
- Категорию `tech` — не менял, зафиксирована решением fact-check-этапа.
- Ни одна из ссылок не переставлена и не добавлена новая — только косметическая правка вокруг
  существующих anchor-текстов при разбивке предложений.
